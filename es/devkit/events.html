Eventos

Cada evento que lanza el kit y que tu código puede escuchar: dónde corre, qué te entrega, cómo suscribirte para que sobreviva al Play sin recarga de dominio, y ejemplos.

#Eventos estáticos

La mayoría de los eventos del kit son static: te suscribes una vez, para todos los jugadores o monstruos, desde una clase estática tuya. Hay tres tipos:

  • Los eventos del servidor empiezan con Server y corren en el servidor de mapa (y en el host de un jugador). Úsalos para reglas: recompensas, progreso, registro.
  • Los eventos del cliente del dueño corren en el cliente del jugador involucrado. Úsalos para la interfaz.
  • Los eventos del cliente corren en todos los clientes que ven la cosa, como los efectos de combate.

#Suscribirse bien

El proyecto del kit juega sin recarga de dominio, así que cada clase limpia sus eventos estáticos en un método SubsystemRegistration al comienzo de cada Play. Unity no define el orden entre los métodos SubsystemRegistration, así que suscríbete después, en AfterAssembliesLoaded:

public static class LevelRewards
{
    [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterAssembliesLoaded)]
    static void Hook()
    {
        PlayerCharacter.ServerLeveledUp -= OnLevel;
        PlayerCharacter.ServerLeveledUp += OnLevel;
    }

    static void OnLevel(PlayerCharacter player) { /* ... */ }
}

El -= antes del += evita que te suscribas dos veces si el método vuelve a correr. Suscríbete con métodos con nombre, no con lambdas, para que -= funcione. AfterSceneLoad también sirve; corre después.

Consulta Play sin recarga de dominio para ver todas las reglas.

#Eventos del servidor

Evento Argumentos Se lanza cuando
PlayerCharacter.ServerSpawned PlayerCharacter Un jugador aparece en este mapa, después de cargar su estado guardado.
PlayerCharacter.ServerLeveledUp PlayerCharacter Después de ganar uno o más niveles.
PlayerCharacter.ServerExperienceGained PlayerCharacter, long amount Se ganó experiencia, antes de subir de nivel.
Monster.ServerKilled Monster, PlayerCharacter killer Murió un monstruo. El killer es el jugador que se ganó la muerte, o null.
Monster.ServerPhaseStarted Monster, int phase Un jefe empezó una fase; el índice es dentro de los phases de sus datos.
PlayerQuests.ServerCompleted PlayerCharacter, QuestData Se entregó una misión.
PlayerTrade.ServerTraded PlayerCharacter a, PlayerCharacter b Se concretó un intercambio.
PlayerForge.ServerUpgraded PlayerCharacter, string itemId, bool success, int level Una mejora funcionó (true) o falló (false); level es dónde quedó, -1 cuando la pieza se rompió.
PlayerProgress.ServerFlagChanged PlayerCharacter, string key, int value Cambió una marca del personaje.
PlayerProgress.ServerDiscovered PlayerCharacter, string placeId Se descubrió un mapa o una zona.
PlayerPvp.ServerDefeated PlayerCharacter killer, PlayerCharacter victim, bool duel Un jugador venció a otro, en PvP o en un duelo.
WorldTrigger.ServerFired WorldTrigger, PlayerCharacter Se activó un disparador del mundo (en los disparadores "para todos", el jugador que lo activó).
GmCommands.ServerUsed PlayerCharacter, string line Está por correr un comando con barra. Ensamblado solo de servidor.
GmAudit.Recorded GmAuditEntry Se registró una línea de auditoría de GM. Ensamblado solo de servidor.
MapInstances.ServerChanged string key, bool made Se creó (true) o se soltó una copia de un mapa instanciado. Ensamblado solo de servidor.
GameLog.Written GameLogEntry Cualquier línea del registro del juego, en el momento en que se escribe.

#Eventos del servidor por objeto

Evento En Se lanza cuando
ServerStatsChanged un PlayerCharacter Cambiaron las stats o los estados: la velocidad, los aturdimientos y los enraizamientos pueden ser otros.
ServerChanged un PlayerInventory La bolsa o el equipo se publicaron al dueño.

#Eventos del cliente del dueño

Evento Argumentos Se lanza cuando
PlayerCharacter.LocalSpawned PlayerCharacter Apareció el jugador local. Es el momento de pedirle al servidor el estado de tu función.
PlayerInventory.LocalSpawned PlayerInventory Apareció el inventario del jugador local.
PlayerInventory.LootDropped, LootRemoved, LootOpened LootDrop, int, int Apareció botín personal, desapareció, o se abrió un botín.
PlayerChat.Received ChatView Llegó una línea de chat.
PlayerMail.Arrived string from, string subject Llegó una carta (las cartas de la tienda que se retiran al instante no cuentan).
PlayerMail.Opened ninguno Un NPC abrió el buzón.
PlayerTrade.Asked, Opened, Changed, Closed nombre; nombre; dos ofertas; motivo Pedidos de intercambio y cambios en la ventana de intercambio.
PlayerParty.Invited string name Una invitación a un grupo.
PlayerGuild.Invited string from, string guild Una invitación a un gremio.
PlayerGuild.AllianceInvited string alliance, string guild Una invitación a una alianza.
PlayerGuild.BankOpened, PlayerBank.Opened, PlayerMarket.Opened, PlayerForge.Opened bool open Un NPC abrió (true) o cerró (false) esa ventana.
PlayerGuild.FoundingOpened ninguno Un NPC abrió la fundación de gremio.
PlayerForge.Result string text, bool good Qué hizo el último pedido a la forja.
PlayerPvp.Challenged string name Un desafío a duelo.
PlayerQuests.Shown Npc, QuestData Un NPC mostró una misión.
PlayerInteraction.Talked Npc, string text, int[] options, string[] labels, bool[] open Un NPC respondió: su texto y las líneas en pantalla.
PlayerInteraction.ShopOpened Npc, ShopOption, int[] stock Se abrió una tienda.
PlayerInteraction.StockChanged, BuybackChanged stock; casillas y precios de recompra Cambios en la tienda.
PlayerInteraction.ErrorReceived string code Se rechazó un pedido a un NPC, o una opción de NPC devolvió texto.

Eventos del dueño por objeto: Changed en PlayerQuests, PlayerProgress, PlayerInventory, PlayerMail, PlayerParty, PlayerGuild, PlayerBank y otros sistemas (cambió su estado sincronizado); ErrorReceived en PlayerInventory (se rechazó un pedido de inventario).

#Eventos del cliente para efectos

CombatEvents (namespace Blunnyn.KitARPG.Net) le dice a cada cliente qué pasó en combate cerca, para animaciones, efectos, números de daño y sonidos:

Evento Argumentos
CombatEvents.Damaged Transform who, int amount, bool critical, DamageElement element, GameData source
CombatEvents.Healed Transform who, int amount, GameData cause
CombatEvents.Announced Transform who, string text, Color color (texto corto sobre alguien, como "+12 XP")
CombatEvents.Shouted Transform boss, string text (una línea de fase de un jefe)
CombatEvents.SkillLanded Transform caster, SkillData skill, Vector3 point
CombatEvents.ActionStarted ActionEvent
CombatEvents.CastStarted, CastStopped Transform, SkillData, float seconds; Transform
CombatEvents.Bounced SkillData, Transform from, Transform to
CombatEvents.ZoneStarted SkillData, Vector3 where, float seconds
FighterStatus.AnyChanged FighterStatus (cambiaron los estados de cualquier combatiente)

Otros eventos para todo el cliente: GameRates.Changed (RatesState, empezó o terminó un evento de experiencia o de botín), ClientOptions.Changed (cambió un ajuste).

Eventos del cliente por objeto: Monster.Acted (CombatAction) y DeadChanged (bool) en los monstruos, DeadChanged en los jugadores.

#Eventos del network manager

KitNetworkManager.Instance lanza ServerStarted, ServerStopping, ServerDisconnecting (NetworkConnectionToClient), ClientConnected y ClientDisconnected. Son eventos de instancia en un objeto que se vuelve a crear en cada Play, y el objeto viejo desaparece con sus suscriptores, así que suscríbete en AfterSceneLoad sin -=. Los eventos estáticos siguen llevando -= primero: suscríbete a ellos antes de revisar si Instance es null, así quedan enganchados aunque la escena no tenga network manager. Consulta Mensajes de red.

#Ejemplos

#Recompensa cada cinco niveles

Servidor, en el ensamblado Game:

using Blunnyn.KitARPG.Data;
using Blunnyn.KitARPG.Net;
using UnityEngine;

namespace Game
{
    public static class MilestoneRewards
    {
        [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterAssembliesLoaded)]
        static void Hook()
        {
            PlayerCharacter.ServerLeveledUp -= OnLevel;
            PlayerCharacter.ServerLeveledUp += OnLevel;
        }

        static void OnLevel(PlayerCharacter player)
        {
            if (player.level % 5 != 0) return;
            // A flag per milestone, so leveling down and up again (death penalties) pays once.
            string key = $"mygame.milestone_{player.level}";
            IPlayerActor actor = player.Facts;
            if (actor.Flag(key) != 0) return;
            actor.SetFlag(key, 1);
            actor.AddCurrency(null, player.level * 100);
            player.ServerAnnounce($"Level {player.level} milestone!", new Color(1f, 0.85f, 0.3f));
        }
    }
}

#Mensaje de bienvenida

[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterAssembliesLoaded)]
static void Hook()
{
    PlayerCharacter.ServerSpawned -= OnSpawned;
    PlayerCharacter.ServerSpawned += OnSpawned;
}

static void OnSpawned(PlayerCharacter player)
{
    if (player.TryGetComponent(out PlayerChat chat)) chat.Tell($"Welcome back, {player.characterName}.");
}

ServerSpawned se lanza en cada mapa al que entra un personaje, no solo al iniciar sesión.

#Rachas de muertes, guardadas en memoria

static readonly Dictionary<PlayerCharacter, int> streaks = new Dictionary<PlayerCharacter, int>();

[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.SubsystemRegistration)]
static void ResetStatics() => streaks.Clear();

[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterAssembliesLoaded)]
static void Hook()
{
    Monster.ServerKilled -= OnKilled;
    Monster.ServerKilled += OnKilled;
    PlayerPvp.ServerDefeated -= OnDefeated;
    PlayerPvp.ServerDefeated += OnDefeated;
}

static void OnKilled(Monster monster, PlayerCharacter killer)
{
    if (killer == null) return;
    streaks.TryGetValue(killer, out int n);
    streaks[killer] = ++n;
    if (n % 10 == 0) killer.ServerAnnounce($"{n} kills!", Color.yellow);
}

static void OnDefeated(PlayerCharacter killer, PlayerCharacter victim, bool duel) => streaks.Remove(victim);

Los diccionarios con jugadores como clave crecen a medida que los jugadores entran y salen. Quita las entradas cuando se van (KitNetworkManager.ServerDisconnecting) o salta las de objetos destruidos (player == null).

#Un sonido en los golpes críticos

Cliente, en el ensamblado Game. El clip se carga desde una carpeta Resources tuya:

static AudioClip clip;

[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterAssembliesLoaded)]
static void Hook()
{
    clip = Resources.Load<AudioClip>("MyGame/CriticalHit");
    CombatEvents.Damaged -= OnDamaged;
    CombatEvents.Damaged += OnDamaged;
}

static void OnDamaged(Transform who, int amount, bool critical, DamageElement element, GameData source)
{
    if (critical && clip != null) GameAudio.PlayAt(clip, who.position, SoundChannel.Effects);
}

GameAudio.PlayAt respeta los controles de volumen del jugador.

#Enviar el botín raro a un webhook

GameLog.Written ve cada línea del registro, incluido item.loot para los botines notables. Consulta la plantilla Game Log Listener en Plantillas.

#Eventos propios

Lanza tus propios eventos estáticos de la misma forma, y límpialos en SubsystemRegistration:

public static event Action<PlayerCharacter, MonsterData> ServerTurnedIn;

[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.SubsystemRegistration)]
static void ResetStatics() => ServerTurnedIn = null;

Así el código de Game.Server se suscribe a eventos lanzados en Game (consulta Ensamblados).

#Errores comunes

  • Suscribirse en SubsystemRegistration. El kit puede limpiar el evento después de que te suscribiste.
  • Suscribirse con una lambda que no puedes quitar, en un método que puede correr dos veces.
  • Eventos del servidor en código del cliente. Nunca se lanzan en un cliente en línea.
  • Trabajo pesado en CombatEvents o GameLog.Written. Se lanzan seguido; mantén cortos los manejadores.
  • Lanzar una excepción en un manejador. Puede que no corran los demás suscriptores que vienen después. GameLog.Written atrapa las excepciones; la mayoría de los otros eventos no.
