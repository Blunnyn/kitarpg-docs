Plantillas

Cada plantilla de script en Create > KitARPG > Scripts: qué crea, en qué carpeta de ensamblado va, su código completo con notas y qué hacer después.

#Cómo funcionan las plantillas

Haz clic derecho en una carpeta de la ventana Project y abre Create > KitARPG > Scripts. Las tres primeras entradas crean definiciones de ensamblado; el resto crea un script a partir de una plantilla, pide su nombre de archivo y usa ese nombre como nombre de la clase. La clase queda dentro del namespace raíz del ensamblado donde cae (Game para los ensamblados creados desde este menú).

Las plantillas son archivos de texto en Assets/Blunnyn/KitARPG/Editor/DevKit/Templates/*.cs.txt. El kit revisa en cada versión que todas compilen escribiendo cada una en un proyecto de prueba (DevKitTemplates.WriteAll).

Consejo

Crea el script dentro de la carpeta correcta. Una plantilla que usa KitARPG.Server solo compila en Game.Server, y las plantillas del editor solo en Game.Editor. Si te sale un error "type or namespace not found" justo después de crear un script, casi siempre está en la carpeta equivocada.

#Ensamblados

Game Assembly, Game Editor Assembly y Game Server Assembly escriben un archivo .asmdef en la carpeta seleccionada. Su contenido exacto y las reglas para usarlos están en la página Ensamblados. Créalos primero: todas las demás plantillas necesitan uno de ellos.

#Skill Effect

Crea un efecto de skill que aparece en la lista de efectos de cada skill.

using System;
using Blunnyn.KitARPG.Data;
using UnityEngine;

namespace Game
{
    /// <summary>A skill effect. It shows up in the effect list of every skill once this compiles.</summary>
    [Serializable]
    public class NewSkillEffect : SkillEffect
    {
        public LevelValue amount = new LevelValue(10, 2);

        public override string Summary => $"NewSkillEffect {amount.baseValue:0}";

        // True lands it on enemies; false on the caster and allies.
        public override bool Harmful => true;

        public override void Apply(SkillCast cast, IFighter target)
        {
            int value = Mathf.RoundToInt(amount.At(cast.level));
            var hit = new Hit { amount = value, source = cast.skill };
            target.ServerDamage(hit, cast.caster);
        }
    }
}

amount vale 10 en el rango 1 y sube 2 por rango. Summary es el texto corto de la lista de efectos del editor de skills. Apply corre solo en el servidor, una vez por cada objetivo que alcanzó el skill.

Esto hace una cantidad fija y se salta la fórmula de daño (sin elemento, poder, resistencias ni críticos). Para daño que siga las reglas del juego, arma el golpe con GameInstance.Combat.Attack, como se muestra en Efectos de skill.

Siguiente: abre un skill en la Game Database, presiona + en Effects y elige NewSkillEffect.

#Item Effect

Crea algo que hace un consumible al usarse.

using System;
using Blunnyn.KitARPG.Data;
using UnityEngine;

namespace Game
{
    /// <summary>What using an item does. Add it to a consumable's effects in the Game Database.</summary>
    [Serializable]
    public class NewItemEffect : ItemEffect
    {
        public long experience = 100;

        public override string Summary => $"+{experience} XP";

        // Every effect of the item is checked before any runs; return why not, or null.
        public override string Check(IItemUser user) => user.ExperienceToNext <= 0 ? "You're at the highest level" : null;

        public override void Use(IItemUser user, ItemData item) => user.GainExperience(experience);

}

Summary es el texto corto del editor de ítems y la línea por defecto del tooltip. Use corre solo en el servidor, y el ítem se gasta cuando termina.

#Condition

Crea una regla que pueden exigir las misiones, las opciones de NPC, los saludos y las líneas de diálogo.

using System;
using Blunnyn.KitARPG.Data;
using UnityEngine;

namespace Game
{
    /// <summary>A rule quests, dialog lines and NPC options can ask for. Lists of conditions show it on their own.</summary>
    [Serializable]
    public class NewCondition : Condition
    {
        public string flag = "my_game.mark";
        public int atLeast = 1;

        protected override string DefaultText => "Not yet";

        // Runs on the server and on the owner's client, so the client can show what is locked.
        public override bool Met(IPlayerFacts facts) => facts.Flag(flag) >= atLeast;
    }
}

DefaultText se muestra cuando la condición no se cumple y el diseñador dejó Fail Text vacío.

#Quest Objective

Crea un tipo nuevo de objetivo de misión más una clase estática que lo hace avanzar. Aquí cuenta cada subida de nivel.

using System;
using Blunnyn.KitARPG.Data;
using Blunnyn.KitARPG.Net;
using UnityEngine;

namespace Game
{
    /// <summary>A quest objective. Advance it from your own code with PlayerQuests.ServerAdvance.</summary>
    [Serializable]
    public class NewObjective : QuestObjective
    {
        public int count = 3;

        protected override string DefaultText => "Do the thing";

        public override int Required => Mathf.Max(1, count);
    }

    /// <summary>Counts the objective. Here every level up does; hook whatever event your game has.</summary>
    public static class NewObjectiveCounter
    {
        // After the kit cleared its events, which it does again on every Play.
        [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterAssembliesLoaded)]
        static void Hook()
        {
            PlayerCharacter.ServerLeveledUp -= OnLevel;
            PlayerCharacter.ServerLeveledUp += OnLevel;
        }

        static void OnLevel(PlayerCharacter player)
        {
            if (player.TryGetComponent(out PlayerQuests quests)) quests.ServerAdvance<NewObjective>(o => true);
        }
    }
}

Required es cuántas veces tiene que pasar. El contador se suscribe en AfterAssembliesLoaded, después de que el kit limpió sus eventos, así que sigue funcionando en Play sin recarga de dominio (consulta Play sin recarga de dominio).

Siguiente: agrega el objetivo a los Objectives de una misión. Consulta Objetivos de misión.

#NPC Option

Crea un botón en el diálogo de un NPC. Este cura al jugador a cambio de oro.

using System;
using Blunnyn.KitARPG.Data;
using Blunnyn.KitARPG.Net;
using UnityEngine;

namespace Game
{
    /// <summary>A button in an NPC's dialog. Add it to the NPC's options in the inspector.</summary>
    [Serializable]
    public class NewNpcOption : NpcOption
    {
        public long price = 50;

        protected override string DefaultLabel => "Bless me";

        // Server only. False hides it from this player.
        public override bool AvailableTo(PlayerCharacter player) => true;

        // Server only. Answers go to the player's chat; the returned text only shows in an open shop.
        public override string Run(Npc npc, PlayerCharacter player)
        {
            var inventory = player.GetComponent<PlayerInventory>();
            if (inventory.gold < price)
            {
                if (player.TryGetComponent(out PlayerChat chat)) chat.Tell($"That costs {price} {GameInstance.Database.GoldName}.");
                return null;
            }
            inventory.AddGold(-price);
            player.ServerHeal(player.maxHealth, null);
            GameLog.Write("my_game.blessing", player, gold: price, detail: npc.Id);
            return null;
        }
    }
}

DefaultLabel es el texto del botón cuando el diseñador deja Label vacío.

Nota

Cuando el jugador no puede pagar, la opción se lo dice en el chat con PlayerChat.Tell y devuelve null. El texto que devuelve Run va a PlayerInteraction.ErrorReceived en el cliente del dueño, y de las ventanas del kit solo la de la tienda lo muestra, mientras está abierta. Consulta Opciones de NPC.

Siguiente: selecciona un NPC en la escena, presiona + en sus Options y elige NewNpcOption.

#Player System

Crea un NetworkBehaviour para el jugador: un valor sincronizado, un comando que envía el dueño, una respuesta que solo recibe el dueño y un Local estático para la interfaz.

using System;
using Blunnyn.KitARPG.Net;
using Mirror;
using UnityEngine;

namespace Game
{
    /// <summary>
    /// A system of your own on the player. Add it to every player model prefab. The server decides,
    /// the owner asks with commands; what it keeps between sessions goes in PlayerProgress flags.
    /// </summary>
    [RequireComponent(typeof(PlayerCharacter))]
    public class PlayerNewSystem : NetworkBehaviour
    {
        const string SavedKey = "my_game.points";

        [SyncVar(hook = nameof(OnPointsChanged))] public int points;

        /// <summary>Owner's client: points changed.</summary>
        public static event Action<int> Changed;

        public static PlayerNewSystem Local { get; private set; }

        // Statics outlive Play when domain reload is off.
        [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.SubsystemRegistration)]
        static void ResetStatics()
        {
            Changed = null;
            Local = null;
        }

        PlayerCharacter player;
        PlayerProgress progress;

        void Awake()
        {
            player = GetComponent<PlayerCharacter>();
            progress = GetComponent<PlayerProgress>();
        }

        public override void OnStartServer()
        {
            points = progress != null ? progress.Flag(SavedKey) : 0;
        }

        public override void OnStartAuthority() => Local = this;

        public override void OnStopAuthority()
        {
            if (Local == this) Local = null;
        }

        /// <summary>Owner. Asks the server for a point.</summary>
        public void Earn() => CmdEarn();

        [Command]
        void CmdEarn()
        {
            // Every command spends from the connection's budget, so a client can't flood the server.
            if (!CommandPacing.Allow(connectionToClient)) return;
            // Check everything here: the client only asks.
            if (player.IsDead) return;
            points++;
            if (progress != null) progress.SetFlag(SavedKey, points);
            TargetTold($"You have {points} points.");
        }

        [TargetRpc]
        void TargetTold(string text) => Debug.Log(text);

        void OnPointsChanged(int _, int now)
        {
            if (isOwned) Changed?.Invoke(now);
        }
    }
}

points se sincroniza del servidor a los clientes, y OnPointsChanged corre en los clientes cuando cambia. Local es la copia del jugador local, para las ventanas. Las marcas del personaje se cargan antes de que aparezca el jugador, así que OnStartServer puede leerlas. CmdEarn primero gasta del presupuesto de la conexión con CommandPacing.Allow, como debe hacer todo [Command]. Consulta Sistemas del jugador y Reglas de seguridad.

Siguiente: agrega el componente a cada prefab de modelo de jugador (Game Database > Models). Su valor points se guarda como una marca del personaje.

#Network Message

Crea un pedido de cliente a servidor, una respuesta de servidor a cliente y los manejadores en ambos lados. Los mensajes no necesitan ningún componente en el prefab del jugador.

using Blunnyn.KitARPG.Net;
using Mirror;
using UnityEngine;

namespace Game
{
    /// <summary>Client to server. Messages need no component on the player prefab.</summary>
    public struct NewMessageRequest : NetworkMessage
    {
        public string text;
    }

    /// <summary>Server to client.</summary>
    public struct NewMessageReply : NetworkMessage
    {
        public string text;
    }

    /// <summary>Registers the handlers on both sides as the network starts.</summary>
    public static class NewMessage
    {
        [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterSceneLoad)]
        static void Hook()
        {
            KitNetworkManager manager = KitNetworkManager.Instance;
            if (manager == null) return;
            manager.ServerStarted += () => NetworkServer.ReplaceHandler<NewMessageRequest>(OnRequest);
            manager.ClientConnected += () => NetworkClient.ReplaceHandler<NewMessageReply>(OnReply);
        }

        /// <summary>Client. Sends a request.</summary>
        public static void Ask(string text) => NetworkClient.Send(new NewMessageRequest { text = text });

        static void OnRequest(NetworkConnectionToClient conn, NewMessageRequest message)
        {
            if (!CommandPacing.Allow(conn)) return;
            // The connection says who sent it; never trust a player id inside the message.
            if (conn.identity == null || !conn.identity.TryGetComponent(out PlayerCharacter player)) return;
            if (string.IsNullOrEmpty(message.text) || message.text.Length > 100) return;
            conn.Send(new NewMessageReply { text = $"{player.characterName} said {message.text}" });
        }

        static void OnReply(NewMessageReply message) => Debug.Log(message.text);
    }
}

OnRequest gasta del presupuesto de la conexión con CommandPacing.Allow antes que nada, y toma al remitente de la conexión. En un jugador el host se reinicia en cada cambio de mapa, así que Hook vuelve a registrar los manejadores en cada arranque. Consulta Mensajes de red.

#GM Command

Crea un comando con barra. Va en la carpeta Game.Server.

using Blunnyn.KitARPG.Net;
using Blunnyn.KitARPG.Server;
using UnityEngine;

namespace Game
{
    /// <summary>
    /// Slash commands of your own. /help lists them for the ranks that may use them. Keep this file in a
    /// server-only assembly (references KitARPG.Server, define constraint UNITY_SERVER || UNITY_EDITOR || KITARPG_SERVER)
    /// so client builds don't carry it.
    /// </summary>
    public static class MyCommands
    {
        [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterSceneLoad)]
        static void Register()
        {
            GmCommands.Register(new GmCommand
            {
                name = "refresh", rank = GmRank.Moderator, usage = "refresh [player]", description = "Fills a player's health.",
                run = c =>
                {
                    PlayerCharacter target = c.Target(0);
                    if (target == null) return "Nobody by that name here.";
                    target.ServerHeal(target.maxHealth, null);
                    return $"Healed {target.characterName}.";
                },
            });
        }
    }
}

c.Target(0) es el jugador nombrado en la primera palabra, o el que escribió el comando. El texto devuelto se le muestra al jugador que lo escribió.

Siguiente: escribe /refresh en el chat. Consulta Comandos de GM en código.

#Game Log Listener

Ve cada línea del registro del juego en el servidor de mapa a medida que se escribe.

using Blunnyn.KitARPG.Net;
using Blunnyn.KitARPG.Shared.Central;
using UnityEngine;

namespace Game
{
    /// <summary>
    /// Sees every game log line on the map server as it is written, to send some elsewhere: a chat
    /// webhook for moderators, analytics. Lines already go to the database without this.
    /// </summary>
    public static class MyLogListener
    {
        // The kit clears its events in SubsystemRegistration, so hook in after that.
        [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterAssembliesLoaded)]
        static void Hook()
        {
            GameLog.Written -= OnLine;
            GameLog.Written += OnLine;
        }

        static void OnLine(GameLogEntry line)
        {
            if (line.kind == LogKinds.Trade && line.gold >= 100000)
                Debug.LogWarning($"Big trade: {line.character} and {line.other}, {line.gold} gold. {line.detail}");
        }
    }
}

Campos de GameLogEntry: time (milisegundos Unix), kind, accountId, characterId, character, otherId, other, itemId, amount, gold, detail, mapId. Los tipos que escribe el kit son constantes en LogKinds. Consulta Eventos.

#Stat Formula

Reemplaza cómo la clase, el nivel, los atributos y el equipo se suman en stats.

using System.Collections.Generic;
using Blunnyn.KitARPG.Data;
using Blunnyn.KitARPG.Shared.Characters;
using UnityEngine;

namespace Game
{
    /// <summary>Your own rules for how class, level, attributes and gear add up to stats.</summary>
    public class MyStatFormula : StatFormula
    {
        [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.BeforeSceneLoad)]
        static void Install() => GameInstance.Formula = new MyStatFormula();

        // Two attribute points per level instead of the class's own number.
        public override int PointsEarned(CharacterClass characterClass, int level) => 2 * (level - 1);

        // Start from the kit's sheet and change what you need. Stats are whole numbers.
        public override StatSheet Sheet(CharacterClass characterClass, int level, IReadOnlyList<AttributeAmount> spent,
            GameDatabase database, IReadOnlyList<IStatSource> sources = null)
        {
            return base.Sheet(characterClass, level, spent, database, sources);
        }
    }
}

#Saved Player Data

Crea un componente que guarda su propio estado en el personaje, guardado en un jugador y online, que nunca se envía a los clientes.

using System;
using System.Collections.Generic;
using Blunnyn.KitARPG.Net;
using Blunnyn.KitARPG.Shared.Characters;
using Mirror;
using UnityEngine;

namespace Game
{
    /// <summary>
    /// State of your own on a character, saved with it in single player and online. Add it to every
    /// player model prefab. Only the server reads and writes it; clients never see the saved value.
    /// </summary>
    [RequireComponent(typeof(PlayerCharacter))]
    public class PlayerCollection : NetworkBehaviour, IPlayerSave
    {
        // Prefix keys with your game's name so they never meet the kit's or another module's.
        const string Key = "my_game.collection";

        [Serializable]
        public class Saved
        {
            public List<string> found = new List<string>();
        }

        Saved saved = new Saved();

        /// <summary>What the owner's client sees. Sync only what the interface needs.</summary>
        [SyncVar] public int foundCount;

        public void ServerLoad(PlayerCharacter player, CharacterState state)
        {
            saved = PlayerData.Get<Saved>(player, Key);
            foundCount = saved.found.Count;
        }

        public void WriteTo(PlayerCharacter player, CharacterState state)
        {
            if (!PlayerData.Set(player, Key, saved)) Debug.LogWarning($"{player.characterName}: {Key} is too big to save.");
        }

        /// <summary>Server. Call it from your own game rules, never straight from a client's request.</summary>
        [Server]
        public bool ServerFind(string id)
        {
            if (string.IsNullOrEmpty(id) || saved.found.Contains(id)) return false;
            saved.found.Add(id);
            foundCount = saved.found.Count;
            return true;
        }
    }
}

ServerLoad corre cuando el personaje entra a un mapa, antes de que aparezca el jugador. WriteTo corre antes de cada guardado.

using UnityEngine;

#Settings Option

Agrega una opción a la ventana Settings, guardada en la computadora del jugador.

using Blunnyn.KitARPG.Client;
using UnityEngine;

namespace Game
{
    /// <summary>
    /// An option of your own in the Settings window. Kept on the player's computer and never sent
    /// anywhere, so use it for how the game looks and sounds, not for anything the server decides.
    /// </summary>
    public static class MySettings
    {
        const string Key = "MyGame.ShowHints";

        public static bool ShowHints
        {
            get => PlayerPrefs.GetInt(Key, 1) == 1;
            set => PlayerPrefs.SetInt(Key, value ? 1 : 0);
        }

        [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterAssembliesLoaded)]
        static void Register()
        {
            ClientOptions.Add(new ToggleOption
            {
                // A page name the kit doesn't have becomes a new tab.
                page = ClientOptions.Interface,
                label = "Show hints",
                hint = "Short tips the first time something new shows up.",
                get = () => ShowHints,
                set = v => ShowHints = v,
                reset = () => ShowHints = true,
            });
        }
    }
}

#Validator Check (Editor)

Agrega una revisión a KitARPG > Project Check y a la revisión antes de los builds. Va en la carpeta Game.Editor.

using System.Collections.Generic;
using Blunnyn.KitARPG.Data;
using Blunnyn.KitARPG.Editor;
using UnityEditor;

namespace Game
{
    /// <summary>A check of your own for KitARPG > Project Check and the check before builds. Editor only.</summary>
    public static class MyValidatorCheck
    {
        [InitializeOnLoadMethod]
        static void Register()
        {
            ProjectValidator.Checks.Remove(Check);
            ProjectValidator.Checks.Add(Check);
        }

        static void Check(List<ValidationIssue> issues)
        {
            foreach (string guid in AssetDatabase.FindAssets("t:ItemData"))
            {
                var item = AssetDatabase.LoadAssetAtPath<ItemData>(AssetDatabase.GUIDToAssetPath(guid));
                if (item != null && string.IsNullOrEmpty(item.Description))
                    issues.Add(new ValidationIssue { level = IssueLevel.Info, area = "My game", message = $"{item.name} has no description.", context = item });
            }
        }
    }
}

Register quita la revisión antes de agregarla, así que una recompilación no la agrega dos veces.

#Kit Update (Editor)

Envía un cambio a los juegos ya hechos con tu paquete. Se muestra en Overview con Apply. Va en la carpeta Game.Editor.

using System.Linq;
using Blunnyn.KitARPG.Data;
using Blunnyn.KitARPG.Editor;
using UnityEditor;

namespace Game
{
    /// <summary>
    /// Something your own package adds to games already made with it. It shows in Overview with Apply
    /// next to the kit's updates. Only add what is missing; never rebuild what the game changed.
    /// </summary>
    public class MyGameUpdate : KitUpdate
    {
        const string Word = "badword";

        public override string Title => "My game: chat filter word";
        public override string Changes => $"Game Settings > Chat: adds \"{Word}\" to the blocked words.";

        public override bool Needed()
        {
            GameInstance game = ModulesWindow.Find();
            return game != null && !game.blockedWords.Contains(Word);
        }

        public override string Apply()
        {
            GameInstance game = ModulesWindow.Find();
            game.blockedWords = game.blockedWords.Append(Word).ToArray();
            EditorUtility.SetDirty(game);
            AssetDatabase.SaveAssets();
            return $"Added \"{Word}\" to the blocked words.";
        }
    }
}

Las ventanas llaman a Needed cada pocos segundos, así que mantenlo liviano.
