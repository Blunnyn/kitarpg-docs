Opciones de menús y ajustes

Cómo agregar líneas al menú de ítems y al menú del jugador, y opciones a la ventana Settings, desde código propio.

Las tres son listas del cliente que el kit llena con sus propias entradas al inicio de cada Play. Tú agregas las tuyas después, desde un método estático en el ensamblado Game.

#Menú de ítems

Hacer clic derecho en un ítem de la bolsa o del equipo abre el menú de ítems (ItemMenu). Sus líneas vienen de ItemMenu.Entries, en orden, empezando por las del kit: la acción de la ventana abierta junto a la bolsa (vender, guardar, ofrecer), Equip, Take off, Use, Split, Salvage all, Possible values, View set y Destroy.

#ItemMenuEntry

Campo Qué es
string label El texto de la línea.
Func<ItemMenuTarget, string> labelFor El texto para este ítem, cuando cambia. Si es null se usa label.
Func<ItemMenuTarget, bool> shows Si la línea se muestra para este ítem. Si es null se muestra siempre.
Action<ItemMenuTarget> run Lo que hace elegir la línea.

#ItemMenuTarget

Miembro Qué es
UIItem view La casilla del ítem en pantalla.
InventoryWindow window La ventana de inventario desde la que se abrió el menú.
ItemContainer Container Bag, Equipment o Bank.
int Slot El índice de la casilla en ese contenedor.
ItemSlotState State Lo que tiene la casilla: id del ítem, cantidad, nivel de mejora, tiradas.
IItem Item Los datos del ítem (ItemData y sus subclases lo implementan).
bool InBag Container == ItemContainer.Bag.

#Ejemplo: comparar con lo que llevas puesto

using Blunnyn.KitARPG.Client;
using Blunnyn.KitARPG.Data;
using UnityEngine;

namespace Game
{
    public static class CompareLine
    {
        [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterAssembliesLoaded)]
        static void Register()
        {
            ItemMenu.Entries.Add(new ItemMenuEntry
            {
                label = "Compare",
                shows = t => t.InBag && t.Item is IEquippable,
                run = t => CompareWindow.Instance?.Show((IEquippable)t.Item),
            });
        }
    }
}

(CompareWindow representa una ventana tuya.)

#Ejemplo: insertar una línea en una posición

Entries es una List<ItemMenuEntry> común. Usa Insert para poner una línea antes del Destroy del kit:

int destroy = ItemMenu.Entries.FindIndex(e => e.label == "Destroy");
ItemMenu.Entries.Insert(destroy >= 0 ? destroy : ItemMenu.Entries.Count, myEntry);

#Líneas que cambian el juego

El menú se ejecuta en el cliente. Una línea que le hace algo al juego se lo pide al servidor, con un comando de un sistema del jugador o un mensaje de red, y el servidor vuelve a revisar todo: que la casilla tenga ese ítem y que el jugador pueda hacerlo. Las líneas del kit llaman a PlayerInventory.Local.Equip(slot), Use(slot) y similares, que son pedidos. Consulta Sistemas del jugador y Mensajes de red.

#Menú del jugador

Hacer clic derecho sobre otro jugador en top-down, o sobre un nombre en el chat, abre el menú del jugador (PlayerMenu). Sus líneas vienen de PlayerMenu.Entries: Whisper, Trade, Invite to party, Make leader, Remove from party, Add friend, Invite to guild, Duel, Report y Give up the duel. Cada línea del kit se oculta sola cuando su módulo está apagado.

#PlayerMenuEntry

Campo Qué es
string label El texto de la línea.
Func<PlayerMenuTarget, bool> shows Si la línea se muestra para este jugador. Si es null se muestra siempre.
Action<PlayerMenuTarget> run Lo que hace elegir la línea.

#PlayerMenuTarget

Campo Qué es
string name El nombre del personaje.
PlayerCharacter character El jugador en pantalla, o null cuando solo se lo nombró en el chat.

#Ejemplo: inspeccionar el equipo de un jugador

[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterAssembliesLoaded)]
static void Register()
{
    PlayerMenu.Entries.Add(new PlayerMenuEntry
    {
        label = "Inspect",
        shows = t => t.character != null,
        run = t => InspectWindow.Instance?.Show(t.character),
    });
}

El equipo puesto se sincroniza con todos los que ven al jugador (PlayerCharacter.gear, ids de ítems por posición de equipo), así que una ventana de inspección puede leerlo en el cliente. La bolsa es privada del dueño.

#Ejemplo: una línea para uno de tus módulos

PlayerMenu.Entries.Add(new PlayerMenuEntry
{
    label = "Challenge to a race",
    shows = t => t.character != null && RaceRules.Enabled,
    run = t => Races.Ask(t.name),
});

Races.Ask envía un pedido por nombre; el servidor busca al jugador por nombre en su mapa (PlayerCharacter.ServerFind(name)) y revisa la distancia y las reglas.

#Ventana Settings

La ventana Settings (Esc o el engranaje, luego Settings, y también en la pantalla de título) tiene pestañas: Graphics, Audio, Interface, además de Controls del modo top-down y cualquier página que agregues. Cada línea es una GameOption en ClientOptions.All. Los valores viven en la computadora del jugador y nunca llegan al servidor.

#Tipos de opción

Todas tienen estos campos:

Campo Qué es
string page La pestaña: ClientOptions.Graphics, ClientOptions.Audio, ClientOptions.Interface, o un nombre nuevo, que se vuelve una pestaña nueva al final.
string label El texto de la línea.
string hint Una explicación corta.
Func<bool> available Oculta la línea cuando dice que no, para opciones que una plataforma no tiene.
Action reset Devuelve el valor a su estado inicial, para el botón Reset de la pestaña.
Tipo Campos extra
ToggleOption Func<bool> get, Action<bool> set
SliderOption int min (0), int max (100), int step (5), Func<int> get, Action<int> set, Func<int, string> format (muestra "50%" por defecto)
ChoiceOption Func<string[]> choices, Func<int> get, Action<int> set (el índice)

ClientOptions.Add(option) agrega una. Los cambios se aplican a medida que el jugador los hace; el kit guarda sus propios valores cuando se cierra la ventana, y tu set guarda los tuyos.

#Ejemplo: la plantilla

using Blunnyn.KitARPG.Client;
using UnityEngine;

namespace Game
{
    /// <summary>
    /// An option of your own in the Settings window. Kept on the player's computer and never sent
    /// anywhere, so use it for how the game looks and sounds, not for anything the server decides.
    /// </summary>
    public static class MySettings
    {
        const string Key = "MyGame.ShowHints";

        public static bool ShowHints
        {
            get => PlayerPrefs.GetInt(Key, 1) == 1;
            set => PlayerPrefs.SetInt(Key, value ? 1 : 0);
        }

        [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterAssembliesLoaded)]
        static void Register()
        {
            ClientOptions.Add(new ToggleOption
            {
                // A page name the kit doesn't have becomes a new tab.
                page = ClientOptions.Interface,
                label = "Show hints",
                hint = "Short tips the first time something new shows up.",
                get = () => ShowHints,
                set = v => ShowHints = v,
                reset = () => ShowHints = true,
            });
        }
    }
}

#Ejemplo: un deslizador y una elección en una página propia

[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterAssembliesLoaded)]
static void Register()
{
    ClientOptions.Add(new SliderOption
    {
        page = "Gameplay",
        label = "Screen shake",
        min = 0, max = 100, step = 10,
        get = () => PlayerPrefs.GetInt("MyGame.Shake", 50),
        set = v => PlayerPrefs.SetInt("MyGame.Shake", v),
        reset = () => PlayerPrefs.DeleteKey("MyGame.Shake"),
    });

    ClientOptions.Add(new ChoiceOption
    {
        page = "Gameplay",
        label = "Damage numbers",
        choices = () => new[] { "All", "Mine only", "None" },
        get = () => PlayerPrefs.GetInt("MyGame.Numbers", 0),
        set = i => PlayerPrefs.SetInt("MyGame.Numbers", i),
        reset = () => PlayerPrefs.DeleteKey("MyGame.Numbers"),
    });
}

Un deslizador se mueve en pasos enteros. Dale a cada opción un reset, para que el botón Reset de la pestaña la cubra.

#Ejemplo: una opción solo en algunas plataformas

available = () => Application.platform == RuntimePlatform.WindowsPlayer,

#Para qué son los ajustes

Los ajustes son para cómo se ve, suena y se maneja el juego en esa computadora. Todo lo que afecte a otros jugadores o a las reglas (PvP encendido o apagado, reparto del botín) va en el servidor, en un sistema del jugador con un comando, no en PlayerPrefs. Para teclas propias, revisa GameInstance.KeysOn antes de leerlas: con la disposición de entrada Touch las teclas del juego están apagadas.

#Cuándo registrar

El kit rearma ItemMenu.Entries y PlayerMenu.Entries con sus propias líneas, y vacía ClientOptions.All, en SubsystemRegistration al inicio de cada Play. Registra las tuyas en AfterAssembliesLoaded o después. La ventana Settings lee la lista cuando se abre, así que aparecen las opciones agregadas en cualquier momento antes de eso.

Los servidores de mapa se ejecutan en modo batch y nunca abren estos menús; registrar ahí no hace daño.

#Errores comunes

  • Registrar en SubsystemRegistration. El kit puede reiniciar la lista después de ti.
  • Hacer el cambio en run. Los menús son código de cliente; pídeselo al servidor.
  • Sin reset. El botón Reset de la pestaña deja tu opción como estaba.
  • Reglas del juego en PlayerPrefs. Los jugadores pueden editarlas.
