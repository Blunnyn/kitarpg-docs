Modos de juego en código

Cómo se arman y se registran los modos de control, qué deben hacer la mitad de cliente y la mitad de servidor de un modo, y un esqueleto completo para un modo propio.

#Cómo funcionan los modos

El modo de control del juego es un texto en Game Settings > Game mode (GameInstance.controlMode): TopDown, FreeCamera o ThirdPerson en el kit. Las mismas escenas se juegan en todos los modos. Cada modo es un conjunto de componentes:

  • Componentes de cliente, que se agregan a la cámara principal de cada escena de mapa: la cámara y el input. Leen el mouse, las teclas y los controles táctiles, apuntan y mandan pedidos al servidor.
  • Componentes de servidor, que se agregan al network manager en el servidor de mapa (y en el host de un jugador): reciben los pedidos de movimiento y de acción, los revisan, y mueven y actúan por el jugador.

GameModes (namespace Blunnyn.KitARPG.Net) guarda la lista. Cuando carga un mapa, el kit agrega los componentes del modo que se juega y apaga los de todos los demás modos. Los modos del kit viven en sus propios ensamblados: KitARPG.Modes.TopDown con KitARPG.Modes.TopDown.Server, y KitARPG.Modes.ThirdPerson con KitARPG.Modes.ThirdPerson.Server (que atiende tanto tercera persona como cámara libre).

#GameModes

Miembro Qué hace
const string TopDown, ThirdPerson, FreeCamera Los nombres de los modos del kit.
string Current El modo que se juega: GameInstance.controlMode, o TopDown si está vacío.
bool Is(string mode) Si ese modo es el que se juega (no distingue mayúsculas).
IEnumerable<string> Known Todos los modos para los que se registró algún componente.
void AddServer(string mode, Type component) Registra un componente de servidor para un modo.
void AddClient(string mode, Type component) Registra un componente de cliente para un modo.
void EquipServer(GameObject host), EquipClient(GameObject camera) Agregan los componentes del modo que se juega y apagan el resto. Los llama el kit.
bool HasClientParts(GameObject target) Si el objeto lleva un componente de cliente de cualquier modo.

#Cuándo equipa el kit

  • Servidor: cuando arranca un servidor de mapa, o el host de un jugador arranca un mapa, EquipServer corre en el objeto del network manager.
  • Cliente: cuando carga una escena cuya cámara principal ya lleva un componente de cliente de algún modo, y otra vez cuando aparece el jugador local, EquipClient corre en Camera.main. Un componente que registró otro modo se desactiva; uno que registró el modo que se juega se agrega si falta y se activa.

Los componentes compartidos entre modos quedan prendidos: los modos tercera persona y cámara libre del kit registran las mismas clases.

#Registrar

Registra desde SubsystemRegistration. A diferencia de los otros estáticos del kit, las tablas de modos nunca se limpian, así que el orden de registro no importa, y agregar el mismo tipo dos veces se ignora:

[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.SubsystemRegistration)]
static void RegisterMode()
{
    GameModes.AddClient("Grid", typeof(GridCamera));
    GameModes.AddClient("Grid", typeof(GridInput));
}

El registro de servidor va en un ensamblado solo de servidor, junto al componente de servidor:

[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.SubsystemRegistration)]
static void RegisterMode() => GameModes.AddServer("Grid", typeof(GridServer));

#Elegir tu modo

El desplegable Game mode lista los tres modos del kit más todos los nombres de GameModes.Known. Los registros corren al empezar Play, así que presiona Play una vez con tu código compilado y luego elige tu modo en el desplegable. Desde ahí el nombre queda guardado en GameInstance.

#Servidor y cliente deben coincidir

El cliente manda su modo con su ticket. Un servidor de mapa que juega otro modo lo rechaza con mode_mismatch ("The server plays a different game mode. Update the game."), porque el cliente mandaría pedidos que el servidor no sabe atender. Compila el cliente y el servidor de mapa con el mismo Game mode.

#Qué hace la mitad de cliente

Tarea Cómo
Cámara Seguir a PlayerCharacter.Local (null hasta que aparece el jugador).
Input de movimiento Leer KitInput (teclas y mouse) y TouchControls.Axis("Move"); mandar pedidos.
Apuntar Poner en AimInput.Pointer hacia dónde apunta el jugador: AimInput.Mouse, AimInput.Center (una mira) o una función propia. Lo usan el apuntado de skills, las vistas previas y la barra rápida del kit.
Acciones Atacar, hablar, recoger: mandar los mensajes del kit o los tuyos.
Respetar la disposición Revisar GameInstance.KeysOn antes de leer teclas del juego: con la disposición Touch las teclas están apagadas.
Apagarse solo En OnEnable, salir antes cuando !GameModes.Is("YourMode"): las escenas pueden llevar tus componentes mientras se juega otro modo.

El propio código de cliente del kit también manda pedidos que tu servidor debe atender, sea cual sea el modo:

Mensaje Lo manda Campos
CastSkillMessage El apuntado de skills y la barra rápida (AimInput) skillId, target (netId), point
PickupMessage Interactuar en táctil y la tecla F (Interactables) drop
TalkMessage Lo mismo npc (el id del NPC)

Otros mensajes que usan los modos del kit y que el tuyo puede reutilizar: MoveToMessage (destination), MoveDirectionMessage (direction), AttackMessage (target), SwingMessage (aim, target), PlayerInputMessage y MoveAckMessage (el movimiento con predicción de tercera persona). Viven en KitARPG.Net.

#Qué hace la mitad de servidor

Una mitad de servidor es un MonoBehaviour en el objeto del network manager. Hace esto:

  1. Registra sus manejadores de mensajes en cada arranque del servidor (el host de un jugador se reinicia en cada cambio de mapa): se suscribe a KitNetworkManager.ServerStarted y además registra de inmediato si NetworkServer.active.
  2. Toma el control de cada jugador cuando aparece (PlayerCharacter.ServerSpawned): su NavMeshAgent, su velocidad.
  3. Revisa cada pedido: ritmo, el jugador del remitente desde conn.identity, vivo y cargado, posiciones finitas, distancias, línea de visión (Sight.Clear), objetivos mediante Fighters.TargetFor.
  4. Actúa con los métodos de servidor del kit:
Para Llama
Ataque básico player.ServerTryAttack(target) (false mientras se recarga)
Lanzar un skill player.GetComponent<PlayerSkills>().ServerCast(skill, target, point) (revisa maná, enfriamiento, alcance y objetivo; devuelve por qué no)
Recoger Rewards.Instance.Pickup(player, dropId) (revisa el alcance; devuelve un código de error)
Hablar player.GetComponent<PlayerInteraction>().ServerTalk(npc) después de npc.InReach(...)
Si se puede mover player.Statuses.CanMove, !player.Motion.Busy, !inventory.Overloaded
Qué tan rápido player.Stats.moveSpeed
Alcance de ataque player.AttackRange

TopDownServer y ThirdPersonServer son ejemplos completos; léelos antes de escribir el tuyo.

#Un esqueleto completo: un modo por grilla

Un modo que camina una casilla a la vez con las flechas, en una grilla de 1 m, con cámara fija. Reutiliza los mensajes del kit para las acciones.

#Mensaje compartido (ensamblado Game)

using Mirror;

namespace Game
{
    /// <summary>Client to server: one tile in a direction (-1, 0 or 1 on each axis).</summary>
    public struct GridStepMessage : NetworkMessage
    {
        public sbyte x;
        public sbyte z;
    }
}

#Mitad de cliente (ensamblado Game)

using Blunnyn.KitARPG.Client;
using Blunnyn.KitARPG.Data;
using Blunnyn.KitARPG.Net;
using Mirror;
using UnityEngine;

namespace Game
{
    public class GridCamera : MonoBehaviour
    {
        public Vector3 offset = new Vector3(0, 12, -8);

        [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.SubsystemRegistration)]
        static void RegisterMode()
        {
            GameModes.AddClient("Grid", typeof(GridCamera));
            GameModes.AddClient("Grid", typeof(GridInput));
        }

        protected virtual void LateUpdate()
        {
            PlayerCharacter player = PlayerCharacter.Local;
            if (player == null) return;
            transform.position = player.transform.position + offset;
            transform.LookAt(player.transform.position);
        }
    }

    public class GridInput : MonoBehaviour
    {
        public float repeatSeconds = 0.25f;
        float next;

        protected virtual void OnEnable()
        {
            if (!GameModes.Is("Grid")) return;
            AimInput.Pointer = AimInput.Mouse;
        }

        protected virtual void Update()
        {
            if (!NetworkClient.ready || PlayerCharacter.Local == null || !GameInstance.KeysOn) return;
            if (Time.unscaledTime < next) return;
            int x = (KitInput.GetKey(KeyCode.RightArrow) ? 1 : 0) - (KitInput.GetKey(KeyCode.LeftArrow) ? 1 : 0);
            int z = (KitInput.GetKey(KeyCode.UpArrow) ? 1 : 0) - (KitInput.GetKey(KeyCode.DownArrow) ? 1 : 0);
            Vector2 stick = TouchControls.Axis("Move");
            if (x == 0 && z == 0 && stick.sqrMagnitude > 0.25f)
            {
                x = Mathf.RoundToInt(stick.x);
                z = Mathf.RoundToInt(stick.y);
            }
            if (x == 0 && z == 0) return;
            next = Time.unscaledTime + repeatSeconds;
            NetworkClient.Send(new GridStepMessage { x = (sbyte)x, z = (sbyte)z });
        }
    }
}

#Mitad de servidor (ensamblado Game.Server)

using Blunnyn.KitARPG.Data;
using Blunnyn.KitARPG.Net;
using Blunnyn.KitARPG.Server;
using Mirror;
using UnityEngine;
using UnityEngine.AI;

namespace Game
{
    public class GridServer : MonoBehaviour
    {
        static readonly Color Refused = new Color(1f, 0.5f, 0.45f);

        [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.SubsystemRegistration)]
        static void RegisterMode() => GameModes.AddServer("Grid", typeof(GridServer));

        protected virtual void OnEnable()
        {
            PlayerCharacter.ServerSpawned += TakeOver;
            KitNetworkManager manager = GetComponent<KitNetworkManager>();
            if (manager != null) manager.ServerStarted += Register;
            if (NetworkServer.active) Register();
        }

        protected virtual void OnDisable()
        {
            PlayerCharacter.ServerSpawned -= TakeOver;
            KitNetworkManager manager = GetComponent<KitNetworkManager>();
            if (manager != null) manager.ServerStarted -= Register;
        }

        void Register()
        {
            NetworkServer.ReplaceHandler<GridStepMessage>(OnStep);
            NetworkServer.ReplaceHandler<AttackMessage>(OnAttack);
            NetworkServer.ReplaceHandler<CastSkillMessage>(OnCastSkill);
            NetworkServer.ReplaceHandler<PickupMessage>(OnPickup);
            NetworkServer.ReplaceHandler<TalkMessage>(OnTalk);
        }

        void TakeOver(PlayerCharacter player)
        {
            if (!player.TryGetComponent(out NavMeshAgent agent)) return;
            agent.enabled = true;
            agent.Warp(player.transform.position);
            agent.speed = player.Stats.moveSpeed > 0 ? player.Stats.moveSpeed : 3.5f;
        }

        static bool TryGetPlayer(NetworkConnectionToClient conn, out PlayerCharacter player)
        {
            player = conn.identity != null ? conn.identity.GetComponent<PlayerCharacter>() : null;
            return player != null && player.State != null && !player.Released && !player.IsDead;
        }

        void OnStep(NetworkConnectionToClient conn, GridStepMessage msg)
        {
            if (!CommandPacing.Allow(conn) || !TryGetPlayer(conn, out PlayerCharacter player)) return;
            if (Mathf.Abs(msg.x) > 1 || Mathf.Abs(msg.z) > 1 || (msg.x == 0 && msg.z == 0)) return;
            if (!player.Statuses.CanMove || player.Motion.Busy) return;
            if (player.TryGetComponent(out PlayerInventory inventory) && inventory.Overloaded) return;
            if (!player.TryGetComponent(out NavMeshAgent agent) || !agent.isOnNavMesh) return;
            Vector3 here = player.transform.position;
            Vector3 tile = new Vector3(Mathf.Round(here.x) + msg.x, here.y, Mathf.Round(here.z) + msg.z);
            if (NavMesh.SamplePosition(tile, out NavMeshHit hit, 0.5f, NavMesh.AllAreas)) agent.SetDestination(hit.position);
        }

        void OnAttack(NetworkConnectionToClient conn, AttackMessage msg)
        {
            if (!CommandPacing.Allow(conn) || !TryGetPlayer(conn, out PlayerCharacter player)) return;
            ICombatant target = Fighters.TargetFor(conn, player, msg.target);
            if (target == null || target.IsDead || !Fighters.Enemies(player, target)) return;
            Vector3 to = target.transform.position - player.transform.position;
            to.y = 0;
            if (to.magnitude > player.AttackRange + 0.5f || !Sight.Clear(player.transform.position, target.transform.position))
            {
                player.ServerAnnounce("Too far", Refused);
                return;
            }
            if (to.sqrMagnitude > 0.001f) player.transform.rotation = Quaternion.LookRotation(to);
            player.ServerTryAttack(target);
        }

        void OnCastSkill(NetworkConnectionToClient conn, CastSkillMessage msg)
        {
            if (!CommandPacing.Allow(conn) || !TryGetPlayer(conn, out PlayerCharacter player)) return;
            if (!player.TryGetComponent(out PlayerSkills skills) || skills.IsBusy) return;
            if (GameInstance.Database == null || !GameInstance.Database.TryGet(msg.skillId ?? "", out SkillData skill)) return;
            Vector3 p = msg.point;
            if (!float.IsFinite(p.x) || !float.IsFinite(p.y) || !float.IsFinite(p.z)) return;
            ICombatant target = Fighters.TargetFor(conn, player, msg.target);
            string error = skills.ServerCast(skill, target, p);
            if (error != null) player.ServerAnnounce(error, Refused);
        }

        void OnPickup(NetworkConnectionToClient conn, PickupMessage msg)
        {
            if (!CommandPacing.Allow(conn) || !TryGetPlayer(conn, out PlayerCharacter player) || Rewards.Instance == null) return;
            string error = Rewards.Instance.Pickup(player, msg.drop);
            if (error != null && player.TryGetComponent(out PlayerInventory inventory)) inventory.ServerError(error);
        }

        void OnTalk(NetworkConnectionToClient conn, TalkMessage msg)
        {
            if (!CommandPacing.Allow(conn) || !TryGetPlayer(conn, out PlayerCharacter player)) return;
            if (!Npc.TryFind(msg.npc, out Npc npc) || !player.TryGetComponent(out PlayerInteraction interaction)) return;
            if (!npc.InReach(player.transform.position))
            {
                player.ServerAnnounce("Too far", Refused);
                return;
            }
            interaction.ServerTalk(npc);
        }
    }
}

Este esqueleto deja fuera lo que los modos del kit agregan encima: caminar hasta quedar a distancia antes de atacar o lanzar, perseguir objetivos, actualizar la velocidad cuando cambian las stats (player.ServerStatsChanged) y la predicción en cliente del modo tercera persona. Copia esas partes de TopDownServer o ThirdPersonServer según lo que necesite tu modo.

#Reutilizar partes de un modo del kit

Puedes registrar los componentes del kit con el nombre de tu propio modo, por ejemplo TopDownServer con una cámara tuya. Lee cada componente antes: TopDownInput.OnEnable solo prepara el apuntado cuando GameModes.Is(GameModes.TopDown), así que con otro nombre deja AimInput.Pointer a tu cargo. Un modo que solo cambia la cámara suele ser más simple como otro asset CameraSettings (tercera persona y cámara libre leen los suyos de GameInstance.thirdPersonCamera y freeCamera).

#Un jugador y MMO

Los mismos componentes corren en los dos. En un jugador, el host corre la mitad de servidor y la mitad de cliente en un solo proceso; el host se reinicia en cada cambio de mapa, y por eso las mitades de servidor registran sus manejadores en cada ServerStarted.

#Errores comunes

  • Código de servidor en el ensamblado de cliente. Pon la mitad de servidor en un ensamblado .Server para que los clientes no la lleven.
  • Olvidar los mensajes propios del kit. Sin manejadores para CastSkillMessage, PickupMessage y TalkMessage, la barra rápida y el botón de interactuar no hacen nada en tu modo.
  • Confiar en las posiciones del cliente. Limita las distancias, muestrea el NavMesh, revisa la línea de visión.
  • Componentes de cliente que no revisan GameModes.Is. Corren en escenas donde se juega otro modo.
  • Modos distintos en el cliente y el servidor de mapa. Los jugadores reciben mode_mismatch.
