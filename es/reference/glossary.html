Referencia

Glosario

Las palabras que usan este manual y el editor de KitARPG, en orden alfabético, con una definición corta y un enlace a donde se explica cada una. Los términos quedan en inglés, como aparecen en pantalla, con la palabra en español entre paréntesis.

#A

Account (cuenta) El inicio de sesión de un jugador: un nombre de usuario, un hash de contraseña, un nivel de GM y un banco de cuenta. Una cuenta puede tener varios personajes (6 por defecto). Solo MMO. Consulta Servicios.

Account bank (banco de cuenta) Un banco que comparten todos los personajes de una cuenta, que se abre en un NPC banquero, sin límite de peso. Consulta Inventario y banco.

Action (game action) (acción) Algo que premia o cambia a un jugador cuando lo ejecuta una misión, una línea de diálogo, una opción de NPC o un disparador: dar ítems, experiencia, enseñar una skill, poner una marca, viajar. Consulta Condiciones y acciones.

Alliance (alianza) Un grupo de gremios con su propio canal de chat (/al). Consulta Gremios.

Assembly (ensamblado) Una unidad de código compilado en Unity, definida por un archivo .asmdef. El kit está dividido en ensamblados (KitARPG.Shared, KitARPG.Data, KitARPG.Net, KitARPG.Server, KitARPG.Client y más) para que cada build lleve solo su propio código. Consulta Ensamblados.

Attribute (atributo) Un valor del personaje en el que los jugadores reparten puntos, como Strength o Vitality. Cada punto suma stats. Consulta Atributos y stats.

Audit (GM audit) (auditoría) El registro de cada comando del equipo en la tabla gm_audit. Los comandos del equipo no corren cuando no se pueden registrar. Consulta Comandos de GM.

#B

Bestiary (bestiario) El libro de monstruos del juego (B): dónde vive cada uno y qué suelta. Consulta Bestiario.

Build Separation (separación de builds) La revisión que corre antes de cada build y la detiene cuando una build llevaría código que no le corresponde, como código de servidor en un cliente MMO. KitARPG > Check Build Separation muestra la tabla. Consulta Builds.

#C

Caddy El servidor web que el archivo Docker Compose pone delante de Login y Central para dar HTTPS. Consulta Docker.

Central El servicio .NET que guarda las sesiones, da los tickets para entrar a los mapas, inicia los servidores de mapa, y maneja el chat, los amigos, los grupos, los gremios, el correo y el mercado. Exactamente uno por base de datos. Consulta Servicios.

Character (personaje) El héroe de un jugador en el mundo: nombre, modelo, clase, nivel, ítems y progreso. Pertenece a una cuenta.

Class (clase) Lo que es un personaje: atributos y stats por nivel, skills e ítems iniciales. La muestra tiene Warrior, Hunter, Mage y Monk. Consulta Clases.

Condition (condición) Una regla que bloquea una misión, una línea de diálogo o una opción de NPC: nivel, clase, misión, ítem, marca, hora del día y más. Consulta Condiciones y acciones.

Control mode (modo de control) Cómo se juega: top-down, cámara libre o tercera persona. Se define en Game Settings (controlMode); los clientes y los servidores de mapa deben usar el mismo. Consulta Modos de control.

Cosmetic (cosmético) Una pieza de equipo que solo cambia el aspecto, sin stats.

Currency (moneda) Dinero que no es un ítem: oro, fichas de evento, o una moneda premium para la tienda. Consulta Monedas.

#D

DevKit Las partes del kit para escribir tu propio código: plantillas, eventos, el ejemplo y la guía. Consulta Visión general del DevKit.

Domain reload (recarga de dominio) Unity recargando todos los scripts al entrar en Play. El kit funciona con ella apagada, lo que hace que Play arranque más rápido. Consulta Recarga de dominio.

#E

Element (elemento) Un tipo de daño, como Fire o Water, con resistencias contra él.

Elite / Boss (élite / jefe) Rangos de monstruo por encima de Normal. Los jefes tienen una barra arriba de la pantalla y pueden tener fases. Consulta Jefes.

#F

Flag (story mark) (marca de historia) Un número entero guardado por clave en un personaje, que ponen las acciones y leen las condiciones, para recordar el progreso de la historia. /flag las lee y las pone.

Forge (forja) El servicio de NPC que mejora el equipo con runas, engarza gemas y rompe piezas en runas. Consulta Forja.

#G

Game Database El asset que lista todos los datos del juego (modelos, clases, skills, ítems, monstruos, misiones, mapas y reglas compartidas), y la página de la ventana KitARPG que lo edita. El de la muestra es StarterDatabase.asset. Consulta Game Database.

gamedata.json El archivo que el editor exporta de la Game Database para Login, para que pueda crear personajes con modelos, clases y valores iniciales válidos.

Game log (registro del juego) Un registro de lo que importa para el soporte (intercambios, botín, correo, muertes, comandos de GM) en la tabla game_logs, que se lee con /logs. Consulta Registro del juego y reportes.

Game Settings La página de la ventana KitARPG que edita el GameInstance del prefab de red: cómo se juega. Consulta Game Settings.

GameInstance El componente del prefab de red (KitNetwork.prefab) que tiene la Game Database y cada ajuste del juego, y sobrevive a los cambios de mapa.

GM level (role) (nivel de GM, rol) El nivel de equipo de una cuenta: 1 Player, 2 Moderator, 3 Game Master, 4 Admin. Se guarda en accounts.Role. Consulta Comandos de GM.

GM panel (panel de GM) La ventana del juego para el equipo (F8 o /gm) que corre comandos de GM con botones.

Guild hall (casa del gremio) Un mapa instanciado que un gremio compra una vez y al que entra por un NPC.

#H

Headless (sin pantalla) Correr sin ventana ni gráficos. Los servidores de mapa y el lanzador en modo --headless corren así.

HUD La interfaz del juego: barras, barra rápida, chat, minimapa y ventanas, en un prefab (GameHud.prefab). Consulta HUD y ventanas.

#I

Id El nombre en texto de un dato, como fire_bolt. Se completa con el nombre del archivo al crearse y nunca cambia después, así que los guardados siguen apuntando a él.

IL2CPP El backend de scripting de Unity que compila C# a código nativo. Los clientes de release siempre lo usan.

Instance (instanced map) (instancia, mapa instanciado) Un mapa donde cada grupo, o cada jugador solo, recibe su propia copia, como la Sunken Crypt. Consulta Mazmorras.

Item copy (item instance) (copia de ítem) Un ítem concreto que tiene un jugador, con sus propias bonificaciones aleatorias, mejoras y gemas. En el MMO cada copia tiene exactamente un dueño.

#K

KCP El transporte UDP que usa Mirror entre los clientes y los servidores de mapa.

Kit update (actualización del kit) Un cambio que un kit más nuevo le hace a un juego hecho con uno más viejo, aplicado desde Overview. Solo agrega lo que falta. Consulta Actualizar el kit.

KitARPGSettings El asset en Assets/Settings/Resources que dice cómo corre el juego (un jugador o MMO) y adónde se conectan los clientes.

KitInput La capa de input del kit, con las mismas llamadas que Input de Unity, que funciona con el Input System o con el Input Manager.

KitARPG window (ventana KitARPG) La ventana del editor con todas las herramientas del kit, que se abre con Ctrl/Cmd+Shift+K. Consulta La ventana KitARPG.

#L

Launcher (lanzador) El programa que inicia Login, Central, los mapas y si quieres Shop, con ventana o sin pantalla. Play & Servers lo usa. Consulta Lanzador.

Ledger (libro de cuentas) El registro que mueve copias de ítems (ItemLedger) o moneda premium (currency_ledger) entre dueños, dentro de transacciones.

LiteNetLib La biblioteca de red que usan los servidores de mapa para hablar con Central por el enlace de los mapas.

Login El servicio .NET de cuentas, inicio de sesión y personajes. Consulta Servicios.

Loot table (tabla de botín) Una lista de lo que suelta un monstruo y con qué frecuencia. Consulta Botín.

#M

Map (mapa) Una entrada de la Game Database más una escena. En el MMO, cada mapa corre en su propio servidor de mapa. Consulta Mapas.

Map link (enlace de los mapas) La conexión UDP (puerto 7700) entre los servidores de mapa y Central. No está cifrada; mantenla fuera de internet.

Map server (servidor de mapa) Una build de Unity sin pantalla que corre un mapa, sus jugadores y sus monstruos. Central los inicia desde la build del servidor de mapa.

Market (mercado) El mercado entre jugadores en un NPC; a los vendedores se les paga por correo. Solo MMO. Consulta Mercado.

Mirror La biblioteca de red entre los clientes y los servidores de mapa. Viene en Assets/Mirror.

Model (player model) (modelo de jugador) Un prefab de jugador: un aspecto que eligen los jugadores, con las clases que puede ser. Consulta Modelos de jugador.

Module (kit module) (módulo del kit) Un sistema entero (Chat, Guilds, Mail, Market y más) que prendes y apagas en la página Modules. Consulta Modules.

Module (service module) (módulo de servicio) Una biblioteca .NET que amplía Login o Central sin editarlos. Consulta Módulos de servicio.

Multiplayer Play Mode El paquete de Unity que corre un segundo editor, que usa Play with two players.

#N

NavMesh La superficie caminable horneada en cada escena de mapa. El servidor mueve a jugadores y monstruos sobre ella.

Network version (versión de red) Un hash corto de todo lo que viaja por la red. Un cliente cuya versión difiere de la del servidor de mapa se rechaza con version_mismatch.

NPC option (opción de NPC) Una cosa que ofrece un NPC: tienda, teletransporte, misión, diálogo, maestro, banco y más. Consulta NPCs.

#O

Overview La primera página de la ventana KitARPG, con la lista de pendientes y el botón Play. Consulta Overview.

#P

Play & Servers La página de la ventana KitARPG donde eliges un jugador o MMO, inicias los servicios y juegas. Consulta Play & Servers.

Premium currency (moneda premium) Una moneda que tiene la cuenta, no el personaje, y que solo se gasta en la tienda del juego. Consulta Tienda del juego.

Project Check La página de la ventana KitARPG que encuentra problemas en el proyecto, y que corre antes de cada build. Consulta Project Check.

#Q

Quick bar (hotbar) (barra rápida) La fila de casillas abajo del HUD, en las teclas 1 a 9 y 0, para skills e ítems.

#R

Rates (tasas) Multiplicadores del servidor para la experiencia, el botín y el oro, que se ponen en Game Settings, más los eventos temporales con /rates.

Remember me (recordarme) La opción de inicio de sesión que guarda un token de un solo uso en la computadora del jugador para que no tenga que escribir la contraseña la próxima vez.

#S

Services (servicios) Login, Central y Shop, los programas .NET detrás del MMO. Vienen como Services.zip y se desempaquetan en Services~.

Services~ La carpeta donde el editor desempaqueta los servicios. El ~ impide que Unity la importe.

Session (sesión) El tiempo de una cuenta en el juego, desde que inicia sesión hasta que se va. Una por cuenta.

Set Piezas de equipo que dan bonificaciones cuando se llevan juntas. Consulta Sets, mejoras y engarces.

Shop (service) (servicio Shop) El servicio .NET opcional para la tienda del juego: catálogo, saldos, compras y pagos. Consulta Servicio Shop.

Shop (NPC) (tienda de NPC) Una tienda en un NPC, listada en Shops de la Game Database. Consulta Tiendas de NPC.

Single player (un jugador) El modo en que el juego hospeda su propio mundo y guarda en la computadora del jugador. Consulta Inicio rápido: un jugador.

Skill Una acción con un objetivo, una forma de área, un costo, una recarga y efectos. Consulta Skills.

SpawnPoint (punto de aparición) El componente que marca dónde aparecen los jugadores en un mapa.

Starter sample (muestra Starter) La muestra jugable en Samples/Starter: Title, Town, Forest y Crypt con sus datos.

Start over La herramienta de Overview que arma otra vez la muestra Starter desde cero, perdiendo los cambios que se le hicieron.

Status (estado) Un buff o un debuff sobre un personaje o un monstruo, como el veneno o el aturdimiento. Consulta Estados y buffs.

#T

Tax collector (recaudador) Un NPC de un gremio que se pone en un punto de un mapa y se lleva una parte de lo que se caza cerca. Consulta Recaudadores.

Test client (cliente de prueba) Un cliente compilado con el símbolo KITARPG_DEV que lleva las herramientas de prueba del kit. Solo para revisiones locales, nunca para jugadores.

Ticket Un pase de un solo uso que Central le da a un cliente para entrar a un servidor de mapa. Vence a los 30 segundos.

Trigger (world trigger) (disparador del mundo) Algo en un mapa que ejecuta acciones cuando un jugador entra en él o una acción lo activa, para un jugador o para todos. Consulta Disparadores del mundo.

#U

UserSettings/KitARPG La carpeta de tu proyecto, fuera de Assets, con los ajustes del lanzador, las claves, la base de datos local y los registros de esta computadora. Nunca se publica.
