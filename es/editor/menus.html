El editor

Menus

Esta página aún no está traducida. Se muestra en inglés.

This page lists every menu the kit adds to the Unity editor: the KitARPG menu in the menu bar, its Starter, Tools and DevKit submenus, and the Create > KitARPG menu in the Project window. Each entry says what it does and where to read more.

#The KitARPG menu

The KitARPG menu sits in Unity's menu bar. Its entries, from top to bottom:

Menu Shortcut What it does
KitARPG > Open KitARPG Ctrl/Cmd+Shift+K Opens the KitARPG window on the last page you used
KitARPG > Setup Wizard Opens the Setup wizard: how the game runs, then graphics, fonts and the sample scenes in one click
KitARPG > Play and Servers Opens the window on Play & Servers
KitARPG > Game Database Opens the window on Game Database
KitARPG > Play With Two Players Starts the services if needed, opens a second editor and logs both in with test accounts. MMO only. See Playing with two players
KitARPG > Game Settings Opens the window on Game Settings
KitARPG > Export Game Data for Services Writes the game database to gamedata.json in the Login folder of the services source, for services you run by hand or put in Docker. Play & Servers writes its own copy when it starts the services
KitARPG > Modules Opens the window on Modules
KitARPG > Render Missing Item Icons Renders a 128 by 128 icon for every item that has none, from its model, into an Icons folder next to the item. The Console says how many it made
KitARPG > Shop Opens the window on the Shop page
KitARPG > Render Missing Monster Icons Renders a portrait for every monster with a prefab and no icon, for the bestiary. See Bestiary
KitARPG > Project Check Opens the window on Project Check and runs a full check, scenes included
KitARPG > Check Build Separation Checks, for each kind of build (MMO client, MMO map server, single player), which kit assemblies it would carry, and reports any code a build shouldn't have. A dialog gives the result and the Console the detail. See Security
KitARPG > DevKit > Add Bounty Board to the Open Scene Places the DevKit example's bounty board, with two hunts made from your own monsters, at the center of the Scene view. See Example: bounty board
KitARPG > Starter > ... Builds the sample and the builds; see below
KitARPG > Tools > Rebuild Character Controller Makes the Animator controller every character uses again. See below
KitARPG > Run Play Mode Tests Runs the kit's Play mode tests (KitARPG.Tests.PlayMode) and writes the results to Logs/KitARPG-PlayMode-Tests.xml in the Unity project
KitARPG > Documentation Opens this documentation in your browser from the copy inside the package, in the editor's language when the site has it. It works offline
KitARPG > What's New Opens the changelog, newest version first, with Open the file to read Documentation/CHANGELOG.md

#KitARPG > Starter

Menu What it does Output
Build Scenes and Prefabs Builds the starter sample: Title, Server, Town, Forest and the dungeon scenes, the network prefab, player and monster prefabs, the HUD and the sample data. Running it again makes them again from scratch, so changes to the sample are lost. Stop Play first Assets/Blunnyn/KitARPG/Samples/Starter/
Build Mac Server The local map server for Mac: a player build with the server code (KITARPG_SERVER) that the launcher runs without graphics Builds/Starter/MacServer/KitARPGServer.app
Build Windows Server The same for Windows Builds/Starter/WindowsServer/KitARPGServer.exe
Build Mac Client The MMO client for Mac, compiled with IL2CPP Builds/Starter/MacClient/KitARPG.app
Build Mac Test Client A Mac client with the test tools (automatic login, smoke tests), compiled with Mono for a fast build. For local checks only, never for players Builds/Starter/MacTestClient/KitARPGTest.app
Build Windows Client The MMO client for Windows, compiled with IL2CPP Builds/Starter/WindowsClient/KitARPG.exe
Build Mac Single Player The single player game for Mac, with the server code so it hosts itself Builds/Starter/MacSinglePlayer/KitARPG.app
Build Windows Single Player The same for Windows Builds/Starter/WindowsSinglePlayer/KitARPG.exe
Build Linux Server The Linux dedicated server for Docker, compiled with IL2CPP. Needs Unity's Linux Dedicated Server module Deploy/builds/starter/KitARPGServer.x86_64

The Builds and Deploy paths are relative to the folder that contains your Unity project folder.

Every build:

  • takes its scenes from the maps in the Game Database, so a new map is in every build without editing a list. If a map names a scene that doesn't exist, the build stops and says which;
  • sets the game mode it needs for the build in the settings asset and puts yours back afterwards;
  • runs Project Check first and stops on errors, unless Stop builds on errors is off;
  • checks that it carries only the code it should.

See Builds and Docker.

#KitARPG > Tools

Rebuild Character Controller deletes and makes again Runtime/Resources/KitARPG/KitCharacter.controller, the one Animator controller every character uses. Its states hold placeholder clips that each character's Character Animations component swaps for its own, so you never edit it. Use this only if the controller was deleted or damaged.
