El editor

Menús

Esta página lista cada menú que el kit agrega al editor de Unity: el menú KitARPG de la barra de menú, sus submenús Starter, Tools y DevKit, y el menú Create > KitARPG de la ventana Project. Cada entrada dice qué hace y dónde leer más.

#El menú KitARPG

El menú KitARPG está en la barra de menú de Unity. Sus entradas, de arriba abajo:

Menú Atajo Qué hace
KitARPG > Open KitARPG Ctrl/Cmd+Shift+K Abre la ventana KitARPG en la última página que usaste
KitARPG > Setup Wizard Abre el Setup Wizard: cómo corre el juego, y luego gráficos, fuentes y las escenas de muestra en un clic
KitARPG > Play and Servers Abre la ventana en Play & Servers
KitARPG > Game Database Abre la ventana en Game Database
KitARPG > Play With Two Players Inicia los servicios si hace falta, abre un segundo editor e inicia sesión en los dos con cuentas de prueba. Solo MMO. Consulta Jugar con dos jugadores
KitARPG > Game Settings Abre la ventana en Game Settings
KitARPG > Export Game Data for Services Escribe la base de datos del juego en gamedata.json dentro de la carpeta Login del código de los servicios, para servicios que corres a mano o pones en Docker. Play & Servers escribe su propia copia cuando inicia los servicios
KitARPG > Modules Abre la ventana en Modules
KitARPG > Render Missing Item Icons Genera un ícono de 128 por 128 para cada ítem que no tiene, a partir de su modelo, en una carpeta Icons junto al ítem. La Console dice cuántos hizo
KitARPG > Shop Abre la ventana en la página Shop
KitARPG > Render Missing Monster Icons Genera un retrato para cada monstruo con prefab y sin ícono, para el bestiario. Consulta Bestiario
KitARPG > Project Check Abre la ventana en Project Check y hace una revisión completa, escenas incluidas
KitARPG > Check Build Separation Revisa, para cada tipo de build (cliente MMO, servidor de mapa MMO, un jugador), qué ensamblados del kit llevaría, e informa cualquier código que una build no debería tener. Un diálogo da el resultado y la Console el detalle. Consulta Seguridad
KitARPG > DevKit > Add Bounty Board to the Open Scene Pone el tablón de recompensas del ejemplo del DevKit, con dos cacerías hechas con tus propios monstruos, en el centro de la vista Scene. Consulta Ejemplo: tablón de recompensas
KitARPG > Starter > ... Arma la muestra y las builds; ver más abajo
KitARPG > Tools > Rebuild Character Controller Vuelve a crear el Animator controller que usan todos los personajes. Ver más abajo
KitARPG > Run Play Mode Tests Corre las pruebas de modo Play del kit (KitARPG.Tests.PlayMode) y escribe los resultados en Logs/KitARPG-PlayMode-Tests.xml dentro del proyecto de Unity
KitARPG > Documentation Abre esta documentación en tu navegador desde la copia dentro del paquete, en el idioma del editor cuando el sitio lo tiene. Funciona sin conexión
KitARPG > What's New Abre el registro de cambios, la versión más nueva primero, con Open the file para leer Documentation/CHANGELOG.md

#KitARPG > Starter

Menú Qué hace Resultado
Build Scenes and Prefabs Arma la muestra Starter: las escenas Title, Server, Town, Forest y las de la mazmorra, el prefab de red, los prefabs de jugador y de monstruos, el HUD y los datos de muestra. Correrlo otra vez los crea de nuevo desde cero, así que se pierden los cambios a la muestra. Detén Play antes Assets/Blunnyn/KitARPG/Samples/Starter/
Build Mac Server El servidor de mapa local para Mac: una build de jugador con el código de servidor (KITARPG_SERVER) que el lanzador corre sin gráficos Builds/Starter/MacServer/KitARPGServer.app
Build Windows Server Lo mismo para Windows Builds/Starter/WindowsServer/KitARPGServer.exe
Build Mac Client El cliente MMO para Mac, compilado con IL2CPP Builds/Starter/MacClient/KitARPG.app
Build Mac Test Client Un cliente de Mac con las herramientas de prueba (inicio de sesión automático, pruebas de humo), compilado con Mono para una build rápida. Solo para revisiones locales, nunca para jugadores Builds/Starter/MacTestClient/KitARPGTest.app
Build Windows Client El cliente MMO para Windows, compilado con IL2CPP Builds/Starter/WindowsClient/KitARPG.exe
Build Mac Single Player El juego de un jugador para Mac, con el código de servidor para hospedarse a sí mismo Builds/Starter/MacSinglePlayer/KitARPG.app
Build Windows Single Player Lo mismo para Windows Builds/Starter/WindowsSinglePlayer/KitARPG.exe
Build Linux Server El servidor dedicado Linux para Docker, compilado con IL2CPP. Necesita el módulo Linux Dedicated Server de Unity Deploy/builds/starter/KitARPGServer.x86_64

Las rutas Builds y Deploy son relativas a la carpeta que contiene la carpeta de tu proyecto de Unity.

Cada build:

  • toma sus escenas de los mapas de la Game Database, así que un mapa nuevo está en cada build sin editar ninguna lista. Si un mapa nombra una escena que no existe, la build se detiene y dice cuál;
  • pone en el asset de configuración el modo de juego que necesita la build y deja el tuyo de vuelta al terminar;
  • corre primero Project Check y se detiene si hay errores, salvo que Stop builds on errors esté apagado;
  • revisa que lleve solo el código que le corresponde.

Consulta Builds y Docker.

#KitARPG > Tools

Rebuild Character Controller borra y vuelve a crear Runtime/Resources/KitARPG/KitCharacter.controller, el único Animator controller que usan todos los personajes. Sus estados tienen clips de relleno que el componente Character Animations de cada personaje cambia por los suyos, así que nunca lo editas. Úsalo solo si el controller se borró o se dañó.

#Create > KitARPG

Haz clic derecho en la ventana Project, o usa Assets > Create > KitARPG, para crear assets y scripts del kit.

Consejo

Los assets creados desde este menú existen en el proyecto pero no en el juego hasta que la base de datos del juego llega a ellos. Crear las entradas desde la página Game Database las lista por ti; Project Check señala las que no puede alcanzar.
