El editor

Project Check

Project Check recorre tu proyecto buscando problemas que rompen el juego, sus guardados o sus builds: referencias rotas, ids repetidos, prefabs que no pueden ir por la red, escenas que faltan, ofertas de la tienda que el juego no puede vender y más. Lista lo que encuentra por área, con un botón para seleccionar la causa y, para muchos problemas, un botón que lo corrige. También corre antes de cada build.

#Dónde está

  • KitARPG > Project Check (abre la página y hace una revisión completa), o
  • la página Project Check de la ventana KitARPG (Ctrl/Cmd+Shift+K), bajo Project.

La barra lateral muestra la cantidad de errores en rojo, o de advertencias en naranja cuando no hay errores. Overview muestra el mismo resultado en su mosaico project check.

#Cuándo corre

Cuándo Qué revisa
Al abrirse la ventana KitARPG Todo menos el interior de las escenas de mapa, un momento después de abrirse, para que la ventana siga rápida
KitARPG > Project Check o Check again Todo, incluso abriendo aparte la escena de cada mapa para revisar su contenido
Antes de cada build Todo menos el interior de las escenas de mapa. Detiene la build si hay errores, salvo que lo apagues
Después de presionar un botón de corrección Todo otra vez

Revisar escenas abre cada escena de mapa de forma aditiva y la vuelve a cerrar si no estaba abierta, así que tarda más en un proyecto grande.

#La página

Tres mosaicos muestran los conteos:

Mosaico Significa
errors: break the game or its saves Corrígelos. Las builds se detienen con ellos
warnings: worth a look El juego corre, pero algo probablemente no es lo que quieres
notes Información, como ítems sin íconos o datos a los que el juego no puede llegar

Debajo:

  • Check again hace una revisión completa.
  • Show notes: las notas están ocultas hasta que marcas esto.
  • Stop builds on errors (prendido por defecto): la revisión antes de cada build detiene la build cuando encuentra errores. La elección se guarda en las preferencias del editor.

Luego los hallazgos, una tarjeta por área, con el nombre del área y un conteo. El color de la tarjeta es el de su peor hallazgo. Cada hallazgo tiene un punto de color, el mensaje y hasta dos botones:

  • Select selecciona y resalta el asset, el prefab o la escena de que se trata.
  • Un botón de corrección, como Add it o Use starter scenes, que lo corrige. Los assets se guardan después de la corrección y la revisión corre otra vez.

Cuando no se encuentra nada: "No problems found. The project is ready to play and build." (o cuántas notas están ocultas).

#Cada revisión

Las revisiones corren en este orden. Las tablas listan cada mensaje, su nivel, qué significa y cómo corregirlo. Los mensajes muestran los nombres reales de tus assets en lugar de ....

#Updates

Nivel Mensaje Significado y solución
Advertencia "Update title is missing. What it changes" El kit tiene algo que tu juego todavía no tiene. Apply agrega solo lo que falta. Consulta Actualizar el kit

#Input y Settings

Nivel Área Mensaje Significado y solución
Advertencia Input "...'s EventSystem has the UI module of the other input system, so menus may not take clicks." El EventSystem de la escena usa el módulo del Input Manager en un proyecto que usa el Input System, o al revés. Fix scenes cambia el módulo en cada escena que lo necesita
Advertencia Settings "... overrides Game Settings on its Game Instance (fields), so changes in Game Settings don't reach that scene." La escena cambió valores en su copia del prefab de red. Fix scenes revierte esos cambios para que la escena use Game Settings

Fix scenes pide guardar primero las escenas abiertas, corrige cada escena, la guarda y vuelve a abrir lo que tenías abierto.

#Text

Nivel Mensaje Significado y solución
Error "TextMesh Pro's essential resources aren't in the project, so every label in the kit's UI and sample has no font." Import TMP Essentials los importa

#Database

Nivel Mensaje Significado y solución
Error "No game database. Put one on the GameInstance of the network prefab, or build the starter sample." Build sample arma la muestra Starter, que trae una. O pon la tuya en Game Settings
Error Cada problema que informa la base de datos, como "Two player models use the id '...'", "Player model '...' has no classes, so nobody can pick it.", "'...' is used by both ... and ...", "... has no id.", "Map '...' has no scene.", "No damage elements: hits without an element can't be dealt or resisted.", "... is in Player Models but has no PlayerModel component." Abre la Game Database y corrige la entrada nombrada
Error "No start map: new characters have nowhere to appear." Pon Start Map en los Settings de la Game Database
Error "No gold currency: gold shows without a name or icon." Pon Gold en los Settings de la Game Database

#Ids

Nivel Mensaje Significado y solución
Error "... has no id, so saves can't point at it." Use the name crea un id con el nombre del asset
Advertencia "... has the id '...'. Ids read best as lowercase letters, digits, - and _." Cambia el id, salvo que los jugadores ya lo hayan guardado
Error "... and ... are both Type '...'. Only one will be found." Dos assets del mismo tipo comparten un id. Cambia uno. Tipos distintos pueden compartir un id

#Unused data

Nivel Mensaje Significado y solución
Nota "... (Type) isn't reached from the game database, so the game won't know it. List it in the database or reference it from something that is." El asset existe en el proyecto pero nunca en el juego. Crea las entradas desde la página Game Database, o usa su botón Collect referenced después de enlazarlas

#Items

Nivel Mensaje Significado y solución
Advertencia "... stacks up to N but has random bonuses. Each copy keeps its own rolls, so copies never stack. Make the bonuses fixed or set Max Stack to 1." Make bonuses fixed convierte cada bonificación aleatoria en una fija en el medio de su rango

#References

Nivel Mensaje Significado y solución
Error "...: 'field' points at something that was deleted." Un campo muestra "Missing" en el Inspector. Elige otra cosa o vacíalo. Se revisa en cada asset de datos del juego y en cada componente de las escenas de mapa
Error "... has an effect or condition whose class no longer exists." Un efecto de skill, efecto de ítem, condición o acción se borró o se renombró en el código. Restaura la clase o quita la entrada
Advertencia "Loot table ... has a drop with no item." Pon el ítem o quita la entrada de botín
Advertencia "Shop ... has an entry with no item." Pon el ítem o quita la entrada
Error "...: ... has an option whose class no longer exists." Un NPC de una escena de mapa tiene una opción cuya clase ya no está

#Quests

Nivel Mensaje Significado y solución
Advertencia "Quest ... hands out ..., which isn't a quest item. It can be traded or sold, and then the quest can't be given up. Tick Quest Item on it." Abandonar una misión recupera sus ítems iniciales. Marca Quest Item en el ítem

#Icons

Nivel Mensaje Significado y solución
Nota "... has no icon." Render icons genera un ícono para cada ítem que no tiene

#Shop

Nivel Mensaje Significado y solución
Error "Shop ... charges in ..., a premium currency. Premium currency is only spent at the in-game shop." Una tienda de NPC usa la moneda premium. Cámbiala a oro u otra moneda normal
Error "Player model ... has no PlayerShop, so the shop can't open for it." Aparece cuando el juego tiene una moneda premium. Aplica la actualización del kit "Shop on the player prefabs"
Error "... can't be read: ..." El archivo del catálogo de la tienda no es JSON válido
Advertencia "Shop offer ... problem. The Shop service skips it." La oferta rompe una regla del catálogo, como no tener id, precio o ítems. Corrígela en la página Shop
Advertencia "Two shop offers use the id '...'." Dale un id nuevo a una
Advertencia "Shop offer ... charges in '...', which isn't a premium currency of the game database." Marca Premium en esa moneda, o arma la muestra Starter para tener Gems
Advertencia "Shop offer ... sells '...', which the game database doesn't have." Corrige el ítem o agrégalo a la base de datos
Advertencia "Shop offer ... sells a quest item, ..." Quítalo de la oferta

Las revisiones de la tienda leen el catálogo que edita la página Shop (UserSettings/KitARPG/shop-conf.json), o el de muestra que viene con el servicio Shop cuando no hay uno. Los problemas del catálogo son advertencias porque el catálogo pertenece al servicio Shop, no a la build del juego.

#Guilds

Nivel Mensaje Significado y solución
Error "The guild hall map ... isn't instanced, so every guild would share one hall." Make it instanced marca Instanced en el mapa
Error "The guild hall map ... isn't in the game database's maps, so no map server runs it." Agrega el mapa a la lista Maps
Advertencia "The founding item ... is a quest item." Elige otro ítem para fundar gremios

#Network y Scripts

Nivel Área Mensaje Significado y solución
Error Network "Player model ... has no NetworkIdentity." Add it agrega el componente al prefab
Error Network "Monster ... has no prefab, so it can't spawn." Pon el prefab del monstruo
Error Network "..., the prefab of ..., has no NetworkIdentity." Add it
Error Network "..., the prefab of ..., has no Monster component." Agrega el componente Monster al prefab, o créalo con el asistente New monster
Error Scripts "... has N missing script(s)." Un prefab en Assets/Blunnyn o Assets/Game tiene componentes cuyo script ya no está. Quítalos en el prefab
Error Network "... has Component but no NetworkIdentity." Un prefab tiene un componente en red sin un NetworkIdentity en él o en un padre. Add it
Advertencia Network "... lists an empty spawnable prefab." El prefab del network manager tiene una casilla vacía en sus prefabs spawnables. Quítala
Error Network "... is spawnable in ... but has no NetworkIdentity." Agrega un NetworkIdentity a ese prefab

#Scenes

Nivel Mensaje Significado y solución
Error "Build Settings has no scenes." Use starter scenes
Error "Build Settings lists ..., which doesn't exist." Quita la entrada en File > Build Profiles
Advertencia "The first scene is ...; the kit starts at Title." Use starter scenes, o mueve Title arriba
Error "Map '...' names no scene. Pick its scene in the Game Database, on the map's page." Pon la Scene del mapa
Error "Map '...' uses the scene '...', and no scene has that name. Make it, or fix the name on the map's page." Crea la escena o corrige el nombre
Error "Map '...' uses the scene '...', which isn't in Build Settings. Builds add it anyway; Play in the editor needs it listed." Add map scenes agrega cada escena de mapa a Build Settings
Error "... has no SpawnPoint; players arriving at '...' have nowhere to stand." Agrega un Spawn Point a la escena. Solo en la revisión completa
Error "...: ... has N missing script(s)." Un objeto de una escena de mapa tiene scripts que faltan. Solo en la revisión completa
Error "...: ... and ... share the NPC id '...', so the server can't tell them apart." Dale a cada NPC su propio id. Solo en la revisión completa
Advertencia "...: spawner ... has no monster." Pon el monstruo del spawner. Solo en la revisión completa

Los hallazgos "solo en la revisión completa" vienen de abrir las escenas, así que aparecen después de Check again o KitARPG > Project Check, no en la revisión rápida al abrir la ventana.

#Validator

Nivel Mensaje Significado
Error "A check failed: ..." Una revisión misma lanzó un error. El error completo está en la Console

#Antes de cada build

Cada build, desde los menús del kit o desde la ventana Build de Unity, corre primero la revisión sin abrir escenas. Cuando encuentra errores y Stop builds on errors está prendido, escribe cada error en la Console con [KitARPG] y detiene la build con "KitARPG found N problem(s) in the project. See the Console or KitARPG > Project Check. The check can be turned off there."

Atención

Apagar Stop builds on errors deja pasar builds rotas. Úsalo solo para probar una build cuando sabes qué está mal.

El kit también revisa que cada build lleve solo el código que le corresponde. Esa revisión es aparte; consulta KitARPG > Check Build Separation en Menús y Seguridad.

#Paso a paso: llegar a cero errores

  1. Abre KitARPG > Project Check. Hace la revisión completa.
  2. Trabaja primero las tarjetas rojas. Presiona el botón de corrección donde lo haya; si no, presiona Select y corrige el asset a mano.
  3. Presiona Check again.
  4. Lee las advertencias. Corrige las que importan para tu juego.
  5. Marca Show notes de vez en cuando para encontrar datos a los que el juego no llega e ítems sin íconos.

#Agregar tus propias revisiones

Agrega un método a ProjectValidator.Checks desde un script de editor, y corre con las demás, también antes de las builds. Create > KitARPG > Scripts > Validator Check (Editor) crea un script inicial. Consulta Extensiones del editor.
