KitARPG.Server

Esta página aún no está traducida. Se muestra en inglés.

#Blunnyn.KitARPG.Server

#CentralLink (class)

The map server's line to Central over LiteNetLib. Registers the map, keeps it alive and turns request/reply messages into callbacks, which always run on the main thread.

Member Description
public float logSeconds Log lines go to Central in batches this often.
public int maxUnconfirmedAudit GM commands stop running once this many lines wait for Central.

#CentralMessages (class)

The game's own messages between this map server and its modules in Central. Messages are [Serializable] classes with public fields, sent as their type name and JSON, so the module reads them with the same file. Server only: clients never see these.

Member Description
public static bool Online The map is registered with Central. False in single player and while Central is away.
public static bool Send<T>(T message) where T : class Sends a message to Central's modules. False when Central can't be reached; nothing is queued.
public static void On<T>(Action<T> handler) where T : class Calls handler, on the main thread, for each Central sends. Register once, for example in a [RuntimeInitializeOnLoadMethod]; a second handler for the same type replaces the first.

#Copy (class)

#GmAudit (class)

The GM audit: every GM command, run or refused, ends up in the database. Server only. The sink is set by the map server; without one, staff commands don't run at all.

Member Description
public static event Action<GmAuditEntry> Recorded Server only. Every line, as it is recorded.

#GmCommand (class)

Member Description
public GmRank rank The GM level it asks for by default. Game Settings can change it per command (GameInstance.gmCommandLevels).
public string usage Like "item id [amount] [player]".
public Func<GmContext, string> run Returns the answer to show, or null.

#GmCommands (class)

Slash commands for moderators and admins, run on the map server and only compiled into server builds. The account's role comes from Central; in a single player world EveryoneRank can make the player an admin. Add your own with Register from a server-only assembly. Every use is logged.

Member Description
public static GmRank EveryoneRank The rank every player has at least. Set by the map server: admin for single player cheats, player online.
public static event Action<PlayerCharacter, string> ServerUsed Server only. A command ran: who, and the whole line.
public static GmRank LevelOf(GmCommand command) The level a command asks for now: the Game Settings one when set, its default otherwise. /role always asks for admin.
public static string[] AllowedFor(PlayerCharacter player) The commands a player may use, by name.
public static string Run(PlayerCharacter player, string line) Server only. Runs a line like "/item health_potion 5" and returns the answer for the player. Every staff command, run or refused for its level, goes to the GM audit; when the audit can't reach the database the command doesn't run.

#GmContext (class)

What a command gets: who typed it and the words after its name.

Member Description
public string rest Everything after the command name, as typed.
public int level The level this command asks for, sent along to Central so it checks the same.
public PlayerCharacter Target(int i) The player named at i, on this map; the one who typed it when there is no name.

#IGmAuditSink (interface)

Where GM lines are stored: Central's gm_audit table, or the single player save.

Member Description
bool Ready Whether a line written now is sure to reach the database. GM commands refuse to run when it isn't.
string ChangeRole(RoleChange change) Asks for another account's GM level to change. Returns why not, or null when it went.

#IWorldBackend (interface)

Where a map server checks tickets and saves characters. Central over the network for an MMO, or the game itself when it hosts a single player world. Callbacks may run later.

Member Description
void Transfer(CharacterState character, string targetMap, Vector3 target, Action<TransferResult> done, string instance = null) Moves a character to another map. instance picks the copy of an instanced map, like a guild's hall; the backend checks it.

#MapInstances (class)

Copies of an instanced map on one map server: one per party, or per player alone. Each is the map's scene loaded again, moved far from the others so they never see or reach each other, and unloaded a while after its last player leaves. The scene the server starts with is only the template; its spawners stay idle.

Member Description
public static event Action<string, bool> ServerChanged Raised on the server when a copy is made or let go, with its key.
public void Get(string key, Action<Copy> ready) The copy for this key, made if needed; ready runs once it is loaded.
public void Tick() Lets go of copies that stayed empty long enough. Call now and then.

#MapServer (class)

Runs one map: lets players in with their ticket, spawns their characters, saves them and moves them through portals. As a dedicated server it works for Central; a single player game hosts it through Host with its own backend. Command line: -map town -port 7777 -central 127.0.0.1:7700 -centralKey key [-address public.ip]; the key can come from KITARPG_CENTRAL_KEY instead. The in-game shop needs -shop url -shopKey key (or KITARPG_SHOP_URL and KITARPG_SHOP_KEY); see ShopClient.

Member Description
public string mapId Map from the game database to run when started without -map.
public string publicAddress Address clients should connect to. Empty lets Central use the address it sees.
public bool startInEditor Start the server when entering Play mode in the editor.
public CentralLink Link Central's link when running as a dedicated server, otherwise null.
public void Host(string map, IWorldBackend worldBackend) Runs a map inside this game for a single player: starts a host with its own backend.
public bool SendTo(PlayerCharacter player, string map, Vector3 position, Action failed = null, string instance = null) Server only. Moves a player to another map; failed runs if that map can't take them.

#Rewards (class)

Pays out kills: experience, gold and loot. How loot reaches the player follows lootMode: on the ground, in the monster's body or straight to the bag. A guild tax collector nearby takes its share first; one that falls pays its takers. Loot is only for the killer, so nobody can take it from them; it lives here on the server and the owner is told where it is.

Member Description
public float scatter Ground drops land within this many meters of the monster.
protected virtual void OnKilled(Monster monster, PlayerCharacter killer) What a kill gives. Override to share with a party or change the payout.
protected virtual float DropChance(LootTable.Drop entry, float luck) A drop's chance for this kill: the table's, grown by the killer's loot chance and the server's loot rate. Quest items keep theirs, so a quest never gets easier with luck.
protected virtual void ShareExperience(Monster monster, PlayerCharacter killer) Party members close by split the experience, each by their own level, with a bonus for every extra member. Alone, the killer gets it all.
protected long Taxed(long experience) Experience after the share a tax collector nearby takes.
protected virtual void PayCollector(TaxCollector collector, PlayerCharacter killer) A tax collector fell: whoever hit it hardest gets everything it gathered.
public void Pay(PlayerCharacter owner, PlayerInventory inventory, List<LootEntry> items, long gold, Monster from) Server only. Hands items and gold to a player the way the game's loot mode says.
public void Place(PlayerCharacter owner, PlayerInventory inventory, ItemData item, int amount, Vector3 near) Server only. Puts one item on the ground for one player.
public const string Overloaded Said when loot puts a character over its weight limit.
public bool TryFind(PlayerCharacter player, int id, out Vector3 position) Where a player's drop is, if it is theirs and still there.
public string Pickup(PlayerCharacter player, int id) Server only. The player reached a drop: a body opens its loot window, anything else goes to the bag. Returns an InventoryErrors code or null.

#ShopClient (class)

The map server's line to the Shop service over HTTP. The key goes in X-Shop-Key and never leaves the server; players only reach the shop through their map. Command line: -shop http://shop:5300 -shopKey key, or KITARPG_SHOP_URL and KITARPG_SHOP_KEY.

Member Description
public static ShopClient FromEnvironment() The configured Shop service, or null when the game runs without one.
