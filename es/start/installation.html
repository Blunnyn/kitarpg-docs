Primeros pasos

Instalación

Cómo poner KitARPG en un proyecto de Unity, qué trae la importación, qué pasa la primera vez que se abre el editor y cómo arreglar una importación que salió mal. Cuando termines, el Setup Wizard toma el control.

#Antes de empezar

  • Instala Unity 6000.6.0f1 (Unity 6.6) o más nuevo con Unity Hub. Consulta Requisitos.
  • Decide si empiezas un proyecto nuevo (recomendado) o si importas en uno existente.
  • Si piensas probar el MMO en tu computadora, instala ahora el SDK de .NET 10. También puedes hacerlo después.
Consejo

Pon tu proyecto bajo control de versiones (Git o Unity Version Control) antes de importar. Así cada paso posterior, incluidas las actualizaciones del kit, se puede deshacer sin riesgo.

#Paso a paso: un proyecto nuevo

  1. Abre Unity Hub y presiona New project.
  2. Elige Unity 6000.6.0f1 o más nuevo como versión del editor.
  3. Elige una plantilla. Sirve cualquier plantilla 3D, incluida la vacía Universal 3D. El kit instala lo que necesita.
  4. Ponle nombre al proyecto y presiona Create project. Espera a que se abra el editor.
  5. Abre Window > Package Manager.
  6. En la columna izquierda, abre My Assets (necesitas haber iniciado sesión con la cuenta de Unity que compró el kit).
  7. Busca KitARPG y presiona Download, luego Import.
  8. La ventana Import Unity Package lista todos los archivos. Deja todo marcado y presiona Import.
  9. Unity importa los archivos y luego instala los paquetes de Unity que declara el kit (URP, AI Navigation, uGUI, Input System, Test Framework). Puede compilar varias veces.
  10. Si Unity pregunta si quieres habilitar los nuevos backends del Input System y reiniciar, puedes responder que sí o que no. El kit funciona con cualquiera de las dos entradas. Si respondes que sí, el editor se reinicia.
  11. Cuando el editor se estabiliza, la ventana KitARPG Setup se abre sola. Sigue con el Setup Wizard.

#Qué contiene el paquete

Ruta en tu proyecto Qué es
Assets/Blunnyn/KitARPG/ El kit: código de ejecución, herramientas del editor, modos, DevKit, muestra, pruebas, plugins y documentación
Assets/Blunnyn/KitARPG/Services.zip Los servicios .NET (Login, Central, Shop, Data, Hosting, Modules, Launcher, pruebas y ejemplos) como código fuente
Assets/Blunnyn/Art/ El arte voxel: personajes, equipo, armas, monstruos, animaciones e íconos
Assets/Mirror/ Mirror, la biblioteca de red, con el transporte KCP
Assets/ScriptTemplates/ Las plantillas de script de Mirror

La estructura completa está en Estructura del proyecto.

Atención

Si tu proyecto ya tiene Mirror en otra carpeta, terminas con dos copias y errores de tipos duplicados. Deja una sola copia de Mirror: la de Assets/Mirror que trae el kit es la versión con la que se prueba el kit.

#Qué pasa la primera vez que se abre el editor

Después de la importación corren varias cosas solas. Algunas las ves en la Console.

#Se desempaquetan los servicios

Un .unitypackage solo puede llevar assets, así que los servicios .NET vienen como Services.zip. La primera vez que carga el editor, el kit lo desempaqueta en:

Assets/Blunnyn/KitARPG/Services~

Unity nunca importa una carpeta cuyo nombre termina en ~, así que los archivos C# de los servicios no terminan en tu juego. La Console muestra:

[KitARPG] Services <version> unpacked to .../Assets/Blunnyn/KitARPG/Services~.

El zip lleva un archivo kit-services.version. El kit vuelve a desempaquetar solo cuando la versión del zip es distinta de la que ya está desempaquetada, por ejemplo después de importar un kit más nuevo.

Nota

Si existe una carpeta Services con KitARPG.Services.slnx junto a la carpeta de tu proyecto de Unity o dentro de ella, el kit usa esa y no toca el zip. Play & Servers muestra la carpeta en uso en la línea Services source, con un botón Browse para elegir otra.

#Se abre el Setup Wizard

El asistente se abre una vez por proyecto, salvo que exista el archivo UserSettings/KitARPG/setup-done. Nunca se abre en modo batch ni en el segundo editor de Multiplayer Play Mode. Siempre puedes volver a abrirlo desde KitARPG > Setup Wizard.

#El kit recuerda su versión

El kit escribe su versión en UserSettings/KitARPG/seen-version. En una primera importación no pasa nada más. Cuando más adelante importas un kit más nuevo, la ventana What's New se abre una vez con el registro de cambios. Consulta Actualizar el kit.

#Importar en un proyecto existente

Puedes agregar KitARPG a un proyecto que ya tienes. Revisa esto primero:

Revisión Por qué
Unity 6000.6.0f1 o más nuevo El kit no compila en versiones anteriores
El proyecto usa URP, o estás listo para cambiar El Setup Wizard pone URP como pipeline de render en Graphics y en cada nivel de calidad. Tus propios materiales de Built-in van a necesitar conversión
Ninguna otra copia de Mirror Dos copias entran en conflicto
Build Settings El asistente reemplaza la lista de escenas por las escenas de la muestra Starter, con Title primero. Anota antes tus propias escenas
Espacio de color El asistente pone Linear

El asistente solo toca ajustes del proyecto (pipeline de render, espacio de color, Build Settings) y la muestra Starter. Nunca cambia tus propios assets.

#Comprobar que la importación funcionó

Después del asistente, todo lo siguiente debería cumplirse:

  • La Console no tiene errores en rojo.
  • La barra de menús tiene un menú KitARPG.
  • Ctrl/Cmd+Shift+K abre la ventana KitARPG.
  • Overview en esa ventana dice "Everything is ready", o lista solo pasos del MMO que todavía no hiciste.
  • Project Check no muestra errores.

#Cuando la importación sale mal

Síntoma Causa Solución
Cientos de errores de compilación que mencionan UnityEngine.Rendering.Universal URP no se instaló Abre Window > Package Manager, instala Universal RP 17.6.0 y vuelve a abrir el proyecto
Errores sobre Unity.AI.Navigation o NavMeshSurface AI Navigation no se instaló Instala AI Navigation 2.0.14 desde el Package Manager
InvalidOperationException sobre UnityEngine.Input desde tus propios scripts al dar Play El proyecto usa solo el Input System y tu script llama a Input directamente Llama a KitInput en su lugar. El código del kit ya lo hace
Errores de tipos de Mirror duplicados Dos copias de Mirror Borra una copia
El Setup Wizard no se abrió Ya corrió antes en este proyecto, o el editor está en modo batch Abre KitARPG > Setup Wizard
Falta Services~ El editor no terminó de cargar, o Services.zip no se importó Espera a que termine la compilación, o vuelve a importar el paquete con Services.zip marcado
"Missing ... Import the KitARPG package again." para la biblioteca SQLite El plugin de SQLite para tu plataforma no se importó Vuelve a importar el paquete con Plugins/SQLite marcado

Para más, consulta Solución de problemas.

#Desinstalar

Para quitar el kit de un proyecto, borra Assets/Blunnyn, Assets/Mirror, Assets/ScriptTemplates, Assets/Settings/Resources/KitARPGSettings.asset y UserSettings/KitARPG. Los paquetes de Unity que instaló se quedan; quítalos desde el Package Manager si no los usas.

Importante

UserSettings/KitARPG guarda la base de datos local del MMO, las claves del lanzador, las cuentas de prueba y el catálogo local de la tienda. Borrarlo borra todas las cuentas y personajes que creaste en local.
