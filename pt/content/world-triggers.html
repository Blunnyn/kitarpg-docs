Gatilhos do mundo

Um gatilho do mundo faz algo acontecer no mundo quando um jogador entra em um lugar, ou quando uma fala de diálogo, uma missão ou um objeto clicado o dispara: monstros aparecem, objetos surgem ou somem, e ações são executadas no jogador. Esta página cobre todos os campos do componente WorldTrigger, os gatilhos pessoais e compartilhados, como eles se repetem e se restauram, e exemplos passo a passo.

#O que é um gatilho do mundo

Um WorldTrigger é um componente em um objeto de uma cena de mapa. Como um portal, é um dado simples da cena: o cliente e o servidor o têm, o servidor decide quando ele dispara e diz aos clientes o que mostrar.

Quando dispara, ele pode:

  • executar ações no jogador que o disparou,
  • fazer surgir monstros ao redor dele,
  • mostrar objetos (um portal, um baú, uma runa brilhante) e esconder outros (uma parede, uma porta selada),
  • contar para missões com um objetivo Trigger que o nomeia.

Ele dispara de uma de duas formas:

  • Enter: um jogador entra no raio dele.
  • Manual: uma opção Trigger em um NPC ou objeto, uma ação Fire Trigger, o comando de GM /trigger id ou código.

E acontece para um de dois públicos:

  • Personal: só o jogador que o disparou vê o que ele faz. Os monstros dele são só desse jogador.
  • Everyone: acontece para todos no mapa.

#Onde fica no editor

Selecione qualquer objeto em uma cena de mapa e Add Component > World Trigger. A Scene view desenha o raio dele no chão: roxo para gatilhos pessoais, laranja para os compartilhados (um círculo pequeno para gatilhos manuais).

#Campos

#Disparar

Campo O que faz Padrão
Trigger Id (triggerId) Único no seu mapa. Missões, ações e falas de diálogo o nomeiam. Vazio usa o nome do objeto. Vazio
Activation (activation) Enter: entrar no raio. Manual: só por uma opção Trigger, uma ação Fire Trigger, o comando de GM ou código. Enter
Radius (radius) Metros ao redor do objeto, no chão, para gatilhos Enter. 4
Scope (scope) Personal: só o jogador que o disparou vê o que ele faz. Everyone: todos no mapa. Personal
Conditions (conditions) Quem pode dispará-lo: uma missão em andamento, um item carregado, uma classe. Vazio
Once (once) Uma vez por jogador quando é pessoal (fica feito), uma vez enquanto o mapa roda quando é para todos. Senão, de novo depois da recarga. Ligado
Cooldown (cooldown) Segundos até poder disparar de novo quando não é único. Nos gatilhos pessoais, a recarga é por jogador. 30
Reset After (resetAfter) Segundos até os objetos voltarem a ser como eram. 0 os deixa assim. Um gatilho pessoal também fica armado de novo para aquele jogador. 0

#O que acontece

Campo O que faz Padrão
Actions (actions) Executadas no jogador que o disparou. Se uma não pode, nada acontece. Vazio
Monsters (monsters) Monstros que ele faz surgir (abaixo). Vazio
Monster Lifetime (monsterLifetime) Segundos que os monstros ficam; 0 até serem mortos. Os pessoais também vão embora quando o jogador deles sai. 120
Show (show) Objetos mostrados quando ele dispara: um portal, um baú, uma runa brilhante. Eles começam escondidos. Vazio
Hide (hide) Objetos escondidos quando ele dispara: uma parede, uma porta selada. Vazio

#Cada entrada de monstro

Campo O que faz Padrão
Monster (monster) O monstro. Nenhum
Count (count) Quantos. 1
Offset (offset) A partir do gatilho, onde eles aparecem. 0, 0, 0
Spread (spread) Metros ao redor desse ponto em que eles se espalham. 2

#Como ele dispara

No servidor, a cada tentativa:

  1. Um jogador morto ou saindo é ignorado.
  2. As condições são conferidas. Se uma falha, um gatilho manual diz ao jogador o motivo (sobre a cabeça dele); um gatilho Enter fica em silêncio. Nos dois casos, o jogador não é conferido de novo por 3 segundos, então andar dentro do raio não repete a recusa.
  3. Progresso de missão: um objetivo Trigger que nomeia este gatilho conta agora para o jogador, mesmo que o gatilho esteja gasto.
  4. Se o gatilho está gasto (veja abaixo), para aqui.
  5. As ações são conferidas e executadas. Se uma não pode ser executada, nada acontece e o jogador fica sabendo o motivo (gatilhos manuais).
  6. O gatilho é marcado como feito, os objetos são mostrados e escondidos, os monstros surgem.

Os gatilhos Enter conferem os jogadores dentro do raio quatro vezes por segundo.

#Gasto, único e recarga

Escopo Once ligado Once desligado
Personal Uma vez por jogador, para sempre. É salvo como a marca de história trigger.<id> no personagem. De novo para aquele jogador depois de Cooldown.
Everyone Uma vez enquanto o servidor de mapa roda. Um reinício o arma de novo. De novo para qualquer um depois de Cooldown.

#Reset After

Com Reset After acima de 0:

  • Everyone: depois desses segundos, os objetos mostrados se escondem de novo e os escondidos voltam, para todos.
  • Personal: depois desses segundos, a marca trigger.<id> do jogador é apagada, então os objetos voltam ao normal na tela dele e o gatilho fica armado de novo para ele.

#Pessoal e para todos

#Pessoal

  • Os objetos mudam só na tela daquele jogador. Cada cliente mostra o que a marca trigger.<id> do próprio jogador diz, então uma runa acesa ontem continua acesa quando o jogador volta.
  • Os monstros são monstros de evento só daquele jogador: só ele os vê, enfrenta e pode feri-los, junto com as invocações dele. Os ataques de outros jogadores não os alcançam. Eles vão embora quando o jogador sai do mapa.
  • Uma condição Flag com Key trigger.<id> diz se um jogador já o fez.
Atenção

Em um servidor de mapa dedicado, os objetos de um gatilho pessoal só mudam no cliente. O NavMesh do servidor não muda. Para abrir de verdade uma passagem (uma parede que cai), use um gatilho para todos, ou garanta que o objeto não bloqueie o NavMesh do servidor.

#Para todos

  • O servidor troca os objetos e avisa todos os jogadores no mapa. Um jogador que chega depois recebe o estado atual ao entrar.
  • Os monstros são monstros de evento que qualquer um pode enfrentar.
  • Em um mapa instanciado, "todos" são todos na mesma cópia. Cada cópia tem os próprios gatilhos.

#Monstros de evento

Os monstros que um gatilho faz surgir:

  • não voltam depois de morrer; vão embora 4 segundos depois,
  • vão embora depois de Monster Lifetime segundos (0: só quando mortos),
  • dão experiência e saque como qualquer outro monstro.

#Criar uma alavanca, um altar ou um baú

O Strange Altar do exemplo, na Forest: com a missão "Whispers in the Woods" pega, tocá-lo desperta dois guardiões cogumelo e acende uma runa, e só aquele jogador os vê.

  1. Monte o objeto: uma base de pedra e um filho Rune. Deixe a runa ativa no editor; o gatilho esconde os objetos de Show quando a cena começa.
  2. Add Component > Npc. Npc Id altar, Display Name "Strange Altar", Greeting vazio, Talk Range 2,5. Dê a ele um colisor.
  3. Em Add option, pressione Trigger. Trigger forest_altar, Label "Touch the altar". Sem cumprimento e com uma opção, clicar no altar o dispara na hora.
  4. Add Component > World Trigger no mesmo objeto:
    • Trigger Id forest_altar, Activation Manual, Scope Personal.
    • Conditions: Quest, Quest Whispers in the Woods, Check Taken, Fail Text "The stone is cold and silent."
    • Actions: Message, Text "The altar hums. Something stirs!"
    • Monsters: Mushroom, Count 2, Offset 0, 0, 3, Spread 1,5.
    • Show: a Rune.
  5. Crie a missão: objetivos Trigger (Trigger forest_altar, Target Name "the altar in the forest") e Kill Mushroom x2 com o texto "Defeat what the altar called". Veja Missões.
  6. Dê a missão a um NPC com uma opção Quest.

Sem a missão, clicar no altar mostra "The stone is cold and silent." Com ela, a runa acende e os guardiões saem.

#Criar um evento de área para todos

O Slime Swarm do exemplo, no meio da Forest: a partir do nível 2, entrar faz 4 slimes saírem para todos, e ele descansa 2 minutos.

  1. GameObject > Create Empty na clareira, com o nome Slime Swarm Trigger.
  2. Add Component > World Trigger:
    • Trigger Id slime_swarm, Activation Enter, Radius 3, Scope Everyone.
    • Once desligado, Cooldown 120.
    • Conditions: Level, Min 2.
    • Actions: Message, Text "Slimes pour out of the bushes!", uma cor laranja.
    • Monsters: Slime, Count 4, Offset 0, 0, 4, Spread 3.
    • Monster Lifetime 90.

#Criar uma emboscada quando uma missão é pega

  1. Coloque um gatilho manual bandit_ambush com Scope Personal e bandidos em Monsters, perto da estrada.
  2. Na missão, On Accept: Fire Trigger bandit_ambush.

O NPC da missão precisa estar no mesmo mapa que o gatilho: Fire Trigger dispara um gatilho no mapa atual do jogador.

#Criar uma porta que abre depois de uma conversa

  1. Um objeto de parede, e um World Trigger old_gate com Activation Manual, Scope Everyone, Hide: a parede, Reset After 300.
  2. Uma fala de diálogo no porteiro com Actions: Fire Trigger old_gate.

Todos veem a parede sumir por 5 minutos, e depois ela volta. Veja Diálogos.

#Testar gatilhos

  • /trigger forest_altar o dispara como se você tivesse clicado, condições incluídas.
  • /flag trigger.forest_altar 0 arma de novo um gatilho pessoal para você.
  • Reiniciar o mapa (parar o Play, ou o servidor de mapa) arma os gatilhos para todos.

Veja Comandos de GM.

#Um jogador e MMO

  • Um jogador: o jogo é o host; os gatilhos pessoais e para todos se comportam igual, e os objetos de um gatilho pessoal mudam de verdade no único mundo que existe.
  • MMO: o servidor de mapa decide e avisa os clientes. Os monstros pessoais só são enviados ao seu jogador, então nenhum outro cliente, mesmo modificado, consegue vê-los. Os gatilhos para todos que são Once disparam uma vez por execução do servidor de mapa.

#Para programadores

WorldTrigger.ServerFire(id, player, tell) dispara um pelo código. WorldTrigger.ServerFired (gatilho, jogador) avisa outros sistemas que um disparou. Monster.ServerMakeEvent(player, seconds) transforma um monstro que você faz surgir em um monstro de evento. Veja Eventos.

#Erros comuns

  • Nada acontece ao clicar. O id da opção Trigger não corresponde ao Trigger Id do gatilho, ou eles estão em mapas diferentes.
  • Os objetos de Show ficam visíveis antes de disparar. Eles são escondidos quando a cena começa; confira se estão listados em Show, não em Hide.
  • Dispara uma vez e nunca mais. Once está ligado. Desligue-o e defina um Cooldown.
  • Outros jogadores atravessam uma parede "caída". Era um gatilho pessoal. Use Everyone para coisas que mudam o caminho.
  • O passo da missão não conta. O Trigger do objetivo não corresponde, ou o jogador não cumpre as condições do gatilho.
