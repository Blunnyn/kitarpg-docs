Lojas de NPC

Uma loja de NPC é um asset ShopData que lista o que um NPC vende, a que preço e em que moeda, com estoque limitado opcional que se reabastece com o tempo. Esta página cobre todos os campos de uma loja, a compra, a venda e a recompra, como o estoque funciona e um passo a passo de um NPC com loja.

#O que é uma loja

Uma loja tem duas partes:

  • Os dados da loja (ShopData, Game Database > Items > Shops): a moeda, as entradas e se ela compra dos jogadores.
  • Uma opção Shop em um NPC que a abre. Vários NPCs podem compartilhar os mesmos dados de loja, cada um com o próprio estoque.

O exemplo tem oito lojas: o Alchemist (Mira), a Armory (Brann), o Hatter (Pip), o Tailor (Doran), o Cobbler (Wren), o Arcanist (Selis), o Blacksmith (Garrick) e o Guild Registrar (Edda, cartas de fundação de guilda).

As lojas vendem por ouro ou outra moeda do jogo. A loja do jogo que vende por moeda premium é outro sistema: veja Loja do jogo.

#Onde fica no editor

Game Database > Items > Shops. + New shop cria uma em uma pasta Shops ao lado do banco de dados e a adiciona à lista shops do banco de dados. Você também pode usar Create > KitARPG > Shop. As entradas aparecem como linhas com o ícone de cada item.

#Campos

#A loja

Campo O que faz Padrão
Id, Display Name, Description, Icon Comuns a todo asset do banco de dados. Do nome do arquivo
Currency (currency) Em que ela cobra. Vazio é ouro. Uma moeda premium é um erro no Project Check: a moeda premium só se gasta na loja do jogo. Vazio (ouro)
Items (items) O que ela vende, na ordem em que a janela os lista. Vazio
Buys Items (buysItems) Os jogadores podem vender seus itens aqui, por ouro. Só quando Game Settings deixa os jogadores venderem para NPCs. Ligado
Buyback Slots (buybackSlots) Os últimos itens que cada jogador vendeu, que ele pode recomprar pelo que recebeu até sair da loja. 0 desliga. 10

#Cada entrada

Campo O que faz Padrão
Item (item) O que ela vende. Project Check avisa sobre uma entrada sem item. Nenhum
Price (price) Preço de uma unidade, na moeda da loja. 0 usa o preço de compra do item. 0
Stock (stock) Quantos ela tem. 0 nunca acaba. 0
Restock Minutes (restockMinutes) Minutos para recuperar uma unidade depois de algumas serem vendidas. 0 só reabastece quando o mapa reinicia. 5

O preço de compra do item é o Buy Price (buyPrice) dele, ou quatro vezes o Sell Price (sellPrice) quando Buy Price é 0. Veja Itens.

#Em Game Settings

Campo O que faz Padrão
Players Sell To Npcs (playersSellToNpcs, Game Settings > Economy) As lojas compram o que os jogadores trazem. Desligado, nada é vendido para NPCs: os itens passam entre jogadores, vão para o mercado ou para a forja, e o saque nunca vira ouro. Uma loja ainda pode recusar por conta própria com Buys Items desligado. Desligado

Uma loja só compra quando o Buys Items dela e o Players Sell To Npcs do jogo estão ligados. Com as configurações padrão, nenhuma loja compra.

#Comprar

A janela da loja lista cada entrada com ícone, nome, preço e o estoque restante nas entradas limitadas, e um botão Buy.

  • Buy ou clique direito em uma entrada compra uma unidade.
  • Com Shift, compra uma pilha: até a pilha máxima do item ou o que resta no estoque.
  • O servidor confere se a entrada existe, se há estoque, se o jogador pode pagar o preço vezes a quantidade na moeda da loja e se a bolsa tem espaço.
  • Os erros aparecem na janela: "You can't afford that.", "Sold out. Come back later.", "You're too far away." ou o motivo da própria bolsa.

Cada compra é escrita no registro do jogo (ShopBuy) com a loja, o item, a quantidade e o preço.

#Vender

Quando a loja compra, abri-la também abre a bolsa ao lado, e a bolsa vende enquanto a loja está aberta:

  • Clique com o botão direito em um item da bolsa para vendê-lo, ou arraste-o para a loja. A linha de dica da bolsa mostra as outras formas (duplo clique, Shift para um, Ctrl para todos).
  • Uma pilha pergunta quantos.
  • O jogador recebe o Sell Price do item vezes a quantidade, sempre em ouro, seja qual for a moeda da loja.
  • Itens com Sell Price 0 e itens de missão não podem ser vendidos: "Nobody would buy that."
  • Com a loja sem comprar: "This shop doesn't buy items."

Cada venda é escrita no registro do jogo (ShopSell).

#Recomprar

Cada venda vai para o início da fileira de recompra do jogador, até Buyback Slots itens. Clique com o botão direito em um para recuperá-lo pelo ouro que o jogador recebeu. O item volta exatamente como foi vendido, com seus bônus sorteados e aprimoramentos. A fileira começa vazia toda vez que a loja é aberta.

#Estoque

  • O estoque é mantido por NPC enquanto o mapa roda. Dois NPCs com os mesmos dados de loja têm estoques separados.
  • Uma entrada limitada começa cheia (Stock). Quando uma unidade é vendida, um relógio começa: a cada Restock Minutes, uma volta, até a entrada ficar cheia de novo.
  • Com Restock Minutes 0, os itens vendidos só voltam quando o servidor de mapa reinicia.
  • Todos no mapa compartilham o estoque de um NPC. No MMO, cada servidor de mapa, e cada cópia de um mapa instanciado, tem o seu.

A Armory do exemplo vende suas melhores armas com estoque de 1 a 3, reabastecido a cada 5 a 10 minutos: "The good pieces sell out."

#Colocar um NPC com loja

Isto cria uma herbalista que vende poções e um elixir raro.

  1. Crie a loja. Game Database > Items > Shops > + New shop. Renomeie para Herbalist.

  2. Deixe Currency vazio (ouro).

  3. Adicione entradas em Items:

    Item Preço Estoque Restock Minutes
    Health Potion 20 0 5
    Mana Potion 20 0 5
    Antidote 0 (usa o preço de compra dele) 0 5
    Fortitude Elixir 45 3 10

  4. Deixe Buys Items ligado se o seu jogo deixa os jogadores venderem para NPCs.

  5. Coloque o NPC. Abra a cena do mapa. Adicione o modelo do personagem e dê ao objeto o nome Herbalist.

  6. Add Component > Npc. Npc Id herbalist, Display Name Hanna, Greeting "Herbs for every ache."

  7. Add Component > Capsule Collider e ajuste-o ao corpo.

  8. No Inspector do Npc, pressione Shop em Add option. Na nova opção, escolha Herbalist em Shop. Deixe Label vazio para "Trade", ou digite "Browse herbs".

  9. Salve a cena e dê Play. Clique em Hanna e depois em Trade.

Com uma única opção e Greeting vazio, clicar no NPC abre a loja diretamente.

#Uma loja que abre depois

Dê Conditions à opção Shop, por exemplo uma QuestCondition em "Help Hanna" com Done, e ligue Show When Locked para que os jogadores vejam "Trade (Finish Help Hanna first)" acinzentado até lá. Veja Condições e ações.

#Uma loja dentro de uma conversa

Uma opção Shop pode ficar dentro das Options de uma fala de diálogo, para que a loja abra depois de um pouco de conversa.

#Uma loja em outra moeda

Defina Currency como uma moeda do seu jogo, por exemplo fichas de uma missão. O preço fica nessa moeda; vender continua pagando ouro. Veja Moedas.

#Um jogador e MMO

As regras são as mesmas. No MMO, o servidor de mapa confere cada compra e venda; o cliente só pede. O estoque vive no servidor de mapa, então recomeça quando esse servidor de mapa reinicia.

#Para programadores

PlayerInteraction.ServerBuy, ServerSell e ServerBuyBack são virtuais: sobrescreva-os para mudar preços (um desconto para uma guilda, um preço por reputação) ou adicionar regras. ShopWindow.Describe transforma códigos de erro em texto; sobrescreva-o para traduzi-los. Veja Sobrescrever o comportamento do kit.

#Erros comuns

  • Os jogadores não conseguem vender nada. Players Sell To Npcs está desligado em Game Settings, que é o padrão. Ligue-o, ou mantenha-o desligado de propósito e direcione os jogadores para o mercado e a forja.
  • Um item custa quatro vezes o que você esperava. O Price da entrada é 0 e o item não tem Buy Price, então usa quatro vezes o preço de venda.
  • O estoque nunca se reabastece. Restock Minutes é 0.
  • Erro do Project Check sobre moeda premium. A loja cobra em uma moeda premium. Use a loja do jogo para isso.
