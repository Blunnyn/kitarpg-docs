Monstros

Um monstro é um asset MonsterData no Game Database mais um prefab que é o seu corpo no mundo. Esta página cobre todos os campos de um monstro, o assistente que cria um a partir de qualquer modelo 3D, os spawners de monstros, como o servidor executa o comportamento de um monstro e como os monstros funcionam no modo de um jogador e no MMO.

#O que é um monstro

Um monstro tem duas partes:

  • Os dados (MonsterData, no Game Database em World > Monsters). Dizem o que o monstro é: nível, stats, ataques, habilidades, comportamento, categoria, recompensas e tempo para reaparecer. Todas as cópias desse monstro no mundo usam o mesmo asset de dados.
  • O prefab (MonsterData.prefab). É o corpo: o modelo, a rede, um agente de NavMesh, um colisor de clique, o componente Monster, as animações e a placa com o nome. O assistente o monta para você.

Os monstros aparecem no mundo por um Monster Spawner em uma cena de mapa, um gatilho do mundo, uma fase de chefe (como reforços), uma habilidade de invocação ou o comando de GM /spawn.

Chefes e elites são monstros com outra categoria. Os campos extras deles estão na página Chefes. O que um monstro deixa cair é uma tabela de saque.

#Onde fica no editor

Abra a janela KitARPG (KitARPG > Open KitARPG, Ctrl/Cmd+Shift+K), vá para Game Database e escolha Monsters no grupo World. A lista mostra cada monstro com seu ícone. Escolher um abre o cartão dele à direita, com os campos agrupados em cartões por seção.

No fim da lista há dois botões:

Botão O que faz
+ New monster Abre o assistente de quatro passos no painel direito. Cria os dados e o prefab a partir de um modelo 3D.
Blank monster data Cria só o asset MonsterData, com os valores padrão e sem prefab. Use quando você já tem um prefab de monstro.

Você também pode criar o asset pela janela Project com Create > KitARPG > Monster. Um asset criado assim não está no banco de dados até você adicioná-lo à lista monsters.

#Criar um monstro a partir de um modelo 3D

O assistente (+ New monster) tem quatro passos: Model, Combat, Animations e Create. Next fica desativado enquanto um passo tem um problema, e o problema aparece escrito acima do botão.

#Passo 1: Model

  1. Arraste um FBX ou um prefab para o campo do modelo. Uma prévia o mostra.
  2. A linha de estado embaixo diz Animated quando o modelo tem um Animator, ou No Animator quando não tem.
    • Animated: você escolhe os clipes dele no passo Animations.
    • No Animator: o prefab recebe um componente MonsterBody. O monstro dá pulinhos ao se mover, respira quando está parado, se inclina nos ataques, pisca quando é atingido, encolhe e some quando morre e cresce de novo saindo do chão quando reaparece. Os slimes, cogumelos e monstros do vazio do exemplo funcionam assim. Os ataques continuam acertando no tempo certo.
  3. Digite o Display name. Ele é preenchido com o nome do modelo na primeira vez. A linha embaixo mostra o id gerado a partir dele, por exemplo Cave Bat vira cave_bat.

O id precisa ser único entre os monstros. Se outro monstro já o tem, o passo avisa.

#Passo 2: Combat

  1. Start from a monster copia tudo o que outro monstro tem: stats, habilidades, resistências, fases, saque e o resto. Deixe em Nothing, start from the defaults para um monstro novo.

  2. Defina os números em How it fights:

    Campo O que faz Padrão
    Level O nível do monstro. A experiência cai para jogadores mais de 3 níveis acima dele. 1
    Rank Normal, Elite ou Boss. Elites e chefes ganham uma moldura na placa; chefes, uma barra no alto da tela. Normal
    Health Vida máxima. 50
    Damage Dano mínimo a máximo do ataque básico e seu elemento. Elemento vazio usa o elemento padrão do banco de dados. 1 a 3
    Attack range (m) Cerca de 1,4 para corpo a corpo; mais para monstros que atiram. 1,4
    Attacks per second Com que frequência ele ataca. 0,8
    Move speed Metros por segundo. 3
    Aggression Passive, Aggressive ou Pack (veja Comportamento). Aggressive

  3. Em Rewards, defina Experience, a Loot table (vazia não deixa nada; as tabelas são criadas em Items > Loot) e Respawn seconds.

#Passo 3: Animations

Só para modelos com um Animator. Sem um, o passo diz que não há nada para escolher.

  1. Start from a monster copia os clipes e os tempos de golpe de outro monstro animado. Os clipes que você escolher abaixo substituem esses.

  2. Escolha os clipes. Os vazios são ignorados: sem Hit o monstro não recua, sem Death ele não cai.

    Clipe Usado para
    Idle Ficar parado
    Walk Mover-se
    Hit Receber um golpe
    Death Morrer
    Attack O ataque básico

  3. Com um clipe de ataque, Hit lands at diz quando o dano acerta, de 0 (início do clipe) a 1 (fim). O servidor espera esse momento antes de aplicar o golpe.

#Passo 4: Create

  1. Prefab folder é, por padrão, uma pasta Prefabs ao lado da pasta do seu banco de dados. Precisa estar dentro de Assets. O caminho completo do prefab aparece embaixo; se já existe um prefab ali, mude o nome ou a pasta.
  2. Deixe Render its bestiary icon ligado para renderizar um retrato para o bestiário.
  3. What will be made lista os dados, o prefab e a entrada no banco de dados.
  4. Pressione Create monster.

O asset de dados vai para uma pasta Monsters ao lado do banco de dados, entra na lista monsters do banco de dados e abre no Game Database. O prefab recebe:

  • NetworkIdentity e um transform de rede
  • NavMeshAgent, dimensionado a partir do modelo (desligado nos clientes; só o servidor move os monstros)
  • CapsuleCollider, a área em que os jogadores clicam
  • Monster, com os FighterStatus, FighterMotion e CombatRelay de que ele precisa
  • CharacterAnimations com os clipes que você escolheu
  • MonsterBody quando o modelo não tem Animator
  • MonsterPlate, o nome, o nível e a vida sobre a cabeça

O network manager registra sozinho todos os prefabs de monstro do banco de dados. Você não os adiciona aos prefabs instanciáveis do Mirror.

Dica

Para dar a um monstro um ataque à distância, aumente Attack range e dê aos attackEffects dele um projétil no Game Database. A animação fica no prefab; o projétil e os efeitos ficam nos dados.

#Todos os campos de um monstro

O cartão do Game Database mostra estes campos. O nome, a descrição e o ícone vêm de GameData, a base de todo asset do banco de dados.

#Identidade

Campo O que faz Padrão
Id (id) Salvo com os personagens e enviado pela rede. Preenchido uma vez a partir do nome do arquivo e depois mantido. Mudá-lo quebra os salvamentos e as missões que usam este monstro. Do nome do arquivo
Display Name (displayName) Nome mostrado no jogo. Vazio usa o nome do asset. Vazio
Description (description) Mostrada no bestiário. Vazio
Icon (icon) Retrato para o bestiário e os objetivos de missão. KitARPG > Render Missing Monster Icons renderiza os que faltam. Nenhum

#Corpo e stats

Campo O que faz Padrão
Prefab (prefab) O corpo no mundo. Precisa de um componente Monster. Project Check aponta um monstro sem prefab, ou com um prefab sem Monster. Nenhum
Level (level) O nível dele, mostrado na placa. Também usado para a experiência que um jogador ganha (veja Experiência). 1
Stats (stats) Vida e mana máximas, regeneração, poder, chance e dano crítico, cura, velocidade de ataque, velocidade de movimento e o resto dos stats. 50 de vida, 3 de velocidade de movimento
Modifiers (modifiers) Dano de elemento e resistências além dos stats, fixos e em porcentagem. O slime do exemplo resiste 30 % a água e recebe 20 % a mais de ar. Vazio
Status Defense (statusDefense) Estados que ele ignora ou que duram menos nele: marcas de imunidade (atordoamento, enraizamento, silêncio...), etiquetas imunes, estados imunes e resistências em porcentagem inteira (100 é imune). Só os estados nocivos vindos de outros são bloqueados. Veja Estados e buffs. Vazio

#Comportamento e ataque

Campo O que faz Padrão
Aggression (aggression) Passive, Aggressive ou Pack. Aggressive
Sight Range (sightRange) Metros a partir dos quais ele nota os jogadores. Monstros Pack também chamam outros dentro desse alcance. 8
Leash Range (leashRange) Até que distância de casa ele segue um jogador antes de desistir e voltar. 18
Wander Radius (wanderRadius) Metros que ele anda ao redor de casa enquanto não há ninguém por perto. 4
Attack Range (attackRange) Metros a partir dos quais ele acerta. 1,4
Attacks Per Second (attacksPerSecond) Ritmo de ataque base. O stat de velocidade de ataque dele o altera. 0,8
Attack Effects (attackEffects) Projétil e efeitos do ataque básico: um efeito no atacante a cada golpe, um projétil e um efeito em quem é atingido (vazio usa o do elemento). A animação fica no prefab. Vazio
Attack (attack) Faixas do ataque básico, uma por elemento, cada uma com mínimo e máximo. Várias entradas fazem um ataque misto, como 6 a 10 de terra mais 2 a 4 de fogo. Uma entrada, 1 a 3, elemento padrão
Skills (skills) Habilidades que ele lança (veja Habilidades). Vazio

#Categoria

Campo O que faz Padrão
Rank (rank) Normal, Elite ou Boss. Normal
Phases (phases) Só chefes. Veja Chefes. Vazio
Enrage Seconds (enrageSeconds) Só chefes. Segundos de luta até ele ficar furioso; 0 nunca. 0
Enrage Status (enrageStatus) Só chefes. Aplicado em si mesmo quando fica furioso. Nenhum
Enrage Shout (enrageShout) Só chefes. Dito quando fica furioso. "Enough!"

#Recompensas e reaparecimento

Campo O que faz Padrão
Experience (experience) Experiência base por matá-lo. 10
Loot (loot) Sua tabela de saque. Vários monstros podem compartilhar uma. Vazio não deixa nada. Nenhum
Respawn Seconds (respawnSeconds) Segundos até ele voltar depois de morrer. 30
In Bestiary (inBestiary) Listado no bestiário. Desligue para ajudantes como coletores ou invocações que ninguém caça. Ligado

#No prefab: o componente Monster

Estes ficam no componente Monster do prefab, não nos dados.

Campo O que faz Padrão
Think Interval (thinkInterval) Segundos entre decisões. Os monstros são distribuídos para que um mapa cheio deles não pense todo no mesmo frame. 0,2
Corpse Seconds (corpseSeconds) Segundos que o corpo fica onde caiu antes de ser levado para casa, fora de vista, para esperar o reaparecimento. 1

O componente MonsterBody (modelos sem Animator) tem Model (model, o filho que se move; vazio usa o primeiro filho), Hop Height (hopHeight, 0,08), Hops Per Meter (hopsPerMeter, 2,5) e Hit Color (hitColor, um brilho vermelho claro).

#Categorias

Categoria O que muda
Normal Nada de especial.
Elite O nome na placa fica dourado, com uma etiqueta "Elite". O bestiário e o mapa do mundo o marcam como elite. Os números dele são os que você der: a categoria em si não soma stats.
Boss Uma barra no alto da tela enquanto ele luta, fases, um cronômetro de fúria e uma restauração completa quando ele volta para casa. Veja Chefes.

#Comportamento

O servidor executa um pequeno cérebro para cada monstro, umas cinco vezes por segundo:

  1. Agressividade.
    • Passive: nunca começa uma luta. Revida quando é atingido.
    • Aggressive: ataca o inimigo mais próximo que consegue ver dentro de Sight Range.
    • Pack: como Passive, mas quando um é atingido, todo monstro do mesmo tipo dentro do Sight Range dele que não tem alvo entra na luta. Os cogumelos do exemplo funcionam assim.
  2. Visão. Ele só nota os jogadores que consegue ver, pela regra de linha de visão do jogo (Game Settings > Combat > Line Of Sight). Atrás de uma parede, ele dá a volta em vez de acertar através dela. Jogadores invisíveis não são notados.
  3. Ameaça. O dano causado a ele e a cura dada a quem ele enfrenta (Heal Threat em Game Settings) o deixam bravo com alguém. Outro lutador ganha a atenção dele quando sua ameaça passa a do alvo atual multiplicada por Threat Switch (1,1 por padrão).
  4. Coleira. Se ele se afasta mais que Leash Range de casa, desiste: esquece o alvo e a ameaça, cura a vida toda e volta para casa.
  5. Perambular. Sem ninguém para enfrentar, ele anda até um ponto aleatório dentro de Wander Radius de casa a cada 3 a 8 segundos.
  6. Dormir. Com Monsters Sleep Unseen ligado (Game Settings, Combat), um monstro que nenhum jogador consegue ver para de pensar até alguém chegar perto. Isso economiza tempo do servidor em mapas grandes.

#Habilidades

Um monstro usa a primeira habilidade da lista Skills que esteja pronta e alcance o alvo, e depois espera o intervalo de ataque. Os monstros lançam no grau 1, instantaneamente, com uma recarga de pelo menos 1 segundo. Habilidades passivas são ignoradas. Uma habilidade com área mirada em si mesmo espera até o alvo estar dentro dessa área. As habilidades são criadas em Combat > Skills; veja Habilidades.

#Morte e reaparecimento

  1. A morte vai para o jogador que causou mais dano, não para o último golpe.
  2. Esse jogador ganha a experiência (dividida com os membros do grupo por perto) e o saque. Veja Saque.
  3. O corpo fica ali por Corpse Seconds e depois é levado para casa fora de vista.
  4. Depois de Respawn Seconds, ele volta com a vida toda no seu ponto de origem.

Os monstros trazidos por um evento (gatilhos do mundo, /spawn) não voltam: somem 4 segundos depois de morrer. As invocações somem 2 segundos depois de morrer e não dão recompensas.

#Experiência

A experiência que um jogador ganha é a Experience do monstro, ajustada pela diferença de nível: completa até 3 níveis acima do monstro, depois 20 % a menos por nível extra, nunca abaixo de 10 %. Um jogador de nível 10 que mata um monstro de nível 5 (5 níveis acima) ganha 60 %. Depois aplicam-se o stat Experience Gain do jogador e a taxa de experiência do servidor. Em um grupo, os membros por perto a dividem. Veja Combate e Amigos e grupos.

#Spawners de monstros

Um Monster Spawner mantém uma quantidade de um monstro em um círculo em um mapa.

#Campos

Campo O que faz Padrão
Monster (monster) O monstro que ele cria. Nenhum
Count (count) Quantos ele mantém. 5
Radius (radius) Metros ao redor do spawner onde eles aparecem. Cada um cai no NavMesh a até 3 m do seu ponto aleatório. 8
When (when) Always, Day (fora de dia, some à noite) ou Night. Usa o relógio do jogo; veja Dia e noite. Always

A Scene view desenha o raio como um círculo vermelho.

#Configurar um spawner

  1. Abra a cena do mapa.
  2. GameObject > Create Empty e dê um nome, por exemplo Bat Spawner.
  3. Add Component > Monster Spawner.
  4. Escolha o Monster, defina Count e Radius e mova o objeto para onde os monstros devem viver. Mantenha-o no NavMesh e longe do SpawnPoint, para que os jogadores que voltam depois de morrer fiquem seguros.
  5. Salve a cena.
  6. No Game Database, no cartão do mapa, pressione Read from scene para que o bestiário liste o monstro neste mapa. Veja Mapas.

#Como funciona

  • Ele só faz algo no servidor. Nos clientes, é um objeto vazio.
  • Ele faz surgir toda a quantidade uma vez, quando o mapa começa. Depois, cada monstro reaparece sozinho no ponto onde surgiu pela primeira vez, após o seu Respawn Seconds. O spawner não completa a quantidade.
  • Com When em Day ou Night, ele confere a cada 2 segundos. Quando chega a hora deles, a quantidade completa aparece. Quando ela acaba, eles vão embora, mesmo no meio de uma luta.
  • Um spawner cujo monstro não tem prefab, ou tem um prefab sem componente Monster, registra um erro e não faz nada. Project Check avisa sobre spawners sem monstro.
Dica

Um chefe costuma ser um spawner com Count 1 e Radius 0, para ficar sempre no mesmo lugar. Dê a ele também um Wander Radius pequeno, como o Mushroom King do exemplo tem (1,5).

#Um jogador e MMO

  • Um jogador: o jogo é o host. Os monstros rodam na mesma máquina que o jogador, com o mesmo cérebro.
  • MMO: cada mapa roda no seu próprio servidor de mapa. Os monstros existem só nesse servidor; os clientes recebem a posição, a vida e as animações deles. Um cliente não pode alterar um monstro.
  • Mapas instanciados: cada cópia de uma masmorra tem os próprios monstros, criados pelos spawners da própria cópia. A primeira cena que o servidor de mapa carrega é um modelo cujos spawners ficam parados. Veja Masmorras.

#Testar monstros

Com comandos de GM (sempre permitidos no modo de um jogador quando Single Player Commands está ligado):

  • /spawn monster_id 3 traz três na sua frente. Eles não voltam.
  • /killall 20 mata os monstros a até 20 m; eles dão suas recompensas.
  • /god faz você não receber dano enquanto observa uma luta.

Veja Comandos de GM.

#Erros comuns

  • O monstro não aparece. O spawner está fora do NavMesh, o monstro não tem prefab ou a cena não é a que o mapa usa.
  • Ele atravessa paredes para acertar. A linha de visão está em Off, ou as paredes não são buracos no NavMesh (modo NavMesh) ou não estão em uma camada que bloqueia a visão (modo Colliders).
  • Ele nunca ataca. Aggression é Passive, ou Sight Range é menor que a distância em que os jogadores passam.
  • Ele volta correndo com a vida cheia no meio da luta. Ele passou do Leash Range. Aumente-o ou afaste o spawner de onde os jogadores o puxam.
  • Uma missão salva ou uma entrada do bestiário quebrou depois de renomear. Você mudou o Id. Renomeie o nome de exibição em vez disso.
