Skills

Esta página ainda não foi traduzida. Ela aparece em inglês.

A skill is a target, an area and a list of effects: damage, heals, buffs, statuses, pushes, revives and summons, plus how the caster moves, whether it bounces, stays on the ground or is channeled. This page covers every field of a skill, every skill effect, how players learn and cast skills, and how to build a skill with an area and a status step by step.

#What a skill is

Every skill answers four questions:

  • Who or where it aims at: the caster, an enemy, an ally, or a point on the ground.
  • What area it covers: one target, a circle, a cone or a line.
  • What it does: a list of effects. Harmful effects land on the enemies it reaches; friendly ones on the caster and the allies it reaches. So one skill can hurt the enemies around you and buff your party at the same time.
  • How it plays: cast time, animation, projectile, movement, bounces, ground zone, channel.

Every number that can grow with rank is a level value: Base Value at rank 1 and Per Level added for each rank after it. Fire Bolt's damage at rank 3 with min 12 and 5 per level is 12 + 5 × 2 = 22.

Areas are abstract shapes. Real-time modes read sizes in meters.

Players use skills; monsters do too, from Skills on their monster data (always at rank 1, with no cast time, when ready and in reach, sharing the turn of their basic attack). See Monsters.

#Where skills are

Game Database > Combat > Skills lists every skill. Create one there (+ New skill) or with Create > KitARPG > Skill. A skill takes part in the game when a class lists it, an item or NPC teaches or casts it, or a monster uses it.

In the game, the Skills window (K) lists the class's skills first and then the ones learned elsewhere, each with its icon (drag it to the hotbar), rank, the requirement it is missing, and + to raise it. A badge on the skills button shows unspent points. The skill card (tooltip) shows cost, cooldown, cast time, range, area, weapons needed and every effect at the current rank.

#Fields

Besides Id, Display Name, Description and Icon:

#Basics

Field What it does Default
Max Level (maxLevel) Highest rank. A class can set a lower limit for itself. 5
Passive (passive) Never cast. Its Stat Buff effects count as permanent stat sources while the skill is learned. Off
Target (target) Self, Enemy, Ally or Ground. See Targets and areas. Enemy
Mana Cost (manaCost) Mana per cast, per rank. 10, +2 per rank
Cooldown (cooldown) Seconds before it can be cast again, per rank. 5
Cast Time (castTime) Seconds before the effects land, per rank. 0 is instant. 0
Range (range) Meters from the caster to the target or point. Ignored for Self. 8
Targets Dead (targetsDead) Reaches fallen allies only, for revives. Off

#Area

Field What it does Default
Shape (shape) Single, Circle, Cone or Line. Single
Size (size) Circle radius, cone length or line length, in meters, per rank. 3
Width (width) Cone angle in degrees, or line width in meters. 60

#Requirements

Field What it does Default
Weapons (weapons) Only castable with one of these weapon types in the main hand. Empty means any, or none. Empty
Levels Per Rank (levelsPerRank) Character levels between one rank and the next, counted from the level the skill unlocks. 2
Requires (requires) Skills that must be known at a rank before this one can be learned or raised, from any source: Skill and Rank. Empty

#Learning outside a class

Field What it does Default
Teachable (teachable) Scrolls, books and trainers can teach it to characters whose class doesn't have it. On
Learnable By (learnableBy) Classes a scroll or trainer can teach it to. Empty is any class. Empty
Learn Level (learnLevel) Character level needed to learn it from a scroll or trainer. Later ranks follow Levels Per Rank. 1

#Effects

Field What it does Default
Effects (effects) What the skill does, in order. Add an entry with +, then Pick a type. See Skill effects. Empty

#Movement

Field What it does Default
Movement (movement) How the caster gets to the target or point before the effects land: None, Teleport (appears there at once), Dash (rushes along the ground; walls stop it) or Leap (jumps in an arc and lands there). The effects land around where the caster arrives. None
Move Speed (moveSpeed) Meters per second of a dash or leap. 16
Leap Height (leapHeight) Meters a leap rises at its highest. 1.6
Stop Short (stopShort) Meters short of a target the caster stops, so it lands beside it. 1

A rooted caster can't dash or leap but can teleport. Teleports and leaps land on the closest walkable point.

#Bounces

Field What it does Default
Bounces (bounces) Times it jumps from the first target to the next closest one, like chain lightning or a ricochet. Healing skills jump between allies. Each jump only goes to someone in sight. 0
Bounce Range (bounceRange) Meters a bounce reaches. 5
Bounce Keep (bounceKeep) Share of the damage and healing kept on each jump, from 0 to 1. 0.8

#Zone

Field What it does Default
Zone Time (zoneTime) Seconds the area stays on the ground, landing again on every tick, per rank. 0 lands once. 0
Zone Tick (zoneTick) Seconds between the zone's landings. 1
Zone Effect (zoneEffect) On the ground while the zone lasts, sized to it. Empty shows the area effect instead. On the floor

#Channel

Field What it does Default
Channel Time (channelTime) Seconds the effects keep landing after the cast, with the cast clip looping, per rank. 0 lands them once. 0
Channel Ticks (channelTicks) Times the effects land over the channel. 3

#Look

Field What it does Default
Use Weapon Attack (useWeaponAttack) The caster plays its weapon's attack animation and the weapon's projectile, like a stronger basic attack, and spends ammo if the weapon uses it. Otherwise each character's skill animation plays. Off
Cast Effect (castEffect) On the caster while casting or channeling. On the floor, follows
Launch Effect (launchEffect) On the caster at each hit frame of its animation. On the right hand
Projectile (projectile) Flies to the target or point; the effects land when it arrives. Prefab, From (the socket it leaves from) and Speed (meters per second). None, from the right hand, 20
Area Effect (areaEffect) Where the area lands, sized to it. Without one, a flat outline of the area in the element's color is drawn. On the floor
Hit Effect (hitEffect) On each target. Empty uses the element's. None

Every effect spawn has Prefab, Socket (Body, Floor, Head, RightHand, LeftHand), Follow (moves with the character), Lifetime (0 uses the length of its particles) and Tint (colored like the element, on by default).

Which animation plays is set per character, in Character Animations: a default cast and use, and one per skill. See Animations.

#Targets and areas

#Targets

Target Aimed at Who the effects reach with Single shape
Self Nothing: it centers on the caster. Friendly effects on the caster.
Enemy An enemy. Harmful effects on the target; friendly effects on the caster.
Ally An ally or yourself. Friendly effects on the ally, or on the caster if the target isn't a living ally.
Ground A point on the ground. Everyone within 1 meter of the point.

Self and Ally skills are friendly; Enemy and Ground skills are hostile. Players aim hostile skills by clicking an enemy or the ground. With a target, the server walks the caster into range first (top-down mode).

#Shapes

Shape Where Who it reaches
Single The target. See the table above.
Circle On the caster for Self skills, on the aimed point otherwise. Everyone within Size meters of the center.
Cone From the caster toward the aim. Everyone within Size meters and within Width degrees of the aim direction.
Line From the caster toward the aim. Everyone along the first Size meters, within Width ÷ 2 meters of the line.

Distances are measured flat, ignoring height. Whoever the center of the area can't see (behind a wall) is left out; see Combat for line of sight.

In an area, harmful effects land on every enemy and friendly effects on every ally reached, the caster included when inside.

A Line with a projectile goes through everything in its path: each target is hit when the projectile reaches it ("Goes through everything in its path" on the card).

#Aiming

When a player presses a skill key, the area preview shows on the ground (or a ring on the enemy under the pointer); a click or the same key casts it. Settings > Controls has an option to cast at once instead. How each control mode aims is on Control modes.

#Skill effects

Effects are picked from a menu: + on Effects, then Pick a type. Your own effect classes appear there too (see Skill effects in code).

Each effect is either harmful (lands on enemies) or friendly (lands on the caster and allies). Effects that put buffs, statuses, pushes, revives or summons land once per cast, on the first hit; damage and healing land on every hit of the animation, split between hits.

#Damage

Harmful. Deals damage of one element, optionally adding the caster's weapon.

Field What it does Default
Element (element) The element. Empty uses the default element. None
Min (min) Lowest roll, per rank. 8, +4 per rank
Max (max) Highest roll, per rank. 12, +5 per rank
Weapon Scale (weaponScale) Adds the weapon's damage rolls, each multiplied by this, per rank. 0 ignores the weapon. 0.8 adds 80% of each weapon roll, in the weapon's own elements. 0

The rolls go through the same formula as a basic attack: element damage, power, resistances, critical. The card shows "12 to 18 Fire damage" and "+80% of weapon damage".

#Heal

Friendly. Restores health.

Field What it does Default
Amount (amount) Health restored, per rank, before the caster's heals and heal bonus. 20, +10 per rank

Final heal = (amount + caster's Heals) × (1 + caster's Heal bonus), rounded.

#Stat Buff

Friendly, or harmful when it is a debuff. Changes stats for a while. Use it for quick stat buffs that don't need a status asset.

Field What it does Default
Modifiers (modifiers) A full modifier bundle. The same at every rank. Empty
Duration (duration) Seconds, per rank. 10
Debuff (debuff) Lowers the stats instead (every number turned negative), on enemies. Off

The buff's id is the skill's id: casting again replaces it. On a passive skill, the modifiers count for as long as the skill is learned and Duration is ignored.

#Apply Status

Harmful or friendly, depending on the status. Puts a status on each target.

Field What it does Default
Status (status) The status. Its Harmful setting decides who it lands on. None
Duration (duration) Seconds, per rank. 5
Chance (chance) Chance to land on each target, from 0 to 1, per rank. 1
Stacks (stacks) Stacks added each time it lands. 1

The status lands at the skill's rank, so the status's own level values (damage per tick, shield) grow with the skill. The target's immunities and resistances apply.

#Remove Status

Takes statuses off: debuffs from allies (cleanse) or buffs from enemies (dispel).

Field What it does Default
Dispel (dispel) Off: cleanses debuffs from allies (friendly). On: dispels buffs from enemies (harmful). Off
Only (only) Only these statuses. Empty takes any removable one. Empty
With Flags (withFlags) Only statuses that stop the holder like this, such as Stun and Root. None takes any. None
Count (count) How many come off per target, newest first. 0 takes them all. 0

Statuses with Removable off never come off.

#Knockback

Harmful. Pushes each target away, or pulls it in with a negative distance. Walls stop it.

Field What it does Default
Distance (distance) Meters, per rank. Negative pulls toward the caster, stopping in front of it. 3
Speed (speed) Meters per second. 14
From Point (fromPoint) Away from where the skill landed instead of from the caster, for blasts on the ground. Off

A push cuts off what the target was doing. Unstoppable targets can't be moved.

#Revive

Friendly. Brings fallen allies back. Use it on a skill with Targets Dead on.

Field What it does Default
Health (health) Share of health they come back with, from 0 to 1, per rank. 0.3, +0.1 per rank
Mana (mana) Share of mana they come back with, from 0 to 1, per rank. 0.2

A revived player loses no experience for that death.

#Summon

Lands once per cast on the caster, whoever the skill reaches. Calls monsters that fight for the caster around where the skill lands.

Field What it does Default
Monster (monster) The monster summoned. None
Count (count) How many each cast calls. 1
Max (max) How many of this skill's summons the caster can have at once. The oldest goes when a new one comes. 2
Duration (duration) Seconds they last, per rank. 0 lasts until they die or the caster leaves. 30, +5 per rank
Level (level) Their level, per rank. 0 uses the monster's own. 0

Summons follow their owner and attack nearby enemies. Their kills count for the owner; they give no loot. They go away when their time ends, when they die, or when the owner dies or leaves.

#How a cast plays out

  1. The player picks a skill and a target or point. The client sends the request; the server decides everything after.
  2. The server checks: the skill is learned (at its effective rank), the caster isn't already casting, the cooldown is over, there is enough mana, the right weapon type is held, there is a valid target, it is in range (with 0.6 meters of margin) and in sight, and no status stops casting (Stun, Silence).
  3. Cast. With a Cast Time, the cast clip loops and Cast Effect shows. Moving, attacking or picking something up cuts the cast and costs nothing. A stun or silence cuts it too.
  4. Mana and cooldown are charged.
  5. Movement, if any: teleport, dash or leap.
  6. Use. The use animation plays. At each hit frame, Launch Effect shows and the Projectile is launched.
  7. Effects land at each hit frame, or when the projectile arrives: damage and heals split between hits, buffs and statuses on the first. With a Channel Time, they land Channel Ticks times over it. With a Zone Time, the area stays and lands every Zone Tick. With Bounces, it jumps on.
  8. Area Effect and Hit Effect show.

Attacking or casting ends statuses with Ends On Action, like Invisible and the arrival protection.

#Learning skills

#With skill points

  • A character earns Skill Points Per Level (from its class) for each level after the first, plus points from items like the Scroll of Insight and quest rewards.
  • Class skills with an unlock level of 1 start at rank 1 for free.
  • Pressing + in the Skills window spends one point to raise a skill by one rank.
  • Rank n of a class skill needs character level unlockLevel + (n − 1) × levelsPerRank.
  • The rank can't pass the class's Max Level for it, or the skill's own.
  • Every skill in Requires must be known at its rank.
  • Raising a skill learned outside the class also costs points, once known.

Free points are never stored: they are worked out as earned minus spent.

#Learning skills outside the class

Characters can learn skills their class doesn't have, from three sources:

  • Books and scrolls: a consumable with the Learn Skill item effect. See Items.
  • Trainers: a Skill Trainer option on an NPC, with Skill, Rank (a known skill below it is raised to it) and Price in gold (default 100). The option hides from players who already know the skill at that rank or whose class can't learn it. See NPCs.
  • Quest rewards: a quest can teach a skill. See Quests.

All three follow the skill's rules: Teachable on, the class in Learnable By (or the list empty), the character's level at least Learn Level (plus Levels Per Rank for each rank after the first), and every skill in Requires. Class skills can always be taught to their class.

Ranks taught this way cost no points. After that, the skill is raised with points like the others. A new active skill goes to the first free hotbar key.

The sample teaches three skills no class has: First Aid (any class, level 3, by book), Whirlwind (warriors only, level 6, needs Cleave rank 2; by book or trainer) and Haste (any class, level 4, taught by Sela in Town for 200 gold).

#Ranks from gear and effects

Any modifier bundle (gear, a set bonus, a gem, a status) can add ranks to one skill (Skills) or to every skill (All Skills). These ranks:

  • Only apply to skills the character has learned.
  • Raise the rank the skill is cast at (its effective rank): damage, cost, cooldown, size, everything per rank.
  • Don't change the learned rank, so learning and requirements still use what was learned.

In the sample, 3 pieces of the Knight, Ranger or Wizard set raise Cleave, Power Shot or Fire Bolt by one rank, and the full Noble set raises every skill by one.

#The hotbar

The hotbar has 10 keys (1 to 9 and 0), each holding a skill or an item. Drag skills from the Skills window and items from the bag; drag between keys to move, or off the bar to clear. New characters start with their learned skills and the class's start consumables on the bar. The server checks each key: the slot exists, the item exists, the skill is known. Active buffs show with their seconds left over the bar, and keys show a radial shade while cooling down.

#Make a skill with an area and a status

This example makes Frost Wave: a mage skill that hits every enemy in a cone in front of the caster with water damage and slows them, and leaves a frost zone for two seconds.

  1. Open Game Database > Combat > Skills and press + New skill. Type frost_wave in Id and Frost Wave in Display Name. Write a Description and set an Icon.
  2. Basics. Max Level 5. Target Enemy. Mana Cost 20 base, 3 per level. Cooldown 8 base, -0.5 per level (it gets faster with rank). Cast Time 0.4. Range 8.
  3. Area. Shape Cone, Size 5 base, 0.5 per level, Width 70 degrees.
  4. Requirements. Leave Weapons empty so any weapon works. Levels Per Rank 2.
  5. Effects. Press + and Pick a type > Damage: Element Water, Min 10 base 4 per level, Max 15 base 5 per level, Weapon Scale 0.
  6. Press + again and pick Apply Status: Status Slowed, Duration 3 base 0.5 per level, Chance 1, Stacks 1.
  7. Zone. Zone Time 2, Zone Tick 1. The cone stays where it was cast and lands again every second for two seconds. Each landing applies every effect again, so enemies that stay in it take the damage again and their Slowed is renewed.
  8. Look. Cast Effect: the sample's cast aura. Area Effect: the sample's area burst, or leave it empty for the flat outline in Water's color.
  9. Give it to the class: open Classes > Mage, add Frost Wave to Skills with Unlock Level 8.
  10. Optional: in the mage's player models, open Character Animations > Skills, add Frost Wave with its own Use clip and hit timing. Without it, the default skill animation plays.
  11. Play a mage at level 8 or higher (use /level as a GM), learn it in the Skills window (K), put it on the hotbar and cast it at a group of slimes. The card shows "Cone of 5 m, 70°", "Stays 2s, hitting every 1s", the damage and "Slowed for 3s".

#A friendly skill in a circle

War Cry in the sample: Target Self, Shape Circle, Size 6, one Stat Buff effect (+15% power, 10 seconds +2 per rank). Every ally within 6 meters, the caster included, gets the buff.

#A ground skill that is channeled

Flame Burst in the sample: Target Ground, Shape Circle, Size 3, Range 10, Cast Time 0.8, one Damage effect (fire, 6 to 9), Channel Time 1.5, Channel Ticks 3: the fire lands three times over a second and a half where you point.

#Single player and MMO

Skills run on the server in both modes: the map server in MMO, the game itself in single player. The client only sends which skill and which target or point; the ground point is limited to the skill's reach.

  • Saving. Learned ranks (and which were taught for free) and the hotbar are saved with the character: the Skills and Hotbar columns in MMO, inside the character's JSON in single player. Extra skill points from items go in the character's Extra data.
  • Cooldowns travel to the owner once, as the time they end, not every second.
  • Catalog. In MMO, Login copies every skill (id, name, max rank, passive, classes that have it) into the skills table from gamedata.json. Play & Servers exports it when it starts the services; use KitARPG > Export Game Data for Services for builds.

#Tips

  • Use negative Per Level on Cooldown to make ranks feel rewarding without raising damage forever.
  • Put the stun or slow in a status, not in the skill, so immunities and resistances can name it.
  • Mix effects: a damage effect and a friendly Stat Buff on the same Enemy skill hurts the target and buffs the caster.

#Common mistakes

  • A skill does nothing to enemies. Its only effect is friendly (Heal, a Stat Buff without Debuff, a buff status), so it lands on the caster.
  • "No target" on a Ground skill. The control mode needs a target for hostile skills; aim at an enemy or check Control modes.
  • A skill can't be cast with a bow. Weapons lists other types.
  • Gear gives +1 to a skill and nothing changes. The character hasn't learned the skill.
  • A passive skill does nothing. Passives only apply their Stat Buff effects.
