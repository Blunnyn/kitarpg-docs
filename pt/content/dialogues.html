Dialogues

Esta página ainda não foi traduzida. Ela aparece em inglês.

A dialogue is a conversation with an NPC made of lines the player picks. Each line can run actions (pay, charge, give, take, set a story mark, start a quest), and the NPC answers with new lines, so you build branching talks without code. This page covers the Dialogue option, how branches, conditions and Back lines work, and a step by step branching dialogue.

#What a dialogue is

A dialogue is a tree of Dialogue options (DialogueOption) on an Npc:

  1. The NPC greets the player and shows its top options.
  2. The player picks a Dialogue line. Its actions run.
  3. The NPC answers with the line's Reply and offers the line's own Options.
  4. Those options can be more Dialogue lines, or any other option: a shop, a quest, a teleport, a trigger.

Each line has its own conditions, so different players see different branches: by class, by quest state, by item, by a story mark.

Read NPCs first for the Npc component and the fields every option shares.

#Where it is in the editor

Select the NPC in its scene. In the Npc inspector, press Dialogue under Add option to add a top line. Inside a Dialogue line, its Options list has a type menu next to each entry: pick Dialogue Option for a nested line, or any other kind of option. Conditions and actions lists have type menus too.

#Fields

A Dialogue line has the fields every option has, plus its own.

Field What it does Default
Label (label) What the player picks, like "About the old ruins...". Empty shows "..." (or "Back" with Back To Start). Empty
Required Level (requiredLevel) Hidden from characters below this level. 0
Conditions (conditions) Hidden while one isn't met. Empty
Show When Locked (showWhenLocked) Shown greyed out with the reason while its conditions aren't met, instead of hidden. Off
Reply (reply) What the NPC answers. Empty, with no lines after it, closes the talk. Empty
Actions (actions) Run on picking, before the answer. If one can't, the player is told why and none runs. Empty
Options (options) Lines offered after the answer. Any kind of option. Empty
Back To Start (backToStart) Goes back to the greeting afterwards, like a Back line. Off

When the actions include a cost (Take Item, Charge Currency), the label shows it: "Can you patch me up? (15 Gold)".

#How a line runs

When the player picks a Dialogue line, the server:

  1. Checks the player still stands by the NPC, and that the line is offered to them (level, conditions, module).
  2. Checks every action, then runs them all. If one can't run (not enough gold, a full bag), its reason shows over the player in red and nothing runs.
  3. Then:
    • with Back To Start, shows the greeting and the NPC's top options again;
    • with a Reply or Options, shows the reply and the line's options;
    • with neither, the talk ends.

The server remembers which page each player is on and checks every pick against it. A modified client can't jump to a line it can't reach.

Nesting goes up to 16 levels deep.

#Showing locked lines

A line whose conditions aren't met is hidden. With Show When Locked, it shows greyed out with the reason in brackets, for example "Three spores for two potions? (Needs Mushroom Spore x3)". It can't be picked. Use it to tell players there is more to find.

#Reusing a Back line

A Back line is a Dialogue line with only Back To Start on. You can put the same Back line at the end of several branches.

#Shops and quests inside a branch

A Shop, Quest or any other option can sit inside a line's Options. The NPC's quest mark over its head only counts quests the player can reach through the lines it can pick, so a quest hidden in a locked branch doesn't show a "!".

#Make a branching dialogue

This builds Brann's conversation from the sample: a branch that opens after the player found the old ruins, with a one time tip for warriors and a trade-in.

You need: the Forest's DiscoveryZone with id old_ruins (see Conditions and actions), the items Antidote, Mushroom Spore and Health Potion, and a Warrior class.

#1. The top line

  1. Select Brann's object in the Town scene.
  2. Press Dialogue under Add option.
  3. Label: "About the old ruins...".
  4. Conditions: add Discovered, Zone old_ruins, Place Name "the old ruins".
  5. Show When Locked: on. Players who haven't been there see "About the old ruins... (Find the old ruins first)".
  6. Reply: "Those walls are older than the town. My grandfather swore a king held court there, long before the mushrooms moved in."

#2. A one time tip for warriors

In the top line's Options, add a Dialogue Option:

  1. Label: "Any advice for a warrior?"
  2. Conditions: Class, Classes Warrior; and Flag, Key brann_advice, Compare Equal, Value 0.
  3. Reply: "Keep your shield up and these close. Those spores rot the lungs."
  4. Actions: Give Item Antidote, Amount 2; Set Flag, Key brann_advice (value 1).
  5. Options: add a Back line (a Dialogue Option with Back To Start on).

The flag makes it a one time gift: after it, the line hides for good. Other classes never see it.

#3. A trade-in

In the top line's Options, add another Dialogue Option:

  1. Label: "Three spores for two potions?"
  2. Conditions: Item, Item Mushroom Spore, Count 3. Show When Locked on.
  3. Reply: "Mira pays better, but fine. Don't tell her."
  4. Actions: Take Item Mushroom Spore x3; Give Item Health Potion x2. The label shows "(Mushroom Spore x3)".
  5. Options: a Back line.

If the bag is full, Give Item refuses, so the spores aren't taken either.

#4. A way out

At the end of the top line's Options, add a Back line, so the player can return to Brann's greeting and his shop.

#5. Test it

Press Play and talk to Brann before and after walking into the ruins, with a warrior and another class, with and without 3 spores. /flag brann_advice 0 resets the tip, and /item mushroom_spore 3 gives the spores. See GM commands.

#More patterns

Pattern How
A paid service Actions Charge Currency 15 and Restore, no reply: the sample's Mira heals for 15 gold.
A quest from a conversation Actions Start Quest, or put a Quest option inside the branch.
A choice that changes the story Two lines, each with Set Flag choice to 1 or 2. Later lines and greetings read it with Flag conditions.
A guide Actions Discover a zone and Travel there.
An ambush after a talk Actions Fire Trigger on a trigger for that player. See World triggers.
A different first line per player Greetings on the Npc, each with conditions. See NPCs.

#Single player and MMO

The same in both. In MMO every pick is checked and run on the map server; the client only shows what the server sends.

#Common mistakes

  • The talk closes after a line. The line has no Reply and no Options. Add a reply, or a Back line.
  • A line never shows. Its conditions aren't met. Turn on Show When Locked while testing to see why.
  • The line ran but gave nothing. It did run: check the reason over the player. One action refused, so none ran.
  • A one time line repeats. It has no Set Flag action, or the Flag condition reads a different key.
