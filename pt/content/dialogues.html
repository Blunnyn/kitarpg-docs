Diálogos

Um diálogo é uma conversa com um NPC feita de falas que o jogador escolhe. Cada fala pode executar ações (pagar, cobrar, dar, tirar, definir uma marca de história, iniciar uma missão), e o NPC responde com novas falas, então você monta conversas com ramificações sem código. Esta página cobre a opção Dialogue, como funcionam as ramificações, as condições e as falas de Back, e um passo a passo de um diálogo com ramificações.

#O que é um diálogo

Um diálogo é uma árvore de opções Dialogue (DialogueOption) em um Npc:

  1. O NPC cumprimenta o jogador e mostra suas opções principais.
  2. O jogador escolhe uma fala Dialogue. As ações dela são executadas.
  3. O NPC responde com a Reply da fala e oferece as Options da própria fala.
  4. Essas opções podem ser mais falas Dialogue ou qualquer outra opção: uma loja, uma missão, um teletransporte, um gatilho.

Cada fala tem as próprias condições, então jogadores diferentes veem ramificações diferentes: por classe, por estado de missão, por item, por uma marca de história.

Leia primeiro NPCs para conhecer o componente Npc e os campos que todas as opções compartilham.

#Onde fica no editor

Selecione o NPC na cena dele. No Inspector do Npc, pressione Dialogue em Add option para adicionar uma fala principal. Dentro de uma fala Dialogue, a lista Options tem um menu de tipo ao lado de cada entrada: escolha Dialogue Option para uma fala aninhada, ou qualquer outro tipo de opção. As listas de condições e ações também têm menus de tipo.

#Campos

Uma fala Dialogue tem os campos que toda opção tem, mais os próprios.

Campo O que faz Padrão
Label (label) O que o jogador escolhe, como "About the old ruins...". Vazio mostra "..." (ou "Back" com Back To Start). Vazio
Required Level (requiredLevel) Escondida de personagens abaixo deste nível. 0
Conditions (conditions) Escondida enquanto uma não é cumprida. Vazio
Show When Locked (showWhenLocked) Mostrada acinzentada com o motivo enquanto suas condições não são cumpridas, em vez de escondida. Desligado
Reply (reply) O que o NPC responde. Vazio, sem falas depois, encerra a conversa. Vazio
Actions (actions) Executadas ao escolher, antes da resposta. Se uma não pode, o jogador fica sabendo o motivo e nenhuma é executada. Vazio
Options (options) Falas oferecidas depois da resposta. Qualquer tipo de opção. Vazio
Back To Start (backToStart) Volta ao cumprimento depois, como uma fala de Back. Desligado

Quando as ações incluem um custo (Take Item, Charge Currency), o rótulo o mostra: "Can you patch me up? (15 Gold)".

#Como uma fala é executada

Quando o jogador escolhe uma fala Dialogue, o servidor:

  1. Confere se o jogador ainda está perto do NPC e se a fala é oferecida a ele (nível, condições, módulo).
  2. Confere cada ação e depois executa todas. Se uma não pode ser executada (ouro insuficiente, bolsa cheia), o motivo aparece em vermelho sobre o jogador e nada é executado.
  3. Então:
    • com Back To Start, mostra de novo o cumprimento e as opções principais do NPC;
    • com Reply ou Options, mostra a resposta e as opções da fala;
    • sem nenhum dos dois, a conversa termina.

O servidor lembra em que página cada jogador está e confere cada escolha contra ela. Um cliente modificado não consegue pular para uma fala que não pode alcançar.

O aninhamento vai até 16 níveis de profundidade.

#Mostrar falas bloqueadas

Uma fala cujas condições não são cumpridas fica escondida. Com Show When Locked, ela aparece acinzentada com o motivo entre parênteses, por exemplo "Three spores for two potions? (Needs Mushroom Spore x3)". Ela não pode ser escolhida. Use isso para avisar aos jogadores que há mais para descobrir.

#Reutilizar uma fala de Back

Uma fala de Back é uma fala Dialogue só com Back To Start ligado. Você pode colocar a mesma fala de Back no fim de várias ramificações.

#Lojas e missões dentro de uma ramificação

Uma opção Shop, Quest ou qualquer outra pode ficar dentro das Options de uma fala. A marca de missão sobre a cabeça do NPC só conta as missões que o jogador pode alcançar pelas falas que ele pode escolher, então uma missão escondida em uma ramificação bloqueada não mostra um "!".

#Criar um diálogo com ramificações

Isto monta a conversa de Brann do exemplo: uma ramificação que abre depois que o jogador encontrou as ruínas antigas, com uma dica única para guerreiros e uma troca.

Você precisa de: a DiscoveryZone da Forest com id old_ruins (veja Condições e ações), os itens Antidote, Mushroom Spore e Health Potion, e uma classe Warrior.

#1. A fala principal

  1. Selecione o objeto de Brann na cena Town.
  2. Pressione Dialogue em Add option.
  3. Label: "About the old ruins...".
  4. Conditions: adicione Discovered, Zone old_ruins, Place Name "the old ruins".
  5. Show When Locked: ligado. Os jogadores que não estiveram lá veem "About the old ruins... (Find the old ruins first)".
  6. Reply: "Those walls are older than the town. My grandfather swore a king held court there, long before the mushrooms moved in."

#2. Uma dica única para guerreiros

Nas Options da fala principal, adicione uma Dialogue Option:

  1. Label: "Any advice for a warrior?"
  2. Conditions: Class, Classes Warrior; e Flag, Key brann_advice, Compare Equal, Value 0.
  3. Reply: "Keep your shield up and these close. Those spores rot the lungs."
  4. Actions: Give Item Antidote, Amount 2; Set Flag, Key brann_advice (valor 1).
  5. Options: adicione uma fala de Back (uma Dialogue Option com Back To Start ligado).

A marca a torna um presente único: depois dele, a fala fica escondida para sempre. As outras classes nunca a veem.

#3. Uma troca

Nas Options da fala principal, adicione outra Dialogue Option:

  1. Label: "Three spores for two potions?"
  2. Conditions: Item, Item Mushroom Spore, Count 3. Show When Locked ligado.
  3. Reply: "Mira pays better, but fine. Don't tell her."
  4. Actions: Take Item Mushroom Spore x3; Give Item Health Potion x2. O rótulo mostra "(Mushroom Spore x3)".
  5. Options: uma fala de Back.

Se a bolsa está cheia, Give Item recusa, então os esporos também não são tirados.

#4. Uma saída

No fim das Options da fala principal, adicione uma fala de Back, para que o jogador possa voltar ao cumprimento de Brann e à loja dele.

#5. Teste

Dê Play e fale com Brann antes e depois de entrar nas ruínas, com um guerreiro e com outra classe, com e sem 3 esporos. /flag brann_advice 0 reinicia a dica, e /item mushroom_spore 3 dá os esporos. Veja Comandos de GM.

#Mais padrões

Padrão Como
Um serviço pago Ações Charge Currency 15 e Restore, sem resposta: a Mira do exemplo cura por 15 de ouro.
Uma missão a partir de uma conversa Ações Start Quest, ou coloque uma opção Quest dentro da ramificação.
Uma escolha que muda a história Duas falas, cada uma com Set Flag choice em 1 ou 2. Falas e cumprimentos posteriores a leem com condições Flag.
Um guia Ações Discover uma zona e Travel até lá.
Uma emboscada depois de uma conversa Ações Fire Trigger em um gatilho para aquele jogador. Veja Gatilhos do mundo.
Uma primeira fala diferente por jogador Greetings no Npc, cada um com condições. Veja NPCs.

#Um jogador e MMO

É igual nos dois. No MMO, cada escolha é conferida e executada no servidor de mapa; o cliente só mostra o que o servidor envia.

#Erros comuns

  • A conversa fecha depois de uma fala. A fala não tem Reply nem Options. Adicione uma resposta ou uma fala de Back.
  • Uma fala nunca aparece. As condições dela não são cumpridas. Ligue Show When Locked enquanto testa para ver o motivo.
  • As ações da fala não aconteceram. A fala rodou, mas uma das ações foi recusada, então nenhuma delas rodou. O motivo aparece sobre o jogador.
  • Uma fala única se repete. Ela não tem a ação Set Flag, ou a condição Flag lê outra chave.
