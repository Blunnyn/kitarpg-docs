Missões

Uma missão é uma tarefa que um NPC dá: objetivos para cumprir, depois recompensas quando o jogador a entrega. Esta página cobre todos os campos de uma missão, todos os tipos de objetivo, como as missões são oferecidas e entregues, cadeias, missões diárias e repetíveis, drops de missão, o registro de missões e, passo a passo, uma cadeia com uma missão diária.

#O que é uma missão

Uma missão é um asset QuestData no Game Database. Ela diz:

  • quem pode aceitá-la (nível, classe, missões anteriores, qualquer outra condição),
  • o que fazer (objetivos: matar, coletar, falar, explorar, acionar),
  • o que ela dá (experiência, ouro, moedas, itens, pontos, uma habilidade),
  • o que acontece ao aceitar e ao entregar (ações),
  • se ela pode ser feita de novo (uma vez, diária, sempre).

Um NPC a oferece e a recebe de volta por meio de uma opção Quest. Quem dá e quem recebe podem ser NPCs diferentes. O servidor conta cada objetivo e paga as recompensas; o cliente só pede.

As missões são um módulo: desligar Quests em Módulos esconde todas as opções Quest.

#Onde fica no editor

Game Database > World > Quests. + New quest cria uma em uma pasta Quests ao lado do banco de dados e a adiciona à lista quests do banco de dados. Você também pode usar Create > KitARPG > Quest.

Listas de objetivos, condições e ações têm um menu de tipos ao lado de cada entrada, então você escolhe Kill, Collect e assim por diante ao adicionar uma.

#Campos

#Textos

Campo O que faz Padrão
Id (id) Salvo com os personagens. Mudá-lo faz todos perderem o progresso nesta missão. Do nome do arquivo
Display Name (displayName) O título da missão. Vazio (nome do asset)
Description (description) O que quem dá diz ao oferecê-la. Também aparece no registro de missões. Vazio
Progress Text (progressText) O que quem dá diz enquanto ela ainda não foi concluída. "Not done yet? Come back when it is."
Complete Text (completeText) O que quem dá diz quando ela é entregue. "Well done."
Category (category) A agrupa no registro de missões, como uma região ou um arco de história. Vazio vai para General. Vazio

#Quem pode aceitá-la

Campo O que faz Padrão
Required Level (requiredLevel) Nível mínimo. 1
Max Level (maxLevel) Nível máximo. 0 significa sem limite. 0
Classes (classes) Classes que podem aceitá-la. Vazio significa qualquer classe. Vazio
Required Quests (requiredQuests) Missões que precisam ser entregues antes: uma cadeia. Vazio
Repeat (repeat) Once, Daily ou Always. Once
Conditions (conditions) Qualquer outra coisa que o jogador precise cumprir: um item carregado, um lugar encontrado, uma marca de história. Veja Condições e ações. Vazio

#O que fazer

Campo O que faz Padrão
Objectives (objectives) As tarefas. Todas precisam estar concluídas para entregá-la. Vazio
Start Items (startItems) Entregues ao aceitar, como uma carta para levar. Tomados de volta se a missão for abandonada. Vazio

#Recompensas

Campo O que faz Padrão
Experience (experience) Experiência. O stat Experience Gain do jogador e a taxa de experiência do servidor se aplicam. 0
Gold (gold) Ouro. 0
Currencies (currencies) Outras moedas, cada uma com uma quantia. Vazio
Items (items) Itens, cada um com uma quantidade. O que não cabe na bolsa vai para o banco. Vazio
Attribute Points (attributePoints) Pontos de atributo para gastar. 0
Skill Points (skillPoints) Pontos de habilidade para gastar. 0
Skill (skill) Ensinada como se fosse por um livro: as regras de aprendizado da habilidade continuam valendo. Se o jogador não pode aprendê-la, ela é pulada. Nenhuma
Skill Rank (skillRank) O rank ensinado. 1

#Ações

Campo O que faz Padrão
On Accept (onAccept) Executadas ao aceitá-la. A missão não é aceita se uma não pode rodar, como uma taxa que o jogador não pode pagar. Vazio
On Complete (onComplete) Executadas ao entregá-la, antes das recompensas: definir uma marca de história, tirar um item extra. Se uma não pode rodar, a missão não é entregue. Vazio

Toda ação de uma lista é verificada antes que qualquer uma rode, então uma lista nunca roda pela metade. Veja Condições e ações.

#Objetivos

Cada objetivo tem dois campos em comum:

Campo O que faz Padrão
Text (text) Mostrado no registro de missões. Vazio usa o padrão, como "Slay Slimes". Vazio
Hint (hint) Abre embaixo do objetivo no registro de missões: a quem perguntar, onde procurar. Vazio

Quando um objetivo pede mais de um, o registro mostra uma contagem, como "Slay Slimes 3/6". Cada avanço é anunciado sobre o jogador, e "<quest>: ready to turn in" quando o último é concluído.

#Kill

Matar monstros de um tipo, ou qualquer monstro.

Campo O que faz Padrão
Monster (monster) O monstro. Vazio conta qualquer monstro. Nenhum
Count (count) Quantos. 5

Texto padrão: "Slay <monster>" ou "Slay monsters". O abate conta para o jogador que o conseguiu e para membros do grupo por perto com a mesma missão. Invocações não contam.

#Collect

Carregar uma quantidade de um item. Conta o que está na bolsa neste momento, para cima e para baixo: vender ou largar os itens diminui a contagem.

Campo O que faz Padrão
Item (item) O item. Nenhum
Count (count) Quantos. 5
Take On Turn In (takeOnTurnIn) Quem dá a missão fica com eles quando ela é entregue. Ligado

Texto padrão: "Bring <item>". Itens no banco não contam. Combine com um drop de missão para que o item só caia enquanto a missão está aberta.

Um objetivo de coleta com Count 1 e um Start Item faz uma entrega: "A Letter for Sela", da amostra, entrega uma carta selada e pede que ela seja devolvida a Sela, com o texto "Give the letter to Sela".

#Talk

Falar com um NPC, pelo seu id no mapa.

Campo O que faz Padrão
Npc Id (npcId) O id do NPC, ou o nome do seu objeto quando ele não tem um. Vazio
Npc Name (npcName) Como o registro o chama. Vazio

Texto padrão: "Talk to <name>". Conta quando o jogador começa a falar com esse NPC, com a missão já aberta.

#Explore

Chegar a um lugar: um ponto em um mapa e um raio ao redor dele, ou uma zona de descoberta.

Campo O que faz Padrão
Map (map) O mapa do ponto. Vazio: qualquer mapa. Nenhum
Zone (zone) O id de uma zona: alcançada ao entrar nessa DiscoveryZone. Usado no lugar do ponto quando definido. Vazio
Position (position) O ponto. 0, 0, 0
Radius (radius) Metros ao redor do ponto, no chão. 5
Place Name (placeName) Como o registro o chama, como "the old ruins". Vazio

Texto padrão: "Find <place>". O servidor verifica a cada meio segundo. Uma zona é a escolha mais fácil: coloque uma DiscoveryZone uma vez, e tanto este objetivo quanto as condições podem usar o id dela. Veja Condições e ações.

#Trigger

Disparar um gatilho do mundo: tocar um altar, puxar uma alavanca, entrar em um ponto marcado.

Campo O que faz Padrão
Trigger (trigger) O id do gatilho no seu mapa. Vazio
Count (count) Quantas vezes. 1
Target Name (targetName) Como o registro o chama, como "the altar". Vazio

Texto padrão: "Activate <target>". Conta para qualquer jogador que dispara o gatilho cumprindo as condições dele, mesmo quando um gatilho para todos já foi gasto. Veja Gatilhos do mundo.

#Estados da missão

Para cada personagem, uma missão está em um destes estados:

Estado Significado
Locked Requisitos não cumpridos, ou concluída e ainda não repetível.
Available Pode ser aceita agora.
Active Aceita, faltando objetivos.
Ready Todos os objetivos concluídos; esperando ser entregue.
Done Entregue, e não aberta de novo.

#Oferecer e entregar

Coloque uma opção Quest no NPC que a dá e no que a recebe de volta. Veja NPCs.

  1. A opção só aparece quando há algo a fazer. O rótulo dela diz onde o jogador está: "!" amarelo para aceitar, "?" amarelo e "(complete)" quando pronta, "?" cinza e "(in progress)" enquanto não.
  2. A cabeça do NPC mostra as mesmas marcas com NpcQuestMarker.
  3. Escolher a opção abre a janela da missão: o texto do NPC (descrição, texto de progresso ou texto de conclusão), os objetivos, as recompensas e um botão para aceitar ou entregar. Ela fecha com Escape ou quando o jogador se afasta.

#Aceitar

O servidor verifica, em ordem:

  1. A missão está Available. Caso contrário, responde com o primeiro requisito não cumprido, como "Needs level 3" ou "Finish Slime Trouble first".
  2. O jogador tem menos de 20 missões abertas (Max Active no componente PlayerQuests do jogador). Caso contrário: "Too many quests open".
  3. A bolsa tem espaço para os itens iniciais. Caso contrário: "Make room in your bag or bank first".
  4. As ações de On Accept podem todas rodar.

Então entrega os itens iniciais, abre a missão, conta na hora os objetivos de coleta contra a bolsa e mostra "New quest: <name>". Missões novas são seguidas no HUD.

#Entregar

  1. Todos os objetivos precisam estar concluídos.
  2. As recompensas precisam caber: os itens entregues liberam seus espaços primeiro, e o que a bolsa não aceita vai para o banco. Se nenhum dos dois tem espaço: "Make room in your bag or bank first".
  3. As ações de On Complete rodam.
  4. Objetivos de coleta com Take On Turn In tiram seus itens.
  5. As recompensas são pagas: itens (bolsa, depois banco), ouro, moedas, pontos, a habilidade, experiência.
  6. "Quest complete: <name>".

#Abandonar

No registro de missões, Abandon (com confirmação) larga a missão. Os itens iniciais dela são tomados de volta, todos ou nenhum: se faltam alguns na bolsa, o jogador é avisado para colocá-los de volta primeiro. Isso impede que os jogadores aceitem a missão de novo para ganhar um segundo conjunto.

Atenção

Marque os itens iniciais como itens de missão (Quest Item ligado, e vinculados). O Project Check avisa sobre um item inicial que não é: ele poderia ser trocado ou vendido, e aí a missão não pode ser abandonada.

#Cadeias, missões diárias e repetíveis

  • Cadeia: liste as missões anteriores em Required Quests. A próxima missão fica Locked até que elas sejam entregues. Para mais controle, use uma QuestCondition em Conditions, por exemplo "só enquanto a missão X está em andamento".
  • Diária: Repeat Daily. Depois de entregue, ela abre de novo no dia seguinte, contado em UTC (meia-noite UTC, não a hora local do jogador).
  • Sempre: Repeat Always. Ela abre de novo assim que é entregue.
  • Uma vez: o padrão. Concluída para sempre.

#Drops de missão

Um drop em uma tabela de saque com o campo Quest definido só cai para quem mata tendo essa missão aberta e ainda carregando menos do item do que o objetivo de coleta pede. Sorte e taxas de saque não mudam a chance dele. Coloque os drops de missão primeiro na tabela para que Max Drops nunca os corte.

#O registro de missões e o rastreador

  • Registro de missões (L): abas In progress, Finished e Hidden com suas contagens, uma busca por nome ou categoria e uma faixa de nível. As missões são agrupadas por Category em grupos que se recolhem. Cada linha mostra seu tipo (uma vez, diária, repetível ou pronta para entregar), o nível e um alfinete para segui-la. A página mostra título, nível, tipo, categoria e estado, a descrição, os objetivos com contagens e dicas (o primeiro não concluído se destaca), as recompensas e os botões Track, Hide e Abandon.
  • Rastreador: as missões seguidas e seus objetivos à direita do HUD, até 5 (Max Quests em QuestTracker). Ocultar uma missão também para de segui-la. Seguir e ocultar são salvos com o personagem.

Veja HUD e janelas.

#Criar uma cadeia de missões com uma diária

Isto monta uma cadeia de três missões com um capitão e uma missão diária com uma alquimista, como as da amostra.

#1. A primeira missão: uma missão de matar

  1. Quests > + New quest. Renomeie para Slime Trouble.
  2. Description: "Slimes keep oozing out of the forest toward the gate. Thin them out." Progress Text: "Still hearing them squelch out there." Complete Text: "That's quieter. Here, you earned these."
  3. Category: The Mushroom King.
  4. Required Level 1.
  5. Objectives: adicione Kill. Monster Slime, Count 6, Hint "Out the town gate and into the forest."
  6. Rewards: Experience 80, Gold 30, Items Health Potion x3.

#2. A segunda missão: coletar com um drop de missão

  1. Crie um item Slime Gel em Items > Quest items (item de missão e vinculado).
  2. Nova missão Sticky Samples. Required Quests: Slime Trouble. Required Level 2.
  3. Objectives: Collect, Item Slime Gel, Count 5, Take On Turn In ligado, Hint "Slimes drop it while this quest is open."
  4. Abra Items > Loot > Slime Loot. Adicione um drop no topo: Item Slime Gel, Chance % 60, quantidades 1 e 1, Quest Sticky Samples.
  5. Rewards: Experience 120, Gold 40 e um item.

#3. A terceira missão: explorar e matar

  1. Na cena Forest, adicione uma DiscoveryZone nas ruínas: Zone Id old_ruins, Display Name "Old Forest Ruins", Radius 8.
  2. Nova missão The Old Ruins. Required Quests: Sticky Samples.
  3. Objectives: Explore, Map Forest, Zone old_ruins, Place Name "the old ruins in the forest". Depois Kill, Monster Giant Slime, Count 1.

#4. Dar a cadeia ao capitão

  1. No Npc do capitão, pressione Quest três vezes em Add option e escolha uma missão em cada uma.
  2. Só uma aparece por vez: a próxima fica Available quando a anterior é entregue.
  3. Opcional: uma saudação condicional com uma QuestCondition em The Old Ruins definida como Taken: "Back from the ruins already?". Veja NPCs.

#5. A missão diária

  1. Crie um item de missão Glowing Spore e adicione-o como drop de missão na tabela de saque do cogumelo, com Quest definido para a nova missão.
  2. Nova missão Fresh Spores. Repeat Daily. Required Level 3. Category Forest.
  3. Objectives: Collect Glowing Spore, Count 4.
  4. Rewards: Experience 60, Gold 50, Fortitude Elixir x2.
  5. Adicione uma opção Quest para ela na alquimista.

#6. Testar

Pressione Play. Comandos de GM úteis: /quest give slime_trouble, /quest finish slime_trouble (completa todos os objetivos), /quest reset fresh_spores (a esquece, para que uma diária possa ser aceita de novo na hora), /spawn slime 6. Veja Comandos de GM.

#Salvamento

  • MMO: o progresso e o registro de missões entregues são salvos pela Central nos dados extras do personagem (chaves quests e questsDone), sem migração de banco de dados.
  • Um jogador: no save do personagem, no computador do jogador.
  • Se você mudar os objetivos de uma missão depois, o progresso nos objetivos que ainda correspondem é mantido.

#Um jogador e MMO

As mesmas regras nos dois. No MMO, o servidor de mapa conta abates, conversas, lugares e itens, e valida aceitar e entregar contra um NPC por perto que tenha a opção. O progresso das missões acompanha o personagem entre servidores de mapa.

#Para programadores

Herde de QuestObjective para adicionar seu próprio tipo (por exemplo, "fabricar 3 poções") e avance-o com PlayerQuests.ServerAdvance<T>(match, amount). PlayerQuests.ServerCompleted avisa outros sistemas que uma missão foi entregue. QuestData.CheckRequirements é virtual. Veja Objetivos de missão e Eventos.

#Erros comuns

  • A missão nunca aparece no NPC. Um requisito não é cumprido (nível, classe, missão anterior, uma condição), ela está Done e não é repetível, a opção Quest está com Offers desligado, ou o módulo Quests está desligado.
  • Uma contagem de coleta diminui. O jogador vendeu, largou ou guardou no banco os itens. A coleta conta a bolsa como ela está.
  • O item de missão não cai. O Quest do drop não é a missão em andamento, o jogador já tem o suficiente, ou drops acima dele enchem Max Drops.
  • O objetivo de falar não conta. Npc Id não corresponde ao id do NPC, ou o jogador falou antes de aceitar a missão.
  • Uma diária reabre em uma hora estranha. Ela reabre à meia-noite UTC.
