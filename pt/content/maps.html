Conteúdo do jogo

Mapas

Um mapa é um lugar onde os jogadores podem estar: uma entrada MapData no Game Database mais uma cena do Unity. Esta página cobre cada campo de um mapa, o que uma cena de mapa precisa, como os jogadores viajam entre mapas, os mapas instanciados e um passo a passo completo para adicionar um mapa novo, da cena às builds e aos servidores.

#O que é um mapa

Um mapa tem duas partes:

  • A entrada (MapData, Game Database > World > Maps). Seu id é o que Central, os salvamentos, os portais e as missões usam. Ela indica a cena, sua posição inicial, a música, se é instanciado e suas regras de PvP.
  • A cena. O que carrega: o chão, o NavMesh, o ponto de surgimento, os monstros, os NPCs, os portais.

As builds pegam a cena de cada mapa do Game Database. Você nunca mantém uma lista de cenas à mão.

A amostra tem quatro mapas:

Id Cena O que mostra
town Town NPCs, lojas, missões, o banco, o mercado, serviços de guilda. O mapa inicial.
forest Forest Spawners de monstros, spawners noturnos, o Mushroom King, uma zona de descoberta, gatilhos do mundo, pontos de coletor, PvP em zonas a partir do nível 5.
crypt Crypt Sunken Crypt, uma masmorra instanciada com o chefe Void Herald.
guild_hall GuildHall Um mapa instanciado: cada guilda que compra sua sede recebe sua própria cópia.

#Onde fica no editor

Game Database > World > Maps. + New map cria um em uma pasta Maps ao lado do banco de dados e o adiciona à lista maps do banco de dados. Você também pode usar Create > KitARPG > Map.

O cartão de um mapa começa com o cartão Adding a map, que mostra cada passo com um ponto (feito ou por fazer) e um botão onde ajuda:

  1. A scene: o caminho da cena assim que ela existir.
  2. Picked below, in Scene.
  3. In Build Settings, for Play: um botão Add a coloca ali.
  4. Reached from another map: lembra você do portal ou do teleporte, com o id do mapa.
  5. Monsters for the bestiary: quantos foram lidos, com um botão Read from scene.
  6. Map server rebuilt.

O mapa inicial dos personagens novos é uma configuração do banco de dados: Game Database > Database > Settings, Start Map (startMap). Uma classe pode substituí-lo pelo seu próprio mapa inicial.

#Campos

Campo O que faz Padrão
Id (id) O que Central, os salvamentos, os portais, os teleportes e as missões usam. Preenchido a partir do nome do arquivo uma vez e depois mantido. Mudá-lo deixa presos os personagens salvos neste mapa. Do nome do arquivo
Display Name (displayName) Nome mostrado no jogo, por exemplo em "Travel to Forest" e "Discovered: Forest". Vazio (nome do asset)
Description (description) Mostrada onde os mapas são descritos. Vazio
Scene (scene) A cena que carrega para este mapa. Ela precisa de um SpawnPoint e de um NavMesh. O campo é um seletor de cena que também diz se a cena está em Build Settings. Vazio
Start Position (startPosition) Onde os personagens novos aparecem quando este é o mapa inicial deles. 0, 0, 0
Monsters (monsters) Monstros que vivem aqui, para o bestiário. Preenchido por Read from scene a partir dos spawners da cena, mais os ajudantes que seus chefes chamam. Vazio
Music (music) Toca em loop enquanto os jogadores estão aqui. Vazio: a música de antes continua tocando. Nenhum

#Instâncias

Campo O que faz Padrão
Instanced (instanced) Cada grupo, ou cada jogador sozinho, recebe sua própria cópia: uma masmorra. Só online; um mundo de um jogador já é uma cópia só. Desligado
Instance Spacing (instanceSpacing) Metros entre as cópias no servidor de mapa, para que nunca se vejam. 1000
Empty Minutes (emptyMinutes) Minutos que uma cópia fica depois que o último jogador sai, para quem voltar. 5

#Jogador contra jogador

Campo O que faz Padrão
Pvp (pvp) Off, Zones (só dentro de zonas de PvP, os dois jogadores) ou Everywhere. Os duelos funcionam em qualquer lugar. Off
Pvp Min Level (pvpMinLevel) Jogadores abaixo deste nível não podem lutar contra outros nem ser atacados. 1
Pvp Spare Party (pvpSpareParty) Membros do mesmo grupo nunca se ferem. Ligado
Pvp Spare Guild (pvpSpareGuild) Membros da mesma guilda nunca se ferem. Ligado

As zonas de PvP são componentes PvpZone na cena (um círculo com um Radius, 15 m por padrão). Veja PvP e duelos.

#O que uma cena de mapa precisa

Objeto Por quê Obrigatório
SpawnPoint Onde os personagens aparecem quando sua posição salva não serve: um personagem novinho, alguém voltando depois de morrer, alguém chegando em uma cópia instanciada. Radius (2 m por padrão) os espalha. O Project Check informa uma cena de mapa sem um. Sim
Um NavMesh assado (NavMeshSurface) O servidor move jogadores e monstros sobre ele e, por padrão, a linha de visão trata seus buracos como paredes. Sim
Câmera, entrada e efeitos Os mapas da amostra têm uma Main Camera com a câmera e a entrada do modo, um EventSystem e um objeto Combat Effects com FloatingText, LootDropsView, SkillEffectsView e CombatEffectsView. Sim, para clientes
DayNightCycle Gira o sol e o céu com o relógio do jogo. Deixe-o de fora em mapas com luz fixa, como a cripta. Veja Dia e noite. Não
Portal Manda os jogadores para outro mapa. Para chegar a outros mapas
MonsterSpawner Mantém monstros no mapa. Veja Monstros. Não
Npc Pessoas e objetos com quem falar. Veja NPCs. Não
DiscoveryZone, WorldTrigger, PvpZone, CollectorSpot Lugares com nome, eventos, áreas de PvP, pontos de coletor. Não

Duplicar uma cena de mapa da amostra (Forest é um bom começo) dá a você todos os objetos obrigatórios de uma vez.

#Viajar entre mapas

#Portais

Um Portal manda um jogador que entra nele para outro mapa.

Campo O que faz Padrão
Target Map (targetMap) O id do mapa onde o jogador chega, como Central o conhece. forest
Target Position (targetPosition) Onde o jogador aparece no mapa de destino. 0, 0, 0
Radius (radius) Metros ao redor do portal que enviam o jogador. Desenhado como um círculo azul na vista da cena. 1,5

O componente do portal é só dados; o servidor de mapa vigia os jogadores dentro do seu raio. Os portais da amostra são portões de pedra com brilho; suas peças ficam fora do assado do NavMesh com um NavMeshModifier definido como Ignore From Build, para que o portão seja caminhável.

#Opções de teleporte

Um NPC com uma opção Teleport leva o jogador a um mapa e a uma posição, por ouro. Ele também pode movê-lo dentro do mesmo mapa. Veja NPCs. Uma TravelAction faz o mesmo a partir de uma linha de diálogo ou de uma missão, sem preço. Veja Condições e ações.

#Onde o jogador aparece

  • Por um portal ou teleporte, na posição de destino, ajustada para cima do NavMesh.
  • Ao entrar no jogo, na posição salva do mapa salvo.
  • Quando a posição salva não está no NavMesh (o mapa mudou), no SpawnPoint da cena.
  • Em um mapa instanciado, sempre no SpawnPoint da cópia.

#Descobrir mapas

Entrar em um mapa o marca como descoberto para aquele personagem, com "Discovered: <name>". As condições podem pedir isso (DiscoveredCondition). Veja Condições e ações.

#Mapas instanciados

Com Instanced ligado, cada grupo recebe sua própria cópia do mapa, e um jogador sem grupo recebe uma sozinho. Os membros de um grupo acabam na mesma cópia mesmo quando entram separados.

  • MMO: Central escolhe a cópia (party-<id> ou solo-<id>) e a envia com o ticket. No servidor de mapa, a primeira cena carregada é um modelo cujos spawners ficam parados. Cada cópia é a mesma cena carregada de novo e deslocada Instance Spacing metros ao longo de X, com seu próprio NavMesh, monstros, gatilhos do mundo e chefe. Os jogadores sempre chegam no SpawnPoint da cópia. Uma cópia fecha Empty Minutes depois que o último jogador sai.
  • Um jogador: um mapa instanciado é um mapa normal. Já existe só uma cópia.
  • As sedes de guilda usam o mesmo sistema com uma cópia por guilda (guild-<id>). Veja Guildas.

Mantenha sua cena instanciada menor que Instance Spacing, para que as cópias nunca se alcancem. Veja Masmorras.

#Adicionar um mapa novo, do início ao fim

Isto adiciona um mapa chamado Caves, acessado a partir da Forest.

#1. Criar a cena

  1. Na janela Project, encontre Assets/Blunnyn/KitARPG/Samples/Starter/Scenes/Forest.unity (ou sua própria cena de mapa). Selecione-a e pressione Ctrl/Cmd+D.
  2. Renomeie a cópia para Caves e mova-a para sua própria pasta, por exemplo Assets/Game/Scenes.
  3. Abra-a. Apague o que você não quer: spawners, NPCs, o altar, pontos de coletor, gatilhos. Mantenha os objetos da câmera, o EventSystem, Combat Effects, Spawn (o SpawnPoint) e NavMesh.
  4. Monte seu nível. Mantenha paredes e obstáculos como geometria que o NavMesh enxerga.
  5. Selecione o objeto NavMesh e pressione Bake no seu NavMeshSurface. Os dados da superfície são salvos ao lado da cena.
  6. Mova o objeto Spawn para onde os jogadores devem ficar quando chegam.
  7. Salve a cena.
Atenção

Cada cena precisa dos seus próprios dados de NavMesh. Depois de duplicar uma cena, asse de novo para que a cópia não continue apontando para o asset de NavMesh da Forest.

#2. Adicionar o mapa ao banco de dados

  1. Game Database > World > Maps > + New map. Renomeie-o para Caves. Seu id passa a ser caves.
  2. Em Scene, escolha Caves.
  3. No cartão Adding a map, pressione Add ao lado de In Build Settings, for Play. Build Settings só importa para o Play no editor; as builds adicionam a cena sozinhas.
  4. Defina Music, Pvp e Instanced se quiser.

#3. Conectá-lo

Na cena Forest:

  1. Duplique o portal da Forest (ou adicione um objeto vazio com um Portal).
  2. Defina Target Map como caves e Target Position como um ponto perto do spawn de Caves.
  3. Na cena Caves, adicione um portal de volta com Target Map forest.

Ou dê a um NPC uma opção Teleport cujo Map seja Caves.

#4. Preenchê-lo

  1. Adicione Monster Spawners, NPCs, zonas de descoberta e gatilhos.
  2. No cartão do mapa, pressione Read from scene ao lado de Monsters for the bestiary.
  3. KitARPG > Render Missing Monster Icons para qualquer monstro sem retrato.

#5. Jogá-lo no modo de um jogador

Em Play & Servers, escolha um jogador e pressione Play. Atravesse o portal. Veja Play and Servers.

#6. Fazê-lo funcionar online

Cada mapa roda no seu próprio servidor de mapa, e Central precisa conhecer o id e a porta do mapa.

  1. Central aprende o mapa sozinha no seu computador. Quando o Play & Servers inicia os serviços, cada mapa do game database que ainda não está em UserSettings/KitARPG/launcher.json ganha uma entrada ali, na próxima porta livre a partir de 7777. Para escolher a porta você mesmo, ou para iniciar o mapa com os serviços, pare os serviços e edite sua entrada:

    "Maps": [
  { "Id": "town", "Port": 7777, "AutoStart": true },
  { "Id": "forest", "Port": 7778, "AutoStart": false },
  { "Id": "crypt", "Port": 7779, "AutoStart": false },
  { "Id": "guild_hall", "Port": 7780, "AutoStart": false },
  { "Id": "caves", "Port": 7781, "AutoStart": false }
]

    AutoStart inicia o servidor de mapa com os serviços; caso contrário, Central o inicia quando o primeiro jogador vai para lá. Veja Launcher e Configuração.

  2. Refaça a build do servidor de mapa. Cada build anota suas cenas, e o Play & Servers marca o passo Map server build como pendente quando a cena de um mapa falta nela. Pressione Build ali, ou use KitARPG > Starter > Build Mac Server (ou a de Windows ou Linux). Veja Builds.

  3. Inicie os serviços de novo e pressione Play client. Iniciar os serviços também exporta os dados do jogo que o Login lê.

  4. Docker: adicione o mapa à lista de Central (Central__Maps__N__Id e Central__Maps__N__Port) e copie um bloco de serviço de mapa em Deploy/docker-compose.yml com o novo id e a nova porta, e depois refaça a imagem do servidor Linux. Veja Docker.

  5. Firewall: abra a porta UDP do novo mapa no servidor.

Atenção

Sem o mapa na build do servidor de mapa, os jogadores que viajam para lá acabam de volta no login. Sem o mapa na lista de Central, Central não consegue mandar ninguém para lá.

#7. Conferir

Rode o Project Check. Ele informa um mapa sem cena, um nome de cena que não existe, uma cena que falta em Build Settings, uma cena sem SpawnPoint, dois NPCs com o mesmo id, scripts faltando e spawners sem monstro. Veja Project Check.

#O mapa do mundo

A janela do mapa (M) mostra o mapa atual visto de cima. Com um World Map nos Settings do Game Database (worldMap), ela mostra no lugar uma imagem do mundo inteiro, com uma zona para cada mapa: os jogadores arrastam para mover, usam a rolagem para aproximar, veem onde estão e o nome e os níveis de cada zona, clicam em uma zona para listar seus monstros e em um monstro para ver onde ele vive e o que derruba, com a chance de cada coisa. A busca no topo encontra zonas e monstros pelo nome. A ilha da amostra é pintada por Art/Tools/make_world_map.py.

#Desenhe o seu

  1. Abra KitARPG > World Map Editor e pressione New world map. Ele é criado ao lado do Game Database e definido nele.
  2. Defina a Picture: qualquer sprite do seu mundo.
  3. Arraste em um espaço vazio para criar uma zona. Clique em uma zona para escolhê-la e arraste seus cantos; Add corner e Remove corner mudam sua forma.
  4. À direita, defina o Map dela. Name é opcional (senão aparece o nome do mapa), assim como Min Level e Max Level: deixados em 0, vêm dos monstros do mapa.
  5. Pressione World area from the scene: ele lê quanto terreno a cena do mapa cobre, para que os jogadores apareçam na parte certa da zona. Sem isso eles aparecem no meio dela.

Use a rolagem para aproximar o editor e arraste com o botão do meio, ou com Alt, para mover. Um HUD feito antes do mapa do mundo o recebe pela atualização do kit World map with zones in the map window em Overview.

#Um jogador e MMO

  • Um jogador: todos os mapas rodam dentro do jogo, que é o host. Viajar carrega a outra cena.
  • MMO: um servidor de mapa Unity por mapa, cada um na sua própria porta UDP. Um cliente entra no Login, pede a Central um ticket de uso único e entra no servidor de mapa com ele. Viajar pede a Central um ticket para o outro mapa; Central inicia o servidor daquele mapa se ele não estiver rodando. Veja Arquitetura.

O código da cena é o mesmo nos dois, então um mapa feito para um jogador funciona online.

#Erros comuns

  • De volta ao login depois de um portal. A build do servidor de mapa não tem a cena, ou Central não lista o mapa. Refaça a build e confira o launcher.json.
  • Os jogadores caem ou ficam no ar. O NavMesh não foi assado, ou a cena usa os dados de NavMesh de outra cena.
  • Monstros faltando no bestiário deste mapa. Pressione Read from scene depois de colocar os spawners.
  • O portal não faz nada. Target Map tem o nome exibido em vez do id, ou há um erro de digitação. Os ids são em minúsculas com sublinhados.
  • As cópias instanciadas se veem. A cena é maior que Instance Spacing.
