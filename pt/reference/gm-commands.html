Comandos de GM

Todos os comandos de barra do KitARPG: os comandos de chat que todo jogador tem, e os comandos de GM para moderadores, game masters e administradores, com sua sintaxe, nível padrão, apelidos, limites, respostas e exemplos. Os comandos de GM rodam no servidor de mapa; o servidor verifica o nível da conta a cada linha.

#Como os comandos funcionam

  • Digite um comando no chat: pressione Enter, digite a linha começando com /, pressione Enter.
  • Os comandos de chat (canais, grupos, amigos) são tratados pelo cliente. Todo o resto vai para o servidor de mapa, que conhece o nível de GM da conta.
  • /help (ou /commands) lista os comandos de chat e todos os comandos de GM que o seu nível permite, cada um com seu nível entre colchetes.
  • Um comando acima do seu nível responde "Unknown command /name. Try /help.", igual a um comando que não existe. Comandos de equipe tentados acima do nível ainda são registrados.
  • Os argumentos são separados por espaços. [colchetes] marcam os opcionais. Um argumento player é o nome de um personagem.
  • Onde um [player] é opcional, deixá-lo de fora aplica o comando em você mesmo.
  • Salvo indicação contrária, o alvo precisa estar no mesmo mapa que você; caso contrário, a resposta é "No such player here."
  • Uma linha é cortada em 300 caracteres.

#Níveis de GM

Toda conta tem um nível de GM, guardado em accounts.Role no banco de dados.

Nível Nome Quem
1 Player Toda conta nova
2 Moderator Vigia o chat e os jogadores: who, goto, boot, mute, announce, reports, logs
3 Game Master Cuida do mundo: summon, teleport, ban, heal, god, estados, monstros, mapas, missões, flags, gatilhos
4 Admin Distribui coisas e gerencia a equipe: itens, ouro, moedas, experiência, níveis, pontos, habilidades, taxas, papéis, auditoria

Os níveis nas tabelas abaixo são os padrões. Mude o nível de qualquer comando em Game Settings > Commands > Gm Command Levels (gmCommandLevels): adicione uma linha com o nome do comando sem a barra (como item) e o nível que ele deve pedir. /role sempre pede nível 4, qualquer que seja a configuração.

#Um jogador

No modo de um jogador, Game Settings > Commands > Single Player Commands (singlePlayerCommands, ligado por padrão) torna o jogador um administrador, então todo comando funciona como um cheat. Comandos marcados como Só online respondem "Only on an online server."

#Definir o primeiro administrador

As contas novas começam no nível 1. Defina o primeiro administrador no banco de dados:

UPDATE accounts SET "Role" = 4 WHERE "Username" = 'yourname';

Com o banco de dados SQLite local do Play & Servers (pare os serviços antes):

sqlite3 UserSettings/KitARPG/data/kitarpg.db "UPDATE accounts SET \"Role\" = 4 WHERE \"Username\" = 'yourname';"

Depois disso, os administradores mudam os níveis no jogo com /role. Se o jogador já está em um mapa, o novo nível vale na próxima vez que ele entrar em um mapa.

#A auditoria

Todo comando de nível 2 ou mais é escrito na tabela gm_audit com a conta, o personagem, o nível, o comando, a linha inteira, o alvo, se foi permitido e a resposta. Comandos acima do nível do jogador são registrados como recusados.

Quando a auditoria não pode ser escrita, os comandos de equipe não rodam: "GM commands are paused: they can't be recorded right now. Try again in a moment." As entradas esperam no disco até a Central confirmá-las. Todo comando de equipe também vai para o registro do jogo como gm.command.

Os administradores leem a auditoria com /audit.

Comando O que faz

Comando O que faz

/closereport id Marca uma denúncia como resolvida. Só online
/logs player [kind] As últimas linhas do registro do jogo do jogador. Só online

#Nível 3: Game Master

Comando O que faz
/summon player Traz um jogador deste mapa para o seu lado
/tp x z Salta para um ponto deste mapa

/heal [player] Vida e mana cheias; revive os mortos
/god Não recebe dano, até ser usado de novo
/status id [seconds] [player] Aplica um estado a um jogador
/spawn monster [count] Faz surgir monstros na sua frente
/killall [meters] Mata os monstros ao seu redor
/map id [x z] Vai para um mapa
`/quest give finish
/flag key [value] [player] Lê ou define uma marca de história

#Nível 4: Admin

Comando O que faz
/item id [amount] [player] Coloca itens em uma bolsa
/gold amount [player] Adiciona ouro; negativo tira
/currency id amount [player] Adiciona qualquer moeda; as premium vão para a conta
/xp amount [player] Dá experiência
/level n [player] Sobe um jogador até um nível
/points attribute skill [player] Dá pontos de atributo e de habilidade
/skill id [rank] [player] Ensina uma habilidade
/rates [kind value [minutes]] Mostra as taxas ou inicia um evento de taxas em todos os mapas
/role player level Define o nível de GM de uma conta. Só online
/audit [player] Os últimos comandos de GM registrados. Só online

#Comandos em detalhe

#/help
Sintaxe /help
Apelido /commands
Nível 1

Lista os comandos de chat (/s /m /g /p /gu, /w name, /r, /invite name, /leave, /kick name, /promote name, /friend name, /unfriend name, /trade name, /ginvite name, /report name reason), depois uma linha por comando de GM que você pode usar: sua sintaxe, descrição e nível, como /item id [amount] [player]: Puts items in a bag. [4].

#/report
Sintaxe /report player reason
Nível 1
Só online Sim

Envia aos moderadores uma denúncia sobre um jogador, guardada na tabela reports. Tudo depois do nome é o motivo. Os moderadores as listam com /reports. O menu do jogador também tem Report.

/report Griefer123 spamming the trade channel

#/who
Sintaxe /who
Nível 2

Lista os jogadores deste mapa como Name (level), separados por vírgulas.

#/goto
Sintaxe /goto player
Nível 2

Salta para o lado de um jogador neste mapa. Responde "No such player here." se o nome não está neste mapa ou é o seu, e "Can't go there." se não há chão caminhável ali.

#/boot
Sintaxe /boot player
Nível 2

Desconecta um jogador neste mapa. O jogador vê "Kicked by a moderator." Você só pode expulsar contas de nível menor que o seu ("You can't kick them."). Responde "Name was kicked."

#/mute
Sintaxe /mute player [minutes]
Nível 2
Padrão 10 minutos
Limite 0 a 525.600 minutos (um ano)

Silencia um jogador no chat. O jogador é avisado com "You can't chat for N minutes." /mute player 0 retira o silêncio ("You can chat again."). O silêncio é uma marca no personagem, então sobrevive a trocas de mapa e saídas da sessão. Você só pode silenciar contas de nível menor, ou você mesmo.

/mute LoudPlayer 30
/mute LoudPlayer 0

#/announce
Sintaxe /announce text
Apelido /broadcast
Nível 2

Envia [Announcement] text no canal do sistema para todos online, em todos os mapas. No modo de um jogador, para o jogador.

/announce Server restart in 10 minutes.

#/reports e /closereport
Sintaxe /reports, /closereport id
Nível 2
Só online Sim

/reports lista as denúncias abertas com seus ids, no seu chat. /closereport id marca uma como resolvida.

/reports
/closereport 17

#/logs
Sintaxe /logs player [kind]
Nível 2
Só online Sim

As últimas linhas do registro do jogo do jogador, lidas da tabela game_logs. Dê um tipo para ver só um, por exemplo:

Tipo O que registra
item.trade Trocas
item.loot Saque recolhido
item.shop_buy, item.shop_sell Compras e vendas em lojas de NPC
item.destroy Itens destruídos
item.forge Uso da forja
bank.deposit, bank.withdraw Movimentos do banco
mail.sent, mail.taken Correio
market.listed, market.sold, market.cancelled, market.expired O mercado
shop.premium_buy, shop.premium_gift, shop.premium_grant A loja do jogo
account.login, account.login_failed, session.enter, session.leave Sessões
character.level, quest.done, combat.death, combat.pvp_kill Progresso e combate
chat.line Chat, quando Game Settings o registra
gm.command, gm.ban Ações da equipe 
/logs Aria item.trade

Veja Registro do jogo e denúncias para todos os tipos.

#/summon
Sintaxe /summon player
Nível 3

Traz um jogador deste mapa para o seu lado. Só contas de nível menor ("You can't summon them."). Responde "Can't bring them." quando o lugar não é caminhável.

#/tp
Sintaxe /tp x z
Nível 3

Salta para um ponto deste mapa, pelas suas coordenadas x e z; a altura é obtida do chão. Responde "Nothing to stand on there." quando não há chão caminhável a até 4 metros do ponto.

/tp 120 -45

#/ban
Sintaxe /ban player hours
Nível 3
Só online Sim

Bane a conta do personagem por essa quantidade de horas. O jogador não precisa estar no seu mapa. Uma conta banida perde o acesso em segundos e não consegue entrar ("This account is banned."). /ban player 0 retira o banimento.

/ban Cheater 72
/ban Cheater 0

#/heal
Sintaxe /heal [player]
Nível 3

Restaura a vida e a mana por completo. Um alvo morto é revivido antes.

#/god
Sintaxe /god
Nível 3

Liga ou desliga o modo deus para você: você não recebe dano. Responde "God mode on." ou "God mode off."

#/status
Sintaxe /status id [seconds] [player]
Apelido /buff
Nível 3
Padrão 30 segundos
Limite 1 a 3.600 segundos

Aplica a um jogador um estado do Game Database, pelo seu id. Responde "No status 'id'." para um id desconhecido.

/status stunned 5 Aria
/buff regeneration 60

#/spawn
Sintaxe /spawn monster [count]
Nível 3
Padrão 1
Limite 1 a 50

Faz surgir monstros, pelo seu id no Game Database, a cerca de 4 metros na sua frente, um pouco espalhados. São monstros de evento: não voltam depois de morrer.

/spawn slime 5
/spawn void_herald

#/killall
Sintaxe /killall [meters]
Apelido /kill
Nível 3
Padrão 10 metros
Limite 1 a 100 metros

Mata todos os monstros ao seu redor, exceto invocações. Eles dão suas recompensas, creditadas a você. Responde "Killed N."

#/map
Sintaxe /map id [x z]
Apelido /travel
Nível 3

Vai para um mapa pelo seu id no Game Database, no ponto x z desse mapa (0 0 quando omitido). Em outro mapa, quando não há chão caminhável perto desse ponto, você chega no SpawnPoint do mapa. Responde "No map 'id'." para um id desconhecido e "Can't travel now." quando a viagem é recusada, por exemplo quando o ponto está no seu próprio mapa e não tem chão.

/map forest
/map town 10 25

#/quest
Sintaxe `/quest give
Nível 3
Ação O que faz Resposta
give O jogador aceita a missão, como se fosse do NPC dela "Taken.", ou por que não pode ser aceita
finish Completa todos os objetivos, então a missão fica pronta para entregar "Ready to turn in." ou "Not taken."
reset Esquece a missão, para que possa ser aceita de novo "Forgotten." 
/quest give slime_trouble
/quest finish slime_trouble Aria

#/flag
Sintaxe /flag key [value] [player]
Nível 3

Lê uma marca de história (um número inteiro por chave no personagem), ou a define quando um valor é dado. Responde key = value. As marcas comandam condições em missões, diálogos e gatilhos.

/flag met_the_king
/flag met_the_king 1

#/trigger
Sintaxe /trigger id
Nível 3

Dispara um gatilho do mundo neste mapa, incluindo suas condições, como se você o tivesse disparado. Responde "Done." ou por que ele não disparou. Veja Gatilhos do mundo.

#/item
Sintaxe /item id [amount] [player]
Nível 4
Padrão 1
Limite 1 a 9.999

Coloca itens em uma bolsa, pelo seu id no Game Database. Responde "Gave N Item to Name." e, quando a bolsa está cheia, "N didn't fit."

/item health_potion 20
/item health_potion 5 Aria

#/gold
Sintaxe /gold amount [player]
Nível 4
Limite -1.000.000.000 a 1.000.000.000 por vez

Adiciona ouro, ou o tira com uma quantia negativa (nunca abaixo de 0). Responde "Name has N gold."

/gold 10000
/gold -500 Aria

#/currency
Sintaxe /currency id amount [player]
Nível 4
Limite -1.000.000.000 a 1.000.000.000 por vez

Adiciona qualquer moeda pelo seu id, ou a tira com uma quantia negativa.

  • Uma moeda normal vai para o personagem, que precisa estar neste mapa. Responde "Name has N Currency."
  • Uma moeda premium vai para o saldo da conta no serviço Shop. O alvo pode estar offline ou em outro mapa. O mapa responde "Asking the shop to give N Gems for Name." e a resposta do Shop vem em seguida no chat. Precisa do serviço Shop; caso contrário: "This map has no Shop service."
/currency event_tokens 50
/currency gems 100 Aria

#/xp
Sintaxe /xp amount [player]
Apelido /exp
Nível 4
Limite 1 a 1.000.000.000

Dá experiência, com subidas de nível normais.

#/level
Sintaxe /level n [player]
Nível 4

Sobe um jogador nível a nível até n, com os pontos e recompensas de cada nível. Nunca abaixa um nível. Responde "Name is level N."

#/points
Sintaxe /points attribute skill [player]
Nível 4
Limite 0 a 1.000 cada

Dá pontos de atributo e pontos de habilidade para gastar.

/points 10 5

#/skill
Sintaxe /skill id [rank] [player]
Nível 4
Padrão Rank 1

Ensina uma habilidade pelo seu id, em um rank. Responde "Name knows Skill." ou por que ela não pode ser ensinada.

#/rates
Sintaxe /rates, /rates kind value [minutes], /rates off
Apelidos /rate, /event
Nível 4
Limite Valor de 0 a 100

Sem argumentos, mostra as taxas de experiência, saque e ouro em vigor, com a taxa do servidor e a parte do evento, e quem iniciou o evento e quantos minutos faltam.

Com um tipo e um valor, inicia ou muda um evento de taxas em todos os mapas:

Tipo Também aceito
exp xp, experience
loot drop, drops
gold
all Define as três
  • Um valor de 2 é o dobro. O evento multiplica as taxas do servidor de Game Settings.
  • Um evento novo dura 60 minutos, a menos que você dê os minutos. Mudar um evento em andamento sem minutos mantém o fim dele.
  • /rates off (ou reset, end) encerra o evento.
  • Todos são avisados quando um evento começa ou muda.
/rates
/rates exp 2 120
/rates all 1.5
/rates off

#/role
Sintaxe /role player level
Nível 4, sempre
Só online Sim

Define o nível de GM da conta de um personagem: 1 jogador, 2 moderador, 3 game master, 4 administrador. O jogador não precisa estar no seu mapa. O nível do próprio comando não pode ser mudado em Game Settings.

Caso Resposta
Feito, subindo um nível "Name's account is now Moderator (2). It takes effect the next time they enter a map."
Feito, baixando um nível "... They were disconnected to take it." O jogador é desconectado na hora
Sua própria conta "You can't change your own level."
Alguém do seu nível ou acima "You can't change the level of someone at your level or above."
Um nível acima do seu "You can't give a level above your own."
Um nível inválido "Usage: /role player level (1 to 4)"

A mudança e sua linha de auditoria são salvas juntas.

/role Aria 2

#/audit
Sintaxe /audit [player]
Nível 4
Só online Sim

Os últimos comandos de GM registrados, de um jogador ou de todos.

#Comandos de chat para todo jogador

Estes são tratados pelo cliente e não precisam de nível de GM. Os comandos de canal sozinhos (sem texto) trocam o canal padrão; com texto, enviam uma vez.

Comando Apelidos O que faz
/s [text] /say Dizer: jogadores por perto
/m [text] /y, /map Todos neste mapa
/g [text] /world Todos online
/p [text] /party Seu grupo
/gu [text] /guild Sua guilda
/al [text] /alliance A aliança da sua guilda
/w name text /whisper, /tell Uma mensagem privada
/r text /reply Responde ao último sussurro ("Nobody to reply to yet." se não há nenhum)
/invite name Convida um jogador para o seu grupo
/leave Sai do seu grupo
/kick name Remove um jogador do seu grupo
/promote name /lead Torna um jogador o líder do grupo
/friend name Adiciona um amigo
/unfriend name Remove um amigo
/trade name Pede uma troca a um jogador
/ginvite name Convida um jogador para a sua guilda
/gm /panel Abre o painel de GM, só para a equipe

Com o módulo Chat desligado, texto comum não pode ser enviado ("Chat is off in this game. Commands start with /."), mas os comandos continuam funcionando.

#O painel de GM

F8 ou /gm abre o painel de GM para contas de nível 2 ou mais. Ele monta as mesmas linhas de comando do chat, com botões; o servidor ainda verifica o nível de cada uma, então um cliente modificado não ganha nada. Ele tem quatro abas, cada uma mostrada só quando você pode usar pelo menos um dos comandos dela:

Aba Comandos por trás dos botões
Players who (atualizar a lista), goto, summon, boot, mute e retirar o silêncio, ban e retirar o banimento (pergunta antes, 24 horas por padrão), heal, logs, role (pergunta antes)
Items item, gold, xp, level
World rates (mostrar, aplicar, encerrar), spawn, killall, map, god
Moderation announce, reports, closereport, logs, audit

Clicar em um jogador da lista preenche o alvo; um alvo vazio significa você mesmo. Veja Ferramentas de GM.
