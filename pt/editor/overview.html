O editor

Overview

Overview é a primeira página da janela KitARPG. Ela diz se o projeto está pronto para jogar, lista em ordem o que falta fazer com um botão para cada passo, e reúne em um só lugar o Play e as ferramentas mais usadas.

#Onde fica

Abra a janela KitARPG (KitARPG > Open KitARPG ou Ctrl/Cmd+Shift+K) e escolha Overview no topo da barra lateral. Quando há atualizações do kit esperando, a barra lateral mostra a contagem delas ao lado de Overview.

#O cabeçalho

A página começa com o título "KitARPG" e a linha "Everything for your game in one place. Pick a page on the left, or start here." (tudo para o seu jogo em um só lugar; escolha uma página à esquerda ou comece aqui). Abaixo:

  • Version seguido da versão do kit que você tem instalada.
  • What's new, um link que abre a janela do changelog com todas as versões, da mais nova para a mais antiga. A mesma janela abre em KitARPG > What's New.

#To do

Quando algo está entre o seu projeto e o jogo, aparece um cartão laranja chamado To do (a fazer) com a linha "In order. Each button does that step." (em ordem; cada botão faz esse passo). Cada linha tem uma luz, um título, uma linha de detalhe e um botão. Faça-as de cima para baixo.

Quando não falta nada, o cartão é substituído por uma linha verde:

  • Um jogador: "Everything is ready to play."
  • MMO: "Everything is ready: services up, map server current, nothing missing."

As linhas que podem aparecer, na ordem em que são listadas:

Linha Quando aparece Botão O que o botão faz
1 kit update ou N kit updates O kit adicionou algo que o seu jogo ainda não tem. O detalhe nomeia cada atualização e diz que o que você mudou à mão continua Apply Mostra um diálogo listando cada atualização e exatamente o que ela muda, depois as aplica em ordem. Veja Atualizar o kit
N problem(s) in the project A última verificação do projeto encontrou erros. "Builds stop on them." Review Abre o Project Check
Build the services Só MMO. Login, Central, o Shop e o launcher ainda não estão compilados. Durante a build, o detalhe diz "Building..." e o botão some Build Roda dotnet build na solução dos serviços
The services didn't build Só MMO. A última build falhou. O detalhe mostra as linhas de erro Try again Gera a build de novo
Build the map server Só MMO, quando pelo menos um mapa roda pela build do servidor de mapa e essa build falta, não tem a cena de um mapa, ou é mais antiga que um script, cena ou definição de assembly a partir do qual foi gerada. O detalhe diz qual. Se os serviços estiverem rodando, ele acrescenta "Restart the services after it." Build Gera a build do servidor de mapa para a plataforma do seu editor (Mac ou Windows)
Start the services Só MMO. Os serviços estão compilados mas não estão rodando Start Inicia o Login, o Central e os mapas neste computador
Restart the services Só MMO, aviso. Os serviços rodam código ou um servidor de mapa mais antigo do que o que está compilado agora Restart Para os serviços e os inicia de novo
No map reached Central Só MMO, erro. O Central responde há mais de 25 segundos e nenhum mapa se registrou. Os jogadores não conseguem entrar Build ou Open Build quando a build do servidor de mapa está desatualizada; gere-a e depois reinicie. Caso contrário, Open vai para Play & Servers, cujo log diz por quê
Start the shop Só MMO. O serviço Shop está no projeto, a loja está ligada nas configurações do launcher e o módulo In-game shop está ligado, e o serviço está compilado mas não está rodando Start Inicia o serviço Shop sozinho. Veja Shop
Dica

As linhas dos serviços e do servidor de mapa são as mesmas verificações que Play & Servers faz, em uma só lista. Se você prefere ver o detalhe completo, trabalhe a partir de Play & Servers.

#Blocos de estado

Quatro blocos ficam abaixo do cartão To do. Clique em um bloco para abrir sua página.

Bloco Valores Abre
Como o jogo roda Single player, MMO, ou Not set quando não há asset de configurações Play & Servers
Serviços Not needed no modo de um jogador; no MMO Running (Login e Central respondem), Starting ou Stopped Play & Servers
Verificação do projeto ... enquanto a primeira verificação roda, N errors, N warnings ou All good Project Check
Módulos ligados Uma contagem no estilo 11 of 15, ou None quando nenhum Game Instance foi encontrado Modules

#Play

O cartão Play muda conforme o modo:

Modo e estado Linha do cartão Botões
Um jogador "The editor hosts the world and plays it." ▶ Play abre a cena Title e entra em Play Mode como um jogo de um jogador
MMO, serviços parados "Start the services, then play as a client." Start services abre Play & Servers, onde você os inicia. Play with two players
MMO, serviços rodando "The services are up. Play joins them as a client." ▶ Play abre a cena Title e joga como cliente dos serviços locais. Play with two players

Play with two players abre um segundo editor e entra nos dois com contas de teste. Ele precisa do pacote Multiplayer Play Mode da Unity e fica cinza em Play Mode. Veja Jogar com dois jogadores.

▶ Play fica cinza enquanto o editor já está em Play Mode, e no MMO enquanto os serviços estão parados.

#Game data

O cartão Game data (dados do jogo) mostra o caminho do seu banco de dados do jogo e seis contagens: Classes, Skills, Items, Monsters, Quests e Maps. As contagens incluem as entradas que o banco de dados alcança por referências, não só as que estão nas suas listas.

Se o banco de dados tiver problemas, uma linha laranja diz "N problem(s) in the data. The database page lists them."

Botões:

  • Open the database abre o Game Database.
  • Game settings abre o Game Settings.

Quando o projeto ainda não tem banco de dados do jogo, o cartão diz "No game database yet." e mostra Open the game database, onde você pode criar um.

#Tools

Ferramenta Botão O que faz
Amostra inicial Build sample ou Start over Gera a amostra inicial: as cenas Title, Town e Forest, uma masmorra, o prefab de rede, os prefabs de jogador, toda a interface e os dados da amostra. Quando a amostra já existe, o botão diz Start over e pergunta antes, porque ele faz de novo do zero as cenas, os prefabs e os dados da amostra e as mudanças neles se perdem. Seus próprios assets em outros lugares continuam
Dados do jogo para os serviços Export Escreve gamedata.json na pasta Login do código-fonte dos serviços, para serviços que você roda à mão. Play & Servers escreve sua própria cópia cada vez que inicia os serviços, então você não precisa disto para jogar localmente
Ícones de itens Render icons Renderiza um ícone para cada item que não tem. O mesmo que KitARPG > Render Missing Item Icons
Assistente de configuração Open Roda de novo os primeiros passos: como o jogo roda, depois gráficos, fontes e as cenas da amostra em um clique
Documentação Open Abre esta documentação no seu navegador, a partir da cópia dentro do pacote (Documentation/Web), no idioma do editor quando ele é inglês, espanhol, português ou chinês. Funciona offline. O mesmo que KitARPG > Documentation
Atenção

Start over não é a forma de obter o que uma versão mais nova do kit adiciona. Ele gera a amostra de novo e perde toda mudança que você fez no HUD, nos prefabs, nas cenas e nos dados da amostra. Use as atualizações do kit no cartão To do: elas só adicionam o que falta.

#Um jogador e MMO

  • No modo de um jogador, o cartão To do só mostra atualizações do kit e erros do projeto. Não há serviços, servidor de mapa nem loja para configurar.
  • No MMO, o cartão guia você por gerar a build dos serviços, gerar a build do servidor de mapa, iniciar os serviços e iniciar a loja.

#Erros comuns

  • "No map reached Central" depois de gerar um mapa novo. A build do servidor de mapa ainda não tem a cena nova. Pressione Build, espere a build e depois reinicie os serviços.
  • O bloco dos serviços fica em Starting. Abra Play & Servers e olhe o log. Uma porta em uso ou a falta do SDK do .NET 10 são as causas habituais.
  • A verificação do projeto mostra "..." por muito tempo. A verificação roda uma vez quando a janela abre. Um projeto muito grande leva alguns segundos; ela não abre cenas para esta verificação rápida.
