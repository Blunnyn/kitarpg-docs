O editor

Project Check

O Project Check percorre o seu projeto em busca de problemas que quebram o jogo, os salvamentos ou as builds: referências quebradas, ids repetidos, prefabs que não podem ir pela rede, cenas faltando, ofertas da loja que o jogo não consegue vender e mais. Ele lista o que encontra por área, com um botão para selecionar a causa e, para muitos problemas, um botão que os corrige. Ele também roda antes de cada build.

#Onde fica

  • KitARPG > Project Check (abre a página e faz uma verificação completa), ou
  • a página Project Check na janela KitARPG (Ctrl/Cmd+Shift+K), em Project.

A barra lateral mostra o número de erros em vermelho, ou de avisos em laranja quando não há erros. A Overview mostra o mesmo resultado no bloco project check.

#Quando ele roda

Quando O que verifica
A janela KitARPG abre Tudo, menos o interior das cenas de mapa, um instante depois de abrir, para que a janela continue rápida
KitARPG > Project Check ou Check again Tudo, incluindo abrir a cena de cada mapa em segundo plano para verificar o conteúdo
Antes de cada build Tudo, menos o interior das cenas de mapa. Para a build se houver erros, a menos que você desligue isso
Depois de pressionar um botão de correção Tudo de novo

Verificar as cenas abre cada cena de mapa de forma aditiva e a fecha de novo se ela não estava aberta, então demora mais em um projeto grande.

#A página

Três blocos mostram as contagens:

Bloco Significa
errors: break the game or its saves Corrija estes. As builds param neles
warnings: worth a look O jogo roda, mas algo provavelmente não é o que você quer
notes Informação, como itens sem ícone ou dados que o jogo não alcança

Abaixo deles:

  • Check again faz uma verificação completa.
  • Show notes: as notas ficam ocultas até você marcar isto.
  • Stop builds on errors (ligado por padrão): a verificação antes de cada build para a build quando encontra erros. A escolha fica salva nas preferências do seu editor.

Depois vêm os resultados, um cartão por área, com o nome da área e uma contagem. A cor do cartão é a do seu pior resultado. Cada resultado tem um ponto colorido, a mensagem e até dois botões:

  • Select seleciona e destaca o asset, o prefab ou a cena de que se trata.
  • Um botão de correção, como Add it ou Use starter scenes, que o corrige. Os assets são salvos depois da correção e a verificação roda de novo.

Quando nada é encontrado: "No problems found. The project is ready to play and build." (ou quantas notas estão ocultas).

#Todas as verificações

As verificações rodam nesta ordem. As tabelas listam cada mensagem, o seu nível, o que significa e como corrigir. As mensagens mostram os nomes reais dos seus assets no lugar dos ....

#Updates

Nível Mensagem Significado e correção
Aviso "Update title is missing. What it changes" O kit tem algo que o seu jogo ainda não tem. Apply adiciona só o que falta. Veja Atualizar o kit

#Input e Settings

Nível Área Mensagem Significado e correção
Aviso Input "...'s EventSystem has the UI module of the other input system, so menus may not take clicks." O EventSystem da cena usa o módulo do Input Manager em um projeto que usa o Input System, ou o contrário. Fix scenes troca o módulo em todas as cenas que precisam
Aviso Settings "... overrides Game Settings on its Game Instance (fields), so changes in Game Settings don't reach that scene." A cena mudou valores na sua cópia do prefab de rede. Fix scenes reverte essas sobrescritas para que a cena use o Game Settings

Fix scenes pede para salvar as cenas abertas antes, corrige cada cena, salva-a e reabre o que você tinha aberto.

#Text

Nível Mensagem Significado e correção
Erro "TextMesh Pro's essential resources aren't in the project, so every label in the kit's UI and sample has no font." Import TMP Essentials os importa

#Database

Nível Mensagem Significado e correção
Erro "No game database. Put one on the GameInstance of the network prefab, or build the starter sample." Build sample monta a amostra inicial, que traz um. Ou defina o seu no Game Settings
Erro Cada problema que o banco de dados informa, como "Two player models use the id '...'", "Player model '...' has no classes, so nobody can pick it.", "'...' is used by both ... and ...", "... has no id.", "Map '...' has no scene.", "No damage elements: hits without an element can't be dealt or resisted.", "... is in Player Models but has no PlayerModel component." Abra o Game Database e corrija a entrada indicada
Erro "No start map: new characters have nowhere to appear." Defina Start Map em Settings do Game Database
Erro "No gold currency: gold shows without a name or icon." Defina Gold em Settings do Game Database

#Ids

Nível Mensagem Significado e correção
Erro "... has no id, so saves can't point at it." Use the name cria um id a partir do nome do asset
Aviso "... has the id '...'. Ids read best as lowercase letters, digits, - and _." Renomeie o id, a menos que os jogadores já o tenham salvo
Erro "... and ... are both Type '...'. Only one will be found." Dois assets do mesmo tipo compartilham um id. Mude um deles. Tipos diferentes podem compartilhar um id

#Unused data

Nível Mensagem Significado e correção
Nota "... (Type) isn't reached from the game database, so the game won't know it. List it in the database or reference it from something that is." O asset existe no projeto, mas nunca no jogo. Crie as entradas pela página Game Database, ou use o botão Collect referenced dela depois de ligá-las

#Items

Nível Mensagem Significado e correção
Aviso "... stacks up to N but has random bonuses. Each copy keeps its own rolls, so copies never stack. Make the bonuses fixed or set Max Stack to 1." Make bonuses fixed transforma cada bônus aleatório em um bônus fixo no meio do seu intervalo

#References

Nível Mensagem Significado e correção
Erro "...: 'field' points at something that was deleted." Um campo mostra "Missing" no Inspector. Escolha outra coisa ou limpe-o. Verificado em todo asset de dados do jogo e em todo componente das cenas de mapa
Erro "... has an effect or condition whose class no longer exists." Um efeito de habilidade, efeito de item, condição ou ação foi apagado ou renomeado no código. Restaure a classe ou remova a entrada
Aviso "Loot table ... has a drop with no item." Defina o item ou remova o drop
Aviso "Shop ... has an entry with no item." Defina o item ou remova a entrada
Erro "...: ... has an option whose class no longer exists." Um NPC em uma cena de mapa tem uma opção cuja classe não existe mais

#Quests

Nível Mensagem Significado e correção
Aviso "Quest ... hands out ..., which isn't a quest item. It can be traded or sold, and then the quest can't be given up. Tick Quest Item on it." Abandonar uma missão recolhe os seus itens iniciais. Marque Quest Item no item

#Icons

Nível Mensagem Significado e correção
Nota "... has no icon." Render icons renderiza um ícone para cada item que não tem

#Shop

Nível Mensagem Significado e correção
Erro "Shop ... charges in ..., a premium currency. Premium currency is only spent at the in-game shop." Uma loja de NPC usa a moeda premium. Defina ouro ou outra moeda normal
Erro "Player model ... has no PlayerShop, so the shop can't open for it." Aparece quando o jogo tem uma moeda premium. Aplique a atualização do kit "Shop on the player prefabs"
Erro "... can't be read: ..." O arquivo do catálogo da loja não é um JSON válido
Aviso "Shop offer ... problem. The Shop service skips it." A oferta quebra uma regra do catálogo, como não ter id, preço ou itens. Corrija-a na página Shop
Aviso "Two shop offers use the id '...'." Dê um novo id a uma delas
Aviso "Shop offer ... charges in '...', which isn't a premium currency of the game database." Marque Premium nessa moeda, ou monte a amostra inicial para ter Gems
Aviso "Shop offer ... sells '...', which the game database doesn't have." Corrija o item ou adicione-o ao banco de dados
Aviso "Shop offer ... sells a quest item, ..." Remova-o da oferta

As verificações da loja leem o catálogo que a página Shop edita (UserSettings/KitARPG/shop-conf.json), ou o exemplo que vem com o serviço Shop quando não há um. Os problemas do catálogo são avisos porque o catálogo pertence ao serviço Shop, não à build do jogo.

#Guilds

Nível Mensagem Significado e correção
Erro "The guild hall map ... isn't instanced, so every guild would share one hall." Make it instanced marca Instanced no mapa
Erro "The guild hall map ... isn't in the game database's maps, so no map server runs it." Adicione o mapa à lista Maps
Aviso "The founding item ... is a quest item." Escolha outro item para fundar guildas

#Network e Scripts

Nível Área Mensagem Significado e correção
Erro Network "Player model ... has no NetworkIdentity." Add it adiciona o componente ao prefab
Erro Network "Monster ... has no prefab, so it can't spawn." Defina o prefab do monstro
Erro Network "..., the prefab of ..., has no NetworkIdentity." Add it
Erro Network "..., the prefab of ..., has no Monster component." Adicione o componente Monster ao prefab, ou crie-o com o assistente de novo monstro
Erro Scripts "... has N missing script(s)." Um prefab em Assets/Blunnyn ou Assets/Game tem componentes cujo script não existe mais. Remova-os no prefab
Erro Network "... has Component but no NetworkIdentity." Um prefab tem um componente de rede sem um NetworkIdentity nele ou em um pai. Add it
Aviso Network "... lists an empty spawnable prefab." O prefab do network manager tem um espaço vazio nos seus spawnable prefabs. Remova-o
Erro Network "... is spawnable in ... but has no NetworkIdentity." Adicione um NetworkIdentity a esse prefab

#Scenes

Nível Mensagem Significado e correção
Erro "Build Settings has no scenes." Use starter scenes
Erro "Build Settings lists ..., which doesn't exist." Remova a entrada em File > Build Profiles
Aviso "The first scene is ...; the kit starts at Title." Use starter scenes, ou mova Title para o topo
Erro "Map '...' names no scene. Pick its scene in the Game Database, on the map's page." Defina a Scene do mapa
Erro "Map '...' uses the scene '...', and no scene has that name. Make it, or fix the name on the map's page." Crie a cena ou corrija o nome
Erro "Map '...' uses the scene '...', which isn't in Build Settings. Builds add it anyway; Play in the editor needs it listed." Add map scenes adiciona todas as cenas de mapa ao Build Settings
Erro "... has no SpawnPoint; players arriving at '...' have nowhere to stand." Adicione um Spawn Point à cena. Só na verificação completa
Erro "...: ... has N missing script(s)." Um objeto em uma cena de mapa tem scripts faltando. Só na verificação completa
Erro "...: ... and ... share the NPC id '...', so the server can't tell them apart." Dê a cada NPC o seu próprio id. Só na verificação completa
Aviso "...: spawner ... has no monster." Defina o monstro do spawner. Só na verificação completa

Os resultados "Só na verificação completa" vêm de abrir as cenas, então aparecem depois de Check again ou de KitARPG > Project Check, não na verificação rápida quando a janela abre.

#Validator

Nível Mensagem Significado
Erro "A check failed: ..." Uma verificação em si lançou um erro. O erro completo está no Console

#Antes de cada build

Toda build, pelos menus do kit ou pela própria janela Build do Unity, roda a verificação antes, sem abrir cenas. Quando encontra erros e Stop builds on errors está ligado, ela registra cada erro no Console com [KitARPG] e para a build com "KitARPG found N problem(s) in the project. See the Console or KitARPG > Project Check. The check can be turned off there."

Atenção

Desligar Stop builds on errors deixa passar builds quebradas. Use isso só para testar uma build quando você sabe o que está errado.

O kit também verifica que cada build leva só o código que deve levar. Essa verificação é separada; veja KitARPG > Check Build Separation em Menus e Segurança.

#Passo a passo: chegar a zero erros

  1. Abra KitARPG > Project Check. Ele faz a verificação completa.
  2. Resolva primeiro os cartões vermelhos. Pressione o botão de correção quando houver um; senão, pressione Select e corrija o asset manualmente.
  3. Pressione Check again.
  4. Leia os avisos. Corrija os que importam para o seu jogo.
  5. Marque Show notes de vez em quando para encontrar dados que o jogo não alcança e itens sem ícone.

#Adicionar as suas próprias verificações

Adicione um método a ProjectValidator.Checks a partir de um script de editor, e ele roda com os outros, também antes das builds. Create > KitARPG > Scripts > Validator Check (Editor) cria um script inicial. Veja Extensões do editor.
