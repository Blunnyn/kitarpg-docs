O editor

Menus

Esta página lista todos os menus que o kit adiciona ao editor do Unity: o menu KitARPG na barra de menus, seus submenus Starter, Tools e DevKit, e o menu Create > KitARPG na janela Project. Cada entrada diz o que faz e onde ler mais.

#O menu KitARPG

O menu KitARPG fica na barra de menus do Unity. As entradas, de cima para baixo:

Menu Atalho O que faz
KitARPG > Open KitARPG Ctrl/Cmd+Shift+K Abre a janela KitARPG na última página que você usou
KitARPG > Setup Wizard Abre o assistente de configuração: como o jogo roda, depois gráficos, fontes e as cenas da amostra com um clique
KitARPG > Play and Servers Abre a janela em Play & Servers
KitARPG > Game Database Abre a janela em Game Database
KitARPG > Play With Two Players Inicia os serviços se for preciso, abre um segundo editor e faz login nos dois com contas de teste. Só no MMO. Veja Jogar com dois jogadores
KitARPG > Game Settings Abre a janela em Game Settings
KitARPG > Export Game Data for Services Grava o banco de dados do jogo em gamedata.json na pasta Login do código-fonte dos serviços, para serviços que você roda manualmente ou coloca no Docker. Play & Servers grava a sua própria cópia quando inicia os serviços
KitARPG > Modules Abre a janela em Modules
KitARPG > Render Missing Item Icons Renderiza um ícone de 128 por 128 para cada item que não tem, a partir do modelo dele, em uma pasta Icons ao lado do item. O Console diz quantos foram criados
KitARPG > Shop Abre a janela na página Shop
KitARPG > Render Missing Monster Icons Renderiza um retrato para cada monstro com prefab e sem ícone, para o bestiário. Veja Bestiário
KitARPG > Project Check Abre a janela em Project Check e faz uma verificação completa, com as cenas
KitARPG > Check Build Separation Verifica, para cada tipo de build (cliente MMO, servidor de mapa MMO, um jogador), quais assemblies do kit ela levaria, e informa qualquer código que uma build não deveria ter. Uma caixa de diálogo dá o resultado e o Console, o detalhe. Veja Segurança
KitARPG > DevKit > Add Bounty Board to the Open Scene Coloca o quadro de recompensas do exemplo do DevKit, com duas caçadas feitas com os seus próprios monstros, no centro da Scene view. Veja Exemplo: quadro de recompensas
KitARPG > Starter > ... Monta a amostra e as builds; veja abaixo
KitARPG > Tools > Rebuild Character Controller Cria de novo o Animator controller que todos os personagens usam. Veja abaixo
KitARPG > Run Play Mode Tests Roda os testes de Play Mode do kit (KitARPG.Tests.PlayMode) e grava os resultados em Logs/KitARPG-PlayMode-Tests.xml no projeto Unity
KitARPG > Documentation Abre esta documentação no seu navegador a partir da cópia dentro do pacote, no idioma do editor quando o site o tem. Funciona offline
KitARPG > What's New Abre o registro de mudanças, da versão mais nova para a mais antiga, com Open the file para ler Documentation/CHANGELOG.md

#KitARPG > Starter

Menu O que faz Saída
Build Scenes and Prefabs Monta a amostra inicial: Title, Server, Town, Forest e as cenas de masmorra, o prefab de rede, os prefabs de jogador e de monstros, o HUD e os dados da amostra. Rodá-lo de novo cria tudo outra vez do zero, então as mudanças na amostra se perdem. Pare o Play antes Assets/Blunnyn/KitARPG/Samples/Starter/
Build Mac Server O servidor de mapa local para Mac: uma build de player com o código do servidor (KITARPG_SERVER) que o launcher roda sem gráficos Builds/Starter/MacServer/KitARPGServer.app
Build Windows Server O mesmo para Windows Builds/Starter/WindowsServer/KitARPGServer.exe
Build Mac Client O cliente MMO para Mac, compilado com IL2CPP Builds/Starter/MacClient/KitARPG.app
Build Mac Test Client Um cliente para Mac com as ferramentas de teste (login automático, smoke tests), compilado com Mono para uma build rápida. Só para verificações locais, nunca para jogadores Builds/Starter/MacTestClient/KitARPGTest.app
Build Windows Client O cliente MMO para Windows, compilado com IL2CPP Builds/Starter/WindowsClient/KitARPG.exe
Build Mac Single Player O jogo de um jogador para Mac, com o código do servidor para hospedar a si mesmo Builds/Starter/MacSinglePlayer/KitARPG.app
Build Windows Single Player O mesmo para Windows Builds/Starter/WindowsSinglePlayer/KitARPG.exe
Build Linux Server O servidor dedicado Linux para Docker, compilado com IL2CPP. Precisa do módulo Linux Dedicated Server do Unity Deploy/builds/starter/KitARPGServer.x86_64

Os caminhos Builds e Deploy são relativos à pasta que contém a pasta do seu projeto Unity.

Toda build:

  • pega as cenas dos mapas do Game Database, então um mapa novo entra em todas as builds sem editar uma lista. Se um mapa indica uma cena que não existe, a build para e diz qual;
  • define no asset de configurações o modo de jogo de que a build precisa e depois devolve o seu;
  • roda o Project Check antes e para se houver erros, a menos que Stop builds on errors esteja desligado;
  • verifica que leva só o código que deve levar.

Veja Builds e Docker.

#KitARPG > Tools

Rebuild Character Controller apaga e cria de novo Runtime/Resources/KitARPG/KitCharacter.controller, o único Animator controller que todos os personagens usam. Os estados dele guardam clips provisórios que o componente Character Animations de cada personagem troca pelos seus, então você nunca o edita. Use isso só se o controller foi apagado ou danificado.

#Create > KitARPG

Clique com o botão direito na janela Project, ou use Assets > Create > KitARPG, para criar assets e scripts do kit.

Dica

Os assets criados por este menu existem no projeto, mas não no jogo, até que o banco de dados do jogo chegue até eles. Criar entradas pela página Game Database as coloca na lista para você; o Project Check aponta as que ele não consegue alcançar.
