O editor

Game Settings

O Game Settings guarda as regras do seu jogo que não estão ligadas a um item, monstro ou mapa: o modo de controle, a interface, a bolsa, o saque, a economia, a loja do jogo, as taxas do servidor, o combate, a recuperação, a morte, o filtro do chat, os registros, o dia e a noite, o correio e os comandos de GM. Esta página lista cada configuração com o seu padrão.

#Onde fica

  • KitARPG > Game Settings, ou
  • a página Game Settings na janela KitARPG (Ctrl/Cmd+Shift+K).

#Onde as configurações ficam

As configurações são os campos do componente Game Instance (GameInstance) no prefab de rede. Na amostra inicial, esse prefab é o KitNetwork. As builds de cliente e de servidor o levam, então elas sempre concordam.

A página encontra o prefab sozinha. A linha do topo diz "Saved in KitNetwork." (o nome do prefab) com dois botões:

  • Select prefab seleciona e destaca o prefab na janela Project.
  • Modules abre a página Modules. Os interruptores dos módulos fazem parte do mesmo componente, mas são editados ali.

Cada mudança salva o prefab na hora. Não há botão Apply.

Se nenhuma Game Instance é encontrada, a página mostra No GameInstance found ("It sits on the network prefab. Build the starter sample, or add one.") com Open the setup wizard.

Atenção

As configurações não podem ser mudadas no Play Mode. Os campos ficam desativados e a página diz "Stop Play to change the settings." Pare o Play antes.

Nota

Uma cena que tem uma Game Instance com valores sobrescritos não vê as mudanças que você faz aqui. O Project Check informa isso ("... overrides Game Settings on its Game Instance") e Fix scenes remove as sobrescritas. Veja Project Check.

#As configurações

A página mostra os campos em cartões, um por grupo. Os padrões abaixo são os valores com que uma Game Instance nova começa; a amostra inicial preenche para você os campos de prefab e de asset (HUD, controles de toque, câmeras, arte da loja).

#Game

Campo O que faz Padrão
Database (database) O banco de dados do jogo que o jogo lê. Veja Game Database None

#Game mode

Campo O que faz Padrão
Control Mode (controlMode) Como o jogo é jogado: Top-down (click or keys), no estilo Diablo; Free camera (cursor, right button turns); ou Third person (crosshair aim), em que o mouse gira. O servidor e os clientes precisam coincidir: um mapa recusa um cliente de outro modo. Os modos que o seu código registra também aparecem na lista Top-down
Third Person Camera (thirdPersonCamera) O asset Camera Settings do modo terceira pessoa. Edite-o enquanto joga para testar; as mudanças ficam None
Free Camera (freeCamera) O asset Camera Settings do modo câmera livre. Edite-o enquanto joga para testar; as mudanças ficam None

Veja Modos de controle.

#Interface

Campo O que faz Padrão
Hud Prefab (hudPrefab) Canvas com o HUD e as janelas do jogo. Criado uma vez nos clientes e mantido entre mapas. Vazio: as cenas trazem o seu próprio None
Input Layout (inputLayout) Com o que o jogo é jogado. Auto: toque em celulares e tablets, mouse e teclado no resto. Mouse And Keys. Touch: só os controles na tela, as teclas do jogo ficam desligadas. Touch And Keys: mostra os controles de toque e mantém o teclado funcionando, para tablets com teclado ou para testá-los no editor Auto
Touch Controls Prefab (touchControlsPrefab) Canvas com os controles na tela, mantido entre mapas como o HUD None
Item Details On Hover (itemDetailsOnHover) Apontar para um item mostra os stats dele. Desligado: clique no item para vê-los Off
Title Music (titleMusic) Toca em loop na tela de título. Cada mapa define a sua no Game Database None
Font (font) A fonte de todo texto do jogo, um font asset do TextMesh Pro. Vazio: a padrão do TextMesh Pro None

#Fonte

Abaixo das configurações, o cartão Font muda a fonte do jogo inteiro:

  1. Solte um .ttf ou .otf do projeto em Font file e pressione Make font: o kit cria um font asset do TextMesh Pro em Assets/Game/Fonts que preenche suas letras conforme são usadas, com a padrão do TextMesh Pro como reserva para letras que faltam, e o define como Font. Um font asset do TextMesh Pro que você já tenha pode ir direto em Font.
  2. Pressione Apply to the UI. Todo texto nos prefabs e cenas dentro de Assets que usa a fonte anterior recebe a nova, e textos novos também a usam. Textos aos quais você deu outra fonte à mão mantêm a deles.

Para voltar, esvazie Font e aplique de novo.

Veja HUD e janelas e Controles de toque.

#Bag

Campo O que faz Padrão
Bag Mode (bagMode) Slots: um número fixo de espaços. Weight: cabe qualquer coisa até um peso que cresce com o stat de capacidade de carga Slots
Bag Slots (bagSlots) Os espaços de uma bolsa, no modo Slots 40
Weight Mode Slots (weightModeSlots) Modo Weight: as pilhas diferentes que uma bolsa pode guardar, para que ela não cresça para sempre 200
Carry Weight (carryWeight) Modo Weight: o que qualquer um pode carregar. O equipamento e os atributos somam o seu stat de capacidade de carga 1.000
Bank Slots (bankSlots) Os espaços do banco, que todos os personagens de uma conta compartilham. Ele não tem limite de peso 80

Veja Inventário e banco.

#Loot

Campo O que faz Padrão
Loot Mode (lootMode) Como os jogadores recebem o que os monstros deixam cair. Ground: cada item cai ao lado do monstro. Corpse: os itens ficam no corpo e clicar nele abre uma janela de saque. Automatic: os itens vão direto para a bolsa, e o que não cabe cai no chão. Só o jogador que ganhou a morte o vê Ground
Auto Gold (autoGold) O ouro vai direto para o jogador. Desligado: ele cai como os itens, no chão ou no corpo On

Veja Saque.

#Economy

Campo O que faz Padrão
Players Sell To Npcs (playersSellToNpcs) As lojas compram o que os jogadores trazem. Desligado: nada é vendido aos NPCs; os itens circulam entre jogadores, no mercado ou na forja, e o saque nunca vira ouro. Uma loja ainda pode recusar por conta própria Off
Market Fee Percent (marketFeePercent) A porcentagem do preço pedido que se paga para colocar um lote no mercado, no mínimo 1. Ela tira ouro do jogo. De 0 a 50 2

Veja Lojas de NPC e Mercado.

#Shop

Campo O que faz Padrão
Shop Art (shopArt) Imagens para os cartões e o banner da loja do jogo, encontradas pelas chaves que as ofertas indicam. A página Shop cria um quando você escolhe a primeira imagem None
Shop Top Up Url (shopTopUpUrl) A página onde os jogadores compram moeda premium, aberta pelo + ao lado do saldo. Vazio esconde o botão Vazio
Shop Auto Take (shopAutoTake) As compras e os presentes da loja vão direto para a bolsa quando chegam. Desligado, ou quando a bolsa está cheia, eles esperam no correio On

Veja Página Shop e Loja do jogo.

#Rates

Campo O que faz Padrão
Experience Rate (experienceRate) A experiência de mortes e missões é multiplicada por isto em todo o servidor. 2 é o dobro 1
Loot Rate (lootRate) A chance de drop de cada item é multiplicada por isto. 2 cai duas vezes mais, até sempre 1
Gold Rate (goldRate) O ouro que os monstros deixam cair é multiplicado por isto 1

Nenhuma delas pode ficar abaixo de 0. Os GMs podem fazer eventos de taxas temporários por cima dessas com o comando /rates. Veja Comandos de GM.

#Combat

Campo O que faz Padrão
Line Of Sight (lineOfSight) O que impede ataques, habilidades e monstros de enxergar através das paredes. Off: passam por tudo. Nav Mesh: os buracos no NavMesh bloqueiam (paredes, casas, troncos); não precisa de colliders. Colliders: os colliders nas camadas que bloqueiam a visão bloqueiam Nav Mesh
Sight Blockers (sightBlockers) Modo Colliders: as camadas que bloqueiam a visão. Os personagens nunca bloqueiam Camada Default
Heal Threat (healThreat) A parte da raiva de um monstro que se ganha ao curar alguém com quem ele luta, por ponto curado 0,5
Threat Switch (threatSwitch) Outro lutador toma a atenção de um monstro quando a sua ameaça passa a do alvo atual por este fator. Valores abaixo de 1 contam como 1 1,1
Monsters Sleep Unseen (monstersSleepUnseen) Os monstros que nenhum jogador vê param de pensar até que um se aproxime. Economiza tempo do servidor em mapas grandes On

Veja Combate.

#Recovery

Campo O que faz Padrão
Combat Seconds (combatSeconds) Os segundos que um jogador fica em combate depois do último golpe que recebeu ou deu, incluindo golpes errados e bloqueados 6
Regen In Combat (regenInCombat) A regeneração de vida e de mana continua em combate. Desligado: espera até a luta acabar On
Out Of Combat Regen (outOfCombatRegen) A regeneração fora de combate é multiplicada por isto. 3 recupera três vezes mais rápido entre as lutas 1
Level Up Restores Health (levelUpRestoresHealth) Chegar a um nível novo enche a vida On
Level Up Restores Mana (levelUpRestoresMana) Chegar a um nível novo enche a mana On

#Death

Campo O que faz Padrão
Death Experience Loss (deathExperienceLoss) A porcentagem da experiência que o nível atual exige que um jogador perde ao voltar no ponto de surgimento. Nunca tira um nível, e o reviver de um aliado a evita. De 0 a 100 5
Pvp Death Costs Experience (pvpDeathCostsExperience) Os jogadores mortos por outros jogadores também a perdem. Os duelos nunca custam nada Off
Respawn Health (respawnHealth) A porcentagem de vida com que um jogador volta no ponto de surgimento. De 1 a 100 100
Respawn Mana (respawnMana) A porcentagem de mana com que um jogador volta no ponto de surgimento. De 0 a 100 100

Veja Recuperação e morte.

#Chat filter

Campo O que faz Padrão
Blocked Words (blockedWords) As palavras que ninguém pode dizer, uma por entrada. Termine uma com * para pegar também o que começa com ela Vazio
Blocked Words File (blockedWordsFile) Mais palavras bloqueadas, uma por linha, para listas longas. Um asset de texto None
Chat Filter Mode (chatFilterMode) Mask esconde as palavras bloqueadas com asteriscos; Block descarta a linha inteira Mask

Veja Chat.

#Logs

Campo O que faz Padrão
Log Loot From (logLootFrom) O saque desta raridade ou melhor vai para o registro do jogo: Common, Magic, Rare, Epic ou Legendary Rare
Log Chat (logChat) Cada linha do chat também vai para o registro do jogo. As denúncias sempre levam as linhas ao redor Off

Veja Registro do jogo e denúncias.

#Day and night

Campo O que faz Padrão
Day Minutes (dayMinutes) Os minutos reais que dura um dia inteiro do jogo. 0 para o relógio na hora fixa 48
Day Start Hour (dayStartHour) A hora em que o relógio começa, para deslocar os dias em relação ao tempo real. De 0 a 24 8
Fixed Hour (fixedHour) A hora que o relógio mostra quando não corre. De 0 a 24 12
Night From (nightFrom) A noite começa nesta hora 20
Night To (nightTo) A noite termina nesta hora 6

Com o módulo Day and night desligado, é sempre a hora fixa. Veja Dia e noite.

#Mail

Campo O que faz Padrão
Mail Anywhere (mailAnywhere) Ler e enviar correio de qualquer lugar. Desligado: só em um NPC com a opção de caixa de correio On
Mail Postage (mailPostage) O ouro para enviar uma carta 10
Mail Postage Per Item (mailPostagePerItem) Mais ouro por item anexado 5
Mail Items (mailItems) Os itens que uma carta pode levar. A configuração MaxMailItems do Central deve coincidir 5

Veja Correio.

#Commands

Campo O que faz Padrão
Single Player Commands (singlePlayerCommands) Em um mundo de um jogador, o jogador pode usar todos os comandos de GM, como trapaças. Online, o papel da conta decide On
Gm Command Levels (gmCommandLevels) O nível de GM que cada comando exige, quando não é o padrão dele. Cada entrada tem Command (o nome sem a barra, como item) e Level: 1 jogador, 2 moderador, 3 game master, 4 admin. Mudar um papel (/role) sempre exige 4 Vazio

Veja Ferramentas de GM.

#Passo a passo: mudar uma configuração

  1. Pare o Play Mode se ele estiver rodando.
  2. Abra KitARPG > Game Settings.
  3. Encontre o cartão e mude o campo. O prefab se salva sozinho.
  4. Um jogador: pressione Play; a mudança já está valendo.
  5. MMO: compile o servidor de mapa de novo e reinicie os serviços pelo Play & Servers, porque os servidores de mapa rodam a partir da sua build. Os clientes que você distribui também precisam de uma build nova.

#Um jogador e MMO

  • No modo de um jogador, o jogo lê estas configurações diretamente do prefab na build.
  • No MMO, os servidores de mapa aplicam as regras do jogo (saque, taxas, combate, recuperação, morte, custos de correio) e os clientes usam as configurações de interface. Os dois leem o mesmo prefab das suas builds, então compile os dois de novo depois de mudar as configurações. O modo de controle precisa coincidir dos dois lados.
  • Alguns valores têm uma configuração correspondente nos serviços, como Mail Items e o MaxMailItems do Central. Veja Configuração.

#Dicas

  • Teste as taxas e os valores de recuperação primeiro no modo de um jogador; ele inicia em segundos.
  • Use Gm Command Levels para deixar os moderadores usarem um comando que por padrão é só de admin, sem mudar código.
  • Para um servidor hardcore, coloque Death Experience Loss alto e ative Pvp Death Costs Experience.

#Erros comuns

  • Editar a Game Instance em uma cena em vez do prefab. A cena mantém uma sobrescrita e o Game Settings não chega mais até ela. O Project Check a encontra.
  • Mudar configurações e testar uma build antiga do servidor de mapa. O servidor ainda tem os valores antigos. Compile-o de novo.
  • Um modo de controle diferente entre as builds de cliente e de servidor. O mapa recusa o cliente por modo diferente.
