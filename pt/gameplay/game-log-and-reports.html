Registro do jogo e denúncias

Três ferramentas ajudam você a administrar um jogo e mantê-lo justo: o registro do jogo, que anota o que acontece com contas, personagens, itens e ouro; as denúncias dos jogadores, que levam um problema aos moderadores junto com o chat ao redor; e o filtro do chat, que mascara ou bloqueia as palavras que você escolher. Esta página cobre cada uma delas, todas as opções e como funcionam em um jogador (single player) e no MMO.

#O registro do jogo

O registro do jogo é uma tabela, game_logs, com uma linha por evento: quando, tipo, mapa, conta, personagem, a outra parte, item, quantidade, ouro e um detalhe. Ela não tem chaves estrangeiras, então as linhas sobrevivem a personagens excluídos.

#O que ele registra

Tipo Quando
account.created, account.login, account.login_failed, account.resumed Contas criadas, logins e logins com falha com o IP, logins com "Remember me"
character.created, character.deleted Personagens criados e excluídos
session.enter, session.leave Entrar e sair do mundo
item.trade Trocas, com o que cada lado deu
item.shop_buy, item.shop_sell Compras e vendas em lojas de NPC
item.loot Espólio de raridade Log Loot From ou melhor
item.destroy Itens destruídos
item.forge Melhorias, engastes e desmontagem na forja
bank.deposit, bank.withdraw O banco da conta
guild.bank, guild.created, guild.collector O banco da guilda, guildas novas, coletores de impostos
mail.sent, mail.taken Cartas enviadas e itens ou ouro retirados delas
market.listed, market.sold, market.cancelled, market.expired O mercado
shop.premium_buy, shop.premium_gift, shop.premium_grant, shop.premium_topup, shop.premium_refund A loja do jogo e a moeda premium
combat.death, combat.pvp_kill Mortes e abates em PvP
character.level, character.experience_lost Níveis e experiência perdida ao morrer
quest.done Missões concluídas
chat.line Cada linha do chat, só com Log Chat ligado
gm.command, gm.ban Comandos de GM com a resposta, banimentos
report.sent, report.closed Denúncias de jogadores

O tipo é texto livre, então seu jogo pode adicionar os próprios (veja No código).

#Opções

Em KitARPG > Game Settings, seção Logs:

Campo O que faz Padrão
Log Loot From (logLootFrom) Espólio desta raridade ou melhor vai para o registro do jogo Rare
Log Chat (logChat) Cada linha do chat também vai para o registro do jogo. As denúncias sempre levam as linhas ao redor Desligado

No Login e no Central (appsettings.json ou variáveis de ambiente):

Opção O que faz Padrão
Logs:Days Linhas mais antigas que isto são excluídas, uma vez por hora. 0 as mantém para sempre 180

#Como as linhas chegam lá

  • O servidor de mapa junta suas linhas e as envia ao Central a cada 2 segundos. Se o Central estiver fora do ar, até 5.000 linhas ficam esperando. O Central marca cada linha com o mapa que a enviou.
  • O Login e o Central escrevem suas próprias linhas diretamente.
  • A escrita acontece em lotes a partir de uma fila, separada de cada requisição, então o registro nunca deixa um login ou uma troca mais lentos.

#Lendo o registro

  • No jogo, um moderador digita /logs player [kind] para ver as últimas 15 linhas daquele jogador, opcionalmente de um só tipo. item cobre todos os tipos item.*. A aba Moderation do painel de GM e o botão de registros de cada jogador em Players fazem o mesmo.
  • Fora do jogo, consulte a tabela game_logs com qualquer ferramenta SQL. Veja Banco de dados.
SELECT "At", "Kind", "Character", "Other", "ItemId", "Amount", "Gold", "Detail"
FROM game_logs WHERE "Kind" LIKE 'item.%' ORDER BY "At" DESC LIMIT 50;

As colunas são Id, At (UTC), Kind, MapId, AccountId, CharacterId, Character, OtherId, Other, ItemId, Amount, Gold e Detail. No PostgreSQL os nomes precisam das aspas duplas, como acima.

#Denúncias de jogadores

#Para o jogador

  • Clique com o botão direito em um jogador (ou no nome dele no chat) e escolha Report. Uma caixa de diálogo pergunta "Report name to the moderators?" com um campo de texto para contar o que aconteceu (até 200 caracteres).
  • Ou digite /report name reason.

Um jogador espera 60 segundos entre denúncias, e o Central aceita no máximo 10 por dia de uma mesma conta.

#O que uma denúncia leva

O mapa adiciona as últimas 30 linhas de chat que o denunciante viu, para que os moderadores leiam o contexto sem registrar todo o chat. A denúncia vai para a tabela reports e para o registro do jogo como report.sent.

#Para os moderadores

  • Os moderadores online recebem um aviso quando chega uma denúncia.
  • /reports lista as denúncias abertas.
  • /closereport id marca uma como resolvida (report.closed no registro).
  • /logs player [kind] mostra o que o jogador fez.

A aba Moderation do painel de GM tem o mesmo. Veja Ferramentas de GM.

#Filtro do chat

O filtro do chat oculta ou bloqueia as palavras que você listar. Ele roda no servidor.

#Opções

Em KitARPG > Game Settings, seção Chat filter:

Campo O que faz Padrão
Blocked Words (blockedWords) Palavras que ninguém pode dizer, uma por entrada. Termine uma com * para pegar também o que começa com ela Vazio
Blocked Words File (blockedWordsFile) Um asset de texto com mais palavras, uma por linha, para listas longas. Linhas que começam com # são comentários Vazio
Chat Filter Mode (chatFilterMode) Mask oculta as palavras bloqueadas com asteriscos; Block descarta a linha inteira e avisa o jogador Mask

#Como ele compara

  • Só palavras inteiras, então "class" não é pega por "ass".
  • Uma entrada terminada em * também pega palavras mais longas: dumb* pega "dumbest".
  • Dígitos e símbolos no lugar de letras são lidos como as letras, então d4rn e @ss são pegos.
  • Maiúsculas e minúsculas não importam.

#Onde ele se aplica

  • Linhas de chat em todos os canais.
  • Assuntos e textos do correio.
  • O aviso da guilda.
  • Nomes de guilda: um nome com uma palavra bloqueada é recusado.

#Passo a passo: adicionar uma lista de palavras

  1. Crie um arquivo de texto no seu projeto, por exemplo Assets/Game/BlockedWords.txt, com uma palavra por linha e linhas com # para anotações.
  2. Em Game Settings > Chat filter, arraste-o para Blocked Words File.
  3. Escolha o Chat Filter Mode.
  4. Recompile o servidor de mapa: o filtro roda lá.

#Um jogador e MMO

Um jogador MMO
Registro do jogo Na tabela game_logs do arquivo de salvamento, mantido por 90 dias No banco de dados do Central, mantido por Logs:Days
Denúncias, /reports, /logs Não disponíveis Sim
Filtro do chat Sim Sim, no servidor de mapa

#No código

  • GameLog.Write(kind, player, other, itemId, amount, gold, detail) adiciona uma linha a partir do código do servidor. Use seus próprios tipos, como bounty.claimed.
  • GameLog.Written é disparado para cada linha, para enviá-las também a outro lugar.
  • ChatFilter.Mask, ChatFilter.Blocks e ChatFilter.Apply verificam qualquer texto que você deixe os jogadores escreverem. SocialHub.Filter executa suas próprias regras de chat depois do filtro.

Veja Eventos e Regras de segurança.

#Erros comuns

  • O filtro deixa passar uma palavra com sufixo. Adicione * à entrada.
  • O filtro pega uma palavra inocente. Remova uma entrada com * que seja curta demais.
  • O espólio nunca aparece no registro. Log Loot From está acima da raridade dos itens.
  • A tabela cresce demais. Diminua Logs:Days ou deixe Log Chat desligado.
