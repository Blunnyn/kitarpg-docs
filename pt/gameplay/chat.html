Sistemas de jogo

Chat

A caixa de chat, seus canais, todos os comandos de barra, o filtro de palavras, silenciamentos, denúncias e os limites que o servidor impõe. Também explica como o chat viaja entre mapas em um MMO e o que sobra em um jogador.

#O que é

O chat é a caixa no canto inferior esquerdo do HUD. Os jogadores escrevem linhas para quem está perto, no mesmo mapa, no servidor inteiro, em privado, para o grupo, a guilda ou a aliança. O jogo também escreve linhas de sistema ali: "Letter sent to Ana.", "Ana is online.", erros de pedidos.

  • É o módulo Chat (PlayerChat no prefab do jogador, ChatWindow no HUD).
  • As linhas Say e Map são tratadas pelo servidor de mapa. As linhas World, Whisper para outro mapa, Party, Guild e Alliance passam pelo Central em um MMO.
  • O servidor verifica cada linha: tamanho, ritmo, silenciamentos, a lista de palavras bloqueadas e o seu próprio código de filtro.
  • Com o módulo desligado, os jogadores não podem conversar, mas comandos de barra como /help e os comandos de GM continuam funcionando.

#Onde fica no editor

O quê Onde
Ligar ou desligar KitARPG > Modules, módulo Chat. Veja Módulos.
Palavras bloqueadas, modo do filtro, registro do chat KitARPG > Game Settings, cartões Chat filter e Logs. Veja Game Settings.
Alcance do Say, tamanho da linha, ritmo, evidência de denúncia O componente PlayerChat em cada prefab de jogador.
A caixa de chat, cores, número de linhas ChatWindow no prefab do HUD. Veja HUD e janelas.
Esconder o chat em celulares TouchChatButton nos controles de toque. Veja Controles de toque.

#Canais

Canal Quem ouve Aparece como Cor na amostra
Say Jogadores na mesma cena de mapa dentro do Say Range (30 m). Name: text Branco suave
Map Todos na mesma cena de mapa. [Map] Name: text Laranja
World Todos os que estão online em todos os mapas. [World] Name: text Azul claro
Whisper Um jogador, pelo nome, em qualquer mapa. Name whispers: text e, para você, To Name: text Rosa
Party Os membros online do seu grupo, em qualquer mapa. [Party] Name: text Azul
Guild Os membros online da sua guilda, em qualquer mapa. [Guild] Name: text Verde
Alliance Todo membro online de toda guilda da aliança da sua guilda. [Alliance] Name: text Azul pálido
System Só você. Linhas do jogo. O texto Dourado

Cada cópia de uma masmorra instanciada é uma cena própria, então Say e Map em uma masmorra só chegam à sua cópia. Veja Masmorras.

Erros que você pode ver:

Situação Mensagem
Linha de Party sem grupo "You are not in a party."
Linha de Guild sem guilda "You are not in a guild."
Linha de Alliance sem aliança "Your guild is in no alliance."
Sussurro para si mesmo "Talking to yourself?"
Sussurro para alguém que não está online "Name is not online."

#Usar o chat como jogador

#Escrever

  • Pressione Enter (ou o Enter do teclado numérico), ou clique em qualquer lugar da caixa de chat, para começar a escrever. A caixa fica mais escura enquanto você escreve, para ficar claro para onde vão as teclas.
  • Enter envia a linha e para de escrever.
  • Esc limpa a linha e para de escrever.
  • Uma linha normal vai para o canal atual, mostrado no botão de canal à esquerda do campo. Clique nesse botão para alternar entre Say, Map, World, Party, Guild e Alliance.
  • Uma linha que começa com / é um comando.

Enquanto você escreve, as teclas do jogo não disparam (por exemplo, N não abre a caixa de correio).

#Nomes no chat

Os nomes dos jogadores são links:

  • Clique com o botão esquerdo em um nome para começar um sussurro para ele (/w Name é escrito para você).
  • Clique com o botão direito em um nome para abrir o menu do jogador: sussurrar, trocar, convidar para o grupo, adicionar amigo, convidar para a guilda, duelo, denunciar. Veja HUD e janelas.

Clicar no seu próprio nome não faz nada.

#O que a caixa guarda

A caixa guarda as últimas Max Lines (100) linhas. Ela fica oculta enquanto nenhum personagem está no mundo (título, seleção de personagem, carregamento). Trocar de personagem a limpa.

#Comandos de barra

Comandos tratados pela caixa de chat:

Comando Apelidos O que faz
/s text /say Say. Sem texto, torna Say o canal padrão.
/m text /y, /map Map. Sem texto, torna Map o canal padrão.
/g text /world World. Sem texto, torna World o canal padrão.
/p text /party Party. Sem texto, torna Party o canal padrão.
/gu text /guild Guild. Sem texto, torna Guild o canal padrão.
/al text /alliance Alliance. Sem texto, torna Alliance o canal padrão.
/w Name text /whisper, /tell Sussurra para um jogador.
/r text /reply Sussurra para o último jogador que sussurrou para você. "Nobody to reply to yet." se ninguém sussurrou.
/invite Name Convida um jogador para o seu grupo. Veja Amigos e grupos.
/leave Sai do seu grupo.
/kick Name Remove um membro (só o líder).
/promote Name /lead Torna um membro o líder (só o líder).
/friend Name Envia um pedido de amizade, ou aceita o dele.
/unfriend Name Remove um amigo ou um pedido.
/trade Name Pede uma troca a um jogador. Veja Troca.
/ginvite Name Convida um jogador para a sua guilda. Veja Guildas.
/gm /panel Abre o painel de GM, se a sua conta pode usá-lo. Veja Ferramentas de GM.

Qualquer outra coisa que comece com / vai para o servidor:

Comando Quem O que faz
/help (/commands) Todos Lista os comandos do chat e depois todo comando de GM que o nível da sua conta permite, com o nível.
/report Name reason Todos Denuncia um jogador aos moderadores. Só em MMO.
Comandos de GM Moderadores e acima /mute, /kick, /ban e o resto. Veja Comandos de GM.
Nota

/g é o canal World, não a guilda. Guilda é /gu.

#Limites que o servidor impõe

#PlayerChat (prefab do jogador)

Campo O que faz Padrão
Say Range (sayRange) Metros que uma linha Say alcança. 30
Max Length (maxLength) Caracteres por linha. Linhas mais longas são cortadas. 200
Burst (burst) Linhas permitidas em sequência; uma volta a cada segundo. 5
Report Lines (reportLines) Linhas que o jogador viu recentemente e que vão junto com uma denúncia que ele envia. 30
Report Cooldown (reportCooldown) Segundos entre duas denúncias de um jogador. 60

Com os padrões, um jogador pode enviar 5 linhas de uma vez e depois uma por segundo. Além disso: "You are talking too fast." Os comandos de barra dividem a mesma cota e respondem "You are typing too fast." Uma linha de comando para o servidor pode ter no máximo 300 caracteres.

Além disso, todo comando do cliente no servidor de mapa gasta de uma cota por conexão (30 por segundo, rajadas de 60). Um cliente muito acima dela é desconectado por flood.

#Limpeza

Antes de qualquer coisa, o servidor limpa cada linha: tira espaços das pontas, transforma caracteres de controle em espaços e quebra todo < para que nenhuma etiqueta de rich text possa abrir. Um jogador que escreve <color=red> o vê impresso como escrito, no chat de todos. Os nomes são limpos do mesmo jeito e cortados em 32 caracteres.

#Filtro de palavras

O filtro de palavras bloqueia as palavras que você lista. Ele roda no servidor para linhas de chat, assuntos e textos de cartas e avisos de guilda. Nomes de guilda com uma palavra bloqueada são recusados.

#Game Settings, cartão Chat filter

Campo O que faz Padrão
Blocked Words (blockedWords) Palavras que ninguém pode dizer, uma por entrada. Termine uma com * para pegar também as palavras que começam com ela. Vazio
Blocked Words File (blockedWordsFile) Um asset de texto com mais palavras bloqueadas, uma por linha, para listas longas. Linhas que começam com # são comentários. Nenhum
Chat Filter Mode (chatFilterMode) Mask transforma as palavras bloqueadas em asteriscos. Block descarta a linha inteira e diz ao remetente "That line has words this game doesn't allow." Mask

Como as palavras são comparadas:

  • Só palavras inteiras. Com ass bloqueado, "class" e "passage" passam.
  • Uma entrada que termina em * pega também palavras mais longas: darn* pega "darn", "darned" e "darnit".
  • Maiúsculas e minúsculas não importam.
  • Dígitos e símbolos no lugar de letras são lidos como letras: 0→o, 1→i, 3→e, 4 e @→a, 5 e $→s, 7→t. Então d4rn e @ss são pegos.
  • O correio sempre mascara, mesmo no modo Block, para que uma carta nunca seja descartada.

A lista é lida uma vez por execução. Se você a editar durante o Play, a mudança vale na próxima vez que você pressionar Play.

#Seu próprio filtro

O código pode mudar ou descartar linhas depois do filtro de palavras com SocialHub.Filter: retorne uma linha alterada, ou null para descartá-la. Use para uma lista própria de silenciados, links ou uma regra contra spam. Veja Eventos.

#Silenciamentos

Um moderador silencia um jogador com /mute Name minutes (10 minutos se não houver número, 0 remove). O jogador silenciado lê "You can't chat for 10 minutes." e toda linha que ele tenta enviar recebe "You are muted." O silenciamento fica guardado no personagem (marca chat.muted), então sobrevive a sair do jogo e a trocar de mapa. Moderadores não podem silenciar alguém do mesmo nível ou acima. Veja Comandos de GM.

#Denúncias

Um jogador denuncia outro com /report Name reason, ou clicando nele com o botão direito (no mundo ou no chat) e escolhendo Report, que pergunta "What happened?".

  • A denúncia leva as últimas Report Lines (30) linhas que o denunciante viu, com horários e canais, como evidência.
  • Uma denúncia a cada Report Cooldown (60) segundos por jogador: "Wait a moment before sending another report." O Central também permite no máximo 10 denúncias por dia por jogador.
  • O denunciante lê "Thanks. Your report on Name went to the moderators."
  • Você não pode denunciar a si mesmo.
  • Denúncias precisam de um servidor online. Em um jogador: "Only on an online server."

Os moderadores as leem com /reports. Veja Registro do jogo e denúncias.

#Registrar o chat

Log Chat (logChat, cartão Logs em Game Settings, desligado por padrão) escreve cada linha de chat no registro do jogo como chat.line, com o canal e o destino do sussurro. As denúncias sempre levam as linhas em volta, mesmo com ele desligado. Veja Registro do jogo e denúncias.

Atenção

Registrar cada linha guarda sussurros privados no seu banco de dados. Verifique o que a sua política de privacidade e a lei local permitem antes de ligá-lo.

#Um jogador e MMO

Um jogador MMO
Say, Map No único mapa, como sempre. Tratados pelo servidor de mapa.
World Chega a todos no mapa (em um jogador, só a você). O Central o envia a todos os mapas.
Whisper Só para um jogador no mesmo mapa. Senão "Name is not online." O mapa procura o jogador localmente primeiro e depois pergunta ao Central, que o encontra em qualquer mapa.
Party, Guild, Alliance Sem grupos nem guildas, então nada para enviar. O Central envia a linha a todo membro online, agrupado por mapa.
Denúncias "Only on an online server." Enviadas ao Central.

#Passo a passo

#Bloquear uma lista de palavras

  1. Crie um arquivo de texto no seu projeto, por exemplo Assets/Game/BlockedWords.txt.
  2. Escreva uma palavra por linha. Termine uma palavra com * para pegar palavras mais longas. Comece uma linha com # para deixar um comentário.
  3. Abra KitARPG > Game Settings, cartão Chat filter, e arraste o arquivo para Blocked Words File.
  4. Escolha Chat Filter Mode: Mask ou Block.
  5. Pressione Play e escreva uma palavra bloqueada para testar.

O filtro roda no servidor, então recompile os seus servidores de mapa depois de mudar a lista.

#Fazer o Say alcançar mais longe

  1. Abra cada prefab de jogador (a amostra tem PlayerMale, PlayerFemale e PlayerPanda em Samples/Starter/Prefabs).
  2. Em PlayerChat, defina Say Range, por exemplo como 50.

#Mudar as cores do chat

Selecione a caixa de chat no prefab do HUD e mude as cores em ChatWindow (Say Color, Map Color, World Color, Whisper Color, Party Color, Guild Color, Alliance Color, System Color). Elas são só do cliente.

#Erros comuns

  • Escrever /g hello para falar com a guilda. Isso é World. Use /gu.
  • O filtro não pega uma palavra. Ela precisa ser uma palavra inteira, ou termine a entrada com *. Mudanças feitas durante o Play esperam a próxima execução.
  • "You are talking too fast." Mais de 5 linhas em sequência. Aumente Burst em PlayerChat se o seu jogo precisar.
  • O chat World chega a só um mapa. O servidor de mapa não está conectado ao Central. Verifique Play and Servers.
  • Configurações diferentes em prefabs de jogador diferentes. PlayerChat fica em cada prefab. Mude todos.
