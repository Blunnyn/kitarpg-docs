Configurações do jogador

Os jogadores mudam gráficos, som, interface e controles na janela Settings (configurações), e saem do mundo, trocam de personagem ou fecham o jogo pelo menu do jogo. Esta página cobre os dois, cada opção com seu padrão, onde as configurações ficam salvas, como sons e músicas seguem os canais de volume e como adicionar opções próprias.

#Menu do jogo

Pressione Esc (quando nenhuma janela estiver aberta) ou clique na engrenagem da barra de ícones no canto superior direito. O menu tem:

Botão O que faz
Resume Fecha o menu
Settings Abre a janela Settings
Change character Sai do mundo e volta para a seleção de personagens. Em um jogador (single player) aparece como Save and leave
Sign out Volta para a tela de login. Só no MMO
Quit game Fecha o jogo

Sair, encerrar a sessão e fechar o jogo pedem confirmação ("Leave the world and go back to your characters?", "Sign out and go back to the login screen?", "Quit the game?"). Quando o personagem está em combate, a pergunta acrescenta "You are in combat."

Esc fecha primeiro uma janela ou popup aberto e só abre o menu quando nada estava aberto. Ele não abre o menu enquanto você digita no chat, responde a uma confirmação ou está com Settings aberto. Veja HUD e janelas.

O menu do jogo também mostra um contador de quadros no canto superior esquerdo enquanto Show FPS estiver ligado.

#A janela Settings

Abra-a pelo menu do jogo ou com o botão Settings na tela de título. Ela tem uma aba por página: Graphics, Audio, Interface e Controls quando o modo de controle adiciona opções. As mudanças se aplicam na hora. Cada aba tem um botão Reset que pergunta "Put the page settings back as they came?".

#Onde as configurações ficam salvas

As configurações pertencem ao computador, não à conta: nada vai para o servidor. Elas são salvas em PlayerPrefs na chave KitARPG.Options (como JSON) quando a janela fecha ou o jogo é encerrado. As opções de controles usam chaves próprias de PlayerPrefs.

#Gráficos

Opção Escolhas Padrão
Display Tela cheia, tela cheia exclusiva (só Windows) ou janela. Não aparece no editor O modo atual
Resolution As resoluções da tela. Não aparece no editor A atual
Quality Os níveis de qualidade do projeto. As linhas abaixo ajustam mais O nível atual do projeto
Vertical sync Acompanha a taxa de atualização da tela. Evita o tearing; o limite de quadros é ignorado Ligado
Frame limit 30, 60, 120, 144, 240 FPS ou Unlimited Unlimited
Render scale 50% a 150%, de 5 em 5. Menor desenha menos pixels: mais rápido, mais suave 100%
Anti-aliasing Off, 2x, 4x, 8x (MSAA) 4x
Shadows Off, Low, Medium, High (distância das sombras e resolução do mapa de sombras) Medium
Textures Full, Half, Quarter Full
Post-processing Bloom, correção de cor e afins Ligado

As opções do URP são aplicadas a uma cópia do asset do pipeline de renderização feita em tempo de execução, então o asset do seu projeto nunca é gravado. No editor, sair do Play devolve o nível de qualidade e o pipeline. O pós-processamento é desligado por câmera, e uma câmera que já estava com ele desligado continua desligada.

#Sons e música

#Música

Campo Onde O que faz
Title Music (titleMusic) Game Settings > Interface Toca em loop na tela de título
Music (music) Cada mapa no Game Database Toca em loop enquanto os jogadores estão no mapa. Vazio: a música de antes continua tocando

A música faz uma transição entre faixas de 1,5 segundo e segue o volume Music.

#Efeitos sonoros

Tudo o que o kit toca passa por GameAudio, no volume do seu canal vezes o volume master:

  • GameAudio.PlayAt(clip, position, channel) para um som no mundo (Effects por padrão).
  • GameAudio.Play(clip, channel) para um som sem lugar, como um botão ou uma subida de nível (Interface por padrão).

#Sons ambientes em uma cena

Para um AudioSource fixo em uma cena (uma fogueira, um rio), adicione um SoundChannelSource ao lado dele:

Campo O que faz Padrão
Channel (channel) Effects, Music, Interface ou Ambience Ambience
Volume (volume) O volume próprio da fonte, de 0 a 1, antes do do jogador 1

Ele mantém a fonte no volume do seu canal e acompanha as mudanças em Settings.

#Passo a passo: adicionar uma opção própria

As opções são adicionadas por código com ClientOptions.Add. A janela monta suas linhas a partir de três modelos (uma lista suspensa, um controle deslizante e um interruptor), então opções novas não exigem trabalho de UI. Um nome de página que ainda não existe adiciona uma aba.

using Blunnyn.KitARPG.Client;
using UnityEngine;

public static class CameraShakeOption
{
    const string Pref = "Game.CameraShake";

    public static bool On => PlayerPrefs.GetInt(Pref, 1) == 1;

    [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterSceneLoad)]
    static void Register()
    {
        ClientOptions.Add(new ToggleOption
        {
            page = ClientOptions.Interface,
            label = "Camera shake",
            hint = "Shakes the camera on heavy hits.",
            get = () => On,
            set = on => PlayerPrefs.SetInt(Pref, on ? 1 : 0),
            reset = () => PlayerPrefs.DeleteKey(Pref),
        });
    }
}
Tipo Campos
ToggleOption get, set
SliderOption min, max (100), step (5), get, set, format (adiciona % por padrão)
ChoiceOption choices, get, set
Todos page, label, hint, available (esconde a opção quando diz que não), reset (para o botão Reset da aba)

A lista de opções é limpa no início de cada Play, então um RuntimeInitializeOnLoadMethod como o de cima a registra uma vez por execução, com ou sem recarga de domínio. Se, em vez disso, você adicionar uma opção a partir do OnEnable de um componente, verifique antes ClientOptions.All.Contains(option), como fazem os modos de controle do kit, ou ela será adicionada de novo em cada mapa. Veja Menus e opções de configuração e Recarga de domínio.

#Mudar o visual das janelas

O menu do jogo (GameMenu) e a janela Settings (SettingsWindow) ficam no prefab do HUD como as outras janelas. A janela Settings tem um Tab Template copiado para cada página, cores das abas (Tab On, Tab Off) e três modelos de linha: um Label, um Hint e uma lista suspensa Value; um Label, um Hint, um controle deslizante Value e um rótulo Amount; um Label, um Hint e um interruptor Value. Mantenha esses nomes de filhos ao mudar o visual. Veja HUD e janelas.

#Um jogador e MMO

As configurações funcionam igual nos dois. Sign out só aparece no MMO, e Change character aparece como Save and leave em um jogador.

#Erros comuns

  • As configurações de gráficos mudaram o asset do URP do meu projeto. Não mudam: o jogo trabalha sobre uma cópia. Se a qualidade parecer errada no editor depois do Play, confira o nível de qualidade do projeto em Project Settings.
  • Um som ignora os controles de volume. Ele é tocado com um AudioSource comum ou PlayClipAtPoint. Use GameAudio ou adicione um SoundChannelSource.
  • Minha opção aparece duas vezes. Ela é adicionada a partir de um componente que roda em cada mapa. Verifique ClientOptions.All.Contains antes de adicioná-la.
