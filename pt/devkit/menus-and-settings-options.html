Menus e opções de configuração

Como adicionar linhas ao menu de item e ao menu do jogador, e opções à janela Settings, a partir do seu próprio código.

As três são listas do lado do cliente que o kit preenche com suas próprias entradas no início de cada Play. Você adiciona as suas depois disso, a partir de um método estático no assembly Game.

#Menu de item

Clicar com o botão direito em um item na bolsa ou no equipamento abre o menu de item (ItemMenu). Suas linhas vêm de ItemMenu.Entries, em ordem, começando pelas do próprio kit: a ação da janela aberta ao lado da bolsa (vender, guardar, oferecer), Equip, Take off, Use, Split, Salvage all, Possible values, View set e Destroy.

#ItemMenuEntry

Campo O que é
string label O texto da linha.
Func<ItemMenuTarget, string> labelFor O texto para este item, quando ele muda. Null usa label.
Func<ItemMenuTarget, bool> shows Se a linha aparece para este item. Null sempre a mostra.
Action<ItemMenuTarget> run O que escolher a linha faz.

#ItemMenuTarget

Membro O que é
UIItem view O espaço do item na tela.
InventoryWindow window A janela de inventário de onde o menu abriu.
ItemContainer Container Bag, Equipment ou Bank.
int Slot O índice do espaço nesse contêiner.
ItemSlotState State O que o espaço contém: id do item, quantidade, nível de melhoria, rolagens.
IItem Item Os dados do item (ItemData e suas subclasses a implementam).
bool InBag Container == ItemContainer.Bag.

#Exemplo: comparar com o que você está usando

using Blunnyn.KitARPG.Client;
using Blunnyn.KitARPG.Data;
using UnityEngine;

namespace Game
{
    public static class CompareLine
    {
        [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterAssembliesLoaded)]
        static void Register()
        {
            ItemMenu.Entries.Add(new ItemMenuEntry
            {
                label = "Compare",
                shows = t => t.InBag && t.Item is IEquippable,
                run = t => CompareWindow.Instance?.Show((IEquippable)t.Item),
            });
        }
    }
}

(CompareWindow representa uma janela sua.)

#Exemplo: inserir uma linha em uma posição

Entries é uma List<ItemMenuEntry> comum. Use Insert para colocar uma linha antes do Destroy do kit:

int destroy = ItemMenu.Entries.FindIndex(e => e.label == "Destroy");
ItemMenu.Entries.Insert(destroy >= 0 ? destroy : ItemMenu.Entries.Count, myEntry);

#Linhas que mudam o jogo

O menu roda no cliente. Uma linha que faz algo no jogo pede ao servidor, por um comando de um sistema do jogador ou por uma mensagem de rede, e o servidor verifica tudo de novo: que o espaço contém aquele item, que o jogador pode fazer aquilo. As linhas do próprio kit chamam PlayerInventory.Local.Equip(slot), Use(slot) e assim por diante, que são pedidos. Veja Sistemas do jogador e Mensagens de rede.

#Menu do jogador

Clicar com o botão direito em outro jogador no top-down, ou em um nome no chat, abre o menu do jogador (PlayerMenu). Suas linhas vêm de PlayerMenu.Entries: Whisper, Trade, Invite to party, Make leader, Remove from party, Add friend, Invite to guild, Duel, Report e Give up the duel. Cada linha do kit se oculta quando seu módulo está desligado.

#PlayerMenuEntry

Campo O que é
string label O texto da linha.
Func<PlayerMenuTarget, bool> shows Se a linha aparece para este jogador. Null sempre a mostra.
Action<PlayerMenuTarget> run O que escolher a linha faz.

#PlayerMenuTarget

Campo O que é
string name O nome do personagem.
PlayerCharacter character O jogador na tela, ou null quando ele só foi mencionado no chat.

#Exemplo: inspecionar o equipamento de um jogador

[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterAssembliesLoaded)]
static void Register()
{
    PlayerMenu.Entries.Add(new PlayerMenuEntry
    {
        label = "Inspect",
        shows = t => t.character != null,
        run = t => InspectWindow.Instance?.Show(t.character),
    });
}

O equipamento vestido é sincronizado com todos que veem o jogador (PlayerCharacter.gear, ids de itens por posição de equipamento), então uma janela de inspeção pode lê-lo no cliente. A bolsa é privada do dono.

#Exemplo: uma linha para um dos seus módulos

PlayerMenu.Entries.Add(new PlayerMenuEntry
{
    label = "Challenge to a race",
    shows = t => t.character != null && RaceRules.Enabled,
    run = t => Races.Ask(t.name),
});

Races.Ask envia um pedido pelo nome; o servidor encontra o jogador pelo nome no seu mapa (PlayerCharacter.ServerFind(name)) e verifica a distância e as regras.

#Janela Settings

A janela Settings (Esc ou a engrenagem, depois Settings, e também na tela de título) tem abas: Graphics, Audio, Interface, mais Controls do modo top-down e qualquer página que você adicionar. Cada linha é um GameOption em ClientOptions.All. Os valores ficam no computador do jogador e nunca chegam ao servidor.

#Tipos de opção

Todas têm estes campos:

Campo O que é
string page A aba: ClientOptions.Graphics, ClientOptions.Audio, ClientOptions.Interface, ou um nome novo, que vira uma nova aba no final.
string label O texto da linha.
string hint Uma explicação curta.
Func<bool> available Oculta a linha quando responde não, para opções que uma plataforma não tem.
Action reset Volta o valor ao original, para o botão Reset da aba.
Tipo Campos extras
ToggleOption Func<bool> get, Action<bool> set
SliderOption int min (0), int max (100), int step (5), Func<int> get, Action<int> set, Func<int, string> format (mostra "50%" por padrão)
ChoiceOption Func<string[]> choices, Func<int> get, Action<int> set (o índice)

ClientOptions.Add(option) adiciona uma. As mudanças se aplicam conforme o jogador as faz; o kit salva seus próprios valores quando a janela fecha, e o seu set guarda os seus.

#Exemplo: o template

using Blunnyn.KitARPG.Client;
using UnityEngine;

namespace Game
{
    /// <summary>
    /// An option of your own in the Settings window. Kept on the player's computer and never sent
    /// anywhere, so use it for how the game looks and sounds, not for anything the server decides.
    /// </summary>
    public static class MySettings
    {
        const string Key = "MyGame.ShowHints";

        public static bool ShowHints
        {
            get => PlayerPrefs.GetInt(Key, 1) == 1;
            set => PlayerPrefs.SetInt(Key, value ? 1 : 0);
        }

        [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterAssembliesLoaded)]
        static void Register()
        {
            ClientOptions.Add(new ToggleOption
            {
                // A page name the kit doesn't have becomes a new tab.
                page = ClientOptions.Interface,
                label = "Show hints",
                hint = "Short tips the first time something new shows up.",
                get = () => ShowHints,
                set = v => ShowHints = v,
                reset = () => ShowHints = true,
            });
        }
    }
}

#Exemplo: um slider e uma escolha em uma página sua

[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterAssembliesLoaded)]
static void Register()
{
    ClientOptions.Add(new SliderOption
    {
        page = "Gameplay",
        label = "Screen shake",
        min = 0, max = 100, step = 10,
        get = () => PlayerPrefs.GetInt("MyGame.Shake", 50),
        set = v => PlayerPrefs.SetInt("MyGame.Shake", v),
        reset = () => PlayerPrefs.DeleteKey("MyGame.Shake"),
    });

    ClientOptions.Add(new ChoiceOption
    {
        page = "Gameplay",
        label = "Damage numbers",
        choices = () => new[] { "All", "Mine only", "None" },
        get = () => PlayerPrefs.GetInt("MyGame.Numbers", 0),
        set = i => PlayerPrefs.SetInt("MyGame.Numbers", i),
        reset = () => PlayerPrefs.DeleteKey("MyGame.Numbers"),
    });
}

Um slider se move em passos inteiros. Dê um reset a toda opção, para que o botão Reset da aba a cubra.

#Exemplo: uma opção só em algumas plataformas

available = () => Application.platform == RuntimePlatform.WindowsPlayer,

#Para que servem as configurações

As configurações servem para como o jogo aparece, soa e responde naquele computador. Qualquer coisa que afete outros jogadores ou as regras (PvP ligado ou desligado, divisão de saque) pertence ao servidor, em um sistema do jogador com um comando, não em PlayerPrefs. Para teclas suas, verifique GameInstance.KeysOn antes de lê-las: com o layout de entrada Touch, as teclas do jogo ficam desligadas.

#Quando registrar

O kit reconstrói ItemMenu.Entries e PlayerMenu.Entries com suas próprias linhas, e limpa ClientOptions.All, em SubsystemRegistration no início de cada Play. Registre as suas em AfterAssembliesLoaded ou depois. A janela Settings lê a lista quando abre, então opções adicionadas a qualquer momento antes disso aparecem.

Os servidores de mapa rodam em batch mode e nunca abrem esses menus; registrar lá não causa problema.

#Erros comuns

  • Registrar em SubsystemRegistration. O kit pode reiniciar a lista depois de você.
  • Fazer a mudança em run. Menus são código de cliente; peça ao servidor.
  • Sem reset. O botão Reset da aba deixa sua opção como estava.
  • Regras do jogo em PlayerPrefs. Os jogadores podem editá-las.
