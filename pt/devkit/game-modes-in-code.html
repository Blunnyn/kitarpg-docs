Modos de jogo em código

Como os modos de controle são montados e registrados, o que as metades de cliente e de servidor de um modo precisam fazer, e um esqueleto completo para um modo seu.

#Como os modos funcionam

O modo de controle do jogo é uma string em Game Settings > Game mode (GameInstance.controlMode): TopDown, FreeCamera ou ThirdPerson no kit. As mesmas cenas rodam em todos os modos. Cada modo é um conjunto de componentes:

  • Componentes de cliente, adicionados à câmera principal de cada cena de mapa: a câmera e a entrada. Eles leem o mouse, as teclas e os controles de toque, miram e enviam pedidos ao servidor.
  • Componentes de servidor, adicionados ao network manager no servidor de mapa (e no host de um jogador): eles recebem os pedidos de movimento e de ação, verificam esses pedidos e movem e agem pelo jogador.

GameModes (namespace Blunnyn.KitARPG.Net) guarda a lista. Quando um mapa carrega, o kit adiciona os componentes do modo em jogo e desliga os de todos os outros modos. Os modos do kit ficam em assemblies próprios: KitARPG.Modes.TopDown com KitARPG.Modes.TopDown.Server, e KitARPG.Modes.ThirdPerson com KitARPG.Modes.ThirdPerson.Server (que atende tanto a terceira pessoa quanto a câmera livre).

#GameModes

Membro O que faz
const string TopDown, ThirdPerson, FreeCamera Os nomes dos modos do kit.
string Current O modo em jogo: GameInstance.controlMode, ou TopDown quando vazio.
bool Is(string mode) Se esse modo está em jogo (ignora maiúsculas e minúsculas).
IEnumerable<string> Known Todo modo para o qual algum componente foi registrado.
void AddServer(string mode, Type component) Registra um componente de servidor para um modo.
void AddClient(string mode, Type component) Registra um componente de cliente para um modo.
void EquipServer(GameObject host), EquipClient(GameObject camera) Adiciona os componentes do modo em jogo e desliga o resto. O kit os chama.
bool HasClientParts(GameObject target) Se o objeto tem um componente de cliente de qualquer modo.

#Quando o kit equipa

  • Servidor: quando um servidor de mapa inicia, ou o host de um jogador inicia um mapa, EquipServer roda no objeto do network manager.
  • Cliente: quando carrega uma cena cuja câmera principal já tem um componente de cliente de algum modo, e de novo quando o jogador local aparece, EquipClient roda em Camera.main. Um componente que outro modo registrou é desativado; um que o modo em jogo registrou é adicionado se faltar e ativado.

Componentes compartilhados entre modos continuam ligados: os modos de terceira pessoa e de câmera livre do kit registram as mesmas classes.

#Registrar

Registre em SubsystemRegistration. Ao contrário dos outros estáticos do kit, as tabelas de modos nunca são limpas, então a ordem de registro não importa, e adicionar o mesmo tipo duas vezes é ignorado:

[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.SubsystemRegistration)]
static void RegisterMode()
{
    GameModes.AddClient("Grid", typeof(GridCamera));
    GameModes.AddClient("Grid", typeof(GridInput));
}

O registro de servidor fica em um assembly só de servidor, junto com o componente de servidor:

[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.SubsystemRegistration)]
static void RegisterMode() => GameModes.AddServer("Grid", typeof(GridServer));

#Escolher o seu modo

O menu Game mode lista os três modos do kit mais todo nome em GameModes.Known. Os registros rodam quando o Play começa, então aperte Play uma vez com o seu código compilado e depois escolha o seu modo no menu. Depois disso o nome fica salvo em GameInstance.

#Servidor e cliente precisam coincidir

O cliente envia o seu modo junto com o ticket. Um servidor de mapa que roda outro modo o recusa com mode_mismatch ("The server plays a different game mode. Update the game."), porque o cliente enviaria pedidos para os quais o servidor não tem handler. Compile o cliente e o servidor de mapa com o mesmo Game mode.

#O que a metade de cliente faz

Tarefa Como
Câmera Seguir PlayerCharacter.Local (null até o jogador aparecer).
Entrada de movimento Ler KitInput (teclas e mouse) e TouchControls.Axis("Move"); enviar pedidos.
Mira Definir AimInput.Pointer para onde o jogador mira: AimInput.Mouse, AimInput.Center (uma mira no centro) ou uma função sua. A mira de habilidades, as prévias e a barra rápida do kit usam isso.
Ações Atacar, falar, pegar: enviar as mensagens do kit ou as suas.
Respeitar o layout Verificar GameInstance.KeysOn antes de ler as teclas do jogo: com o layout Touch as teclas ficam desligadas.
Desligar-se Em OnEnable, sair cedo quando !GameModes.Is("YourMode"): as cenas podem ter os seus componentes enquanto outro modo está em jogo.

O próprio código de cliente do kit também envia pedidos que o seu servidor precisa responder, seja qual for o modo:

Mensagem Enviada por Campos
CastSkillMessage Mira de habilidades e a barra rápida (AimInput) skillId, target (netId), point
PickupMessage Interagir no toque e a tecla F (Interactables) drop
TalkMessage O mesmo npc (o id do NPC)

Outras mensagens que os modos do kit usam, e que o seu pode reaproveitar: MoveToMessage (destination), MoveDirectionMessage (direction), AttackMessage (target), SwingMessage (aim, target), PlayerInputMessage e MoveAckMessage (o movimento com predição da terceira pessoa). Elas ficam em KitARPG.Net.

#O que a metade de servidor faz

A metade de servidor é um MonoBehaviour no objeto do network manager. Ela:

  1. Registra os seus handlers de mensagem a cada início do servidor (o host de um jogador reinicia a cada troca de mapa): assine KitNetworkManager.ServerStarted e também registre na hora se NetworkServer.active.
  2. Assume cada jogador quando ele aparece (PlayerCharacter.ServerSpawned): o seu NavMeshAgent, a sua velocidade.
  3. Verifica todo pedido: ritmo, o jogador do remetente a partir de conn.identity, vivo e carregado, posições finitas, distâncias, linha de visão (Sight.Clear), alvos por meio de Fighters.TargetFor.
  4. Age pelos métodos de servidor do kit:
Para Chamada
Ataque básico player.ServerTryAttack(target) (false enquanto recarrega)
Lançar uma habilidade player.GetComponent<PlayerSkills>().ServerCast(skill, target, point) (verifica mana, recarga, alcance e alvo; devolve o motivo da recusa)
Pegar Rewards.Instance.Pickup(player, dropId) (verifica o alcance; devolve um código de erro)
Falar player.GetComponent<PlayerInteraction>().ServerTalk(npc) depois de npc.InReach(...)
Pode se mover player.Statuses.CanMove, !player.Motion.Busy, !inventory.Overloaded
Quão rápido player.Stats.moveSpeed
Alcance de ataque player.AttackRange

TopDownServer e ThirdPersonServer são exemplos completos; leia-os antes de escrever o seu.

#Um esqueleto completo: um modo em grade

Um modo que anda uma casa por vez com as setas, em uma grade de 1 m, com câmera fixa. Ele reaproveita as mensagens do kit para as ações.

#Mensagem compartilhada (assembly Game)

using Mirror;

namespace Game
{
    /// <summary>Client to server: one tile in a direction (-1, 0 or 1 on each axis).</summary>
    public struct GridStepMessage : NetworkMessage
    {
        public sbyte x;
        public sbyte z;
    }
}

#Metade de cliente (assembly Game)

using Blunnyn.KitARPG.Client;
using Blunnyn.KitARPG.Data;
using Blunnyn.KitARPG.Net;
using Mirror;
using UnityEngine;

namespace Game
{
    public class GridCamera : MonoBehaviour
    {
        public Vector3 offset = new Vector3(0, 12, -8);

        [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.SubsystemRegistration)]
        static void RegisterMode()
        {
            GameModes.AddClient("Grid", typeof(GridCamera));
            GameModes.AddClient("Grid", typeof(GridInput));
        }

        protected virtual void LateUpdate()
        {
            PlayerCharacter player = PlayerCharacter.Local;
            if (player == null) return;
            transform.position = player.transform.position + offset;
            transform.LookAt(player.transform.position);
        }
    }

    public class GridInput : MonoBehaviour
    {
        public float repeatSeconds = 0.25f;
        float next;

        protected virtual void OnEnable()
        {
            if (!GameModes.Is("Grid")) return;
            AimInput.Pointer = AimInput.Mouse;
        }

        protected virtual void Update()
        {
            if (!NetworkClient.ready || PlayerCharacter.Local == null || !GameInstance.KeysOn) return;
            if (Time.unscaledTime < next) return;
            int x = (KitInput.GetKey(KeyCode.RightArrow) ? 1 : 0) - (KitInput.GetKey(KeyCode.LeftArrow) ? 1 : 0);
            int z = (KitInput.GetKey(KeyCode.UpArrow) ? 1 : 0) - (KitInput.GetKey(KeyCode.DownArrow) ? 1 : 0);
            Vector2 stick = TouchControls.Axis("Move");
            if (x == 0 && z == 0 && stick.sqrMagnitude > 0.25f)
            {
                x = Mathf.RoundToInt(stick.x);
                z = Mathf.RoundToInt(stick.y);
            }
            if (x == 0 && z == 0) return;
            next = Time.unscaledTime + repeatSeconds;
            NetworkClient.Send(new GridStepMessage { x = (sbyte)x, z = (sbyte)z });
        }
    }
}

#Metade de servidor (assembly Game.Server)

using Blunnyn.KitARPG.Data;
using Blunnyn.KitARPG.Net;
using Blunnyn.KitARPG.Server;
using Mirror;
using UnityEngine;
using UnityEngine.AI;

namespace Game
{
    public class GridServer : MonoBehaviour
    {
        static readonly Color Refused = new Color(1f, 0.5f, 0.45f);

        [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.SubsystemRegistration)]
        static void RegisterMode() => GameModes.AddServer("Grid", typeof(GridServer));

        protected virtual void OnEnable()
        {
            PlayerCharacter.ServerSpawned += TakeOver;
            KitNetworkManager manager = GetComponent<KitNetworkManager>();
            if (manager != null) manager.ServerStarted += Register;
            if (NetworkServer.active) Register();
        }

        protected virtual void OnDisable()
        {
            PlayerCharacter.ServerSpawned -= TakeOver;
            KitNetworkManager manager = GetComponent<KitNetworkManager>();
            if (manager != null) manager.ServerStarted -= Register;
        }

        void Register()
        {
            NetworkServer.ReplaceHandler<GridStepMessage>(OnStep);
            NetworkServer.ReplaceHandler<AttackMessage>(OnAttack);
            NetworkServer.ReplaceHandler<CastSkillMessage>(OnCastSkill);
            NetworkServer.ReplaceHandler<PickupMessage>(OnPickup);
            NetworkServer.ReplaceHandler<TalkMessage>(OnTalk);
        }

        void TakeOver(PlayerCharacter player)
        {
            if (!player.TryGetComponent(out NavMeshAgent agent)) return;
            agent.enabled = true;
            agent.Warp(player.transform.position);
            agent.speed = player.Stats.moveSpeed > 0 ? player.Stats.moveSpeed : 3.5f;
        }

        static bool TryGetPlayer(NetworkConnectionToClient conn, out PlayerCharacter player)
        {
            player = conn.identity != null ? conn.identity.GetComponent<PlayerCharacter>() : null;
            return player != null && player.State != null && !player.Released && !player.IsDead;
        }

        void OnStep(NetworkConnectionToClient conn, GridStepMessage msg)
        {
            if (!CommandPacing.Allow(conn) || !TryGetPlayer(conn, out PlayerCharacter player)) return;
            if (Mathf.Abs(msg.x) > 1 || Mathf.Abs(msg.z) > 1 || (msg.x == 0 && msg.z == 0)) return;
            if (!player.Statuses.CanMove || player.Motion.Busy) return;
            if (player.TryGetComponent(out PlayerInventory inventory) && inventory.Overloaded) return;
            if (!player.TryGetComponent(out NavMeshAgent agent) || !agent.isOnNavMesh) return;
            Vector3 here = player.transform.position;
            Vector3 tile = new Vector3(Mathf.Round(here.x) + msg.x, here.y, Mathf.Round(here.z) + msg.z);
            if (NavMesh.SamplePosition(tile, out NavMeshHit hit, 0.5f, NavMesh.AllAreas)) agent.SetDestination(hit.position);
        }

        void OnAttack(NetworkConnectionToClient conn, AttackMessage msg)
        {
            if (!CommandPacing.Allow(conn) || !TryGetPlayer(conn, out PlayerCharacter player)) return;
            ICombatant target = Fighters.TargetFor(conn, player, msg.target);
            if (target == null || target.IsDead || !Fighters.Enemies(player, target)) return;
            Vector3 to = target.transform.position - player.transform.position;
            to.y = 0;
            if (to.magnitude > player.AttackRange + 0.5f || !Sight.Clear(player.transform.position, target.transform.position))
            {
                player.ServerAnnounce("Too far", Refused);
                return;
            }
            if (to.sqrMagnitude > 0.001f) player.transform.rotation = Quaternion.LookRotation(to);
            player.ServerTryAttack(target);
        }

        void OnCastSkill(NetworkConnectionToClient conn, CastSkillMessage msg)
        {
            if (!CommandPacing.Allow(conn) || !TryGetPlayer(conn, out PlayerCharacter player)) return;
            if (!player.TryGetComponent(out PlayerSkills skills) || skills.IsBusy) return;
            if (GameInstance.Database == null || !GameInstance.Database.TryGet(msg.skillId ?? "", out SkillData skill)) return;
            Vector3 p = msg.point;
            if (!float.IsFinite(p.x) || !float.IsFinite(p.y) || !float.IsFinite(p.z)) return;
            ICombatant target = Fighters.TargetFor(conn, player, msg.target);
            string error = skills.ServerCast(skill, target, p);
            if (error != null) player.ServerAnnounce(error, Refused);
        }

        void OnPickup(NetworkConnectionToClient conn, PickupMessage msg)
        {
            if (!CommandPacing.Allow(conn) || !TryGetPlayer(conn, out PlayerCharacter player) || Rewards.Instance == null) return;
            string error = Rewards.Instance.Pickup(player, msg.drop);
            if (error != null && player.TryGetComponent(out PlayerInventory inventory)) inventory.ServerError(error);
        }

        void OnTalk(NetworkConnectionToClient conn, TalkMessage msg)
        {
            if (!CommandPacing.Allow(conn) || !TryGetPlayer(conn, out PlayerCharacter player)) return;
            if (!Npc.TryFind(msg.npc, out Npc npc) || !player.TryGetComponent(out PlayerInteraction interaction)) return;
            if (!npc.InReach(player.transform.position))
            {
                player.ServerAnnounce("Too far", Refused);
                return;
            }
            interaction.ServerTalk(npc);
        }
    }
}

Este esqueleto deixa de fora o que os modos do kit acrescentam por cima: caminhar até o alcance antes de atacar ou lançar, perseguir alvos, atualizar a velocidade quando os stats mudam (player.ServerStatsChanged) e a predição no cliente do modo de terceira pessoa. Copie essas partes de TopDownServer ou ThirdPersonServer conforme o seu modo precisar.

#Reaproveitar partes de um modo do kit

Você pode registrar os componentes do kit sob o nome do seu modo, por exemplo TopDownServer com uma câmera sua. Leia cada componente antes: TopDownInput.OnEnable só configura a mira quando GameModes.Is(GameModes.TopDown), então sob outro nome ele deixa AimInput.Pointer por sua conta. Um modo que só muda a câmera costuma ser mais simples como outro asset CameraSettings (terceira pessoa e câmera livre leem os seus de GameInstance.thirdPersonCamera e freeCamera).

#Um jogador e MMO

Os mesmos componentes rodam nos dois. Em um jogador, o host roda a metade de servidor e a de cliente em um só processo; o host reinicia a cada troca de mapa, e é por isso que as metades de servidor registram os seus handlers a cada ServerStarted.

#Erros comuns

  • Código de servidor no assembly do cliente. Coloque a metade de servidor em um assembly .Server para que os clientes não a carreguem.
  • Esquecer as mensagens do próprio kit. Sem handlers para CastSkillMessage, PickupMessage e TalkMessage, a barra rápida e o botão de interagir não fazem nada no seu modo.
  • Confiar em posições vindas do cliente. Limite distâncias, consulte o NavMesh, verifique a linha de visão.
  • Componentes de cliente que não verificam GameModes.Is. Eles rodam em cenas onde outro modo está em jogo.
  • Modos diferentes no cliente e no servidor de mapa. Os jogadores recebem mode_mismatch.
