Primeiros passos

Início rápido: MMO

Rode a amostra como um MMO no seu próprio computador: gere as builds dos serviços e do servidor de mapa, inicie-os, crie uma conta, jogue e veja dois jogadores se encontrarem. Tudo é conduzido pela página Play & Servers da janela KitARPG.

#O que você está prestes a rodar

Peça O que faz Porta no seu computador
Login Contas, entrada, lista e criação de personagens 5100 (HTTP)
Central Sessões, tickets de uso único para entrar nos mapas, chat, amigos, grupos, guildas, correio, mercado; inicia os servidores de mapa 5200 (HTTP), 7700 (link de mapas UDP)
Servidores de mapa Um servidor Unity por mapa, rodando o jogo 7777 town, 7778 forest, 7779 crypt (UDP)
Shop (opcional) Moeda premium, ofertas, compras, pagamentos 5300 (HTTP)
Banco de dados Arquivo SQLite ou PostgreSQL

O editor roda tudo isso pelo launcher, sem janela. O Central inicia cada servidor de mapa a partir da sua build do servidor de mapa quando o primeiro jogador precisa dele; town inicia junto com os serviços.

#Antes de começar

  • Conclua o Setup Wizard.
  • Instale o SDK do .NET 10 em https://dotnet.microsoft.com/download/dotnet/10.0. Veja Requisitos.
  • Confira se as portas 5100, 5200, 7700 e 7777 a 7779 estão livres.

#Passo a passo

#1. Abra Play & Servers e escolha MMO

  1. Abra a janela KitARPG: KitARPG > Open KitARPG ou Ctrl/Cmd+Shift+K.
  2. Vá para Play & Servers.
  3. Clique no cartão MMO no topo.

Quatro passos numerados aparecem abaixo dos cartões. Eles se desbloqueiam em ordem: os passos concluídos se recolhem com uma marca de visto, o passo atual se abre e os passos bloqueados ainda não podem ser abertos. O cabeçalho de cada passo resume em que pé ele está.

#2. Passo 1: Check the project

O cabeçalho do passo mostra quantas verificações estão prontas ("3 of 5 ready."). Percorra as linhas de cima para baixo:

Linha Está certo quando O que pressionar
Scenes in Build Settings Title é a primeira cena e Server está na lista Use starter scenes
.NET 10 SDK "Installed: 10.x..." Get .NET abre a página de download. Depois de instalar, pressione Check again
Services source Mostra a pasta com KitARPG.Services.slnx, normalmente Assets/Blunnyn/KitARPG/Services~ Browse para escolher outra pasta
Services built "Login, Central and the launcher are compiled." Build services. Ele roda dotnet build nos serviços, uma vez. Depois o botão diz Rebuild
Map server build "Ready. Rebuild after changing scenes or server code." Build. Em um Mac ele roda KitARPG > Starter > Build Mac Server, no Windows Build Windows Server. A primeira build leva alguns minutos

Mais duas linhas podem aparecer:

  • N kit updates, quando o kit tem atualizações que faltam no seu jogo. Pressione Review e aplique-as antes de gerar a build do servidor de mapa, para que os dois as tenham.
  • In-game shop, quando o serviço Shop está disponível. Ela diz se a loja está desligada, rodando, ou ligada mas sem rodar, com Open Shop. A loja é opcional; veja Página Shop.

A build do servidor de mapa vai para Builds/Starter/MacServer/KitARPGServer.app ou Builds/Starter/WindowsServer/KitARPGServer.exe, em uma pasta Builds ao lado da pasta do seu projeto da Unity. Cada build anota as cenas que leva, para que Play & Servers saiba quando falta nela a cena de um mapa.

Atenção

Gere de novo a build do servidor de mapa depois de mudar uma cena, adicionar um mapa ou mudar o código do servidor. Um servidor de mapa mais antigo que o seu código pode recusar clientes com "The game and the server are different versions", e um que não tem a cena de um mapa manda os jogadores que viajam para lá de volta ao login.

Se Build services falhar, o passo mostra as primeiras linhas de erro. Se não houver nenhuma: "dotnet build failed. Run it in a terminal to see why." Abra um terminal na pasta dos serviços e rode dotnet build para ver a saída completa.

#3. Passo 2: Escolha o banco de dados

Opção Quando usar
SQLite: a local file (padrão) Desenvolvimento e servidores pequenos. Nada para instalar
PostgreSQL: for production Produção, ou para desenvolver com o mesmo banco de dados que você implanta

Deixe SQLite para este início rápido. O arquivo é UserSettings/KitARPG/data/kitarpg.db.

O PostgreSQL precisa de uma conexão: Set up PostgreSQL... se conecta a um servidor que você roda, pode criar o banco de dados e o usuário para você, ou roda o PostgreSQL 17 no Docker. Você também pode escrever a string de conexão à mão. Veja Banco de dados.

A linha Keys explica que as chaves de assinatura e de mapas são feitas para este computador e guardadas em UserSettings/KitARPG. New keys faz uma nova chave de assinatura e uma nova chave de mapas. Ele fica desabilitado enquanto os serviços rodam. Os tokens assinados com a chave antiga deixam de ser aceitos, então os clientes que estavam conectados precisam entrar de novo.

Você não pode mudar o banco de dados enquanto os serviços rodam: "Stop the services to change the database."

#4. Passo 3: Inicie os serviços

  1. Pressione Start services.

  2. Aparecem três luzes:

    Luz Detalhe
    Login Contas e personagens, porta 5100
    Central Sessões, chat, guildas e mapas, porta 5200
    Maps "Started by Central when someone enters", depois os mapas que se registraram

    Cada luz diz off, starting ou up.

  3. Espere até Login e Central estarem up. O cabeçalho do passo então diz "Running. Maps: ..." e se recolhe.

Enquanto os serviços rodam, o passo oferece Restart e Stop. Antes de eles iniciarem, roda a exportação dos dados do jogo: Play & Servers escreve o gamedata.json que o Login lê para criar personagens.

Map in the editor escolhe um mapa para rodar dentro deste editor em vez de pela build, para você depurá-lo. Deixe-o em "None, every map runs from the map server build" por enquanto. Ele só pode mudar com os serviços parados.

Avisos que este passo pode mostrar:

Mensagem Significado Solução
"Services from an earlier editor session are still running (process ...)" Um launcher iniciado antes de o editor reiniciar ainda ocupa as portas Stop the old services
"Something else is using port ..." Serviços iniciados de um terminal ou de outra sessão ocupam as portas Pare-os e depois inicie estes
"The services or the map server were rebuilt after they started, so they still run the old code. Restart them." Você gerou uma build nova enquanto eles rodavam Restart

#5. Passo 4: Play

  1. Pressione Play client. O editor abre Title e se junta aos serviços em execução como cliente em http://127.0.0.1:5100 (Login) e http://127.0.0.1:5200 (Central).
  2. A tela de login aparece com Username, Password, Remember me, Sign in automatically, Sign in e Create account.
  3. Digite um nome de usuário (de 3 a 16 letras, dígitos ou _) e uma senha (8 caracteres ou mais), depois pressione Create account. O estado diz "Creating account...", depois "Account created, signing in...".
  4. A lista de personagens abre. Pressione New, preencha Name, Look, Class e Hair, e pressione Create. Veja Início rápido: um jogador para as regras de cada campo.
  5. Selecione o personagem e pressione Play. O Central dá ao cliente um ticket para town, e você aparece na cidade.

Remember me guarda um token de uso único neste computador para você não digitar a senha da próxima vez; a senha em si nunca é salva. Sign in automatically (só com Remember me) entra ao iniciar. Para entrar como outra pessoa, pressione Sign out na lista de personagens.

#Dois jogadores ao mesmo tempo

Play with two no passo 4 (também em Overview e em KitARPG > Play With Two Players) mostra dois jogadores se encontrando:

  1. Ele inicia os serviços se estiverem parados.
  2. Ele abre um segundo editor com o Multiplayer Play Mode da Unity. Se o pacote faltar, ele oferece instalá-lo ("Install").
  3. Quando o Login responde e o segundo editor está aberto, ele pressiona Play nos dois. Cada um entra sozinho com uma conta de teste e um personagem feitos para este computador: kitplayer1 jogando com Aria e kitplayer2 jogando com Bram. Eles ficam guardados em UserSettings/KitARPG/quickplay.json.

Na primeira vez, o segundo editor importa o projeto, o que demora um pouco. Se o Player 2 não puder ser iniciado automaticamente, a janela Multiplayer Play Mode abre: ative o Player 2 ali e pressione o botão de novo.

Para mais de dois jogadores, Built client no passo 4 tem Build (um cliente MMO para a sua plataforma) e Open: abra quantos clientes gerados quiser. Cada um abre conectado aos serviços locais.

#Rodar um mapa no editor

Para depurar o código do servidor de um mapa:

  1. Pare os serviços.
  2. No passo 3, defina Map in the editor para o mapa, por exemplo forest: runs in this editor, to debug it.
  3. Inicie os serviços. O Central agora espera esse mapa se registrar em vez de iniciá-lo.
  4. No passo 4, pressione Play map server: forest. O editor roda a cena Server como esse servidor de mapa.
  5. Entre com um cliente gerado ou com Play with two: um jogador que caminhar para a floresta cai no seu editor.

#Tornar-se admin

As contas novas começam no nível de GM 1 (Player). Para usar comandos de GM online, defina o primeiro admin no banco de dados. Com o banco de dados SQLite padrão, pare os serviços e rode:

sqlite3 UserSettings/KitARPG/data/kitarpg.db "UPDATE accounts SET \"Role\" = 4 WHERE \"Username\" = 'yourname';"

Com PostgreSQL:

UPDATE accounts SET "Role" = 4 WHERE "Username" = 'yourname';

Depois disso, os admins mudam os níveis no jogo com /role player level. Veja Comandos de GM.

#O log

O cartão Log no fim de Play & Servers mostra as últimas linhas da saída dos serviços. Open log file abre UserSettings/KitARPG/services.log. Cada servidor de mapa escreve seu próprio log em UserSettings/KitARPG/data/logs/map-<id>.log.

#Parar

Pressione Stop no passo 3. O launcher para o Login, o Central e todos os servidores de mapa que iniciou. Fechar o editor nem sempre os para: se ainda estiverem rodando da próxima vez, Play & Servers oferece Stop the old services.

#O que dá errado com mais frequência

Sintoma Solução
"Can't reach the server." na tela de login Os serviços não estão rodando, ou o Login ainda não está up. Confira o passo 3
"That map is not running right now. Try again in a moment." O Central não conseguiu iniciar o mapa. A build do servidor de mapa falta ou está quebrada; confira o log do mapa em UserSettings/KitARPG/data/logs
"The game and the server are different versions. Update the game." O servidor de mapa foi gerado a partir de código mais antigo. Gere-o de novo e pressione Restart
"No map reached Central" em Overview A build do servidor de mapa falta ou está desatualizada. Gere-a e reinicie
Viajar para um mapa manda você de volta ao login A build do servidor de mapa não tem a cena desse mapa. Gere-a de novo
"Your character is still being saved. Try again in a moment." Você entrou de novo enquanto a sessão antiga estava salvando. Espere alguns segundos
