Primeiros passos

Instalação

Como colocar o KitARPG em um projeto da Unity, o que a importação traz, o que acontece na primeira vez que o editor abre e como consertar uma importação que deu errado. Quando você terminar, o Setup Wizard assume.

#Antes de começar

  • Instale a Unity 6000.6.0f1 (Unity 6.6) ou mais nova com o Unity Hub. Veja Requisitos.
  • Decida se você começa um projeto novo (recomendado) ou importa em um existente.
  • Se você pretende testar o MMO no seu computador, instale o SDK do .NET 10 agora. Você também pode fazer isso depois.
Dica

Coloque seu projeto sob controle de versão (Git ou Unity Version Control) antes de importar. Isso torna seguro desfazer cada passo seguinte, incluindo as atualizações do kit.

#Passo a passo: um projeto novo

  1. Abra o Unity Hub e pressione New project.
  2. Escolha a Unity 6000.6.0f1 ou mais nova como versão do editor.
  3. Escolha um template. Qualquer template 3D funciona, incluindo o vazio Universal 3D. O kit instala o que precisa.
  4. Dê um nome ao projeto e pressione Create project. Espere o editor abrir.
  5. Abra Window > Package Manager.
  6. Na coluna da esquerda, abra My Assets (você precisa estar conectado com a conta Unity que comprou o kit).
  7. Encontre o KitARPG e pressione Download, depois Import.
  8. A janela Import Unity Package lista todos os arquivos. Deixe tudo marcado e pressione Import.
  9. A Unity importa os arquivos e depois instala os pacotes da Unity que o kit declara (URP, AI Navigation, uGUI, Input System, Test Framework). Ela pode compilar algumas vezes.
  10. Se a Unity perguntar se deve habilitar os novos backends do Input System e reiniciar, você pode responder sim ou não. O kit funciona com qualquer entrada. Responder sim reinicia o editor.
  11. Quando o editor se estabilizar, a janela KitARPG Setup abre sozinha. Continue com o Setup Wizard.

#O que o pacote contém

Caminho no seu projeto O que é
Assets/Blunnyn/KitARPG/ O kit: código de execução, ferramentas do editor, modos, DevKit, amostra, testes, plugins e documentação
Assets/Blunnyn/KitARPG/Services.zip Os serviços .NET (Login, Central, Shop, Data, Hosting, Modules, Launcher, testes e exemplos) como código-fonte
Assets/Blunnyn/Art/ A arte voxel: personagens, equipamentos, armas, monstros, animações e ícones
Assets/Mirror/ Mirror, a biblioteca de rede, com o transporte KCP
Assets/ScriptTemplates/ Os templates de script do Mirror

A estrutura completa está em Estrutura do projeto.

Atenção

Se o seu projeto já tem o Mirror em outra pasta, você fica com duas cópias e erros sobre tipos duplicados. Mantenha só uma cópia do Mirror: a de Assets/Mirror que vem com o kit é a versão com que o kit é testado.

#O que acontece na primeira vez que o editor abre

Várias coisas rodam sozinhas depois da importação. Você vê algumas delas no Console.

#Os serviços são descompactados

Um .unitypackage só pode levar assets, então os serviços .NET vêm como Services.zip. Na primeira vez que o editor carrega, o kit o descompacta em:

Assets/Blunnyn/KitARPG/Services~

A Unity nunca importa uma pasta cujo nome termina em ~, então os arquivos C# dos serviços não vão parar no seu jogo. O Console mostra:

[KitARPG] Services <version> unpacked to .../Assets/Blunnyn/KitARPG/Services~.

O zip leva um arquivo kit-services.version. O kit descompacta de novo só quando a versão do zip é diferente da que já foi descompactada, por exemplo depois de importar um kit mais novo.

Nota

Se existir uma pasta Services com KitARPG.Services.slnx ao lado da pasta do seu projeto da Unity ou dentro dela, o kit usa essa e deixa o zip de lado. Play & Servers mostra a pasta em uso na linha Services source, com um botão Browse para escolher outra.

#O Setup Wizard abre

O assistente abre uma vez por projeto, a menos que o arquivo UserSettings/KitARPG/setup-done exista. Ele nunca abre em batch mode nem no segundo editor do Multiplayer Play Mode. Você sempre pode abri-lo de novo em KitARPG > Setup Wizard.

#O kit lembra sua versão

O kit escreve sua versão em UserSettings/KitARPG/seen-version. Numa primeira importação nada mais acontece. Quando depois você importa um kit mais novo, a janela What's New abre uma vez com o changelog. Veja Atualizar o kit.

#Importar em um projeto existente

Você pode adicionar o KitARPG a um projeto que já tem. Confira isto antes:

Verificação Por quê
Unity 6000.6.0f1 ou mais nova O kit não compila em versões mais antigas
O projeto usa URP, ou você está pronto para trocar O Setup Wizard define o URP como pipeline de renderização em Graphics e em todos os níveis de qualidade. Seus próprios materiais Built-in vão precisar de conversão
Nenhuma outra cópia do Mirror Duas cópias entram em conflito
Build Settings O assistente substitui a lista de cenas pelas cenas da amostra inicial, com Title primeiro. Anote suas próprias cenas antes
Espaço de cor O assistente define Linear

O assistente só mexe nas configurações do projeto (pipeline de renderização, espaço de cor, Build Settings) e na amostra inicial. Ele nunca muda seus próprios assets.

#Conferir se a importação funcionou

Depois do assistente, tudo abaixo deve ser verdade:

  • O Console não tem erros vermelhos.
  • A barra de menus tem um menu KitARPG.
  • Ctrl/Cmd+Shift+K abre a janela KitARPG.
  • Overview nessa janela diz "Everything is ready", ou lista só passos de MMO que você ainda não fez.
  • Project Check não mostra erros.

#Quando a importação dá errado

Sintoma Causa Solução
Centenas de erros de compilação mencionando UnityEngine.Rendering.Universal O URP não foi instalado Abra Window > Package Manager, instale o Universal RP 17.6.0 e reabra o projeto
Erros sobre Unity.AI.Navigation ou NavMeshSurface O AI Navigation não foi instalado Instale o AI Navigation 2.0.14 pelo Package Manager
InvalidOperationException sobre UnityEngine.Input vindo dos seus próprios scripts ao dar Play O projeto usa só o Input System e o seu script chama Input diretamente Chame KitInput em vez disso. O código do próprio kit já faz isso
Erros sobre tipos duplicados do Mirror Duas cópias do Mirror Apague uma cópia
O Setup Wizard não abriu Ele já rodou neste projeto, ou o editor está em batch mode Abra KitARPG > Setup Wizard
Services~ não existe O editor ainda não terminou de carregar, ou o Services.zip não foi importado Espere a compilação terminar, ou importe o pacote de novo com Services.zip marcado
"Missing ... Import the KitARPG package again." para a biblioteca SQLite O plugin SQLite da sua plataforma não foi importado Importe o pacote de novo com Plugins/SQLite marcado

Para mais, veja Solução de problemas.

#Desinstalar

Para remover o kit de um projeto, apague Assets/Blunnyn, Assets/Mirror, Assets/ScriptTemplates, Assets/Settings/Resources/KitARPGSettings.asset e UserSettings/KitARPG. Os pacotes da Unity que ele instalou continuam; remova-os pelo Package Manager se você não os usa.

Importante

UserSettings/KitARPG guarda o banco de dados local do MMO, as chaves do launcher, as contas de teste e o catálogo local da loja. Apagá-lo apaga todas as contas e personagens que você criou localmente.
