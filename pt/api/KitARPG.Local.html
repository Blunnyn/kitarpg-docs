KitARPG.Local

Esta página ainda não foi traduzida. Ela aparece em inglês.

#Blunnyn.KitARPG.Local

#LocalBackend (class)

Login and Central for a single player game, inside the game itself. Characters live in a SQLite file and each map runs as a Mirror host in this process, with the same map server code an MMO uses, so everything built for one mode works in the other.

Member Description
protected LocalCharacterStore Store Opened on first use, so a missing native library shows up as a clear error.
protected virtual CharacterState NewCharacter(CreateCharacterRequest request, CharacterClass characterClass) Starting values of a new character. Override to add your own.

#LocalCharacterStore (class)

Single player characters in a SQLite file. The whole state is one JSON column, so new fields need no migration; the version column refuses stale saves like Central does. The account's storage and bank gold sit apart, shared by every character in the file, and so does the game log, trimmed to its last 90 days.

Member Description
public void Insert(CharacterState state) Stores a new character and fills in its id and version.
public int Save(CharacterState state) Saves when the version matches the stored one. Returns the new version, or 0 if refused.

#SqliteDatabase (class)

Small SQLite connection over the bundled e_sqlite3 library (Plugins/SQLite). Use it from one thread; statements must be disposed.

Member Description
public int Execute(string sql, params object[] args) Runs a statement to the end and returns the rows it changed.
public object Scalar(string sql, params object[] args) First column of the first row, or null.
public Statement Prepare(string sql, params object[] args) Parameters are ? placeholders, bound in order: null, integers, bool, floats, strings.
