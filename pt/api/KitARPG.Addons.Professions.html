KitARPG.Addons.Professions

Esta página ainda não foi traduzida. Ela aparece em inglês.

#Blunnyn.KitARPG.Addons.Professions

#CraftObjective (class)

Craft pieces of an item, or anything a profession makes.

Member Description
public ItemData item Empty counts anything the profession below makes.
public ProfessionData profession Empty counts any profession.

#CraftOption (class)

Makes an NPC a crafting station: a forge, a loom, a cauldron. Its recipes are the ones whose station kind matches. Leave the NPC's greeting empty so a click opens the table.

Member Description
public string station Recipes with this station kind are made here, like forge or loom.
public ProfessionData profession The profession shown at the top of the table.
public AnimationClip animation Played while crafting here. Empty uses the profession's.

#CraftServiceSmokeTest (class)

Two clients crafting for each other against real servers, for -smoketest crafting. The lead (-qa lead) is the crafter: it raises Blacksmith, takes the ingredients and invites; the partner (-qa partner) accepts, sets a fee and receives a sword. Both accounts need the GM role.

#CraftServiceView (struct)

What both sides of a crafting session see.

#CraftingWindow (class)

A station's table, Dofus style: put ingredients on it from the bag (or pick a recipe to fill it) and what they make shows on the right. Slots past the profession's level stay locked. In a crafting session with another player it shows the terms both sides lock.

Member Description
public TextMeshProUGUI professionLabel Profession, level and how many ingredients it may use.
public UIItem[] slots Eight slots; the ones past the level are shown locked.
public TextMeshProUGUI[] slotLocks Over each slot, the level that unlocks it.
public TextMeshProUGUI infoLabel Time, experience and gold per piece.

#Drop (class)

Member Description
public int chance Percent. Each drop rolls on its own.

#GatherNode (class)

A tree, vein or fishing spot in the world. Needs an Npc with a GatherOption on the same object, so players click it like an NPC. One player at a time; once gathered it hides and grows back.

Member Description
public string gatherable Which of the profession's gatherables this is.
public float respawnSeconds Seconds before it can be gathered again.
public GameObject model Hidden while it grows back. Empty hides the first child.
public bool TakenByOther(PlayerCharacter player) Server only. Whether another player is already at it.

#GatherObjective (class)

Gather from nodes of one kind, or any node of a profession.

Member Description
public string gatherable The gatherable's id, like oak. Empty counts any of the profession's.

#GatherOption (class)

Gathers from the GatherNode on the same object. Leave the NPC's greeting empty.

#Gatherable (class)

Something this profession gathers: a tree, an ore vein, a fishing spot.

Member Description
public string id Nodes in the world name it by this. Don't change it once nodes use it.
public Sprite icon Empty uses the icon of the first drop.
public float seconds Seconds it takes at the level it unlocks.
public float fastestSeconds Seconds it takes at the top level of the profession.
public int characterExperience Character experience on top. 0 gives none.
public float Seconds(ProfessionData profession, int level) Seconds it takes at this level, from its own unlock level to the profession's top.

#PlayerCraftService (class)

Crafting for another player at a station, for a fee. The crafter brings the profession level; the ingredients come from whichever side the crafter picks. The client sets the fee, both lock the terms, and any change to them unlocks both. The crafter makes pieces one at a time; the server takes the ingredients, hands the result to the client and pays the fee with the first piece, so nobody holds the other's items or gold at any point.

Member Description
public static event Action<CraftServiceView> SessionChanged Owner's client: the session as it stands; inactive when there is none.
public static event Action<string, string, bool> Invited Owner's client: someone invites this player (false) or asks this player to craft (true).
public static Npc StationNear(Vector3 position) A crafting station whose reach covers this point, or null.

#PlayerProfessions (class)

A player's professions: their levels and experience, gathering at GatherNodes and crafting at stations. Every rule runs on the server; the owner sees its own progress.

Member Description
public static event Action<string> StationOpened Owner's client: a station opened (its NPC id), or closed (null).
public static event Action<string, int, int> CraftProgress Owner's client: pieces made so far out of the ones asked for, of a recipe. Total 0 means it stopped.
public static event Action<string, bool> Message Owner's client: something to tell the player, and whether it went well.
public static event Action<ProfessionData, int> Leveled Owner's client: a profession went up to a level.
public static event Action Changed Owner's client: levels or experience changed.
public static event Action<PlayerCharacter, RecipeData, int> ServerCrafted Server only. A player made pieces of a recipe, for others or themselves.
public static event Action<PlayerCharacter, ProfessionData, ProfessionData.Gatherable> ServerGathered Server only. A player gathered from a node.
public int ServerAddExperience(ProfessionData profession, int amount) Server only. Adds profession experience and levels up as often as it reaches; returns the levels gained.
public int ServerAddLevels(ProfessionData profession, int levels) Server only. Experience to reach levels more levels, keeping what the current level has.
public void ServerSetLevel(ProfessionData profession, int level) Server only. Sets a level outright, for GM commands.
public virtual void ServerGather(GatherNode node, Npc npc) Server only. Starts gathering from a node the player clicked.
public virtual void ServerOpenStation(Npc npc) Server only. A station's NPC opens its table for this player.
public void Craft(string npcId, IReadOnlyList<ItemCost> table, int times) Crafts what the table holds at the open station, times times in a row.
public float Seconds(RecipeData recipe) Seconds a piece of the recipe takes at this player's level.
public static string Cant(RecipeData recipe, PlayerProfessions crafter, PlayerInventory materials, PlayerInventory receiver) Server only. Why crafter can't make one piece of the recipe now, taking the ingredients and gold from materials and giving the result to receiver; null when it can.
public static void Make(RecipeData recipe, PlayerProfessions crafter, PlayerInventory materials, PlayerInventory receiver) Server only. Makes one piece; call after Cant said nothing.
public void Tell(string text, bool good) Server only. Tells the owner, in the chat and on the table.

#PlayerWork (class)

Work a player does standing still, seen by everyone around: gathering, crafting. The server runs the timer and stops it when the player moves, dies or the work can't go on; clients loop the activity's animation.

Member Description
public static event Action<PlayerWork> Changed Clients: someone started or stopped working.
public float moveTolerance Meters a player may drift before the work stops.
public string Activity "gather:miner" or "craft:Town Forge": what the player is doing, empty when nothing.
public void ServerBegin(string what, float duration, Action finished, Func<string> keepGoing = null, Action<string> ended = null) Server only. Starts work that ends after duration seconds and then calls finished. keepGoing is asked every frame and stops it with its answer; ended hears why it stopped early.
public void ServerStop(string why) Server only. Stops whatever is going on; why goes to its ended callback.

#ProfessionCatalog (class)

The professions and recipes of the game database, and lookups between them.

Member Description
public static IEnumerable<RecipeData> RecipesAt(string station) Recipes made at a kind of station; empty station kind means the ones made anywhere.
public static RecipeData Match(string station, IReadOnlyList<ItemCost> table) The recipe at this station whose ingredients are exactly the table's, or null.
public static AnimationClip ClipFor(string activity) The animation for a Activity: a profession's gathering, or a station's crafting.
public static CraftOption StationOf(Npc npc) The crafting station an NPC offers, or null.
public static string StationName(string station) What players call a kind of station: the name of one in this map, or the kind itself.
public static List<ItemCost> Table(string[] items, int[] amounts) Items as table slots: one per different item, amounts added up.

#ProfessionData (class)

A profession, like Blacksmith or Miner, with its own level. Every character has each one from level 1. The level unlocks how many ingredients a recipe may use, the way Dofus does it, and makes gathering and crafting faster.

Member Description
public int baseExperience Experience from level 1 to 2. Each level after asks for this times the level to the power of Growth.
public Rank[] ranks = Titles by level, shown in the professions window.
public SlotUnlock[] slots = How many ingredients a recipe may use from each level. A recipe asks for the level that unlocks its count, unless it sets its own.
public float craftTimeAtStart Share of a recipe's time it takes at level 1.
public float craftTimeAtTop Share of a recipe's time it takes at the top level.
public int experiencePerIngredient Experience per ingredient of a crafted recipe, when the recipe sets none.
public int serviceLevel Lowest level that may craft for other players. 0 lets anyone; above the top level it is the top level.
public AnimationClip craftAnimation Played while crafting at a station that sets none.
public AnimationClip gatherAnimation Played over and over while gathering.
public Gatherable[] gatherables What it gathers and from which level. Nodes in the world point at these by id.
public Color color = new Color(0.85f, 0.7f, 0.35f) Of its experience bar and name.
public int IngredientsAt(int level) Most ingredients a recipe may use at this level. No table means no limit.
public int LevelForIngredients(int count) The lowest level that allows a recipe with this many ingredients.
public float CraftTimeRate(int level) Share of a recipe's time it takes at this level.

#ProfessionExperienceItemEffect (class)

Profession experience, for one profession or every one. Not used up when none can take it.

Member Description
public ProfessionData profession Empty gives it to every profession.

#ProfessionLevelItemEffect (class)

Whole profession levels, keeping the experience the current level has.

Member Description
public ProfessionData profession Empty raises every profession.

#ProfessionsWindow (class)

Every profession with its level and experience. The picked one shows its recipes, with what goes in and the level each needs, and what it gathers from which level.

Member Description
public Transform professionList Where the rows go. Empty uses the template's parent.
public TextMeshProUGUI levelLabel Level and rank.
public TextMeshProUGUI slotsLabel How many ingredients its recipes may have now, and when the next one comes.
public TextMeshProUGUI emptyLabel Shown when the list is empty.
public void Show(ProfessionData profession) Opens on one profession.

#Rank (class)

#RecipeData (class)

What a profession makes from what. The ingredients placed on a station's table pick the recipe, so a player who knows the mix can make it without looking it up.

Member Description
public string station The kind of station it is made at, like forge or loom. Empty: anywhere, from the professions window.
public ItemCost[] ingredients Up to 8 different items. How many there are sets the level, unless Level is set.
public int level Profession level it needs. 0 uses the level that unlocks its number of ingredients.
public int experience Profession experience per piece. 0 uses the profession's experience per ingredient.
public float seconds Seconds per piece at level 1; higher levels are faster.
public long gold Gold per piece, paid by whoever puts the ingredients.
public bool Matches(IReadOnlyList<ItemCost> table) True when the table holds exactly these ingredients, in any order.

public CanvasGroup group Dims the row when the player can't make it yet.
