#Blunnyn.KitARPG.Modes.TopDown.Server

#TopDownServer (class)

Server half of click-to-move: takes over each player's NavMeshAgent and paths it toward the clicked point after checking the request. Clicking a monster walks into range and keeps attacking; clicking a drop walks to it and picks it up; clicking an NPC walks to it and talks; a skill walks into its range and is cast once. Any new order stops a cast in progress. Keys and sticks send a direction instead, which walks a short step ahead while it keeps coming.

Member Description
public float maxMoveDistance Farther clicks get pulled in to this distance.
public int maxMessagesPerSecond Requests per second before a connection is dropped as flooding.
public float chaseRepath Seconds between path updates while chasing a target.
public float steerTimeout Seconds a key direction keeps walking without a new one, in case the release never arrives.
