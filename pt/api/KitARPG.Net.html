#CharacterAnimations (class)

Every animation of a character, set on its prefab: moving, getting hit, dying, attacking with each weapon type and using each skill. The Animator needs no setup; this gives it the kit's controller and swaps these clips in. A clip left empty is not played. The server reads the hit frames from here, so damage lands when the animation strikes.

Member Description
public Animator animator Found in the children when empty. Without one nothing plays, but the hit frames still count.
public AnimationClip walk Empty uses the run.
public float runSpeed Meters per second the run clip is made for. Faster or slower plays it faster or slower.
public AnimationClip hit When taking damage, unless attacking or casting.
public AnimationClip stunned Looped while stunned.
public ActionAnimation attack = new ActionAnimation() Bare handed, or with a weapon type not listed below.
public AnimationClip cast Looped while casting or channeling a skill not listed below.
public ActionAnimation skill = new ActionAnimation() Using a skill not listed below. Skills that use the weapon attack play the attack instead.
public AvatarMask upperBodyMask The bones attacks, skills and casts move while the legs keep walking: usually the spine, arms and head. Create one with Create > Avatar Mask. Empty: actions play on the whole body.
public bool maskOnlyWhileMoving Use the mask only for actions that start while moving; standing still they play on the whole body. Off: always, so the legs keep their idle.
public bool maskCasts Casts and channels use the mask too.
public float movingSpeed Speed, in meters per second, from which the character counts as moving.
public const string ControllerPath The controller every character uses, with a placeholder clip in each state.
public static readonly ActionAnimation Default Timing used when a character has no animations set: one hit halfway through 0.6 seconds.
public RuntimeAnimatorController Controller The controller with this character's clips, also when a graph drives the Animator.
public static ActionAnimation For(Component character, SkillData skill, WeaponType weaponType) The animation of an attack (skill null) or a skill on a character, or Default.
public AnimatorOverrideController MakeController() The kit's controller with this character's moving, hit, death and cast clips, for previews and portraits too.
