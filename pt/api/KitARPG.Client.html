#AimInput (class)

What the player points at, the same way in every mode: the play mode only says where the pointer is (the mouse, or the middle of the screen behind a crosshair). Skills, the attack key and the target marker all read it from here.

Member Description
public static readonly Func<Vector2> Mouse = () Aims with the mouse.
public static readonly Func<Vector2> Center = () Aims with the middle of the screen, behind a crosshair.
public static Func<Vector2> Pointer Screen point the player aims with, set by the play mode. Null: nothing aims.
public static Vector3? Point A point on the ground aimed at directly, such as a skill dragged on a touch screen. Wins over Pointer.
public static float PointPickMeters Meters from Point at which a body still counts as aimed at.
public static bool WalksIntoRange The play mode walks into range on its own (top-down), so a far point is not an error.
public static float PickPixels Pixels at 1080p from a body at which the pointer still picks it.
public static bool HasAim Something aims now: the pointer or a point.
public static bool GroundPoint(out Vector3 point, float reach = 30f) Where the aim meets the ground, past monsters, players and drops. Aiming at the sky lands at reach meters, level with the player.
public static ICombatant Enemy(PlayerCharacter player) The enemy under the aim: a monster the ray hits, or the body nearest the pointer on screen.
public static PlayerCharacter Ally(PlayerCharacter player, bool dead) The ally under the aim, the player included; for revives only the fallen.
public static PlayerCharacter OtherPlayer(Vector2 pointer) The other player under the pointer, for the player menu.
public static ICombatant Nearest(PlayerCharacter player, float range) The living enemy nearest the player within range meters, a little in favor of the one ahead.
public static CastSkillMessage? Skill(SkillData skill) The cast request for a skill at the aim, or null when it needs a target and none is aimed at.

#ClientSmokeTest (class)

Headless client that plays the login, map and portal loop end to end and logs what it sees, for CI and local checks. -smoketest enter|portal|systems -user name -password pass -character Name [-model id] [-class id] [-stay seconds] "enter" joins and reports the map, position and other players. "portal" also walks through the first portal and steps a few meters on the other side before leaving. "systems" plays ClientSystemsTest with a second client (-qa lead|partner -partner Name).

#ClientSystemsTest (class)

Two clients playing the social and economy systems against real servers, for -smoketest systems. The lead (-qa lead) drives with GM commands; the partner (-qa partner) answers invites and trades. Both accounts need the GM role. Each step logs PASS or FAIL and the run goes on. -partner names the other character.

#CombatEffectsView (class)

Spawns the effects of attacks and skills on clients, at the moments the server uses: the cast effect while casting, the launch effect and projectile on each hit frame, the area effect where a skill lands and the hit effect on whoever is hit. The hit effect comes from the skill, then the weapon or monster, then the element, then the database default. Effects are pooled per prefab.

Member Description
public float defaultLifetime Seconds an effect lives when it sets none and has no particles to time.
protected virtual EffectSpawn HitEffect(GameData source, DamageElement element) The hit effect for a hit: the skill's, the weapon's or monster's, the element's, or the default.
public static float BodyHeight(Transform character) Where a socket is on a character. A child named like the socket wins; humanoids use their bones; otherwise it is worked out from the character's height. How tall a character's body is, in meters, from its renderers.
