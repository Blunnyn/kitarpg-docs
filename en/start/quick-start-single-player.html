Getting started

Quick start: single player

From a finished Setup Wizard to walking around the sample town, fighting, saving and building a game you can hand to a friend. Single player needs nothing outside Unity.

#What single player means

In single player the game hosts its own world. The player's computer is client and map server at once, and characters are saved in a SQLite file on that computer. There is no login screen, no Login or Central service and no database to set up. The maps, data and code are the same as in the MMO, so the game can become an MMO later.

#Step by step: play in the editor

  1. Open the KitARPG window with KitARPG > Open KitARPG or Ctrl/Cmd+Shift+K.

  2. Go to Play & Servers.

  3. At the top, make sure the Single player card is picked. If MMO is picked, click Single player.

  4. Step 1, Check the project. Two rows must be green:

    Row Fine when If not
    Scenes in Build Settings The first scene is Title. The row lists the scenes Press Use starter scenes
    SQLite library for this platform "Found in Plugins/SQLite." The row names the missing file. Import the KitARPG package again with Plugins/SQLite ticked

  5. Step 2, Play. Press Play single player. The editor opens the Title scene and enters Play mode as client and server at once. You can also press Play in Overview, or Unity's own Play button with the Title scene open.

  6. The title screen opens on the Characters list, empty the first time.

  7. Press New. The New character panel opens.

  8. Fill it in:

    Field What to do Rules
    Name Type a name 3 to 16 letters or digits, starting with a letter. Each name is unique
    Look Click a body: male, female or panda in the sample The 3D preview changes
    Class Pick from the list Only the classes the picked body can be. In the sample, male and female can be Warrior, Hunter or Mage; the panda is a Monk
    Hair Pick a style Bodies that keep their own hair, like the panda, offer none

  9. Press Create. The character appears in the list. Back returns without creating.

  10. Select the character and press Play. A loading screen shows, then you are in Town, the sample's start map.

You can keep up to 6 characters (the Game Database's maxCharactersPerAccount, 6 by default). Delete removes the selected character after asking.

#Your first minutes in the game

The sample uses the top-down control mode by default.

To Do
Walk Click the ground, or hold the button to keep walking toward the pointer. WASD and the arrow keys also walk
Attack Click a monster. Space attacks the nearest enemy within 10 meters
Pick up loot Click it, or press F near it
Talk to an NPC Click it, or press F near it
Use a skill Press its key on the quick bar (1 to 9, 0). Area skills show their shape first: click or press the key again to cast, right click or Esc to cancel
Open the bag I
See your character and spend points C
See your skills K
Read your quests L
Open the world map M
Open the menu Esc, or the gear icon

Every key is in Keys.

#Things to try in the sample

  • Talk to the NPCs marked with a yellow ! to take quests.
  • Walk through the portal to the Forest and fight slimes, mushrooms and wolves.
  • Find the Sunken Crypt, an instanced dungeon with a boss.
  • Open the shops: armor, hats, clothes, shoes, weapons and potions.
  • Press B to open the bestiary.

#Cheats: GM commands in single player

In single player the player can use every GM command, like cheats, because Game Settings > Commands > Single Player Commands (singlePlayerCommands) is on by default. Type them in chat (press Enter first):

/gold 10000
/level 20
/item health_potion 20
/god
/spawn slime 5

/help lists them all. The full list is in GM commands. Turn Single Player Commands off before shipping a game where cheats shouldn't work.

#Saving

The game saves by itself: every 60 seconds, when you change maps and when you leave. In single player the game menu (Esc) has Save and leave, which saves and returns to your characters, and Quit.

Where Path
Save file name savegame.db, set in KitARPGSettings.asset > Save File (saveFile)
Folder Unity's persistent data folder for your project: on Mac ~/Library/Application Support/<Company>/<Product>, on Windows %USERPROFILE%\AppData\LocalLow\<Company>\<Product>

Company and product are the names in Project Settings > Player. Play & Servers shows the full path under Save data, in step 2:

Button What it does
Show folder Opens the folder in Finder or Explorer
Delete save data Deletes every single player character the editor saved, after asking. Disabled while playing
Warning

The editor and a build of the same project on the same computer use the same persistent data folder. Delete save data in the editor also deletes the characters of that build on your computer.

#What doesn't work in single player

Systems that need other players or a server answer "Only on an online server." or are hidden:

  • friends, parties, guilds, alliances and tax collectors;
  • mail and the market;
  • the in-game shop;
  • reports, the moderation commands that read the database (/ban, /reports, /closereport, /logs, /role, /audit).

Everything else works: combat, skills, items, the bank, the forge, quests, dialogues, dungeons, day and night, the bestiary.

#Step 3: Build the game

  1. In Play & Servers, open Step 3, Build the game.
  2. Press Build for Mac or Build for Windows. These are the same as KitARPG > Starter > Build Mac Single Player and Build Windows Single Player.
  3. Project Check runs first and stops the build on errors.
  4. The build goes to Builds/Starter/MacSinglePlayer/KitARPG.app or Builds/Starter/WindowsSinglePlayer/KitARPG.exe. The Builds folder is next to your Unity project folder, not inside it.

The build carries the server code and the local save, so the game hosts itself. Its scenes come from the maps in the Game Database; you don't edit a build list. Give the whole build folder to players.

Tip

A Windows build made with IL2CPP has to be made on Windows, and a Mac one on a Mac.

#Common mistakes

Mistake What happens Fix
Pressing Unity's Play with another scene open The game starts in that scene without the title screen Open Title, or use Play single player
Changing Game Settings during Play The fields are locked Stop Play first
Picking a class the body can't be The class list only offers valid ones; a modified client is refused Add the class to the model in Player models
Expecting mail or parties "Only on an online server." Switch to MMO in Play & Servers
