Getting started

Installation

How to get KitARPG into a Unity project, what the import brings, what happens the first time the editor opens, and how to fix an import that went wrong. When you finish, the Setup Wizard takes over.

#Before you start

  • Install Unity 6000.6.0f1 (Unity 6.6) or newer with Unity Hub. See Requirements.
  • Decide whether you start a new project (recommended) or import into an existing one.
  • If you plan to try the MMO on your computer, install the .NET 10 SDK now. You can also do it later.
Tip

Put your project under version control (Git or Unity Version Control) before importing. It makes every later step, including kit updates, safe to undo.

#Step by step: a new project

  1. Open Unity Hub and press New project.
  2. Pick Unity 6000.6.0f1 or newer as the editor version.
  3. Pick a template. Any 3D template works, including the empty Universal 3D one. The kit installs what it needs.
  4. Name the project and press Create project. Wait for the editor to open.
  5. Open Window > Package Manager.
  6. In the left column, open My Assets (you need to be signed in with the Unity account that bought the kit).
  7. Find KitARPG and press Download, then Import.
  8. The Import Unity Package window lists every file. Leave everything ticked and press Import.
  9. Unity imports the files and then installs the Unity packages the kit declares (URP, AI Navigation, uGUI, Input System, Test Framework). It may compile a few times.
  10. If Unity asks whether to enable the new Input System backends and restart, you can say yes or no. The kit works with either input. Saying yes restarts the editor.
  11. When the editor settles, the KitARPG Setup window opens by itself. Continue with the Setup Wizard.

#What the package contains

Path in your project What it is
Assets/Blunnyn/KitARPG/ The kit: runtime code, editor tools, modes, DevKit, sample, tests, plugins and documentation
Assets/Blunnyn/KitARPG/Services.zip The .NET services (Login, Central, Shop, Data, Hosting, Modules, Launcher, tests and examples) as source code
Assets/Blunnyn/Art/ The voxel art: characters, gear, weapons, monsters, animations and icons
Assets/Mirror/ Mirror, the networking library, with the KCP transport
Assets/ScriptTemplates/ Mirror's script templates

The full layout is in Project structure.

Warning

If your project already has Mirror in another folder, you end up with two copies and errors about duplicate types. Keep only one copy of Mirror: the one in Assets/Mirror from the kit is the version the kit is tested with.

#What happens the first time the editor opens

Several things run by themselves after the import. You see some of them in the Console.

#The services are unpacked

A .unitypackage can only carry assets, so the .NET services come as Services.zip. The first time the editor loads, the kit unpacks it to:

Assets/Blunnyn/KitARPG/Services~

Unity never imports a folder whose name ends in ~, so the C# files of the services don't end up in your game. The Console shows:

[KitARPG] Services <version> unpacked to .../Assets/Blunnyn/KitARPG/Services~.

The zip carries a kit-services.version file. The kit unpacks again only when the zip's version differs from the one already unpacked, for example after importing a newer kit.

Note

If a Services folder with KitARPG.Services.slnx exists next to your Unity project folder or inside it, the kit uses that one and leaves the zip alone. Play & Servers shows the folder in use on the Services source line, with a Browse button to pick another.

#The Setup Wizard opens

The wizard opens once per project, unless the file UserSettings/KitARPG/setup-done exists. It never opens in batch mode or in the second editor of Multiplayer Play Mode. You can always open it again from KitARPG > Setup Wizard.

#The kit remembers its version

The kit writes its version to UserSettings/KitARPG/seen-version. On a first import nothing else happens. When you later import a newer kit, the What's New window opens once with the changelog. See Updating the kit.

#Importing into an existing project

You can add KitARPG to a project you already have. Check these first:

Check Why
Unity 6000.6.0f1 or newer The kit doesn't compile on older versions
The project uses URP, or you are ready to switch The Setup Wizard sets URP as the render pipeline for Graphics and for every quality level. Built-in materials of your own will need converting
No other copy of Mirror Two copies conflict
Build Settings The wizard replaces the scene list with the starter scenes, Title first. Note your own scenes before
Color space The wizard sets Linear

The wizard only touches project settings (render pipeline, color space, Build Settings) and the starter sample. It never changes your own assets.

#Checking that the import worked

After the wizard, everything below should be true:

  • The Console has no red errors.
  • The menu bar has a KitARPG menu.
  • Ctrl/Cmd+Shift+K opens the KitARPG window.
  • Overview in that window says "Everything is ready", or lists only MMO steps you haven't done yet.
  • Project Check shows no errors.

#When the import goes wrong

Symptom Cause Fix
Hundreds of compile errors mentioning UnityEngine.Rendering.Universal URP didn't install Open Window > Package Manager, install Universal RP 17.6.0, then reopen the project
Errors about Unity.AI.Navigation or NavMeshSurface AI Navigation didn't install Install AI Navigation 2.0.14 from the Package Manager
InvalidOperationException about UnityEngine.Input from your own scripts on Play The project uses only the Input System and your script calls Input directly Call KitInput instead. The kit's own code already does
Errors about duplicate Mirror types Two copies of Mirror Delete one copy
The Setup Wizard didn't open It ran before in this project, or the editor is in batch mode Open KitARPG > Setup Wizard
Services~ is missing The editor hasn't finished loading, or Services.zip wasn't imported Wait for compilation to finish, or import the package again with Services.zip ticked
"Missing ... Import the KitARPG package again." for the SQLite library The SQLite plugin for your platform wasn't imported Import the package again with Plugins/SQLite ticked

For more, see Troubleshooting.

#Uninstalling

To remove the kit from a project, delete Assets/Blunnyn, Assets/Mirror, Assets/ScriptTemplates, Assets/Settings/Resources/KitARPGSettings.asset and UserSettings/KitARPG. The Unity packages it installed stay; remove them from the Package Manager if you don't use them.

Important

UserSettings/KitARPG holds the local database of the MMO, the launcher's keys, test accounts and the local shop catalog. Deleting it deletes every account and character you made locally.
