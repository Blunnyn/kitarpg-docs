Getting started

Requirements

What you need on your computer to use KitARPG, what is optional, and what each piece is for. Read it before installing so nothing stops you halfway.

#The short version

  • To play the sample single player: Unity 6.6 (6000.6.0f1) or newer. Nothing else.
  • To play the sample as an MMO on your computer: the above plus the .NET 10 SDK.
  • To deploy an MMO: the above plus Linux Dedicated Server build support in Unity and a machine with Docker.

#Unity

Requirement Value Notes
Unity version 6000.6.0f1 (Unity 6.6) or newer The lowest version the kit supports. Older versions don't compile it
Render pipeline Universal Render Pipeline 17.6 The Setup Wizard turns it on. The kit's materials are URP materials and show pink without it
Color space Linear The Setup Wizard sets it
TextMesh Pro essentials Imported into the project The Setup Wizard imports them. Without them every label in the kit's UI has no font
Active Input Handling Input System, Input Manager or both The kit reads input through its own KitInput layer and works with either
Editor platform macOS or Windows The local map server builds and the launcher's defaults are for Mac and Windows. The editor's SQLite library also ships for Linux

#Unity packages

The KitARPG package declares the Unity packages it needs. When you import it, Unity installs them for you, so an empty project works.

Package Id Version Used for
Universal RP com.unity.render-pipelines.universal 17.6.0 Rendering
AI Navigation com.unity.ai.navigation 2.0.14 NavMesh for players and monsters on the server
uGUI com.unity.ugui 2.6.0 The whole interface, with TextMesh Pro
Input System com.unity.inputsystem 1.20.0 Keyboard, mouse and touch when the project uses it
Test Framework com.unity.test-framework 1.8.0 The kit's Play mode tests. Optional: the kit still compiles if you remove it

Networking is Mirror with the KCP transport (UDP). Mirror comes inside the package, in Assets/Mirror; you don't install it separately.

#Optional Unity packages and modules

Item Needed for How to get it
Multiplayer Play Mode 3.0 (com.unity.multiplayer.playmode) Play with two players, which opens a second editor The button offers to install it the first time
Mac Build Support (IL2CPP) Mac clients and Mac single player games Unity Hub > Installs > Add modules
Windows Build Support (IL2CPP) Windows clients and Windows single player games Unity Hub > Installs > Add modules
Linux Dedicated Server Build Support (IL2CPP) Linux map servers for Docker (KitARPG > Starter > Build Linux Server) Unity Hub > Installs > Add modules
com.unity.toolchain.macos-arm64-linux Building the Linux map server from a Mac Package Manager > Add package by name
Note

Clients released to players are always built with IL2CPP. The build check stops an MMO client built with Mono, because its code would ship as readable DLLs. IL2CPP builds for Windows are made on Windows, and for Mac on a Mac. See Builds.

#For MMO: the .NET 10 SDK

Login, Central, the Shop and the launcher are .NET 10 programs. The editor compiles and runs them for you, but it needs the SDK.

Requirement Value Notes
.NET SDK 10.x Free, from https://dotnet.microsoft.com/download/dotnet/10.0. The runtime alone is not enough: the editor builds the services from source

Where the editor looks for dotnet, since Unity doesn't always get your shell's PATH:

  • Every folder in PATH.
  • Windows: C:\Program Files\dotnet\dotnet.exe.
  • Mac and Linux: /usr/local/share/dotnet/dotnet, /usr/local/bin/dotnet, /opt/homebrew/bin/dotnet, /usr/share/dotnet/dotnet and ~/.dotnet/dotnet.

After installing, press Check again under the .NET 10 SDK line in Play & Servers. Play & Servers shows the versions it found ("Installed: ...").

#Optional: Docker

Item Needed for
Docker Desktop (Mac, Windows) or Docker Engine (Linux) Running PostgreSQL on your computer with one click (Set up PostgreSQL... > Docker on this computer), and deploying with Docker Compose

You don't need Docker to make your game or to play the MMO locally: SQLite works with nothing installed.

#Optional: PostgreSQL

SQLite is enough to develop and for small servers. For production, use PostgreSQL. Any PostgreSQL server works: one on your computer, on a VPS, or a hosted one such as RDS, Supabase or Neon. With Docker, the kit runs PostgreSQL 17 for you. See Database.

#Ports used on your computer

When you run the MMO locally, these ports must be free. Play & Servers warns when something else holds them.

Port Protocol Used by
5100 TCP (HTTP) Login
5200 TCP (HTTP) Central
5300 TCP (HTTP) Shop (only when it runs)
7700 UDP Central's map link, which map servers connect to
7777 UDP Map server for town
7778 UDP Map server for forest
7779 UDP Map server for crypt
5432 and up TCP PostgreSQL in Docker, on the first free port from 5432

#Hardware

The kit has no special hardware needs beyond what Unity 6.6 asks for. Keep in mind:

  • The first map server build takes a few minutes; later ones are faster.
  • Play with two players runs a second Unity editor, which uses about as much memory as the first. The first time it opens, it imports the project.
  • In MMO each running map is its own process. The sample starts town with the services and forest and crypt when a player first enters them.

#For players of your game

Build Players need
Single player Nothing else. The save is a SQLite file in the player's data folder
MMO client A network connection to your Login and Central addresses (HTTPS) and to the map servers' UDP ports
