Reference

Glossary

The words this manual and the KitARPG editor use, in alphabetical order, with a short definition and a link to where each is explained.

#A

Account A player's login: a username, a password hash, a GM level and an account bank. One account can hold several characters (6 by default). MMO only. See Services.

Account bank A bank shared by every character of an account, opened at a banker NPC, with no weight limit. See Inventory and bank.

Action (game action) Something that rewards or changes a player when a quest, dialogue line, NPC option or trigger runs it: give items, experience, teach a skill, set a flag, travel. See Conditions and actions.

Alliance A group of guilds with its own chat channel (/al). See Guilds.

Assembly A compiled unit of code in Unity, defined by an .asmdef file. The kit is split into assemblies (KitARPG.Shared, KitARPG.Data, KitARPG.Net, KitARPG.Server, KitARPG.Client and more) so each build carries only its own code. See Assemblies.

Attribute A character value players spend points on, such as Strength or Vitality. Each point adds stats. See Attributes and stats.

Audit (GM audit) The record of every staff command in the gm_audit table. Staff commands don't run when they can't be recorded. See GM commands.

#B

Bestiary The in-game book of monsters (B): where each lives and what it drops. See Bestiary.

Build Separation The check that runs before every build and stops it when a build would carry code it shouldn't, such as server code in an MMO client. KitARPG > Check Build Separation shows the table. See Builds.

#C

Caddy The web server the Docker Compose file puts in front of Login and Central to provide HTTPS. See Docker.

Central The .NET service that keeps sessions, gives tickets to enter maps, starts map servers, and runs chat, friends, parties, guilds, mail and the market. Exactly one per database. See Services.

Character A player's hero in the world: name, model, class, level, items and progress. Belongs to an account.

Class What a character is: attributes and stats per level, skills and starting items. The sample has Warrior, Hunter, Mage and Monk. See Classes.

Condition A rule that locks a quest, dialogue line or NPC option: level, class, quest, item, flag, time of day and more. See Conditions and actions.

Control mode How the game plays: top-down, free camera or third person. Set in Game Settings (controlMode); clients and map servers must use the same one. See Control modes.

Cosmetic A piece of equipment that changes only the look, without stats.

Currency Money other than items: gold, event tokens, or a premium currency for the shop. See Currencies.

#D

DevKit The parts of the kit for writing your own code: templates, events, the example and the guide. See DevKit overview.

Domain reload Unity reloading all scripts when entering Play. The kit works with it off, which makes Play start faster. See Domain reload.

#E

Element A damage type, such as Fire or Water, with resistances against it.

Elite / Boss Monster ranks above Normal. Bosses get a bar at the top of the screen and can have phases. See Bosses.

#F

Flag (story mark) A whole number stored per key on a character, set by actions and read by conditions, to remember story progress. /flag reads and sets them.

Forge The NPC service that upgrades gear with runes, sets gems and salvages pieces into runes. See Forge.

#G

Game Database The asset that lists all the game's data (models, classes, skills, items, monsters, quests, maps and shared rules), and the KitARPG window page that edits it. The sample's is StarterDatabase.asset. See Game Database.

gamedata.json The file the editor exports from the Game Database for Login, so it can create characters with valid models, classes and start values.

Game log A record of what matters for support (trades, loot, mail, deaths, GM commands) in the game_logs table, read with /logs. See Game log and reports.

Game Settings The KitARPG window page that edits the GameInstance on the network prefab: how the game plays. See Game Settings.

GameInstance The component on the network prefab (KitNetwork.prefab) that holds the Game Database and every game setting, and survives map changes.

GM level (role) An account's staff level: 1 Player, 2 Moderator, 3 Game Master, 4 Admin. Stored in accounts.Role. See GM commands.

GM panel The in-game window for staff (F8 or /gm) that runs GM commands with buttons.

Guild hall An instanced map a guild buys once and enters through an NPC.

#H

Headless Running without a window or graphics. Map servers and the launcher in --headless mode run this way.

HUD The in-game interface: bars, quick bar, chat, minimap and windows, in one prefab (GameHud.prefab). See HUD and windows.

#I

Id The text name of a piece of data, like fire_bolt. Filled from the file name when made and never changed after, so saves keep pointing to it.

IL2CPP Unity's scripting backend that compiles C# to native code. Release clients always use it.

Instance (instanced map) A map where each party, or each player alone, gets its own copy, like the Sunken Crypt. See Dungeons.

Item copy (item instance) One concrete item a player owns, with its own random bonuses, upgrades and gems. In the MMO each copy has exactly one owner.

#K

KCP The UDP transport Mirror uses between clients and map servers.

Kit update A change a newer kit makes to a game made with an older one, applied from Overview. It only adds what is missing. See Updating the kit.

KitARPGSettings The asset in Assets/Settings/Resources that says how the game runs (single player or MMO) and where clients connect.

KitInput The kit's input layer, with the same calls as Unity's Input, working with the Input System or the Input Manager.

KitARPG window The editor window with every tool of the kit, opened with Ctrl/Cmd+Shift+K. See KitARPG window.

#L

Launcher The program that starts Login, Central, the maps and optionally the Shop, with a window or headless. Play & Servers uses it. See Launcher.

Ledger The record that moves item copies (ItemLedger) or premium currency (currency_ledger) between owners, inside transactions.

LiteNetLib The networking library map servers use to talk to Central over the map link.

Login The .NET service for accounts, sign in and characters. See Services.

Loot table A list of what a monster drops and how often. See Loot.

#M

Map A Game Database entry plus a scene. Each map runs on its own map server in the MMO. See Maps.

Map link The UDP connection (port 7700) between map servers and Central. Not encrypted; keep it off the internet.

Map server A headless Unity build that runs one map, its players and monsters. Central starts them from the map server build.

Market The player market at an NPC; sellers are paid by mail. MMO only. See Market.

Mirror The networking library between clients and map servers. Ships in Assets/Mirror.

Model (player model) A player prefab: a look players pick, with the classes it can be. See Player models.

Module (kit module) A whole system (Chat, Guilds, Mail, Market and more) you turn on and off in the Modules page. See Modules.

Module (service module) A .NET library that extends Login or Central without editing them. See Service modules.

Multiplayer Play Mode Unity's package that runs a second editor, used by Play with two players.

#N

NavMesh The walkable surface baked in each map scene. The server moves players and monsters on it.

Network version A short hash of everything that travels over the network. A client whose version differs from the map server's is refused with version_mismatch.

NPC option One thing an NPC offers: shop, teleport, quest, dialogue, trainer, bank and more. See NPCs.

#O

Overview The first page of the KitARPG window, with the to-do list and the Play button. See Overview.

#P

Play & Servers The KitARPG window page where you pick single player or MMO, start the services and play. See Play & Servers.

Premium currency A currency held by the account, not the character, spent only at the in-game shop. See Cash shop.

Project Check The KitARPG window page that finds problems in the project, and runs before every build. See Project Check.

#Q

Quick bar (hotbar) The row of slots at the bottom of the HUD, on keys 1 to 9 and 0, for skills and items.

#R

Rates Server multipliers for experience, loot and gold, set in Game Settings, plus timed events with /rates.

Remember me The sign in option that keeps a one-use token on the player's computer so they don't type the password next time.

#S

Services Login, Central and Shop, the .NET programs behind the MMO. Shipped as Services.zip and unpacked to Services~.

Services~ The folder where the editor unpacks the services. The ~ keeps Unity from importing it.

Session An account's time in the game, from sign in to leaving. One per account.

Set Gear pieces that give bonuses when worn together. See Sets, upgrades and sockets.

Shop (service) The optional .NET service for the in-game shop: catalog, balances, purchases and payments. See Shop service.

Shop (NPC) A store at an NPC, listed in the Game Database's Shops. See NPC shops.

Single player The mode where the game hosts its own world and saves on the player's computer. See Quick start: single player.

Skill An action with a target, area shape, cost, cooldown and effects. See Skills.

SpawnPoint The component that marks where players appear on a map.

Starter sample The playable sample in Samples/Starter: Title, Town, Forest and Crypt with their data.

Start over The Overview tool that builds the starter sample again from scratch, losing changes made to it.

Status A buff or debuff on a character or monster, such as poison or stun. See Statuses and buffs.

#T

Tax collector A guild's NPC placed at a spot on a map that takes a share of what is hunted nearby. See Tax collectors.

Test client A client built with the KITARPG_DEV define that carries the kit's test tools. For local checks only, never for players.

Ticket A one-use pass Central gives a client to enter a map server. It expires after 30 seconds.

Trigger (world trigger) Something in a map that fires actions when a player enters it or an action sets it off, for one player or everyone. See World triggers.

#U

UserSettings/KitARPG The folder in your project, outside Assets, with this computer's launcher settings, keys, local database and logs. Never shipped.
