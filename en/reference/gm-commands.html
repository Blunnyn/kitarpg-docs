GM commands

Every slash command in KitARPG: the chat commands every player has, and the GM commands for moderators, game masters and admins, with their syntax, default level, aliases, limits, answers and examples. GM commands run on the map server; the server checks the account's level on every line.

#How commands work

  • Type a command in chat: press Enter, type the line starting with /, press Enter.
  • Chat commands (channels, parties, friends) are handled by the client. Everything else goes to the map server, which knows the account's GM level.
  • /help (or /commands) lists the chat commands and every GM command your level allows, each with its level in brackets.
  • A command above your level answers "Unknown command /name. Try /help.", the same as a command that doesn't exist. Staff commands tried above one's level are still recorded.
  • Arguments are separated by spaces. [brackets] mark optional ones. A player argument is a character name.
  • Where a [player] is optional, leaving it out targets yourself.
  • Unless stated otherwise, the target must be on the same map as you; otherwise the answer is "No such player here."
  • A line is cut at 300 characters.

#GM levels

Every account has a GM level, stored in accounts.Role in the database.

Level Name Who
1 Player Every new account
2 Moderator Watches chat and players: who, goto, boot, mute, announce, reports, logs
3 Game Master Runs the world: summon, teleport, ban, heal, god, statuses, monsters, maps, quests, flags, triggers
4 Admin Hands out things and manages staff: items, gold, currencies, experience, levels, points, skills, rates, roles, audit

The levels in the tables below are the defaults. Change any command's level in Game Settings > Commands > Gm Command Levels (gmCommandLevels): add a row with the command name without the slash (like item) and the level it should ask for. /role always asks for level 4, whatever the setting.

#Single player

In single player, Game Settings > Commands > Single Player Commands (singlePlayerCommands, on by default) makes the player an admin, so every command works like a cheat. Commands marked Online only answer "Only on an online server."

#Setting the first admin

New accounts start at level 1. Name the first admin in the database:

UPDATE accounts SET "Role" = 4 WHERE "Username" = 'yourname';

With the local SQLite database of Play & Servers (stop the services first):

sqlite3 UserSettings/KitARPG/data/kitarpg.db "UPDATE accounts SET \"Role\" = 4 WHERE \"Username\" = 'yourname';"

After that, admins change levels in game with /role. If the player is already on a map, the new level takes effect the next time they enter a map.

#The audit

Every command of level 2 or more is written to the gm_audit table with the account, character, level, command, whole line, target, whether it was allowed and its answer. Commands above the player's level are recorded as refused.

When the audit can't be written, staff commands don't run: "GM commands are paused: they can't be recorded right now. Try again in a moment." Entries wait on disk until Central confirms them. Every staff command also goes to the game log as gm.command.

Admins read the audit with /audit.

/audit [player] The last GM commands on record. Online only

#Commands in detail

#/help
Syntax /help
Alias /commands
Level 1

Lists the chat commands (/s /m /g /p /gu, /w name, /r, /invite name, /leave, /kick name, /promote name, /friend name, /unfriend name, /trade name, /ginvite name, /report name reason), then one line per GM command you may use: its syntax, description and level, like /item id [amount] [player]: Puts items in a bag. [4].

#/report
Syntax /report player reason
Level 1
Online only Yes

Sends a report about a player to the moderators, stored in the reports table. Everything after the name is the reason. Moderators list them with /reports. The player menu also has Report.

/report Griefer123 spamming the trade channel

#/who
Syntax /who
Level 2

Lists the players on this map as Name (level), separated by commas.

#/goto
Syntax /goto player
Level 2

Jumps to the side of a player on this map. Answers "No such player here." if the name isn't on this map or is yours, and "Can't go there." if there is no walkable ground there.

#/boot
Syntax /boot player
Level 2

Disconnects a player on this map. The player sees "Kicked by a moderator." You can only boot accounts of a lower level than yours ("You can't kick them."). Answers "Name was kicked."

#/mute
Syntax /mute player [minutes]
Level 2
Default 10 minutes
Limit 0 to 525,600 minutes (one year)

Silences a player in chat. The player is told "You can't chat for N minutes." /mute player 0 lifts it ("You can chat again."). The mute is a flag on the character, so it survives map changes and sign outs. You can only mute accounts of a lower level, or yourself.

/mute LoudPlayer 30
/mute LoudPlayer 0

#/announce
Syntax /announce text
Alias /broadcast
Level 2

Sends [Announcement] text on the system channel to everyone online, on every map. In single player, to the player.

/announce Server restart in 10 minutes.

#/reports and /closereport
Syntax /reports, /closereport id
Level 2
Online only Yes

/reports lists the open reports with their ids, in your chat. /closereport id marks one as handled.

/reports
/closereport 17

#/logs
Syntax /logs player [kind]
Level 2
Online only Yes

The player's last game log lines, read from the game_logs table. Give a kind to see only one, for example:

Kind What it records
item.trade Trades
item.loot Loot picked up
item.shop_buy, item.shop_sell NPC shop buys and sells
item.destroy Items destroyed
item.forge Forge use
bank.deposit, bank.withdraw Bank moves
mail.sent, mail.taken Mail
market.listed, market.sold, market.cancelled, market.expired The market
shop.premium_buy, shop.premium_gift, shop.premium_grant The in-game shop
account.login, account.login_failed, session.enter, session.leave Sessions
character.level, quest.done, combat.death, combat.pvp_kill Progress and combat
chat.line Chat, when Game Settings logs it
gm.command, gm.ban Staff actions 
/logs Aria item.trade

See Game log and reports for every kind.

#/summon
Syntax /summon player
Level 3

Brings a player on this map to your side. Only accounts of a lower level ("You can't summon them."). Answers "Can't bring them." when the spot isn't walkable.

#/tp
Syntax /tp x z
Level 3

Jumps to a point on this map, by its x and z coordinates; the height is found from the ground. Answers "Nothing to stand on there." when no walkable ground is within 4 meters of the point.

/tp 120 -45

#/ban
Syntax /ban player hours
Level 3
Online only Yes

Bans the character's account for that many hours. The player doesn't have to be on your map. A banned account loses access within seconds and can't sign in ("This account is banned."). /ban player 0 lifts it.

/ban Cheater 72
/ban Cheater 0

#/heal
Syntax /heal [player]
Level 3

Restores full health and mana. A dead target is revived first.

#/god
Syntax /god
Level 3

Turns god mode on or off for yourself: you take no damage. Answers "God mode on." or "God mode off."

#/status
Syntax /status id [seconds] [player]
Alias /buff
Level 3
Default 30 seconds
Limit 1 to 3600 seconds

Puts a status from the Game Database on a player, by its id. Answers "No status 'id'." for an unknown id.

/status stunned 5 Aria
/buff regeneration 60

#/spawn
Syntax /spawn monster [count]
Level 3
Default 1
Limit 1 to 50

Brings monsters, by their Game Database id, about 4 meters in front of you, scattered a little. They are event monsters: they don't come back after dying.

/spawn slime 5
/spawn void_herald

#/killall
Syntax /killall [meters]
Alias /kill
Level 3
Default 10 meters
Limit 1 to 100 meters

Kills every monster around you, except summons. They give their rewards, credited to you. Answers "Killed N."

#/map
Syntax /map id [x z]
Alias /travel
Level 3

Goes to a map by its Game Database id, at the point x z of that map (0 0 when left out). On another map, when there is no walkable ground near that point, you arrive at the map's SpawnPoint instead. Answers "No map 'id'." for an unknown id and "Can't travel now." when the move is refused, for example when the point is on your own map and has no ground.

/map forest
/map town 10 25

#/quest
Syntax `/quest give
Level 3
Action What it does Answer
give The player takes the quest, as if from its NPC "Taken.", or why it can't be taken
finish Fills every objective, so the quest is ready to turn in "Ready to turn in." or "Not taken."
reset Forgets the quest, so it can be taken again "Forgotten." 
/quest give slime_trouble
/quest finish slime_trouble Aria

#/flag
Syntax /flag key [value] [player]
Level 3

Reads a story mark (a whole number per key on the character), or sets it when a value is given. Answers key = value. Marks drive conditions on quests, dialogues and triggers.

/flag met_the_king
/flag met_the_king 1

#/trigger
Syntax /trigger id
Level 3

Sets off a world trigger on this map, its conditions included, as if you set it off. Answers "Done." or why it didn't fire. See World triggers.

#/item
Syntax /item id [amount] [player]
Level 4
Default 1
Limit 1 to 9999

Puts items in a bag, by their Game Database id. Answers "Gave N Item to Name." and, when the bag is full, "N didn't fit."

/item health_potion 20
/item health_potion 5 Aria

#/gold
Syntax /gold amount [player]
Level 4
Limit -1,000,000,000 to 1,000,000,000 at a time

Adds gold, or takes it with a negative amount (never below 0). Answers "Name has N gold."

/gold 10000
/gold -500 Aria

#/currency
Syntax /currency id amount [player]
Level 4
Limit -1,000,000,000 to 1,000,000,000 at a time

Adds any currency by its id, or takes it with a negative amount.

  • A normal currency goes to the character, who must be on this map. Answers "Name has N Currency."
  • A premium currency goes to the account's balance in the Shop service. The target can be offline or on another map. The map answers "Asking the shop to give N Gems for Name." and the Shop's answer follows in chat. Needs the Shop service: "This map has no Shop service." otherwise.
/currency event_tokens 50
/currency gems 100 Aria

#/xp
Syntax /xp amount [player]
Alias /exp
Level 4
Limit 1 to 1,000,000,000

Gives experience, with level ups as normal.

#/level
Syntax /level n [player]
Level 4

Raises a player level by level up to n, with the points and rewards of each level. It never lowers a level. Answers "Name is level N."

#/points
Syntax /points attribute skill [player]
Level 4
Limit 0 to 1000 each

Gives attribute points and skill points to spend.

/points 10 5

#/skill
Syntax /skill id [rank] [player]
Level 4
Default Rank 1

Teaches a skill by its id, at a rank. Answers "Name knows Skill." or why it can't be taught.

#/rates
Syntax /rates, /rates kind value [minutes], /rates off
Aliases /rate, /event
Level 4
Limit Value 0 to 100

Without arguments, shows the experience, loot and gold rates in effect, with the server rate and the event part, and who started the event and how many minutes are left.

With a kind and a value, starts or changes a rates event on every map:

Kind Also accepted
exp xp, experience
loot drop, drops
gold
all Sets the three
  • A value of 2 is double. The event multiplies the server rates of Game Settings.
  • A new event lasts 60 minutes unless you give minutes. Changing a running event without minutes keeps its end.
  • /rates off (or reset, end) ends the event.
  • Everyone is told when an event starts or changes.
/rates
/rates exp 2 120
/rates all 1.5
/rates off

#/role
Syntax /role player level
Level 4, always
Online only Yes

Sets the GM level of a character's account: 1 player, 2 moderator, 3 game master, 4 admin. The player doesn't have to be on your map. The command's own level can't be changed in Game Settings.

Case Answer
Done, raising a level "Name's account is now Moderator (2). It takes effect the next time they enter a map."
Done, lowering a level "... They were disconnected to take it." The player is disconnected at once
Your own account "You can't change your own level."
Someone at your level or above "You can't change the level of someone at your level or above."
A level above yours "You can't give a level above your own."
A bad level "Usage: /role player level (1 to 4)"

The change and its audit line are saved together.

/role Aria 2

#/audit
Syntax /audit [player]
Level 4
Online only Yes

The last GM commands on record, of one player or of everyone.

#Chat commands for every player

These are handled by the client and need no GM level. Channel commands alone (with no text) switch the default channel; with text they send once.

Command Aliases What it does
/s [text] /say Say: players nearby
/m [text] /y, /map Everyone on this map
/g [text] /world Everyone online
/p [text] /party Your party
/gu [text] /guild Your guild
/al [text] /alliance Your guild's alliance
/w name text /whisper, /tell A private message
/r text /reply Answers the last whisper ("Nobody to reply to yet." if none)
/invite name Invites a player to your party
/leave Leaves your party
/kick name Removes a player from your party
/promote name /lead Makes a player the party leader
/friend name Adds a friend
/unfriend name Removes a friend
/trade name Asks a player to trade
/ginvite name Invites a player to your guild
/gm /panel Opens the GM panel, for staff only

With the Chat module off, plain text can't be sent ("Chat is off in this game. Commands start with /."), but commands still work.

#The GM panel

F8 or /gm opens the GM panel for accounts of level 2 or more. It builds the same command lines as the chat, with buttons; the server still checks the level of each one, so a modified client gains nothing. It has four tabs, each shown only when you may use at least one of its commands:

Tab Commands behind its buttons
Players who (refresh the list), goto, summon, boot, mute and unmute, ban and unban (asks first, 24 hours by default), heal, logs, role (asks first)
Items item, gold, xp, level
World rates (show, apply, end), spawn, killall, map, god
Moderation announce, reports, closereport, logs, audit

Clicking a player in the list fills the target; an empty target means yourself. See GM tools.

Command Level What it does

#Adding your own commands

GM commands are registered from a server-only assembly with GmCommands.Register, and appear in /help and the audit like the kit's own. See GM commands in code.
