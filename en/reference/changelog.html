Changelog

Every version of KitARPG, newest first. The version you have is in the KitARPG window, under Overview. Updating keeps your game: read Kit updates in the guide before importing a new version.

#[Unreleased]

Coming in the next version.

#Editor

  • Add-ons: optional features in their own folder and assemblies, declared with KitAddon, turned on and off in Modules, with their own HUD windows, toolbar buttons, kit updates and GM commands. KitARPG > Create Add-on... makes a new one.
  • Add-on windows are prefabs of their own, placed in the HUD as instances: edit the prefab and every HUD follows.
  • The bestiary is now the first add-on (Addons/Bestiary, window in Prefabs/Bestiary Window.prefab). Games that turned it off keep it off. Apply the kit update Add-on windows in the HUD to link its toolbar button.
  • The UIItem prefab moved from the sample to KitARPG/Prefabs, so windows outside the sample can use it. It keeps its GUID: HUDs and rows that use it don't change.

#Fixed

  • Letters that hold gold or items no longer expire: they stay until the player takes what they hold. Market sales and returns are kept the same way.
  • Salvaging gear with a full bag sends the runes to the bank, and holds them if the bank is full too, instead of losing them.
  • Currency over its cap is held on the character and moves into the purse when spending makes room, instead of being lost.
  • When Central restarts, map servers tell it who is playing, so those players keep saving, chatting and using their guild without logging in again. Parties still end with the restart.

#[1.0.0] - 2026-11-10

First release of KitARPG.

#Game

  • Single player (saved on the computer) and MMO (Login, Central and map servers) from the same scenes and code.
  • Three control modes: top-down click to move (with optional keys), free camera and third person with client prediction. Touch controls with on-screen stick and skill buttons.
  • Modular voxel characters: man, woman and panda bodies, hair styles, hundreds of gear pieces, weapons in 16 types and cosmetics that only change the look.
  • Classes, attributes, levels, whole-number stats and per-copy random bonuses on gear.
  • Skills with area shapes, buffs and statuses, damage over time, shields, summons, revives, bounces, zones, line of sight, stealth, immunities, elites and bosses with phases.
  • Items: bag by slots or by weight, the bank as fallback when the bag is full, gear sets, upgrades with runes, sockets, ammunition and dual wielding.
  • Monsters, spawners, loot tables, experience and server rates, day and night, bestiary.
  • Quests with kill, collect, talk and explore goals, chains, dailies, branching dialogs, conditions, actions and world triggers.
  • NPCs: shops, teleports, skill trainers, banks, the market and guild services.
  • Social: chat with channels and filter, friends, parties, trade, mail with attachments, guilds with roles, levels, emblems, history, alliances, halls and tax collectors, PvP zones and duels.
  • Instanced dungeons, with the Sunken Crypt sample.
  • Economy without selling to NPCs by default, salvage into runes and a player market.
  • In-game shop with its own premium currency as a separate service: catalog with categories, search, banners, ribbons and an offer page; purchases and gifts go straight into the bag, real payments through webhooks.
  • Mail notices: a badge with unread letters on the Mail button, "New mail" on screen and a summary when entering the game.
  • GM tools with four ranks, an audited command log and an in-game panel; game log, player reports and moderation commands.

#Editor

  • The KitARPG window (Ctrl/Cmd+Shift+K): Overview with a to-do list, Play & Servers, Game Database, Game Settings, Modules, Shop and Project Check.
  • Setup Wizard in two steps that sets up URP, fonts, the sample and the scenes, then opens Title and the KitARPG window.
  • Step-by-step assistants for new player models and new monsters.
  • Project Check before every build, build separation between client, server and test code.
  • Kit updates: newer versions add what a game made with an older one lacks, without touching what was changed by hand.
  • The new Input System is used when the project has it on, the Input Manager otherwise. Scenes are brought up to date by the Setup Wizard and Project Check.

#Services

  • Login, Central and Shop on .NET 10 with PostgreSQL in production and SQLite on one computer.
  • Launcher that starts everything with one click, or headless from the editor.
  • Docker Compose with Caddy for TLS, Linux map server builds.
  • One owner for every item copy, moves inside transactions, single-use map tickets, one session per account.

#DevKit

  • Your code goes in your own assemblies made from Create > KitARPG > Scripts; the kit is never edited.
  • Templates: skill effect, item effect, condition, game action, quest objective, NPC option, player system, network message, GM command, game log listener, combat formula, stat formula, saved player data, player system override, item menu line, player menu line, settings option, validator check, KitARPG window page and kit update.
  • Static events for the server and the client, virtual methods on windows, player systems, monsters and NPCs.
  • Your own data saved per character, your own messages to Central and modules for Login and Central.
  • Bounty board example built without touching the kit, on Unity and in Central.
  • API reference for every public type.
