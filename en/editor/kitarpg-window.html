The editor

The KitARPG window

The KitARPG window holds every tool of the kit in one place: a sidebar with pages on the left and the open page on the right. This page explains how the window works, what each page is for and what the sidebar badges mean.

#Opening the window

Use any of these:

  • KitARPG > Open KitARPG in the Unity menu bar.
  • The shortcut Ctrl/Cmd+Shift+K.
  • Any of the page menus: KitARPG > Play and Servers, KitARPG > Game Database, KitARPG > Game Settings, KitARPG > Modules, KitARPG > Shop and KitARPG > Project Check open the window on that page.

The window is a normal Unity editor window titled "KitARPG". You can dock it next to the Inspector or the Scene view like any other. Its smallest size is 560 by 420 pixels.

The Setup Wizard opens the window by itself when it finishes. See Setup wizard.

#The sidebar

The top of the sidebar shows "KitARPG" and "by Blunnyn". Below come the pages, in three groups:

Group Page What it is for
(no heading) Overview Where the project stands, the To do list, Play and shortcuts to common tools
(no heading) Play & Servers Single player or MMO, the steps to run each, the services and their log
Game Game Database Every class, item, skill, monster, quest and map of the game
Game Game Settings How the game plays: bag, loot, combat, recovery, death, chat, day and night, mail
Game Shop The in-game shop: the Shop service, its offers and real-money products
Game Modules Turn whole systems of the kit on or off
Project Project Check Broken references, repeated ids, network prefabs and scenes the maps need

At the bottom of the sidebar, under a thin line, the Setup wizard button opens the Setup wizard in its own window. The wizard and the PostgreSQL setup are the only kit tools that open as separate windows.

#Collapsing the sidebar

The small button at the top right of the sidebar folds it:

  • « (tooltip "Icons only") shrinks the sidebar to icons. Hover an icon to see the page name.
  • » (tooltip "Show names") brings the names back.

The choice is saved in your editor preferences, so it stays the same in every project and after restarting Unity.

#Badges

Some pages show a small pill next to their name. When the sidebar is collapsed, the pill becomes a colored dot on the icon.

Page Badge Means
Overview A number, orange Kit updates waiting to be applied. See Updating the kit
Play & Servers On, green MMO mode, and Login and Central both answer
Play & Servers ... MMO mode, services started but Login or Central don't answer yet
Game Database A number, orange Problems in the game data, such as two entries with the same id or a model without classes
Shop On, green The Shop service on this computer answers
Modules 11/15 style How many modules are on, shown only when at least one is off
Project Check A number, red Errors found by the last check
Project Check A number, orange Warnings found by the last check, when there are no errors

No badge means nothing needs your attention on that page.

#The page area

Most pages are drawn in a centered column up to 860 pixels wide that scrolls as a whole. The Game Database uses the whole width for its three columns.

Pages refresh about ten times a second while the window is open, so service lights, badges and counts update by themselves. Searching the project is slow, so pages that look for assets (the network prefab, the game database, kit updates) do it every few seconds instead of every frame.

The window remembers the last page you opened for the rest of the editor session. After Unity restarts, it opens on Overview.

#The look of the pages

Every page uses the same elements, so you learn them once:

  • Cards: rounded boxes with a title and a short line under it. A card with a gold outline is the one to work on now; an orange one asks for attention.

  • Status rows: a colored light, a title, a detail line and often a button on the right. The light means:

    Light Means
    Green with a check mark Done or running
    Orange with ! Warning
    Red with ! Error
    Gold, pulsing Working, such as building or starting
    Grey To do, off or not needed; the detail line says which

  • Pills: small labels such as Done, To do, Locked or a count.

  • Switches: on and off toggles, used in Modules and Shop.

  • Primary buttons are filled with the gold accent; secondary buttons are outlined.

Game data assets use the same cards in the normal Inspector too: every GameData asset shows a header with its icon, name, type and id, and a new card at every group of fields.

#Adding your own page

A page is a class that inherits from KitPage in an editor assembly. The window finds every such class by itself and adds it to the sidebar, sorted by its Group and Order. Create > KitARPG > Scripts > KitARPG Window Page (Editor) makes a starting script. See Editor extensions.

#Common mistakes

  • The window opens empty or on the wrong page after a script error. Fix the compile error in the Console first; the window finds its pages after scripts compile.
  • Changes don't save while in Play. Game Settings and Modules are greyed out in Play mode. Stop Play, then change them.
