KitARPG.Addons.Bestiary

#Blunnyn.KitARPG.Addons.Bestiary

#BestiaryAddon (class)

#BestiaryWindow (class)

Every monster in the game database: search and filter by map or rank, then read its characteristics, where it lives and what it drops, with each item's chance for the player.

Member Description
public Transform rowList Where the rows go. Empty uses the template's parent.
public TextMeshProUGUI countLabel Like "12 monsters".
public TextMeshProUGUI infoLabel Level, rank and how it behaves.
public TextMeshProUGUI whereLabel Experience and where it lives.
public TextMeshProUGUI lootLabel Gold and how many items one kill can drop.
public void Show(MonsterData monster) Opens on one monster.
protected virtual bool Matches(MonsterData monster) Whether a monster passes the search and filters. Override to add filters of your own.
protected virtual void Characteristics(MonsterData monster, ItemDescription lines) The characteristics page. Override to show more of your own data.
protected virtual float ChanceFor(LootTable.Drop drop) The player's chance for a drop: the table's, grown by their loot chance and the server's rate, as kills roll it.
public static string Percent(float chance) "12%", "0.5%", "0.05%".

#UIBestiaryRow (class)

One monster in the bestiary list: icon, name, where it lives and level.

#UIDropRow (class)

One item a monster drops: the item, its chance for the player and how many.

Member Description
public TextMeshProUGUI chanceLabel Like "12%".
public TextMeshProUGUI detailLabel Amount, the table's own chance when the player's differs, and the quest it needs.
