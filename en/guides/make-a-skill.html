Step by step guides

Make a skill

This guide makes Frost Wave: a cone of ice in front of the caster that deals water damage, slows every enemy it hits and stays on the ground for two seconds. Then it gives it to the warrior.

#1. Make the skill

  1. In Game Database, open Combat > Skills and press + New skill.
  2. In General, set Id frost_wave, Display Name Frost Wave, a Description and an Icon.
  3. Set the basics:
Field Value What it does
Max Level 5 Ranks a player can learn.
Target Enemy Cast at an enemy.
Mana Cost 20, 3 per level Each value has a base and a change per rank.
Cooldown 8, -0.5 per level Faster with every rank.
Cast Time 0.4 Seconds before it goes off.
Range 8 Meters to the target.

#2. Its area

In Area, set Shape to Cone, Size to 5 (0.5 per level) and Width to 70 degrees. Every enemy inside is hit. Circle, Line and Single are the other shapes.

In Zone, set Zone Time to 2 and Zone Tick to 1: the cone stays where it was cast and lands again every second.

#3. What it does

The Effects card is the list of what happens to each target.

  1. Press +, then Pick a type > Damage. Set Element to Water, Min to 10 (4 per level) and Max to 15 (5 per level).
  2. Press + again and pick Apply Status. Set Status to Slowed and Duration to 3 (0.5 per level).

The Look card sets the particles: Cast Effect on the caster, Area Effect on the ground, Hit Effect on each target. With no Area Effect, the area is drawn as a flat outline in the element's color. This guide uses the sample's Frost Nova effects.

#4. Give it to a class

  1. Open Characters > Classes > Warrior.
  2. Open Skills, press + and pick Frost Wave. Set Level to 8: warriors can learn it from level 8.

To let other classes learn it from a trainer or a book instead, see Learning skills outside the class.

#5. Try it

  1. Press Play and enter the game with a warrior. Type /level 8 if it is lower.
  2. Open the Skills window (K), learn Frost Wave and drag it to the hotbar. As a GM, /skill frost_wave 1 teaches it at once.
  3. Find a group of slimes (/spawn slime 4) and press its key. With Cast at once off in Settings > Controls, the cone shows first and a click casts it.

#Next steps

  • Every shape, effect and field: Skills.
  • Buffs and debuffs: Statuses and buffs.
  • An animation for the skill: Character Animations > Skills on the player model. See Player models.
