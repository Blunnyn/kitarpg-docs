NPCs

An NPC is someone, or something, players click to talk to: it greets them and lists options such as a shop, travel, a quest, a conversation, the bank or a lever to pull. This page covers the Npc component, every kind of option with its fields, conditional greetings and options, and how talking works on the server.

#What an NPC is

An NPC is an object in a map scene with an Npc component and a collider. It isn't a network object: the client and the map server both load it with the scene, and requests name it by its id. The server checks every request against the NPC the player stands next to.

An NPC has:

  • an id, a name and a greeting,
  • greetings that change with conditions,
  • a list of options: the lines the player can pick.

The same component makes things that aren't people: the sample's Strange Altar is an Npc with no greeting and one Trigger option, so clicking it acts at once.

#Where it is in the editor

Select the NPC's object in its scene. The Npc inspector shows the fields, then an Add option row with one button per kind of option (Shop, Teleport, Skill Trainer, Quest, Dialogue, Trigger, Bank, Market, Guild Bank, Guild Found, Guild Hall, Collector, Forge, Mail, and any option of your own). Under it, each option has a line with its kind and label and a Remove button.

The inspector warns:

  • "Add a collider so players can click it." when no collider is on the object or its children.
  • "No options yet: players can talk to it but there is nothing to pick." when the list is empty.

Selecting the NPC draws its talk range as a yellow circle in the scene view.

#The Npc component

Field What it does Default
Npc Id (npcId) Unique on its map. Quests (TalkObjective) and requests name it. Empty uses the object's name. Empty
Display Name (displayName) Shown at the top of the talk window. "Villager"
Greeting (greeting) Shown when talking to it. Empty with a single option opens that option right away. "Welcome, traveler."
Talk Range (talkRange) Meters from the NPC a player has to be to talk and trade. Half a meter of slack is added for the step a player takes while asking. 3
Greetings (greetings) Said instead of the greeting to players who meet their conditions; the first that fits wins. Each has a Text and Conditions. Empty
Options (options) The lines it offers. Empty

Two NPCs with the same id on one map is an error: only one answers, the console warns, and Project Check reports it.

#Optional components

These are separate components; the sample adds them to its NPCs.

Component What it does
NpcQuestMarker The mark over the head for the local player: a yellow "!" for a quest to take, a yellow "?" for one to turn in, a grey "?" for one in progress. Fields: Height (2.45), Ready Color, Waiting Color, Refresh Seconds (0.5). It only looks at options the player can reach.
Nameplate The name over the head, with a TextMeshPro label.
CharacterOutfit with ModularCharacter Dresses a voxel body in fixed outfits (hair, a set, a hat) for NPCs that never change gear.
CharacterAnimations Plays the idle clip.

#Options common to every kind

Every option has these fields:

Field What it does Default
Label (label) Button text. Empty uses the default for the option, like "Trade" or "Travel to Forest (10 Gold)". Empty
Required Level (requiredLevel) Hidden from characters below this level. 0
Conditions (conditions) Hidden while one isn't met: a shop that opens after helping its owner, a line only for one class. See Conditions and actions. Empty
Show When Locked (showWhenLocked) Shown greyed out with the reason while its conditions aren't met, instead of hidden. Off

An option also hides when its module is turned off in Modules, and when its own rule says so (for example, a guild bank for a player without a guild).

#Every kind of option

#Shop

Opens a shop from the database's Shops list.

Field What it does Default
Shop (shop) The ShopData to open. The option hides without one. None

Default label: "Trade". Stock is kept per NPC while the map runs. Everything about shops is on NPC shops.

#Teleport

Takes the player to a place on this map or another one, for a price.

Field What it does Default
Map (map) Where to go. The option hides without one. None
Position (position) Where the player appears there. 0, 0, 0
Price (price) Gold it costs. 0 is free. 0

Default label: "Travel to <map>" plus "(<price> Gold)" when it costs something. The gold is taken first and given back if moving to the other map fails.

#Skill Trainer

Teaches a skill for gold, even one outside the player's class, within the skill's learning rules.

Field What it does Default
Skill (skill) The skill it teaches. None
Rank (rank) Rank it teaches. A known skill below it is raised to it. 1
Price (price) Gold. 100

Default label: "Learn <skill> (<price> Gold)". The option is hidden from players whose class can't learn the skill and from those who already know it at that rank. When the skill's own requirements aren't met (level, a skill it needs), the reason shows over the player and nothing is charged. See Skills.

#Quest

Gives a quest, takes it back when done, or both. One option per quest.

Field What it does Default
Quest (quest) The quest. None
Offers (offers) Players can take the quest here. On
Completes (completes) Players turn the quest in here. On

It only shows when there is something to do: the quest is available and the option offers it, or it is in progress and the option completes it. Its label shows where the player stands: a yellow "!" when it can be taken, a yellow "?" and "(complete)" when it is ready, a grey "?" and "(in progress)" while it isn't. Picking it opens the quest window. See Quests.

For a quest handed in to someone else, give the giver Completes off and the receiver Offers off, as the sample's "A Letter for Sela" does with Old Tomas and Sela.

#Dialogue

A line of conversation. Picking it runs its actions, then the NPC answers and offers the next lines. Nest them to make branching talks.

Field What it does Default
Reply (reply) What the NPC answers. Empty, with no lines after it, closes the talk. Empty
Actions (actions) Run on picking, before the answer. If one can't, the player is told why and none runs. Empty
Options (options) Lines offered after the answer. Any kind of option, dialogue lines too. Empty
Back To Start (backToStart) Goes back to the greeting afterwards, like a Back line. Off

Default label: "..." or "Back" with Back To Start. When its actions charge something, the price is added to the label, like "Can you patch me up? (15 Gold)". Everything about conversations is on Dialogues.

#Trigger

Sets off a world trigger by its id.

Field What it does Default
Trigger (trigger) The trigger's id on this map. Empty

Default label: "Use". On an object with an Npc, no greeting and only this option, clicking the object fires the trigger right away: a lever, an altar, a chest. When the trigger's conditions aren't met, the reason shows over the player ("The stone is cold and silent.").

#Bank

Opens the player's account bank. Default label: "Bank". No fields of its own. Module: Bank. See Inventory and bank.

#Market

Opens the market, where players sell to each other. Default label: "Market". Module: Market. See Market.

#Guild Bank

Opens the guild bank, for members whose role may use it. Default label: "Guild bank". Hidden from players without a guild. Module: Guilds. See Guilds.

#Guild Found

Founds a guild here: opens the emblem picker, or the guild window when the game has no emblems. Default label: "Found a guild". Hidden from players already in a guild, and when Game Database > Settings > Guild Found At is Window (founding only from the guild window). Module: Guilds.

#Guild Hall

The door to guild halls.

Field What it does Default
Act (act) Enter: takes a member into their guild's hall. Buy: buys the hall with gold from the guild bank. Enter

Default labels: "Enter the guild hall", or "Buy the guild hall (<price> Gold from the guild bank)". Hidden without a guild hall map in the database, from players without a guild, Enter from guilds without a hall, and Buy from guilds that have one or members whose role lacks the Hall permission. Module: Guilds.

#Collector

One thing to do at a tax collector spot. Goes on an NPC that also has a CollectorSpot component.

Field What it does Default
Act (act) Place the guild's tax collector (label shows the cost), Collect it (label shows its gold, items and experience), or Attack another guild's. Place

Each act only shows when it applies; a spot usually has all three. Online only. Module: Collectors. See Tax collectors.

#Forge

Opens the smith's forge: upgrade gear, salvage it, set gems. Default label: "Forge". Module: Forge. See Forge.

#Mail

Opens the player's mailbox. Default label: "Mail". Useful when Game Settings > Mail > Mail Anywhere is off. Module: Mail. See Mail.

#Conditional greetings

Greetings change what the NPC says first. The first entry whose conditions are all met wins; with none, the plain Greeting is used.

The sample's Captain Hale has two:

  1. "There's the one who dethroned a king. Drinks are on the town tonight." with a QuestCondition on "Long Live the King?" set to Done.
  2. "Back from the ruins already? Tell me what you saw out there." with a QuestCondition on "The Old Ruins" set to Taken.

Order them from the most specific to the least.

#Place an NPC

  1. Open the map scene.
  2. Drag a character model into the scene, or make an empty object with a model as a child. Name the object, for example Herbalist.
  3. Add Component > Npc. Set Npc Id to herbalist, Display Name to Hanna and a Greeting.
  4. Add Component > Capsule Collider and fit it to the body, so players can click it.
  5. Optional: Add Component > Npc Quest Marker for quest marks, and a Nameplate with a TextMeshPro child for the name over the head.
  6. In the Npc inspector, press the buttons under Add option for each line, and fill their fields.
  7. Save the scene. On a server, NPCs need no other step: they load with the scene.

A shop NPC step by step is on NPC shops.

#How talking works

  1. The player clicks the NPC (or presses F near it with keyboard controls). The game mode walks the player to it.
  2. Within reach, the server starts the talk. This also counts any TalkObjective for that NPC in the player's open quests.
  3. The server sends the greeting and the options this player sees, with the locked ones greyed out and their reason. With no greeting text and one option that can be picked, that option runs at once.
  4. The player picks an option. The server checks that the player is still in reach, alive, not over 10 requests a second, and that the option is offered to them, then runs it.
  5. Walking away or pressing Escape closes the window.

Every check is on the server. A modified client can't pick a hidden option, a locked one, or one from an NPC it isn't standing next to.

#Single player and MMO

The same in both. In MMO, NPCs live on the map server of their map and on every client that loads the scene. Shop stock is per map server (and per NPC), and starts over when the map server restarts. In an instanced map, each copy has its own NPCs.

#For programmers

Inherit NpcOption to add your own option: set DefaultLabel, override Run(Npc, PlayerCharacter) (server only), and optionally AvailableTo, LabelFor and Module. The inspector shows a button for it at once. The DevKit's Bounty Board example adds a BountyOption. See NPC options.

#Common mistakes

  • Clicking does nothing. No collider, or the collider is on a layer the camera's clicks ignore.
  • "Too far". Talk Range is smaller than where players stop. Raise it a little.
  • An option never shows. Its conditions aren't met (turn on Show When Locked to see why), its module is off, or a required field (shop, map, quest) is empty.
  • A talk objective doesn't count. The quest's Npc Id doesn't match the NPC's id, or the quest was taken after talking. Talk again.
  • Two NPCs answer as one. They share an id on the same map.
