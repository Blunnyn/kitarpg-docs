Sets, upgrades and sockets

Three ways to make gear grow beyond its base bonuses: equipment sets reward wearing pieces together, upgrade rules let players raise a piece step by step (+1, +2...) with gold and runes, and sockets hold gems with their own bonuses. This page covers every field of sets, upgrade rules and gems, salvaging, and how to build a set step by step.

The forge NPC, where players upgrade, salvage and set gems, is on Forge.

#Equipment sets

A set is a group of pieces that give extra bonuses when several different pieces are worn at once. Each piece points to its set; the set holds the bonuses per number of pieces.

#Where sets are

Game Database > Items > Sets lists the sets. Create one there or with Create > KitARPG > Items > Equipment Set. A piece joins a set from its own page, in the Look and wear card, field Set.

#Fields

Field What it does Default
Id, Display Name, Description, Icon As for every game data asset.
Bonuses (bonuses) The bonuses, ordered by pieces: two pieces, four pieces, the whole set... Empty
Pieces (pieces) How many different pieces of the set must be worn. 0
Modifiers (modifiers) What this tier adds: a full modifier bundle, so it can raise stats, percents, element damage, resistances, attributes and skill ranks. Empty

How tiers count:

  • The kit counts different pieces of the set among worn gear. Two copies of the same ring count as one.
  • Every tier reached adds on top of the tiers below it. With bonuses at 2, 3 and 5 pieces, wearing 5 pieces gives all three.
  • A tier with Pieces at 0 never counts.
  • Cosmetic positions don't count toward sets.
  • Weapons can belong to sets too; they are listed as pieces like armor.

#What players see

  • The item tooltip only names the set and how many of its pieces the reader wears: "Knight Set (3/5)".
  • The full set is in the Set window, opened with View set in the item's menu (right click). The pieces are shown in a row: worn ones lit with a check, the rest dimmed. Picking a piece shows its icon, name, type and level, with an Effects tab (its bonuses, as ranges) and a Conditions tab (level, classes and slot, in orange when not met). At the bottom, a dropdown shows the bonus for each number of pieces, already added up with the tiers below it, and opens on the highest tier reached.

#Make a set

This example makes a three-piece Storm Set (hood, gloves, boots) with a bonus at 2 and 3 pieces.

  1. Make the three pieces in Game Database > Items > Hats, Gloves and Boots (see Make a piece of armor). Set their Id and Display Name.
  2. Open Game Database > Items > Sets and press + New equipment set. Type storm_set in Id and Storm Set in Display Name.
  3. In Bonuses, add two entries:
    • Pieces 2, Modifiers > Damage: Air, 4.
    • Pieces 3, Modifiers > Stats Percent > Attack Speed 0.08 (8%), and Skills: Power Shot, ranks 1.
  4. Open each piece and set its Set to Storm Set.
  5. Play, wear two pieces, and check the Character window: +4 air damage. Wear the third: the air damage stays, and attack speed goes up 8%, and Power Shot casts one rank higher if the character knows it.
Tip

Set bonuses stack with the tiers below. Make each tier add something new instead of repeating a bigger copy of the previous one, or wearing the full set gives double.

#Upgrades

Upgrade rules say how a piece is raised one step at a time (+1, +2...), what each step costs, its chance, what happens on a failure, and what salvaging a piece gives. The game database has the default rules (Game Database > Settings, Upgrade Rules); any piece can use its own.

#Where upgrade rules are

Create upgrade rules with Create > KitARPG > Items > Upgrade Rules, then set them in Game Database > Settings > Upgrade Rules (upgradeRules) for every piece, or in a piece's Upgrade field for that piece only.

A piece can be upgraded when Upgradable is on and it has rules (its own or the database's). Ammo and cosmetics start with Upgradable off.

#Fields

Field What it does Default
Id, Display Name, Description, Icon As for every game data asset.
Steps (steps) One entry per step. The first takes a piece from +0 to +1. The number of steps is the highest upgrade. Empty
Protection (protection) An item (a protection scroll) the player can choose to spend so that a failed step keeps the piece as it was. None
Salvage (salvage) What salvaging or breaking a piece gives: a list of item and amount. The first line grows with rarity, upgrade level and the piece's level. Empty
Salvage Per Level (salvagePerLevel) More of the first salvage line for each upgrade level the piece had. 1
Salvage Per Rarity (salvagePerRarity) More of the first salvage line for each rarity above Common (Magic 1, Rare 2, Epic 3, Legendary 4). 1
Salvage Levels Per Extra (salvageLevelsPerExtra) One more of the first salvage line for every this many levels the piece requires. 0 turns it off. 10
Unsocket Gold (unsocketGold) Gold to take a gem out of a socket. The gem comes back. 50

Each step:

Field What it does Default
Gold (gold) Gold the step costs. 0
Materials (materials) Runes, ores, anything in the bag: item and amount. Empty
Chance (chance) Chance to succeed, in whole percent, from 0 to 100. 100
On Fail (onFail) What happens to the piece when the step fails. Keep
Bonus Percent (bonusPercent) Whole percent this step adds to the piece's bonuses and weapon damage. 5

On Fail options:

Option What happens
Keep Only the cost is lost. The piece stays at its level.
LoseLevel The piece drops one level.
Reset The piece goes back to +0.
Break The piece is destroyed and leaves its salvage behind. Gems in it are lost.

#How an upgrade works

  1. The player opens the forge NPC, picks a piece (from the bag or worn) and presses upgrade, with or without protection.
  2. The server checks the piece has rules and a next step, and that the player has the gold and materials.
  3. Gold and materials are spent, whatever the result.
  4. The server rolls the chance. On success, the piece goes up one level.
  5. On failure, if the player chose protection, has a protection item, and the step's On Fail is not Keep, one protection item is spent and the piece stays as it was. Otherwise On Fail applies.

The upgrade level of a copy is shown in its name: "+3 Knight Helm". The tooltip adds "Upgraded +3: +18% to its bonuses".

#What an upgrade does

A piece at upgrade level N grows by the sum of Bonus Percent of steps 1 to N:

  • Its fixed bonuses and its rolled bonuses, added together, are multiplied by 1 + percent / 100, then rounded to whole numbers and whole percents.
  • A weapon's damage rolls are multiplied the same way and rounded.
  • Gems and set bonuses don't grow.

For example, with the sample rules (+6% per step for the first five steps), a +3 sword has +18%: a sword with 5 to 8 damage hits 6 to 9, and a rolled +10 health becomes +12.

#The sample rules: Standard Upgrades

Ten steps, paid in gold and Forge Runes, safe early and risky later:

Step Gold Forge Runes Chance On fail Bonus
+1 20 2 100% Keep 6%
+2 80 4 100% Keep 6%
+3 180 6 90% Keep 6%
+4 320 8 80% LoseLevel 6%
+5 500 10 70% LoseLevel 6%
+6 720 12 60% LoseLevel 10%
+7 980 14 50% Break 10%
+8 1,280 16 40% Break 10%
+9 1,620 18 30% Break 10%
+10 2,000 20 20% Break 10%

Protection is the Protection Scroll. Salvage is 3 Forge Runes, with 2 more per upgrade level, 2 more per rarity, and one more per 10 required levels. Garrick the smith in Town runs the forge and sells runes, protection scrolls, gems, arrows and bolts.

#Salvaging

Salvaging breaks a piece in the bag into materials. Only pieces with upgrade rules or their own Salvage list can be salvaged.

What a piece gives:

  1. Its own Salvage list if it has one, else its upgrade rules' Salvage.
  2. The first line grows, when the piece has upgrade rules, by: Salvage Per Rarity × rarity (Common 0 to Legendary 4) + Salvage Per Level × upgrade level + required level ÷ Salvage Levels Per Extra (rounded down).
  3. Gems in its sockets come back.

Example with the sample rules: a Rare (2) level 10 helm at +2 salvages into 3 + 2 × 2 + 2 × 2 + 10 / 10 = 12 Forge Runes.

With the forge open, the item menu offers Salvage all (N): it breaks every plain copy of that item in the bag at once, up to 100. Copies that were upgraded or hold gems are left out; salvage those one at a time. The bag must have room for everything salvaged, or nothing happens.

A broken piece (failed step with Break) gives the same salvage, but its gems are lost.

#Sockets and gems

A piece with Sockets above 0 can hold that many gems. Each gem adds its bonuses while the piece is worn.

#Gem fields

Gems are in Game Database > Items > Gems, or Create > KitARPG > Items > Gem. A gem has every field items have, plus:

Field What it does Default
Bonuses (bonuses) What it adds in a socket: a full modifier bundle. Gems don't roll; every copy is the same, so they stack. Empty
Fits (fits) Slots of the gear it fits in. Empty means any. Empty

The tooltip of a gem shows "In a socket" with its bonuses, and "Fits ..." when limited. The tooltip of a piece with sockets lists each socket: the gem and its bonuses, or "Empty socket".

#Setting and removing gems

At the forge:

  • Right click a gem in the bag to set it in the picked piece. It goes in the first free socket. The piece must have sockets, a free one, and a slot the gem fits.
  • Right click a set gem in the forge window to take it out. It costs Unsocket Gold from the piece's upgrade rules (free if the piece has none) and the bag needs room for the gem.

The sample has four gems, sold by Garrick: Ruby (+3 Strength), Sapphire (+3 Intelligence), Emerald (+3 Agility) and Amethyst (+20 health). Sample weapons have 1 socket (2 from Rare up), chest armor 2 and helms 1.

#Single player and MMO

The rules are the same in both modes and run on the server: the client asks, the server checks, rolls and answers. Each copy's upgrade level (refine) and gems (gems) are saved with it: in the copy's Extra column in MMO, inside the character's JSON in single player. Every salvage is written to the game log (item.forge, "salvaged into ...") in MMO.

#Tips

  • Keep the first steps safe (100%, Keep) so every player gets a taste of upgrading.
  • Price protection scrolls so they are worth it only on Break steps.
  • Use Fits to make gem types per slot: attack gems for weapons, defense gems for armor.

#Common mistakes

  • A piece can't be upgraded. Upgradable is off, or neither the piece nor the database has upgrade rules, or it is at the last step.
  • A piece can't be salvaged. It has no upgrade rules and no Salvage list.
  • The full set bonus is huge. Tiers add up. Lower the earlier tiers or make the last one smaller.
  • Two identical rings don't count as two set pieces. Sets count different pieces.
