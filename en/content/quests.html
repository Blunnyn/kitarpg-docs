Quests

A quest is a task an NPC gives: objectives to finish, then rewards when the player turns it in. This page covers every field of a quest, every kind of objective, how quests are offered and turned in, chains, daily and repeatable quests, quest drops, the quest log, and a step by step chain with a daily quest.

#What a quest is

A quest is a QuestData asset in the Game Database. It says:

  • who can take it (level, class, earlier quests, any other condition),
  • what to do (objectives: kill, collect, talk, explore, trigger),
  • what it gives (experience, gold, currencies, items, points, a skill),
  • what happens on accepting and on turning in (actions),
  • whether it can be done again (once, daily, always).

An NPC offers it and takes it back through a Quest option. The giver and the receiver can be different NPCs. The server counts every objective and pays the rewards; the client only asks.

Quests are a module: turning Quests off in Modules hides every Quest option.

#Where it is in the editor

Game Database > World > Quests. + New quest makes one in a Quests folder next to the database and adds it to the database's quests list. You can also use Create > KitARPG > Quest.

Lists of objectives, conditions and actions have a type menu next to each entry, so you pick Kill, Collect and so on when you add one.

#Fields

#Texts

Field What it does Default
Id (id) Saved with characters. Changing it loses everyone's progress on this quest. From the file name
Display Name (displayName) The quest's title. Empty (asset name)
Description (description) What the giver says when offering it. Also in the quest log. Empty
Progress Text (progressText) What the giver says while it isn't done yet. "Not done yet? Come back when it is."
Complete Text (completeText) What the giver says when it is turned in. "Well done."
Category (category) Groups it in the quest log, like a region or a story arc. Empty goes under General. Empty

#Who can take it

Field What it does Default
Required Level (requiredLevel) Lowest level. 1
Max Level (maxLevel) Highest level. 0 means no limit. 0
Classes (classes) Classes that can take it. Empty means any class. Empty
Required Quests (requiredQuests) Quests that must be turned in first: a chain. Empty
Repeat (repeat) Once, Daily or Always. Once
Conditions (conditions) Anything else the player has to meet: an item carried, a place found, a story mark. See Conditions and actions. Empty

#What to do

Field What it does Default
Objectives (objectives) The tasks. All must be done to turn it in. Empty
Start Items (startItems) Handed over on accepting, like a letter to deliver. Taken back if the quest is abandoned. Empty

#Rewards

Field What it does Default
Experience (experience) Experience. The player's Experience Gain stat and the server's experience rate apply. 0
Gold (gold) Gold. 0
Currencies (currencies) Other currencies, each with an amount. Empty
Items (items) Items, each with an amount. What doesn't fit in the bag goes to the bank. Empty
Attribute Points (attributePoints) Attribute points to spend. 0
Skill Points (skillPoints) Skill points to spend. 0
Skill (skill) Taught as if by a book: the skill's learning rules still apply. If the player can't learn it, it is skipped. None
Skill Rank (skillRank) The rank taught. 1

#Actions

Field What it does Default
On Accept (onAccept) Run on taking it. The quest isn't taken if one can't run, like a fee the player can't pay. Empty
On Complete (onComplete) Run on turning it in, before the rewards: set a story mark, take an extra item. If one can't run, the quest isn't turned in. Empty

Every action in a list is checked before any runs, so a list never half runs. See Conditions and actions.

#Objectives

Each objective has two common fields:

Field What it does Default
Text (text) Shown in the quest log. Empty uses the default, like "Slay Slimes". Empty
Hint (hint) Unfolds under the objective in the quest log: who to ask, where to look. Empty

When an objective needs more than one, the log shows a count, like "Slay Slimes 3/6". Each step forward is announced over the player, and "<quest>: ready to turn in" when the last one is done.

#Kill

Kill monsters of one kind, or any monster.

Field What it does Default
Monster (monster) The monster. Empty counts any monster. None
Count (count) How many. 5

Default text: "Slay <monster>" or "Slay monsters". The kill counts for the player who earned it and for party members nearby with the same quest. Summons don't count.

#Collect

Carry some of an item. Counts what is in the bag right now, up and down: selling or dropping the items lowers the count.

Field What it does Default
Item (item) The item. None
Count (count) How many. 5
Take On Turn In (takeOnTurnIn) The giver keeps them when the quest is turned in. On

Default text: "Bring <item>". Items in the bank don't count. Combine it with a quest drop so the item only falls while the quest is open.

A collect objective with Count 1 and a Start Item makes a delivery: the sample's "A Letter for Sela" hands over a sealed letter and asks for it back at Sela, with the text "Give the letter to Sela".

#Talk

Talk to an NPC, by its id on the map.

Field What it does Default
Npc Id (npcId) The NPC's id, or its object's name when it has none. Empty
Npc Name (npcName) How the log names it. Empty

Default text: "Talk to <name>". It counts when the player starts talking to that NPC, with the quest already open.

#Explore

Reach a place: a point on a map and a radius around it, or a discovery zone.

Field What it does Default
Map (map) The map of the point. Empty: any map. None
Zone (zone) A zone's id: reached by walking into that DiscoveryZone. Used instead of the point when set. Empty
Position (position) The point. 0, 0, 0
Radius (radius) Meters around the point, on the ground. 5
Place Name (placeName) How the log names it, like "the old ruins". Empty

Default text: "Find <place>". The server checks every half second. A zone is the easier choice: place a DiscoveryZone once, and both this objective and conditions can use its id. See Conditions and actions.

#Trigger

Set off a world trigger: touch an altar, pull a lever, walk into a marked spot.

Field What it does Default
Trigger (trigger) The trigger's id on its map. Empty
Count (count) How many times. 1
Target Name (targetName) How the log names it, like "the altar". Empty

Default text: "Activate <target>". It counts for any player who sets the trigger off while meeting its conditions, even when a trigger for everyone was already spent. See World triggers.

#Quest states

For each character, a quest is in one of these states:

State Meaning
Locked Requirements not met, or done and not repeatable yet.
Available Can be taken now.
Active Taken, objectives missing.
Ready Every objective done; waiting to be turned in.
Done Turned in, and not open again.

#Offering and turning in

Put a Quest option on the NPC that gives it and the one that takes it back. See NPCs.

  1. The option shows only when there is something to do. Its label says where the player stands: yellow "!" to take, yellow "?" and "(complete)" when ready, grey "?" and "(in progress)" while not.
  2. The NPC's head shows the same marks with NpcQuestMarker.
  3. Picking the option opens the quest window: the NPC's text (description, progress text or complete text), the objectives, the rewards, and a button to accept or turn in. It closes on Escape or when the player walks away.

#Accepting

The server checks, in order:

  1. The quest is Available. Otherwise it answers with the first requirement not met, like "Needs level 3" or "Finish Slime Trouble first".
  2. The player has fewer than 20 open quests (Max Active on the player's PlayerQuests component). Otherwise: "Too many quests open".
  3. The bag has room for the start items. Otherwise: "Make room in your bag or bank first".
  4. The On Accept actions can all run.

Then it hands over the start items, opens the quest, counts collect objectives against the bag at once, and shows "New quest: <name>". New quests are tracked on the HUD.

#Turning in

  1. Every objective must be done.
  2. The rewards must fit: items handed in free their slots first, and what the bag can't take goes to the bank. If neither has room: "Make room in your bag or bank first".
  3. On Complete actions run.
  4. Collect objectives with Take On Turn In take their items.
  5. Rewards are paid: items (bag, then bank), gold, currencies, points, the skill, experience.
  6. "Quest complete: <name>".

#Abandoning

From the quest log, Abandon (with a confirmation) drops the quest. Its start items are taken back, all or nothing: if some are missing from the bag, the player is told to put them back first. This stops players from taking the quest again for a second set.

Warning

Mark start items as quest items (Quest Item on, and bound). Project Check warns about a start item that isn't one: it could be traded or sold, and then the quest can't be given up.

#Chains, daily and repeatable quests

  • Chain: list the earlier quests in Required Quests. The next quest is Locked until those are turned in. For more control, use a QuestCondition in Conditions, for example "only while quest X is in progress".
  • Daily: Repeat Daily. After turning it in, it opens again the next day, counted in UTC (midnight UTC, not the player's local time).
  • Always: Repeat Always. It opens again as soon as it is turned in.
  • Once: the default. Done for good.

#Quest drops

A drop in a loot table with its Quest field set falls only for a killer who has that quest open and still carries fewer of the item than the collect objective asks for. Luck and loot rates don't change its chance. Put quest drops first in the table so Max Drops never cuts them.

#The quest log and tracker

  • Quest log (L): tabs In progress, Finished and Hidden with their counts, a search by name or category and a level range. Quests are grouped by Category in groups that fold. Each row shows its kind (once, daily, repeatable, or ready to turn in), level and a pin to track it. The page shows title, level, kind, category and state, the description, the objectives with counts and hints (the first one not done stands out), the rewards, and the Track, Hide and Abandon buttons.
  • Tracker: tracked quests and their objectives on the right of the HUD, up to 5 (Max Quests on QuestTracker). Hiding a quest also stops tracking it. Tracking and hiding are saved with the character.

See HUD and windows.

#Make a quest chain with a daily

This builds a three quest chain at a captain and a daily quest at an alchemist, like the sample's.

#1. The first quest: a kill quest

  1. Quests > + New quest. Rename it Slime Trouble.
  2. Description: "Slimes keep oozing out of the forest toward the gate. Thin them out." Progress Text: "Still hearing them squelch out there." Complete Text: "That's quieter. Here, you earned these."
  3. Category: The Mushroom King.
  4. Required Level 1.
  5. Objectives: add Kill. Monster Slime, Count 6, Hint "Out the town gate and into the forest."
  6. Rewards: Experience 80, Gold 30, Items Health Potion x3.

#2. The second quest: collect with a quest drop

  1. Make an item Slime Gel in Items > Quest items (quest item and bound).
  2. New quest Sticky Samples. Required Quests: Slime Trouble. Required Level 2.
  3. Objectives: Collect, Item Slime Gel, Count 5, Take On Turn In on, Hint "Slimes drop it while this quest is open."
  4. Open Items > Loot > Slime Loot. Add a drop at the top: Item Slime Gel, Chance % 60, amounts 1 and 1, Quest Sticky Samples.
  5. Rewards: Experience 120, Gold 40, and an item.

#3. The third quest: explore and kill

  1. In the Forest scene, add a DiscoveryZone on the ruins: Zone Id old_ruins, Display Name "Old Forest Ruins", Radius 8.
  2. New quest The Old Ruins. Required Quests: Sticky Samples.
  3. Objectives: Explore, Map Forest, Zone old_ruins, Place Name "the old ruins in the forest". Then Kill, Monster Giant Slime, Count 1.

#4. Give the chain to the captain

  1. On the captain's Npc, press Quest three times under Add option and pick one quest in each.
  2. Only one shows at a time: the next becomes Available when the one before is turned in.
  3. Optional: a conditional greeting with a QuestCondition on The Old Ruins set to Taken: "Back from the ruins already?". See NPCs.

#5. The daily quest

  1. Make a quest item Glowing Spore and add it as a quest drop to the mushroom's loot table, with Quest set to the new quest.
  2. New quest Fresh Spores. Repeat Daily. Required Level 3. Category Forest.
  3. Objectives: Collect Glowing Spore, Count 4.
  4. Rewards: Experience 60, Gold 50, Fortitude Elixir x2.
  5. Add a Quest option for it on the alchemist.

#6. Test

Press Play. Useful GM commands: /quest give slime_trouble, /quest finish slime_trouble (fills every objective), /quest reset fresh_spores (forgets it, so a daily can be taken again at once), /spawn slime 6. See GM commands.

#Saving

  • MMO: progress and the record of turned in quests are saved by Central in the character's extra data (keys quests and questsDone), with no database migration.
  • Single player: in the character's save on the player's computer.
  • If you change a quest's objectives later, progress on the objectives that still match is kept.

#Single player and MMO

The same rules in both. In MMO the map server counts kills, talks, places and items, and validates accepting and turning in against an NPC nearby that has the option. Quest progress follows the character across map servers.

#For programmers

Inherit QuestObjective to add your own kind (for example, "craft 3 potions") and advance it with PlayerQuests.ServerAdvance<T>(match, amount). PlayerQuests.ServerCompleted tells other systems a quest was turned in. QuestData.CheckRequirements is virtual. See Quest objectives and Events.

#Common mistakes

  • The quest never shows on the NPC. A requirement isn't met (level, class, earlier quest, a condition), it is Done and not repeatable, the Quest option has Offers off, or the Quests module is off.
  • A collect count drops. The player sold, dropped or banked the items. Collect counts the bag as it is.
  • The quest item doesn't drop. The drop's Quest isn't the quest being done, the player already has enough, or drops above it fill Max Drops.
  • The talk objective doesn't count. Npc Id doesn't match the NPC's id, or the player talked before taking the quest.
  • A daily reopens at a strange hour. It reopens at midnight UTC.
