Monsters

A monster is a MonsterData asset in the Game Database plus a prefab that is its body in the world. This page covers every field of a monster, the assistant that makes one from any 3D model, monster spawners, how the server runs a monster's behaviour, and how monsters work in single player and MMO.

#What a monster is

A monster has two parts:

  • The data (MonsterData, in the Game Database under World > Monsters). It says what the monster is: level, stats, attacks, skills, behaviour, rank, rewards and respawn time. Every copy of that monster in the world uses the same data asset.
  • The prefab (MonsterData.prefab). It is the body: the model, networking, a NavMesh agent, a click collider, the Monster component, animations and the name plate. The assistant builds it for you.

Monsters appear in the world through a Monster Spawner in a map scene, a world trigger, a boss phase (as adds), a summon skill, or the GM command /spawn.

Bosses and elites are monsters with a different rank. Their extra fields are on the Bosses page. What a monster drops is a loot table.

#Where it is in the editor

Open the KitARPG window (KitARPG > Open KitARPG, Ctrl/Cmd+Shift+K), go to Game Database and pick Monsters in the World group. The list shows every monster with its icon. Picking one opens its card on the right, with the fields grouped in cards by section.

At the bottom of the list there are two buttons:

Button What it does
+ New monster Opens the four step assistant in the right panel. Makes the data and the prefab from a 3D model.
Blank monster data Makes only the MonsterData asset, with defaults and no prefab. Use it when you already have a monster prefab.

You can also create the asset from the Project window with Create > KitARPG > Monster. An asset made that way is not in the database until you add it to the monsters list.

#Make a monster from a 3D model

The assistant (+ New monster) has four steps: Model, Combat, Animations and Create. Next stays disabled while a step has a problem, and the problem is written above the button.

#Step 1: Model

  1. Drag an FBX or a prefab into the model field. A preview shows it.
  2. The status line under it says Animated when the model has an Animator, or No Animator when it has none.
    • Animated: you pick its clips in the Animations step.
    • No Animator: the prefab gets a MonsterBody component. The monster hops as it moves, breathes when still, leans into its attacks, flashes when hit, shrinks away when it dies and grows back out of the ground when it respawns. The sample's slimes, mushrooms and void monsters work like this. Attacks still land on time.
  3. Type the Display name. It is filled from the model's name the first time. The line under it shows the id made from it, for example Cave Bat becomes cave_bat.

The id must be unique among monsters. If another monster has it, the step says so.

#Step 2: Combat

  1. Start from a monster copies everything another monster has: stats, skills, resistances, phases, loot and the rest. Leave it on Nothing, start from the defaults for a fresh monster.

  2. Set the numbers under How it fights:

    Field What it does Default
    Level The monster's level. Experience drops for players more than 3 levels above it. 1
    Rank Normal, Elite or Boss. Elites and bosses get a frame on their plate; bosses a bar at the top of the screen. Normal
    Health Maximum health. 50
    Damage Minimum to maximum damage of the basic attack, and its element. Empty element uses the database's default element. 1 to 3
    Attack range (m) About 1.4 for melee; farther for monsters that shoot. 1.4
    Attacks per second How often it swings. 0.8
    Move speed Meters per second. 3
    Aggression Passive, Aggressive or Pack (see Behaviour). Aggressive

  3. Under Rewards, set Experience, the Loot table (empty drops nothing; tables are made in Items > Loot) and Respawn seconds.

#Step 3: Animations

Only for models with an Animator. Without one the step says there is nothing to pick.

  1. Start from a monster copies another animated monster's clips and hit timings. Clips you pick below replace those.

  2. Pick the clips. Empty ones are skipped: without Hit the monster doesn't flinch, without Death it doesn't fall.

    Clip Used for
    Idle Standing still
    Walk Moving
    Hit Taking a hit
    Death Dying
    Attack The basic attack

  3. With an attack clip, Hit lands at says when the damage lands, from 0 (start of the clip) to 1 (end). The server waits for that moment before applying the hit.

#Step 4: Create

  1. Prefab folder defaults to a Prefabs folder next to your database folder. It must be inside Assets. The full prefab path is shown under it; if a prefab already exists there, change the name or the folder.
  2. Keep Render its bestiary icon on to render a portrait for the bestiary.
  3. What will be made lists the data, the prefab and the database entry.
  4. Press Create monster.

The data asset goes to a Monsters folder next to the database, joins the database's monsters list and opens in the Game Database. The prefab gets:

  • NetworkIdentity and a network transform
  • NavMeshAgent, sized from the model (off on clients; only the server moves monsters)
  • CapsuleCollider, the area players click
  • Monster, with FighterStatus, FighterMotion and CombatRelay it needs
  • CharacterAnimations with the clips you picked
  • MonsterBody when the model has no Animator
  • MonsterPlate, the name, level and health over its head

The network manager registers every monster prefab of the database by itself. You don't add it to Mirror's spawnable prefabs.

Tip

To give a monster a ranged attack, raise Attack range and give its attackEffects a projectile in the Game Database. The animation stays on the prefab; the projectile and effects are on the data.

#Every field of a monster

The Game Database card shows these fields. The name, description and icon come from GameData, the base of every database asset.

#Identity

Field What it does Default
Id (id) Saved with characters and sent over the network. Filled from the file name once, then kept. Changing it breaks saves and quests that use this monster. From the file name
Display Name (displayName) Name shown in game. Empty uses the asset's name. Empty
Description (description) Shown in the bestiary. Empty
Icon (icon) Portrait for the bestiary and quest objectives. KitARPG > Render Missing Monster Icons renders the missing ones. None

#Body and stats

Field What it does Default
Prefab (prefab) The body in the world. Needs a Monster component. Project Check reports a monster without a prefab, or with a prefab that has no Monster. None
Level (level) Its level, shown on the plate. Also used for the experience a player gets (see Experience). 1
Stats (stats) Maximum health and mana, regeneration, power, critical chance and damage, healing, attack speed, move speed and the rest of the stats. 50 health, 3 move speed
Modifiers (modifiers) Element damage and resistances on top of the stats, flat and in percent. The sample's slime resists water by 30% and takes 20% more from air. Empty
Status Defense (statusDefense) Statuses it shrugs off or that last less on it: immune flags (stun, root, silence...), immune tags, immune statuses and resistances in whole percent (100 is immune). Only harmful statuses from others are blocked. See Statuses and buffs. Empty

#Behaviour and attack

Field What it does Default
Aggression (aggression) Passive, Aggressive or Pack. Aggressive
Sight Range (sightRange) Meters at which it notices players. Pack monsters also call others within this range. 8
Leash Range (leashRange) How far from home it follows a player before giving up and going back. 18
Wander Radius (wanderRadius) Meters it walks around home while nobody is near. 4
Attack Range (attackRange) Meters at which it hits. 1.4
Attacks Per Second (attacksPerSecond) Base attack rate. Its attack speed stat changes it. 0.8
Attack Effects (attackEffects) Projectile and effects of its basic attack: an effect on the attacker at each hit, a projectile, and an effect on whoever is hit (empty uses the element's). The animation is on its prefab. Empty
Attack (attack) Rolls of its basic attack, one per element, each with a minimum and maximum. Several entries make a mixed attack, like 6 to 10 earth plus 2 to 4 fire. One entry, 1 to 3, default element
Skills (skills) Skills it casts (see Skills). Empty

#Rank

Field What it does Default
Rank (rank) Normal, Elite or Boss. Normal
Phases (phases) Bosses only. See Bosses. Empty
Enrage Seconds (enrageSeconds) Bosses only. Seconds into a fight before it enrages; 0 never. 0
Enrage Status (enrageStatus) Bosses only. Put on itself when it enrages. None
Enrage Shout (enrageShout) Bosses only. Said when it enrages. "Enough!"

#Rewards and respawn

Field What it does Default
Experience (experience) Base experience for killing it. 10
Loot (loot) Its loot table. Several monsters can share one. Empty drops nothing. None
Respawn Seconds (respawnSeconds) Seconds until it comes back after dying. 30
In Bestiary (inBestiary) Listed in the bestiary. Turn it off for helpers like tax collectors or summons nobody hunts. On

#On the prefab: the Monster component

These are on the Monster component of the prefab, not on the data.

Field What it does Default
Think Interval (thinkInterval) Seconds between decisions. Monsters are spread out so a map full of them doesn't think on one frame. 0.2
Corpse Seconds (corpseSeconds) Seconds the body stays where it fell before it is taken home, out of sight, to wait for its respawn. 1

The MonsterBody component (models without an Animator) has Model (model, the child that moves; empty uses the first child), Hop Height (hopHeight, 0.08), Hops Per Meter (hopsPerMeter, 2.5) and Hit Color (hitColor, a light red flash).

#Ranks

Rank What changes
Normal Nothing special.
Elite Its name on the plate is gold with an "Elite" tag. The bestiary and the world map color it as elite. Its numbers are whatever you give it: the rank itself adds no stats.
Boss A bar at the top of the screen while it fights, phases, an enrage timer, and a full reset when it goes home. See Bosses.

#Behaviour

The server runs a small brain for each monster, about five times a second:

  1. Aggression.
    • Passive: never starts a fight. It fights back when hit.
    • Aggressive: attacks the closest enemy it can see within Sight Range.
    • Pack: like Passive, but when one is hit, every monster of the same kind within its Sight Range that has no target joins in. The sample's mushrooms work like this.
  2. Sight. It only notices players it can see, by the game's line of sight rule (Game Settings > Combat > Line Of Sight). Behind a wall it walks around instead of hitting through it. Invisible players are not noticed.
  3. Threat. Damage dealt to it, and healing given to those it fights (Heal Threat in Game Settings), make it angry at someone. Another fighter takes its attention once their threat passes the current target's by Threat Switch (1.1 by default).
  4. Leash. If it goes farther than Leash Range from home, it gives up: forgets its target and threat, heals to full and walks home.
  5. Wander. With nobody to fight, it walks to a random point within Wander Radius of home every 3 to 8 seconds.
  6. Sleep. With Monsters Sleep Unseen on (Game Settings, Combat), a monster no player can see stops thinking until one comes close. It saves server time on big maps.

#Skills

A monster uses the first skill in its Skills list that is ready and reaches its target, then waits its attack interval. Monsters cast at rank 1, instantly, with a cooldown of at least 1 second. Passive skills are skipped. A skill aimed at itself with an area waits until the target is inside that area. Skills are made in Combat > Skills; see Skills.

#Death and respawn

  1. The kill goes to the player who dealt the most damage, not to the last hit.
  2. That player gets the experience (shared with party members nearby) and the loot. See Loot.
  3. The body lies there for Corpse Seconds, then is moved home out of sight.
  4. After Respawn Seconds it comes back at full health at its home point.

Monsters brought by an event (world triggers, /spawn) don't come back: they go 4 seconds after dying. Summons go 2 seconds after dying and give no rewards.

#Experience

The experience a player gets is the monster's Experience, scaled by level difference: full up to 3 levels above the monster, then 20% less per extra level, never below 10%. A level 10 player killing a level 5 monster (5 levels above) gets 60%. Then the player's Experience Gain stat and the server's experience rate apply. In a party, members nearby split it. See Combat and Friends and parties.

#Monster spawners

A Monster Spawner keeps a number of one monster in a circle on a map.

#Fields

Field What it does Default
Monster (monster) The monster it makes. None
Count (count) How many it keeps. 5
Radius (radius) Meters around the spawner where they appear. Each one lands on the NavMesh within 3 m of its random point. 8
When (when) Always, Day (out by day, gone at night) or Night. Uses the game's clock; see Day and night. Always

The scene view draws the radius as a red circle.

#Set up a spawner

  1. Open the map scene.
  2. GameObject > Create Empty, name it, for example Bat Spawner.
  3. Add Component > Monster Spawner.
  4. Pick the Monster, set Count and Radius, and move the object where the monsters should live. Keep it on the NavMesh and away from the SpawnPoint, so players coming back after dying are safe.
  5. Save the scene.
  6. In the Game Database, on the map's card, press Read from scene so the bestiary lists the monster for this map. See Maps.

#How it works

  • It only does anything on the server. On clients it is an empty object.
  • It spawns its whole count once, when the map starts. Each monster then respawns by itself at the point where it first appeared, after its Respawn Seconds. The spawner does not top up the count.
  • With When set to Day or Night, it checks every 2 seconds. When their time comes, the full count appears. When it is over, they leave, even mid fight.
  • A spawner whose monster has no prefab, or a prefab without a Monster component, logs an error and does nothing. Project Check warns about spawners with no monster.
Tip

A boss is usually a spawner with Count 1 and Radius 0, so it always stands at the same spot. Give it a small Wander Radius too, as the sample's Mushroom King has (1.5).

#Single player and MMO

  • Single player: the game is the host. Monsters run on the same machine as the player, with the same brain.
  • MMO: each map runs on its own map server. Monsters exist only on that server; clients receive their position, health and animations. A client can't change a monster.
  • Instanced maps: each copy of a dungeon has its own monsters, made by the copy's own spawners. The first scene the map server loads is a template whose spawners stay idle. See Dungeons.

#Testing monsters

With GM commands (always allowed in single player when Single Player Commands is on):

  • /spawn monster_id 3 brings three in front of you. They don't come back.
  • /killall 20 kills the monsters within 20 m; they give their rewards.
  • /god makes you take no damage while you watch a fight.

See GM commands.

#Common mistakes

  • The monster doesn't appear. The spawner is off the NavMesh, the monster has no prefab, or the scene isn't the one the map uses.
  • It walks through walls to hit. Line of sight is set to Off, or the walls aren't holes in the NavMesh (NavMesh mode) or aren't on a sight blocker layer (Colliders mode).
  • It never attacks. Aggression is Passive, or Sight Range is smaller than the distance at which players pass.
  • It runs back to full health mid fight. It went past Leash Range. Raise it, or move the spawner away from where players pull it.
  • A saved quest or bestiary entry broke after renaming. You changed the Id. Rename the display name instead.
