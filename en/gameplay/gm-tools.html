Gameplay systems

GM tools

GM tools let your staff moderate and run the game: chat commands, a GM panel, four GM levels per account, and a mandatory audit of every command. This page covers the levels and how to give them, the panel, the commands in short, the audit, the limits the server enforces, and single player cheats. The full command list is in GM commands.

#GM levels

Every account has a GM level from 1 to 4, stored in accounts.Role.

Level Name Default commands
1 Player /help, /report
2 Moderator /who, /goto, /boot, /mute, /announce, /reports, /closereport, /logs
3 Game Master /summon, /tp, /ban, /heal, /god, /status, /spawn, /killall, /map, /quest, /flag, /trigger
4 Admin /item, /gold, /currency, /xp, /level, /points, /skill, /rates, /role, /audit

A level includes everything below it. New accounts start at level 1.

Central gives the map the account's level when the character enters a map. It is never saved with the character, so a level change can't be faked from a save.

#Step by step: name the first admin

Nobody can give the first admin level in game, because only an admin can change levels. Set it in the database once:

  1. Create the account and log in once, so it exists.

  2. Run this on the game's database (SQLite file or PostgreSQL), with the account's username:

    UPDATE accounts SET "Role" = 4 WHERE "Username" = 'yourname';

  3. Log in again. The new level counts from the next time the character enters a map.

See Database for where the database is.

#Step by step: give a GM level in game

As an admin:

  • Type /role name level in chat, where name is one of the account's characters and level is 1 to 4. For example /role Mira 2 makes Mira's account a moderator.
  • Or open the GM panel (F8), pick the player in Players and use the level controls at the bottom.

Rules:

  • Only an admin (level 4) changes levels. /role always needs 4, whatever Game Settings say.
  • Nobody changes the level of someone at their level or higher, changes their own level, or gives a level higher than their own.
  • Lowering a level disconnects the account, so it comes back with the new one. Raising it counts from its next entry to a map.
  • /role works online only.

#Changing which level a command needs

In KitARPG > Game Settings, section Commands:

Field What it does Default
Single Player Commands (singlePlayerCommands) In a single player world the player can use every GM command, like cheats. Online, the account's level decides On
Gm Command Levels (gmCommandLevels) The GM level each command asks for, when it isn't its default. Each entry has Command (the name without the slash, like item) and Level (1 to 4) Empty

For example, add an entry announce with level 3 so moderators can't announce. Entries name the command, not its aliases.

#Using commands

Commands are typed in the chat. Anything the chat doesn't know goes to the server, which runs it if the account's level allows it. /help lists only the commands your level may use, with their usage.

Someone without the level reads "Unknown command", as if it didn't exist.

Commands that act on a player take the character's name. Most take an optional player at the end; without it they act on you.

Common examples:

/who
/goto Mira
/mute Spammer 30
/announce Server restarts in 10 minutes
/heal
/item health_potion 20 Mira
/rates exp 2 60
/rates off
/logs Mira item.trade

The full list with usage is in GM commands.

#The GM panel

Press F8 or type /gm (or /panel). The panel opens only for level 2 and above and closes by itself if the level drops.

Every button and tab shows only if your level allows its command. The server sends the owner the list of allowed commands; the panel uses it only to decide what to draw. The panel sends the same command lines the chat does, and the server checks the account's level on each one. A modified client that opens the panel gains nothing.

Tab What it has
Players The players on this map server with level, class, GM level, and whether dead or muted. Go to, bring, kick, mute and unmute, ban (with confirmation) and unban, heal (admin), see their logs, and the level controls for admins
Items (admin) Search the Game Database and give items, gold, experience or levels to the picked player or yourself
World (admin) Rates events, spawn monsters, kill around you, travel to a map, god mode
Moderation An announcement for everyone (with confirmation), open reports, closing a report, and logs by kind

Clicking a player fills the target; with no target, buttons act on you. Answers, including those Central sends through the chat (reports, logs, bans), show in the box at the bottom, which keeps the last 60 lines.

The panel sends at most a burst of 6 requests, then 4 per second, and drops lines longer than 300 characters.

#Rules every command follows

  • Nobody acts on an equal or higher level. Nobody kicks, mutes, summons or bans someone at their level or higher.
  • Central checks again. For bans, rates events, reports, logs and level changes, Central checks the account's level against the level the map asked for, and never accepts less than 2.
  • Mutes last. A mute is a mark on the character, so it lasts through map changes and reconnecting.
  • Limits. The server caps what one command may do:
Limit Value
Items per command (MaxItems) 9,999
Gold or currency per command (MaxGold) 1,000,000,000
Experience per command (MaxExperience) 1,000,000,000
Attribute or skill points (MaxPoints) 1,000
Status seconds (MaxStatusSeconds) 3,600
/killall range (MaxKillRange) 100 meters
Mute minutes (MaxMuteMinutes) 525,600 (a year)

Numbers with decimals refuse NaN and Infinity.

#The audit

Every command of level 2 or more is written to the gm_audit table, whether it ran or was refused: when, map, account, character, level, command, the whole line, the target, whether it was allowed and the answer. Attempts above the account's level are recorded too, as refused. The table is separate from the game log and is never cleaned up.

No record, no command. The map keeps each line in memory and on disk (gm-audit-<map>.json in the map server's persistent data folder) until Central confirms it is in the database, retrying every 3 seconds and on reconnecting. If Central isn't connected, or more than 500 lines wait for confirmation, GM commands don't run.

/role is saved in the same operation as the level change.

Read the audit with /audit [player] (admin) or the GM audit button in the panel. Each command also goes to the game log as gm.command, which /logs shows.

Single player MMO
Level 4, as cheats, while Single Player Commands is on The account's level
Audit In the save's gm_audit table Central's gm_audit table
Online-only commands /ban, /report, /reports, /closereport, /logs, /role, /audit don't work All

#Security

The commands live in the KitARPG.Server assembly, so an MMO client build doesn't contain a line of them. On the network there is only PlayerGm: the player's GM level (sent only to its owner), the request and the answer. See Security.

Add commands of your own from a server-only assembly. See GM commands in code.

#Common mistakes

  • "Unknown command" for an admin. The level counts from the next entry to a map. Change map or log in again.
  • GM commands stopped working. Central is down or unreachable, so the audit can't be confirmed. Check the services in Play & Servers.
  • /role refuses. You are changing yourself, someone at your level, or giving a level above yours.
  • Players cheat in single player. Turn off Single Player Commands.
