# KitARPG documentation

The manual of **KitARPG**, the Unity kit for online action RPGs and MMOs by Blunnyn, in English,
Spanish, Portuguese and Chinese.

**Read it at https://blunnyn.github.io/kitarpg-docs/**. The same site ships inside the kit and opens
offline from **KitARPG > Documentation** in Unity.

## Issues

This repository is also where you report problems and ask for things:

- [Report a bug](https://github.com/Blunnyn/kitarpg-docs/issues/new?template=bug_report.yml)
- [Request a feature](https://github.com/Blunnyn/kitarpg-docs/issues/new?template=feature_request.yml)
- [Ask a question](https://github.com/Blunnyn/kitarpg-docs/issues/new?template=question.yml)
- [Report a mistake in the documentation](https://github.com/Blunnyn/kitarpg-docs/issues/new?template=docs.yml)

Search the [existing issues](https://github.com/Blunnyn/kitarpg-docs/issues?q=is%3Aissue) first; someone may have asked already.
Write in English, Spanish, Portuguese or Chinese.

Issues are public. Never paste passwords, keys (`KITARPG_CENTRAL_KEY`, shop keys, JWT secrets),
connection strings, your invoice number or anything else private. Replace them with `***`.
