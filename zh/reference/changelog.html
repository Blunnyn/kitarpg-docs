更新日志

KitARPG 的每个版本，最新的在前。你使用的版本显示在 KitARPG 窗口的 Overview 下。 更新会保留你的游戏：导入新版本前请阅读指南中的 Kit updates。

#[1.0.0] - 2026-11-10

KitARPG 的第一个正式版本。

#游戏

  • 单人模式（保存在电脑上）和 MMO（Login、Central 和地图服务器）使用同样的场景和代码。
  • 三种操控模式：俯视角点击移动（可选键盘操作）、自由视角，以及带客户端预测的第三人称。带有屏幕摇杆和技能按钮的触屏操控。
  • 模块化体素角色：男性、女性和熊猫身体、发型、数百件装备部件、16 种类型的武器，以及只改变外观的时装。
  • 职业、属性、等级、整数数值以及装备上按副本随机的加成。
  • 带有范围形状的技能、增益和状态、持续伤害、护盾、召唤、复活、弹射、区域、视线、潜行、免疫、精英以及带阶段的首领。
  • 物品：按格子或按重量计算的背包、背包满时以仓库作为后备、装备套装、用符文强化、镶孔、弹药和双持。
  • 怪物、刷怪点、掉落表、经验和服务器倍率、昼夜、怪物图鉴。
  • 带有击杀、收集、交谈和探索目标的任务、任务链、每日任务、分支对话、条件、动作和世界触发器。
  • NPC：商店、传送、技能训练师、仓库、市场和公会服务。
  • 社交：带频道和过滤的聊天、好友、队伍、交易、带附件的邮件，带有职位、等级、徽章、历史、联盟、会馆和收税员的公会，PvP 区域和决斗。
  • 实例化副本，附带示例 Sunken Crypt。
  • 默认不向 NPC 出售的经济系统、分解为符文以及玩家市场。
  • 作为独立服务、拥有自己付费货币的游戏内商城：带有分类、搜索、横幅、角标和商品页面的目录；购买和赠礼直接进入背包，真实支付通过 webhook 进行。
  • 邮件提醒：Mail 按钮上显示未读信件数的角标、屏幕上的 "New mail"，以及进入游戏时的摘要。
  • 四个等级的 GM 工具、经过审计的命令日志和游戏内面板；游戏日志、玩家举报和管理命令。

#编辑器

  • KitARPG 窗口（Ctrl/Cmd+Shift+K）：带待办列表的 Overview、Play & Servers、Game Database、Game Settings、Modules、Shop 和 Project Check。
  • 两步完成的 Setup Wizard，设置 URP、字体、示例和场景，然后打开 Title 和 KitARPG 窗口。
  • 用于新建玩家模型和新怪物的分步向导。
  • 每次构建前运行 Project Check，客户端、服务器和测试代码之间的构建分离。
  • 套件更新：新版本会补充用旧版本制作的游戏所缺少的内容，而不改动手动修改过的东西。
  • 项目开启了新的 Input System 时使用它，否则使用 Input Manager。场景由 Setup Wizard 和 Project Check 更新到最新。

#服务

  • 基于 .NET 10 的 Login、Central 和 Shop，生产环境使用 PostgreSQL，单台电脑上使用 SQLite。
  • 一键启动全部服务的启动器，或从编辑器无界面运行。
  • 带有 Caddy 提供 TLS 的 Docker Compose，以及 Linux 地图服务器构建。
  • 每个物品副本只有一个所有者，在事务中移动，一次性地图票据，每个账号一个会话。

#DevKit

  • 你的代码放在由 Create > KitARPG > Scripts 创建的你自己的程序集中；永远不修改套件。
  • 模板：技能效果、物品效果、条件、游戏动作、任务目标、NPC 选项、玩家系统、网络消息、GM 命令、游戏日志监听器、战斗公式、数值公式、保存的玩家数据、玩家系统重写、物品菜单项、玩家菜单项、设置选项、验证检查、KitARPG 窗口页面和套件更新。
  • 服务器和客户端的静态事件，窗口、玩家系统、怪物和 NPC 上的虚方法。
  • 按角色保存你自己的数据，向 Central 发送你自己的消息，以及 Login 和 Central 的模块。
  • 不修改套件制作的悬赏板示例，涵盖 Unity 和 Central。
  • 每个公开类型的 API 参考。
