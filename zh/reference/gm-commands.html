GM 命令

KitARPG 中的每个斜杠命令：所有玩家都能用的聊天命令，以及供版主、游戏管理员和管理员使用的 GM 命令，包括它们的语法、默认等级、别名、限制、回应和示例。GM 命令在地图服务器上运行；服务器对每一行都会检查账号的等级。

#命令如何运作

  • 在聊天中输入命令：按 Enter，输入以 / 开头的一行，再按 Enter。
  • 聊天命令（频道、队伍、好友）由客户端处理。其他一切都发送到地图服务器，它知道账号的 GM 等级。
  • /help（或 /commands）列出聊天命令以及你的等级允许的每个 GM 命令，每个都在方括号中标出等级。
  • 超出你等级的命令会回答 "Unknown command /name. Try /help."，与不存在的命令相同。超出等级尝试的管理命令仍会被记录。
  • 参数以空格分隔。[方括号] 表示可选参数。player 参数是角色名。
  • 在 [player] 可选的地方，省略它就以你自己为目标。
  • 除非另有说明，目标必须与你在同一张地图上；否则回答是 "No such player here."
  • 一行在 300 个字符处截断。

#GM 等级

每个账号都有一个 GM 等级，保存在数据库的 accounts.Role 中。

等级 名称 谁
1 Player 每个新账号
2 Moderator 监视聊天和玩家：who、goto、boot、mute、announce、reports、logs
3 Game Master 管理世界：summon、teleport、ban、heal、god、状态、怪物、地图、任务、标记、触发器
4 Admin 发放东西并管理管理人员：物品、金币、货币、经验、等级、点数、技能、倍率、职位、审计

下表中的等级是默认值。在 Game Settings > Commands > Gm Command Levels（gmCommandLevels）中可以更改任何命令的等级：添加一行，填入不带斜杠的命令名（例如 item）和它应要求的等级。无论设置如何，/role 始终要求等级 4。

#单人模式

在单人模式中，Game Settings > Commands > Single Player Commands（singlePlayerCommands，默认开启）让玩家成为管理员，因此每个命令都像作弊码一样可用。标记为仅限在线的命令会回答 "Only on an online server."

#设置第一位管理员

新账号从等级 1 开始。在数据库中指定第一位管理员：

UPDATE accounts SET "Role" = 4 WHERE "Username" = 'yourname';

使用 Play & Servers 的本地 SQLite 数据库时（先停止服务）：

sqlite3 UserSettings/KitARPG/data/kitarpg.db "UPDATE accounts SET \"Role\" = 4 WHERE \"Username\" = 'yourname';"

之后，管理员在游戏中用 /role 更改等级。如果玩家已经在某张地图上，新等级会在其下次进入地图时生效。

#审计

每条等级 2 或以上的命令都会写入 gm_audit 表，包括账号、角色、等级、命令、整行内容、目标、是否被允许以及其回应。超出玩家等级的命令会被记录为已拒绝。

当审计无法写入时，管理命令不会运行："GM commands are paused: they can't be recorded right now. Try again in a moment."。条目在 Central 确认之前保存在磁盘上等待。每条管理命令也会作为 gm.command 写入游戏日志。

管理员用 /audit 读取审计。

#命令详解

#/help
语法 /help
别名 /commands
等级 1

列出聊天命令（/s /m /g /p /gu, /w name, /r, /invite name, /leave, /kick name, /promote name, /friend name, /unfriend name, /trade name, /ginvite name, /report name reason），然后为你可以使用的每个 GM 命令列出一行：语法、描述和等级，例如 /item id [amount] [player]: Puts items in a bag. [4]。

#/report
语法 /report player reason
等级 1
仅限在线 是

向版主发送关于某名玩家的举报，保存在 reports 表中。名字之后的所有内容都是原因。版主用 /reports 列出它们。玩家菜单中也有 Report。

/report Griefer123 spamming the trade channel

#/who
语法 /who
等级 2

以 Name (level) 的形式列出本地图上的玩家，用逗号分隔。

#/goto
语法 /goto player
等级 2

跳到本地图上某名玩家的身边。如果该名字不在本地图上或是你自己，回答 "No such player here."；如果那里没有可行走的地面，回答 "Can't go there."。

#/boot
语法 /boot player
等级 2

断开本地图上某名玩家的连接。该玩家看到 "Kicked by a moderator."。你只能踢出等级低于你的账号（"You can't kick them."）。回答 "Name was kicked."。

#/mute
语法 /mute player [minutes]
等级 2
默认值 10 分钟
限制 0 到 525,600 分钟（一年）

在聊天中禁言一名玩家。该玩家会被告知 "You can't chat for N minutes."。/mute player 0 解除禁言（"You can chat again."）。禁言是角色上的一个标记，因此在切换地图和退出登录后仍然有效。你只能禁言等级低于你的账号，或你自己。

/mute LoudPlayer 30
/mute LoudPlayer 0

#/announce
语法 /announce text
别名 /broadcast
等级 2

在系统频道上向所有地图上的所有在线玩家发送 [Announcement] text。在单人模式中，发送给该玩家。

/announce Server restart in 10 minutes.

#/reports 和 /closereport
语法 /reports、/closereport id
等级 2
仅限在线 是

/reports 在你的聊天中列出未处理的举报及其 id。/closereport id 把其中一条标记为已处理。

/reports
/closereport 17

#/logs
语法 /logs player [kind]
等级 2
仅限在线 是

该玩家最近的游戏日志行，从 game_logs 表中读取。给出一个类型可以只查看该类型，例如：

类型 记录什么
item.trade 交易
item.loot 拾取的掉落
item.shop_buy、item.shop_sell NPC 商店的购买和出售
item.destroy 被销毁的物品
item.forge 锻造使用
bank.deposit、bank.withdraw 仓库存取
mail.sent、mail.taken 邮件
market.listed、market.sold、market.cancelled、market.expired 市场
shop.premium_buy、shop.premium_gift、shop.premium_grant 游戏内商城
account.login、account.login_failed、session.enter、session.leave 会话
character.level、quest.done、combat.death、combat.pvp_kill 进度和战斗
chat.line 聊天，当 Game Settings 设置记录它时
gm.command、gm.ban 管理人员操作 
/logs Aria item.trade

所有类型见游戏日志与举报。

#/summon
语法 /summon player
等级 3

把本地图上的一名玩家带到你身边。只能对等级低于你的账号使用（"You can't summon them."）。该位置不可行走时回答 "Can't bring them."。

#/tp
语法 /tp x z
等级 3

按 x 和 z 坐标跳到本地图上的一个点；高度根据地面确定。该点 4 米内没有可行走的地面时回答 "Nothing to stand on there."。

/tp 120 -45

#/ban
语法 /ban player hours
等级 3
仅限在线 是

封禁该角色的账号指定小时数。玩家不必在你的地图上。被封禁的账号会在几秒内失去访问权限，且无法登录（"This account is banned."）。/ban player 0 解除封禁。

/ban Cheater 72
/ban Cheater 0

#/heal
语法 /heal [player]
等级 3

回满生命值和法力值。死亡的目标会先被复活。

#/god
语法 /god
等级 3

为你自己开启或关闭上帝模式：你不受伤害。回答 "God mode on." 或 "God mode off."。

#/status
语法 /status id [seconds] [player]
别名 /buff
等级 3
默认值 30 秒
限制 1 到 3600 秒

按 id 为玩家施加 Game Database 中的一个状态。id 未知时回答 "No status 'id'."。

/status stunned 5 Aria
/buff regeneration 60

#/spawn
语法 /spawn monster [count]
等级 3
默认值 1
限制 1 到 50

按 Game Database id 在你前方约 4 米处召唤怪物，略微分散。它们是事件怪物：死亡后不会重生。

/spawn slime 5
/spawn void_herald

#/killall
语法 /killall [meters]
别名 /kill
等级 3
默认值 10 米
限制 1 到 100 米

杀死你周围的所有怪物，召唤物除外。它们给出奖励，记在你名下。回答 "Killed N."。

#/map
语法 /map id [x z]
别名 /travel
等级 3

按 Game Database id 前往一张地图，到达该地图的 x z 点（省略时为 0 0）。在其他地图上，当该点附近没有可行走的地面时，你会改为到达该地图的 SpawnPoint。id 未知时回答 "No map 'id'."；移动被拒绝时（例如该点在你自己的地图上且没有地面）回答 "Can't travel now."。

/map forest
/map town 10 25

#/quest
语法 `/quest give
等级 3
操作 作用 回答
give 玩家接取任务，如同从其 NPC 处接取 "Taken."，或无法接取的原因
finish 完成每个目标，使任务可以交付 "Ready to turn in." 或 "Not taken."
reset 遗忘该任务，使其可以再次接取 "Forgotten." 
/quest give slime_trouble
/quest finish slime_trouble Aria

#/flag
语法 /flag key [value] [player]
等级 3

读取剧情标记（角色上每个键对应的一个整数），给出值时设置它。回答 key = value。标记驱动任务、对话和触发器上的条件。

/flag met_the_king
/flag met_the_king 1

#/trigger
语法 /trigger id
等级 3

触发本地图上的一个世界触发器，包括其条件检查，就像你触发了它一样。回答 "Done." 或它没有触发的原因。参见世界触发器。

#/item
语法 /item id [amount] [player]
等级 4
默认值 1
限制 1 到 9999

按 Game Database id 把物品放进背包。回答 "Gave N Item to Name."，背包已满时回答 "N didn't fit."。

/item health_potion 20
/item health_potion 5 Aria

#/gold
语法 /gold amount [player]
等级 4
限制 每次 -1,000,000,000 到 1,000,000,000

增加金币，或以负数扣除（永不低于 0）。回答 "Name has N gold."。

/gold 10000
/gold -500 Aria

#/currency
语法 /currency id amount [player]
等级 4
限制 每次 -1,000,000,000 到 1,000,000,000

按 id 增加任意货币，或以负数扣除。

  • 普通货币给予角色，该角色必须在本地图上。回答 "Name has N Currency."。
  • 付费货币进入该账号在 Shop 服务中的余额。目标可以离线或在其他地图上。地图回答 "Asking the shop to give N Gems for Name."，随后 Shop 的回答会出现在聊天中。需要 Shop 服务：否则回答 "This map has no Shop service."。
/currency event_tokens 50
/currency gems 100 Aria

#/xp
语法 /xp amount [player]
别名 /exp
等级 4
限制 1 到 1,000,000,000

给予经验，正常升级。

#/level
语法 /level n [player]
等级 4

把玩家逐级提升到 n，获得每一级的点数和奖励。它永远不会降低等级。回答 "Name is level N."。

#/points
语法 /points attribute skill [player]
等级 4
限制 各 0 到 1000

给予可分配的属性点和技能点。

/points 10 5

#/skill
语法 /skill id [rank] [player]
等级 4
默认值 等级 1

按 id 以某个等级传授技能。回答 "Name knows Skill." 或无法传授的原因。

#/rates
语法 /rates、/rates kind value [minutes]、/rates off
别名 /rate、/event
等级 4
限制 值 0 到 100

不带参数时，显示当前生效的经验、掉落和金币倍率，包括服务器倍率和活动部分，以及谁开启了活动、还剩多少分钟。

带有类型和值时，在所有地图上开启或修改倍率活动：

类型 也接受
exp xp、experience
loot drop、drops
gold
all 同时设置三者
  • 值为 2 即双倍。活动会乘以 Game Settings 中的服务器倍率。
  • 新活动持续 60 分钟，除非你给出分钟数。不带分钟数修改正在进行的活动会保持其结束时间。
  • /rates off（或 reset、end）结束活动。
  • 活动开始或修改时会通知所有人。
/rates
/rates exp 2 120
/rates all 1.5
/rates off

#/role
语法 /role player level
等级 4，始终
仅限在线 是

设置角色所属账号的 GM 等级：1 玩家、2 版主、3 游戏管理员、4 管理员。玩家不必在你的地图上。该命令自身的等级不能在 Game Settings 中更改。

情况 回答
完成，提升等级 "Name's account is now Moderator (2). It takes effect the next time they enter a map."
完成，降低等级 "... They were disconnected to take it."，该玩家立即被断开连接
你自己的账号 "You can't change your own level."
与你等级相同或更高的人 "You can't change the level of someone at your level or above."
高于你的等级 "You can't give a level above your own."
无效的等级 "Usage: /role player level (1 to 4)"

更改及其审计行会一起保存。

/role Aria 2

#/audit
语法 /audit [player]
等级 4
仅限在线 是

记录在案的最近 GM 命令，可以是某名玩家的，也可以是所有人的。

#所有玩家都能用的聊天命令

这些由客户端处理，不需要 GM 等级。单独输入频道命令（不带文字）会切换默认频道；带文字时只发送一次。

命令 别名 作用
/s [text] /say 附近：附近的玩家
/m [text] /y、/map 本地图上的所有人
/g [text] /world 所有在线玩家
/p [text] /party 你的队伍
/gu [text] /guild 你的公会
/al [text] /alliance 你公会的联盟
/w name text /whisper、/tell 私聊消息
/r text /reply 回复最近的私聊（没有时为 "Nobody to reply to yet."）
/invite name 邀请玩家加入你的队伍
/leave 离开你的队伍
/kick name 把玩家移出你的队伍
/promote name /lead 让玩家成为队长
/friend name 添加好友
/unfriend name 删除好友
/trade name 请求与玩家交易
/ginvite name 邀请玩家加入你的公会
/gm /panel 打开 GM 面板，仅限管理人员

Chat 模块关闭时，无法发送普通文字（"Chat is off in this game. Commands start with /."），但命令仍然可用。

#GM 面板

F8 或 /gm 为等级 2 或以上的账号打开 GM 面板。它用按钮构建与聊天相同的命令行；服务器仍会检查每一条的等级，因此被修改过的客户端得不到任何好处。它有四个标签页，每个只在你至少能使用其中一个命令时显示：

标签页 其按钮背后的命令
Players who（刷新列表）、goto、summon、boot、mute 和解除禁言、ban 和解封（会先询问，默认 24 小时）、heal、logs、role（会先询问）
Items item、gold、xp、level
World rates（显示、应用、结束）、spawn、killall、map、god
Moderation announce、reports、closereport、logs、audit

点击列表中的玩家会填入目标；目标为空表示你自己。参见 GM 工具。

#DevKit 示例的命令

悬赏板示例在你的项目中时会添加一个命令：

命令 等级 作用
`/bounty reset done [player]` 4

#Professions 扩展的命令

命令 等级 作用
/profession id level [player] 4 设置某个专业的等级，从 1 到其最高等级。别名 /prof
/profession list 4 列出各专业的 id

#添加你自己的命令

GM 命令在仅服务器的程序集中用 GmCommands.Register 注册，会像套件自己的命令一样出现在 /help 和审计中。参见代码中的 GM 命令。
