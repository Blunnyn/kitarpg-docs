术语表

本手册和 KitARPG 编辑器使用的词汇，按英文字母顺序排列，附有简短定义以及详细说明所在的链接。

#A

Account（账号） 玩家的登录凭据：用户名、密码哈希、GM 等级和一个账号仓库。一个账号可以拥有多个角色（默认 6 个）。仅限 MMO。参见服务。

Account bank（账号仓库） 账号的所有角色共享的仓库，在仓库管理员 NPC 处打开，没有重量限制。参见背包与仓库。

Action（动作，game action） 当任务、对话台词、NPC 选项或触发器运行它时，奖励或改变玩家的事情：给予物品、经验，传授技能，设置标记，旅行。参见条件与动作。

Alliance（联盟） 拥有自己聊天频道（/al）的一组公会。参见公会。

Assembly（程序集） Unity 中由 .asmdef 文件定义的编译代码单元。套件被拆分为多个程序集（KitARPG.Shared、KitARPG.Data、KitARPG.Net、KitARPG.Server、KitARPG.Client 等），使每个构建只携带属于自己的代码。参见程序集。

Attribute（属性） 玩家在其上分配点数的角色数值，例如 Strength 或 Vitality。每一点会增加数值。参见属性与数值。

Audit（审计，GM audit） gm_audit 表中对每条管理命令的记录。无法记录时，管理命令不会运行。参见 GM 命令。

#B

Bestiary（怪物图鉴） 游戏内的怪物之书（B）：每种怪物栖息在哪里、掉落什么。参见怪物图鉴。

Build Separation（构建分离） 在每次构建前运行的检查，当构建会携带不应包含的代码（例如 MMO 客户端中的服务器代码）时中止构建。KitARPG > Check Build Separation 显示该表格。参见构建。

#C

Caddy Docker Compose 文件放在 Login 和 Central 前面以提供 HTTPS 的 Web 服务器。参见 Docker。

Central 保存会话、发放进入地图的票据、启动地图服务器，并运行聊天、好友、队伍、公会、邮件和市场的 .NET 服务。每个数据库恰好一个。参见服务。

Character（角色） 玩家在世界中的英雄：名字、模型、职业、等级、物品和进度。属于一个账号。

Class（职业） 角色是什么：每级的属性和数值、技能和初始物品。示例中有 Warrior、Hunter、Mage 和 Monk。参见职业。

Condition（条件） 锁定任务、对话台词或 NPC 选项的规则：等级、职业、任务、物品、标记、一天中的时间等。参见条件与动作。

Control mode（操控模式） 游戏的玩法：俯视角、自由视角或第三人称。在 Game Settings 中设置（controlMode）；客户端和地图服务器必须使用同一种。参见操控模式。

Cosmetic（时装） 只改变外观、没有数值的装备。

Currency（货币） 物品以外的钱：金币、活动代币，或用于商城的付费货币。参见货币。

#D

DevKit（开发套件） 套件中用于编写你自己代码的部分：模板、事件、示例和指南。参见 DevKit 概览。

Domain reload（域重新加载） Unity 在进入 Play 时重新加载所有脚本。套件在关闭它的情况下也能运作，这会让 Play 启动得更快。参见域重新加载。

#E

Element（元素） 一种伤害类型，例如 Fire 或 Water，以及针对它的抗性。

Elite / Boss（精英 / 首领） 高于 Normal 的怪物等阶。首领在屏幕顶部有血条，并可以有阶段。参见首领。

#F

Flag（标记，story mark） 按键保存在角色上的一个整数，由动作设置、由条件读取，用于记住剧情进度。/flag 读取和设置它们。

Forge（锻造） 用符文强化装备、镶嵌宝石以及把装备分解为符文的 NPC 服务。参见锻造。

#G

Game Database 列出游戏所有数据（模型、职业、技能、物品、怪物、任务、地图和共享规则）的资源，以及编辑它的 KitARPG 窗口页面。示例中是 StarterDatabase.asset。参见 Game Database。

gamedata.json 编辑器从 Game Database 为 Login 导出的文件，使其能用有效的模型、职业和初始值创建角色。

Game log（游戏日志） game_logs 表中对客服而言重要事项（交易、掉落、邮件、死亡、GM 命令）的记录，用 /logs 读取。参见游戏日志与举报。

Game Settings 编辑网络预制体上 GameInstance 的 KitARPG 窗口页面：游戏的玩法。参见 Game Settings。

GameInstance 网络预制体（KitNetwork.prefab）上的组件，保存 Game Database 和所有游戏设置，并在切换地图时保留。

GM level（GM 等级，role） 账号的管理人员等级：1 Player、2 Moderator、3 Game Master、4 Admin。保存在 accounts.Role 中。参见 GM 命令。

GM panel（GM 面板） 供管理人员使用的游戏内窗口（F8 或 /gm），用按钮运行 GM 命令。

Guild hall（公会会馆） 公会购买一次、通过 NPC 进入的实例化地图。

#H

Headless（无界面） 不带窗口或图形运行。地图服务器和 --headless 模式下的启动器以这种方式运行。

HUD 游戏内界面：血条、快捷栏、聊天、小地图和窗口，集中在一个预制体中（GameHud.prefab）。参见 HUD 与窗口。

#I

Id 一份数据的文本名称，例如 fire_bolt。创建时由文件名填入，之后永不更改，因此存档始终指向它。

IL2CPP 把 C# 编译为原生代码的 Unity 脚本后端。发布版客户端始终使用它。

Instance（实例，instanced map） 每个队伍或每个单独的玩家获得自己副本的地图，例如 Sunken Crypt。参见副本。

Item copy（物品副本，item instance） 玩家拥有的一件具体物品，带有自己的随机加成、强化和宝石。在 MMO 中每个副本恰好有一个所有者。

#K

KCP Mirror 在客户端和地图服务器之间使用的 UDP 传输。

Kit update（套件更新） 新版套件对用旧版制作的游戏所做的改动，从 Overview 应用。它只添加缺失的东西。参见更新套件。

KitARPGSettings Assets/Settings/Resources 中的资源，说明游戏的运行方式（单人模式或 MMO）以及客户端连接到哪里。

KitInput 套件的输入层，调用方式与 Unity 的 Input 相同，可配合 Input System 或 Input Manager 使用。

KitARPG window（KitARPG 窗口） 包含套件所有工具的编辑器窗口，用 Ctrl/Cmd+Shift+K 打开。参见 KitARPG 窗口。

#L

Launcher（启动器） 启动 Login、Central、地图以及可选的 Shop 的程序，可带窗口或无界面运行。Play & Servers 使用它。参见启动器。

Ledger（账本） 在事务中把物品副本（ItemLedger）或付费货币（currency_ledger）在所有者之间转移的记录。

LiteNetLib 地图服务器通过地图连接与 Central 通信所用的网络库。

Login 负责账号、登录和角色的 .NET 服务。参见服务。

Loot table（掉落表） 怪物掉落什么以及多频繁的列表。参见掉落。

#M

Map（地图） 一个 Game Database 条目加上一个场景。在 MMO 中每张地图运行在自己的地图服务器上。参见地图。

Map link（地图连接） 地图服务器与 Central 之间的 UDP 连接（端口 7700）。没有加密；不要让它暴露在互联网上。

Map server（地图服务器） 运行一张地图及其玩家和怪物的无界面 Unity 构建。Central 从地图服务器构建启动它们。

Market（市场） NPC 处的玩家市场；卖家通过邮件收款。仅限 MMO。参见市场。

Mirror 客户端和地图服务器之间的网络库。位于 Assets/Mirror 中随包发布。

Model（模型，player model） 一个玩家预制体：玩家选择的外观，带有它可以担任的职业。参见玩家模型。

Module（模块，kit module） 一个完整的系统（Chat、Guilds、Mail、Market 等），在 Modules 页面中开启和关闭。参见 Modules。

Module（模块，service module） 无需修改即可扩展 Login 或 Central 的 .NET 库。参见服务模块。

Multiplayer Play Mode Unity 的包，用于运行第二个编辑器，由 Play with two players 使用。

#N

NavMesh 在每个地图场景中烘焙的可行走表面。服务器在其上移动玩家和怪物。

Network version（网络版本） 所有通过网络传输的内容的简短哈希。版本与地图服务器不同的客户端会以 version_mismatch 被拒绝。

NPC option（NPC 选项） NPC 提供的一项内容：商店、传送、任务、对话、训练师、仓库等。参见 NPC。

#O

Overview KitARPG 窗口的第一个页面，带有待办列表和 Play 按钮。参见 Overview。

#P

Play & Servers 你在其中选择单人模式或 MMO、启动服务并游玩的 KitARPG 窗口页面。参见 Play & Servers。

Premium currency（付费货币） 由账号而非角色持有、只能在游戏内商城消费的货币。参见商城。

Project Check 查找项目中问题、并在每次构建前运行的 KitARPG 窗口页面。参见 Project Check。

#Q

Quick bar（快捷栏，hotbar） HUD 底部的一排栏位，对应按键 1 到 9 和 0，用于技能和物品。

#R

Rates（倍率） 在 Game Settings 中设置的经验、掉落和金币的服务器倍数，外加用 /rates 举办的限时活动。

Remember me 登录选项，在玩家电脑上保存一个一次性令牌，使其下次无需输入密码。

#S

Services（服务） Login、Central 和 Shop，即 MMO 背后的 .NET 程序。以 Services.zip 发布，并解压到 Services~。

Services~ 编辑器解压服务的文件夹。~ 让 Unity 不导入它。

Session（会话） 账号在游戏中的时间，从登录到离开。每个账号一个。

Set（套装） 同时穿戴时提供加成的装备部件。参见套装、强化与镶孔。

Shop（Shop 服务，service） 用于游戏内商城的可选 .NET 服务：目录、余额、购买和支付。参见 Shop 服务。

Shop（商店，NPC） NPC 处的商店，列在 Game Database 的 Shops 中。参见 NPC 商店。

Single player（单人模式） 游戏自己托管自己的世界并保存在玩家电脑上的模式。参见快速入门：单人模式。

Skill（技能） 带有目标、范围形状、消耗、冷却和效果的行动。参见技能。

SpawnPoint（出生点） 标记玩家在地图上出现位置的组件。

Starter sample（入门示例） Samples/Starter 中的可玩示例：Title、Town、Forest 和 Crypt 及其数据。

Start over 从头重新构建入门示例的 Overview 工具，会丢失对它所做的修改。

Status（状态） 角色或怪物身上的增益或减益，例如中毒或眩晕。参见状态与增益。

#T

Tax collector（收税员） 公会放置在地图某个位置的 NPC，从附近狩猎所得中抽取一部分。参见收税员。

Test client（测试客户端） 用 KITARPG_DEV 定义构建、携带套件测试工具的客户端。仅用于本地检查，永远不要给玩家。

Ticket（票据） Central 发给客户端用于进入地图服务器的一次性通行证。30 秒后过期。

Trigger（触发器，world trigger） 地图中的某个东西，在玩家进入它或某个动作触发它时运行动作，作用于一名玩家或所有人。参见世界触发器。

#U

UserSettings/KitARPG 你项目中位于 Assets 之外的文件夹，存放本机的启动器设置、密钥、本地数据库和日志。永远不会发布。
