#EquipPositions (class)

Where worn items go. The first nine match the item's own slot; rings fit in two places. Keep in step with EquipSlot in KitARPG.Data.

Member Description
public const int FirstCosmetic Cosmetic positions follow the gear ones: what is worn there sets the look of its region and gives nothing. They cover the positions in Looks, in that order.
public static int CosmeticOf(int position) The cosmetic position over a gear position, or -1 when it has none.
public static int LookOf(int position) The gear position a cosmetic one covers; any other position is its own.
public static bool Accepts(int position, ItemRules rules) Cosmetic positions take any piece for their region, even gear with stats; cosmetic-only items go nowhere else.
public static string Look(IReadOnlyList<string> gear, int position) What shows at each gear position: the cosmetic over it when there is one, else the gear.
public static string[] Gear(IEnumerable<OwnedItem> items) Item id worn at each position, empty where nothing is.

#Inventory (class)

A character's bag and worn items. Every change either completes or leaves everything as it was, and returns an error code from InventoryErrors or null. The map server runs it; Unity and the services share it so both lay out items the same way.

Member Description
public int MaxWeight Most weight the character can carry, worn gear included. 0 means only slots limit the bag.
public Func<string, string> CanEquip Extra rules before an item is worn (level, class). Gets the item id, returns an error code or null.
public Func<string, int[]> Roll Rolls the random bonuses of a new copy, by item id; null when the item has none. Copies with rolls never stack, each one is its own.
public IEnumerable<OwnedItem> Equipped Gear worn for its stats. Cosmetics are left out; see Cosmetics.
public int FirstFreeSlot() First empty bag slot, or -1.
public int Weight Weight of everything the character has, worn gear included.
public bool Overloaded Carrying more than MaxWeight, as after picking up loot past it.
public string NoRoomFor(string itemId, bool bound = false) Why one more of an item doesn't fit: BagFull, TooHeavy, or null when it fits.
public OwnedItem[] ToArray() A copy of every item, ready to be saved.
public bool CanAdd(string itemId, int amount, bool bound = false) True if the whole amount fits in the bag.
public int Add(string itemId, int amount, bool bound = false, bool overWeight = false) Puts items in the bag, topping up stacks first. Returns how many did not fit. With overWeight only the slots limit it, and the bag can end up Overloaded.
public string Restore(OwnedItem copy) Puts back a copy that left the bag (sold, traded), keeping its own values. Stackables join equal stacks; the rest take a free slot. All of it fits or nothing changes.
public void Hold(OwnedItem copy) Keeps a copy outside the grid, for when nothing else can take it. It counts and is saved, and takes the first free slot the next time the bag is loaded.
public string Wear(string itemId, bool bound = false, int amount = 1) Puts an item straight on, for starting gear. Ignores CanEquip.
public int Take(string itemId, int amount) Takes up to amount of an item from the bag, smallest stacks first. Returns how many it took.
public string Move(ItemContainer fromContainer, int from, ItemContainer toContainer, int to) Drag and drop: moves, stacks or swaps. Dropping on an equipment position wears the item and whatever was there takes its place.
public string Equip(int bagSlot) Wears a bag item in its slot (the first free one, for rings).
public string Unequip(int position) Takes worn gear off into the first free bag slot.
public string Split(int from, int to, int amount) Takes part of a stack into an empty bag slot.
public void MergeStacks() Tops up the first stacks of each item from the later ones, leaving the rest where they are. Copies saved apart, like ammo from before it stacked, come together on load.
public void Sort() Joins stacks and packs the bag from the first slot: gear first, then by item id.

#ItemRules (struct)

What the inventory needs to know about an item definition.

Member Description
public int equipSlot Slot it is worn in, or -1 when it can't be worn.
public bool offHand A one-handed weapon that can also be held in the off hand.
public bool cosmetic Only changes the look: worn in cosmetic positions, never in gear ones.
public int weight Weight of one, for bags limited by weight.

#ItemTrade (class)

Swaps offered bag items between two inventories, all of it or nothing.

Member Description
public static string Swap(Inventory first, IList<TradeItem> fromFirst, Inventory second, IList<TradeItem> fromSecond, IItemCatalog catalog) Checks every offer against the bags as they are, tries the swap on copies, then does it. Returns null, or OfferChanged, NoRoomFirst or NoRoomSecond. Copies keep their rolls but get new uids, so the same copy can't end up saved twice.

#OwnedItem (class)

One copy of an item a character owns. The definition (what it is) lives in the game data; this only keeps the id and what belongs to this copy.

Member Description
public string uid Unique across every player's items, so the same copy can never be saved twice.
public int slot Bag slot, or equipment position for worn items. -1 is a bag item that had no room.
public int[] rolls Values of the item's random bonuses, rolled when this copy was made. Null when it has none.
public int refine Upgrade level, +0 when never upgraded.
public string[] gems Gem item ids in its sockets, empty where none is. Null when it has none.
