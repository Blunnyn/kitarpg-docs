#Blunnyn.KitARPG.Modes.ThirdPerson.Server

#ThirdPersonServer (class)

Server half of the third person and free camera modes. Each player's ticks of input are queued and run no faster than real time, over the NavMesh, and the owner hears back where it really is. Aiming is free: an attack swings toward the aimed point and hits the enemy there (a wide cone up close, a narrow line for ranged weapons) or the air; a skill goes to the point, within its range and short of walls, and an enemy skill takes the first enemy on the way. Pickups and talks happen only within reach: nothing walks on its own. Space dodges a few meters, on a cooldown the server keeps.

Member Description
public int maxMessagesPerSecond Action requests per second (attacks, skills, pickups) before a connection is dropped as flooding.
public int maxQueuedTicks Ticks waiting per player. More are dropped; the client corrects itself.
public float ackSeconds Seconds between position replies to the owner.
public float reachSlack Meters past the attack or skill range still accepted, for the target taking a step.
public float meleeArc Half the angle, in degrees, in which a melee swing finds its enemy.
public float aimWidth Meters to either side of the aimed line in which a ranged attack or a single-target skill finds its enemy.
