掉落

掉落表说明怪物死亡时掉落什么：一定数量的金币和一个物品列表，每个物品有其几率。本页介绍掉落表的每个字段、掉落如何随机、任务掉落、掉落如何到达玩家，以及改变几率的设置和数值。

#掉落表是什么

掉落表是 Game Database 中的一个 LootTable 资源。怪物在其 Loot 字段（loot）中指向一个掉落表。多个怪物可以共用一个表：示例中的 Slime 和 Giant Slime 都使用 Slime Loot。

怪物死亡时，服务器为获得击杀的玩家掷一次其掉落表。掉落只属于该玩家：其他人看不到也拿不到。

#在编辑器中的位置

Game Database > Items > Loot。列表显示每个掉落表；+ New loot table 在数据库旁的 Loot 文件夹中创建一个，并把它加入数据库的 lootTables 列表。你也可以在 Project 窗口中使用 Create > KitARPG > Loot Table。

在掉落表的卡片上，每个掉落是一行，带有物品图标。几率列显示 Chance %：数据存储为 0 到 1，编辑器以百分比显示和输入。

#字段

#掉落表

字段 作用 默认值
Id、Display Name、Description、Icon 所有数据库资源共有。对掉落表来说只有 id 重要。 来自文件名
Gold（gold） 掉落金币的最小值和最大值（x 和 y，两端都包含）。 1 到 5
Drops（drops） 它可以掉落的物品，按顺序。 空
Max Drops（maxDrops） 一次击杀最多掉落的物品数。0 表示不限。 3

#每个掉落

字段 作用 默认值
Item（item） 物品。Project Check 会对没有物品的掉落发出警告。 None
Chance（chance） 掉落几率，以百分比显示（0 到 100）。 0
Min Amount（minAmount） 掉落时该物品的最少数量。 0
Max Amount（maxAmount） 掉落时该物品的最多数量。 0
Quest（quest） 只为正在进行此任务且仍需要该物品的击杀者掉落。留空：对任何人掉落。 None

数量是 Min Amount 到 Max Amount 之间（两端都包含）的随机整数，且永远不少于 1。两者都为 0 的掉落会掉落一个。

#一次击杀如何随机

怪物死亡时，服务器的 Rewards 组件奖励造成伤害最多的玩家：

  1. 经验给予击杀者，或与附近的队友分摊。参见怪物。
  2. 金币： 从 Gold 中取一个随机数量，乘以服务器的金币倍率。附近的公会收税员会先拿走它的那一份。参见收税员。
  3. 物品： 按列表顺序检查每个掉落：
    1. 带有 Quest 的掉落会被跳过，除非击杀者正在进行该任务，且携带的该物品数量少于其收集目标的要求。
    2. 按掉落的几率进行一次随机（参见几率）。命中时，加入该物品及其数量。
    3. 当已加入的物品数量达到 Max Drops 时，列表中的其余部分不再随机。
  4. 交付： 金币和物品按 Game Settings > Loot 的设置到达玩家（参见掉落如何到达玩家）。

由于列表在 Max Drops 处停止，顺序很重要。把你永远不想被截掉的掉落放在前面。示例正因如此把任务掉落放在 Slime Loot 和 Mushroom Loot 的顶部。

#几率

对于每个不是任务掉落的物品，使用的几率为：

chance x (1 + 击杀者的 Loot Chance 数值) x 服务器的掉落倍率，最高为 100%。

  • Loot Chance（lootChance）是一个数值。0.1 表示每个几率的 +10%，而不是 +10 个百分点：5% 的掉落变为 5.5%。在示例中，每点 Luck 提供 +0.5%。
  • 掉落倍率是 Game Settings > Rates > Loot Rate（lootRate，默认 1）乘以 GM 可能用 /rates loot 2 60 开启的倍率活动。
  • 任务掉落保持自己的几率。 幸运和倍率永远不会让任务变得更容易。

金币以同样方式使用 Gold Rate（goldRate，默认 1）。参见 Game Settings 和 GM 命令。

#掉落如何到达玩家

Game Settings > Loot 有两项设置（GameInstance，位于 KitNetwork 预制体上）：

字段 作用 默认值
Loot Mode（lootMode） 玩家如何获得怪物的掉落。只有获得击杀的玩家能看到。 Ground
Auto Gold（autoGold） 金币直接给玩家。关闭：金币像物品一样掉落，在地上或尸体中。 On

掉落模式：

模式 玩家看到什么
Ground 每个物品落在怪物旁边的地上，散布在约 1.2 米内，显示为其图标，名称以其稀有度颜色显示。点击一个会走过去拾取。金币（Auto Gold 关闭时）落成一堆。
Corpse 物品留在怪物的尸体中，尸体以灰色躺在死亡处。点击它打开拾取窗口，可以逐个或全部拿取物品。
Automatic 物品直接进入背包。放不下的落在地上。

适用于所有模式的细节：

  • 掉落等待 90 秒后消失。其拥有者离开地图时它也会消失。
  • 玩家在 2 米内拾取（拾取窗口打开时稍远一点）。
  • 掉落可能让背包超过重量上限。此时角色无法行走，直到丢弃、出售或存放某些东西。参见背包与仓库。
  • 钱袋放不下的金币会进入仓库。
  • 达到 Game Settings > Logs > Log Loot From 稀有度（默认 Rare）或更高的物品会写入游戏日志。参见游戏日志与举报。

掉落永远不会作为网络对象存在。服务器把它保存在内存中，只告诉其拥有者它在哪里。其他客户端，即使被修改过，也看不到也拾取不了它。

#制作掉落表

以下步骤为狼制作一个带有任务掉落的掉落表。

  1. Game Database > Items > Loot > + New loot table。把它重命名为 Wolf Loot。
  2. 把 Gold 设为 2 和 7。
  3. 把 Max Drops 设为 2。
  4. 先添加任务掉落：Item Wolf Pelt，Chance % 60，Min Amount 1，Max Amount 1，Quest "Pelts for the Tanner"。
  5. 添加普通掉落：Health Potion 25%，1 到 1；一个符文 15%，1 到 2；一件稀有披风 2%，1 到 1。
  6. 打开 World > Monsters > Wolf，在 Loot 中选择 Wolf Loot。
  7. 制作任务：一个收集 5 张 Wolf Pelt 的 CollectObjective。把狼皮标记为任务物品（Items > Quest items 会这样设置）。参见任务。
  8. 测试：/spawn wolf 5，分别在接了任务和没接任务时击杀它们。没接任务时，不会掉落狼皮。
提示

有必定掉落的首领：把那些物品设为 100%，并提高 Max Drops，让其他掉落仍有空间。示例中的 Mushroom King 总会掉落 Holy Water，其 Max Drops 为 5。

#怪物图鉴

怪物图鉴（B）列出每个怪物的掉落及玩家拥有的几率（包括其掉落数值）。关闭某个怪物的 In Bestiary 可以在那里隐藏它。

#单人模式和 MMO

两种模式下的随机方式相同。在 MMO 中，它们发生在怪物死亡所在的地图服务器上，只有拥有者的客户端会被告知掉落信息。在单人游戏中，它们发生在主机上。在 MMO 中，玩家背包中的每个物品都是数据库中有一个所有者的一行；掉落在被拾取时成为这样的一行。

#给程序员

Rewards.OnKilled、Rewards.DropChance 和 Rewards.ShareExperience 是虚方法。重写 DropChance 来改变几率规则，或重写 OnKilled 来与队伍分享掉落。Rewards.Instance.Pay(...) 按掉落模式把物品和金币交给玩家，用于你自己的掉落。参见重写套件行为。

#常见错误

  • 某个掉落从不出现。 它的几率为 0，其上方的掉落已达到 Max Drops，或者它带有击杀者没有在进行的 Quest。
  • 任务物品不再掉落。 玩家携带的数量已经达到目标的要求。这是有意设计的。
  • 掉落似乎太丰厚。 检查 Game Settings 中的掉落倍率、GM 倍率活动，或较高的 Loot Chance 数值。查看 /rates。
  • 队伍疑惑为什么只有一人获得了掉落。 掉落给予造成伤害最多的人。经验和任务击杀计数是共享的；物品不是。
