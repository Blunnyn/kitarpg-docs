世界触发器

世界触发器在玩家走进某个地点，或由对话台词、任务或被点击的对象触发时，让世界中发生某些事：怪物出现、物体出现或消失、对玩家运行动作。本页介绍 WorldTrigger 组件的每个字段、个人触发器和共享触发器、它们如何重复和重置，以及分步示例。

#世界触发器是什么

WorldTrigger 是地图场景中某个对象上的组件。和传送门一样，它只是场景数据：客户端和服务器都有它，由服务器决定它何时触发，并告诉客户端显示什么。

触发时，它可以：

  • 对触发它的玩家运行动作，
  • 在其周围生成怪物，
  • 显示物体（传送门、宝箱、发光的符文）并隐藏其他物体（墙壁、封住的门），
  • 为指定它的 Trigger 目标的任务计数。

它以两种方式之一触发：

  • Enter： 玩家走进其半径内。
  • Manual： NPC 或对象上的 Trigger 选项、Fire Trigger 动作、GM 命令 /trigger id 或代码。

并且作用于两种对象之一：

  • Personal： 只有触发它的玩家能看到它的效果。它的怪物只属于该玩家。
  • Everyone： 对地图上的所有人发生。

#在编辑器中的位置

选择地图场景中的任意对象，然后 Add Component > World Trigger。Scene 视图会在地面上绘制它的半径：个人触发器为紫色，共享触发器为橙色（手动触发器为一个小圆）。

#字段

#触发方式

字段 作用 默认值
Trigger Id（triggerId） 在其地图上唯一。任务、动作和对话台词通过它指定触发器。留空则使用对象的名称。 空
Activation（activation） Enter：走进半径内。Manual：只能通过 Trigger 选项、Fire Trigger 动作、GM 命令或代码。 Enter
Radius（radius） Enter 触发器在对象周围地面上的米数。 4
Scope（scope） Personal：只有触发它的玩家能看到它的效果。Everyone：地图上的所有人。 Personal
Conditions（conditions） 谁可以触发它：进行中的任务、携带的物品、职业。 空
Once（once） 个人触发器时每名玩家一次（之后保持已完成），对所有人时在地图运行期间一次。否则在冷却之后可再次触发。 On
Cooldown（cooldown） 非一次性时，能再次触发前的秒数。对个人触发器，冷却按玩家计算。 30
Reset After（resetAfter） 物体恢复原状前的秒数。0 则保持不变。个人触发器也会为该玩家重新就绪。 0

#发生什么

字段 作用 默认值
Actions（actions） 对触发它的玩家运行。如果有一项无法运行，什么都不会发生。 空
Monsters（monsters） 它生成的怪物（见下文）。 空
Monster Lifetime（monsterLifetime） 怪物停留的秒数；0 表示直到被杀。个人怪物在其玩家离开时也会消失。 120
Show（show） 触发时显示的物体：传送门、宝箱、发光的符文。它们开始时是隐藏的。 空
Hide（hide） 触发时隐藏的物体：墙壁、封住的门。 空

#每个怪物条目

字段 作用 默认值
Monster（monster） 怪物。 None
Count（count） 数量。 1
Offset（offset） 相对于触发器，它们出现的位置。 0, 0, 0
Spread（spread） 它们在该点周围散布的米数。 2

#它如何触发

在服务器上，每次尝试：

  1. 忽略已死亡或正在离开的玩家。
  2. 检查 Conditions。如果有一项不满足，手动触发器会告诉玩家原因（在其头顶）；Enter 触发器则保持安静。无论哪种情况，该玩家在 3 秒内都不会被再次检查，因此在范围内走动不会重复显示拒绝信息。
  3. 任务进度： 指定此触发器的 Trigger 目标会立即为该玩家计数，即使触发器已经用掉。
  4. 如果触发器已用掉（见下文），到此为止。
  5. 检查并运行 Actions。如果有一项无法运行，什么都不会发生，并告诉玩家原因（手动触发器）。
  6. 触发器被标记为已完成，显示和隐藏物体，生成怪物。

Enter 触发器每秒四次检查其半径内的玩家。

#用掉、一次和冷却

范围 Once 开启 Once 关闭
Personal 每名玩家一次，永久。它作为剧情标记 trigger.<id> 保存在角色上。 在 Cooldown 后对该玩家可再次触发。
Everyone 在地图服务器运行期间一次。重启后重新就绪。 在 Cooldown 后对任何人可再次触发。

#Reset After

Reset After 大于 0 时：

  • Everyone： 经过该秒数后，对所有人而言，显示的物体再次隐藏，隐藏的物体重新出现。
  • Personal： 经过该秒数后，清除该玩家的 trigger.<id> 标记，因此物体在其屏幕上恢复原状，触发器对其重新就绪。

#个人与所有人

#Personal

  • 物体只在该玩家的屏幕上变化。每个客户端根据自己玩家的 trigger.<id> 标记来显示，因此昨天点亮的符文在玩家回来时仍然亮着。
  • 怪物是只属于该玩家的事件怪物：只有该玩家及其召唤物能看到、与之战斗并伤害它们。其他玩家的攻击无法触及它们。玩家离开地图时它们会消失。
  • Key 为 trigger.<id> 的 Flag 条件可以判断玩家是否已经做过。
警告

在专用地图服务器上，个人触发器的物体只在客户端上变化。服务器的 NavMesh 不会改变。要真正打开一条通道（倒塌的墙），请使用对所有人生效的触发器，或确保该物体不会阻挡服务器的 NavMesh。

#Everyone

  • 服务器切换物体并通知地图上的每名玩家。之后到达的玩家在进入时获得当前状态。
  • 怪物是任何人都可以与之战斗的事件怪物。
  • 在实例化地图中，"所有人" 指同一副本中的所有人。每个副本都有自己的触发器。

#事件怪物

由触发器生成的怪物：

  • 死亡后不会重生；4 秒后消失，
  • 在 Monster Lifetime 秒后消失（0：只在被杀时），
  • 像其他怪物一样提供经验和掉落。

#制作拉杆、祭坛或宝箱

示例中 Forest 的 Strange Altar：接取任务 "Whispers in the Woods" 后，触碰它会唤醒两只蘑菇守卫并点亮一个符文，只有该玩家能看到它们。

  1. 搭建对象：一个石头底座和一个 Rune 子对象。在编辑器中让符文保持激活；场景启动时，触发器会隐藏 Show 中的物体。
  2. Add Component > Npc。Npc Id altar，Display Name "Strange Altar"，Greeting 留空，Talk Range 2.5。给它一个碰撞体。
  3. 在 Add option 下按 Trigger。Trigger forest_altar，Label "Touch the altar"。没有问候语且只有一个选项时，点击祭坛会立即触发。
  4. 在同一对象上 Add Component > World Trigger：
    • Trigger Id forest_altar，Activation Manual，Scope Personal。
    • Conditions：Quest，Quest Whispers in the Woods，Check Taken，Fail Text "The stone is cold and silent."
    • Actions：Message，Text "The altar hums. Something stirs!"
    • Monsters：Mushroom，Count 2，Offset 0, 0, 3，Spread 1.5。
    • Show：Rune。
  5. 制作任务：目标 Trigger（Trigger forest_altar，Target Name "the altar in the forest"）和 Kill Mushroom x2，文字为 "Defeat what the altar called"。参见任务。
  6. 用 Quest 选项把任务交给某个 NPC。

没有接取任务时，点击祭坛会显示 "The stone is cold and silent."。接取后，符文点亮，守卫出现。

#制作对所有人生效的区域事件

示例中 Forest 中央的 Slime Swarm：从 2 级起，走进去会让 4 只史莱姆对所有人涌出，之后休息 2 分钟。

  1. 在空地中 GameObject > Create Empty，命名为 Slime Swarm Trigger。
  2. Add Component > World Trigger：
    • Trigger Id slime_swarm，Activation Enter，Radius 3，Scope Everyone。
    • Once 关闭，Cooldown 120。
    • Conditions：Level，Min 2。
    • Actions：Message，Text "Slimes pour out of the bushes!"，橙色。
    • Monsters：Slime，Count 4，Offset 0, 0, 4，Spread 3。
    • Monster Lifetime 90。

#制作接取任务时的伏击

  1. 在路边放置一个手动触发器 bandit_ambush，Scope 为 Personal，Monsters 中放置强盗。
  2. 在任务的 On Accept 中：Fire Trigger bandit_ambush。

任务的 NPC 必须与触发器在同一张地图上：Fire Trigger 触发的是玩家当前所在地图上的触发器。

#制作交谈后打开的门

  1. 一个墙壁对象，以及一个 World Trigger old_gate，Activation Manual，Scope Everyone，Hide：该墙壁，Reset After 300。
  2. 守门人身上的一句对话台词，Actions：Fire Trigger old_gate。

所有人都会看到墙壁消失 5 分钟，然后它会回来。参见对话。

#测试触发器

  • /trigger forest_altar 像你点击了一样触发它，包括条件检查。
  • /flag trigger.forest_altar 0 为你重新就绪一个个人触发器。
  • 重启地图（停止 Play，或停止地图服务器）会为所有人重新就绪触发器。

参见 GM 命令。

#单人模式和 MMO

  • 单人模式： 游戏就是主机；个人触发器和所有人触发器的行为相同，个人触发器的物体会在唯一的世界中真正改变。
  • MMO： 地图服务器做出决定并通知客户端。个人怪物只发送给其玩家，因此其他客户端，即使被修改过，也看不到它们。Once 的所有人触发器在每次地图服务器运行期间触发一次。

#给程序员

WorldTrigger.ServerFire(id, player, tell) 从代码中触发一个触发器。WorldTrigger.ServerFired（触发器、玩家）在触发器触发时通知其他系统。Monster.ServerMakeEvent(player, seconds) 把你生成的怪物变为事件怪物。参见事件。

#常见错误

  • 点击后没有任何反应。 Trigger 选项的 id 与触发器的 Trigger Id 不匹配，或它们在不同的地图上。
  • Show 中的物体在触发前就可见。 它们在场景启动时被隐藏；检查它们是否列在 Show 中，而不是 Hide 中。
  • 它触发一次后再也不触发。 Once 开启了。关闭它并设置一个 Cooldown。
  • 其他玩家穿过了 "倒塌" 的墙。 那是一个个人触发器。对于会改变路径的东西请使用 Everyone。
  • 任务步骤没有计数。 目标的 Trigger 不匹配，或玩家不满足触发器的条件。
