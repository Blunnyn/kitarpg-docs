对话

对话是与 NPC 进行的、由玩家选择的台词组成的交谈。每句台词都可以运行动作（付款、收费、给予、收取、设置剧情标记、开始任务），NPC 会用新的台词回答，因此你无需代码就能制作分支对话。本页介绍 Dialogue 选项、分支、条件和 Back 台词如何运作，以及分步制作一段分支对话。

#对话是什么

对话是 Npc 上由 Dialogue 选项（DialogueOption）组成的树：

  1. NPC 向玩家打招呼并显示其顶层选项。
  2. 玩家选择一句 Dialogue 台词。它的动作运行。
  3. NPC 用该台词的 Reply 回答，并提供该台词自己的 Options。
  4. 这些选项可以是更多的 Dialogue 台词，也可以是任何其他选项：商店、任务、传送、触发器。

每句台词都有自己的条件，因此不同的玩家会看到不同的分支：按职业、按任务状态、按物品、按剧情标记。

请先阅读 NPC，了解 Npc 组件以及所有选项共有的字段。

#在编辑器中的位置

在场景中选择 NPC。在 Npc 检视面板中，按 Add option 下的 Dialogue 添加一句顶层台词。在 Dialogue 台词内部，其 Options 列表的每个条目旁都有一个类型菜单：选择 Dialogue Option 添加嵌套台词，或选择任何其他类型的选项。条件和动作列表也有类型菜单。

#字段

Dialogue 台词拥有所有选项都有的字段，外加它自己的字段。

字段 作用 默认值
Label（label） 玩家选择的内容，例如 "About the old ruins..."。留空则显示 "..."（开启 Back To Start 时为 "Back"）。 空
Required Level（requiredLevel） 对低于此等级的角色隐藏。 0
Conditions（conditions） 只要有一项不满足就隐藏。 空
Show When Locked（showWhenLocked） 条件不满足时以灰色显示并附上原因，而不是隐藏。 Off
Reply（reply） NPC 的回答。留空且之后没有台词时，会结束交谈。 空
Actions（actions） 选择时、在回答之前运行。如果有一项无法执行，会告诉玩家原因，且都不会运行。 空
Options（options） 回答之后提供的台词。任何类型的选项。 空
Back To Start（backToStart） 之后回到问候语，就像一句 Back 台词。 Off

当动作包含费用（Take Item、Charge Currency）时，标签会显示它："Can you patch me up? (15 Gold)"。

#一句台词如何运行

玩家选择一句 Dialogue 台词时，服务器：

  1. 检查玩家仍站在 NPC 旁边，且该台词对其提供（等级、条件、模块）。
  2. 检查每个动作，然后全部运行。如果有一个无法运行（金币不足、背包已满），其原因会以红色显示在玩家头顶，且什么都不会运行。
  3. 然后：
    • 开启 Back To Start 时，再次显示问候语和 NPC 的顶层选项；
    • 有 Reply 或 Options 时，显示回答和该台词的选项；
    • 两者都没有时，交谈结束。

服务器会记住每名玩家所在的页面，并据此检查每次选择。被修改过的客户端无法跳到它无法到达的台词。

嵌套最多 16 层。

#显示锁定的台词

条件不满足的台词会被隐藏。开启 Show When Locked 时，它以灰色显示，原因在括号中，例如 "Three spores for two potions? (Needs Mushroom Spore x3)"。它无法被选择。用它告诉玩家还有更多内容可以发现。

#复用 Back 台词

Back 台词是只开启了 Back To Start 的 Dialogue 台词。你可以在多个分支的末尾放同样的 Back 台词。

#分支中的商店和任务

Shop、Quest 或任何其他选项都可以放在某句台词的 Options 中。NPC 头顶的任务标记只计算玩家通过可选台词能够到达的任务，因此藏在锁定分支中的任务不会显示 "!"。

#制作分支对话

以下步骤制作示例中 Brann 的对话：一个在玩家发现古老遗迹后开放的分支，包含一次性的战士建议和一次以物换物。

你需要：Forest 中 id 为 old_ruins 的 DiscoveryZone（参见条件与动作）、物品 Antidote、Mushroom Spore 和 Health Potion，以及一个 Warrior 职业。

#1. 顶层台词

  1. 在 Town 场景中选择 Brann 的对象。
  2. 按 Add option 下的 Dialogue。
  3. Label："About the old ruins..."。
  4. Conditions：添加 Discovered，Zone old_ruins，Place Name "the old ruins"。
  5. Show When Locked：开启。还没去过的玩家会看到 "About the old ruins... (Find the old ruins first)"。
  6. Reply："Those walls are older than the town. My grandfather swore a king held court there, long before the mushrooms moved in."

#2. 给战士的一次性建议

在顶层台词的 Options 中，添加一个 Dialogue Option：

  1. Label："Any advice for a warrior?"
  2. Conditions：Class，Classes Warrior；以及 Flag，Key brann_advice，Compare Equal，Value 0。
  3. Reply："Keep your shield up and these close. Those spores rot the lungs."
  4. Actions：Give Item Antidote，Amount 2；Set Flag，Key brann_advice（值为 1）。
  5. Options：添加一句 Back 台词（开启 Back To Start 的 Dialogue Option）。

标记让它成为一次性的礼物：之后，这句台词会永久隐藏。其他职业永远看不到它。

#3. 以物换物

在顶层台词的 Options 中，再添加一个 Dialogue Option：

  1. Label："Three spores for two potions?"
  2. Conditions：Item，Item Mushroom Spore，Count 3。开启 Show When Locked。
  3. Reply："Mira pays better, but fine. Don't tell her."
  4. Actions：Take Item Mushroom Spore x3；Give Item Health Potion x2。标签显示 "(Mushroom Spore x3)"。
  5. Options：一句 Back 台词。

如果背包已满，Give Item 会拒绝，因此孢子也不会被拿走。

#4. 退出的方式

在顶层台词 Options 的末尾添加一句 Back 台词，让玩家可以回到 Brann 的问候语和他的商店。

#5. 测试

按 Play，分别在走进遗迹之前和之后、用战士和其他职业、带有和不带 3 个孢子与 Brann 交谈。/flag brann_advice 0 重置建议，/item mushroom_spore 3 给予孢子。参见 GM 命令。

#更多模式

模式 做法
付费服务 动作 Charge Currency 15 和 Restore，没有回答：示例中的 Mira 以 15 金币治疗。
来自对话的任务 动作 Start Quest，或在分支中放一个 Quest 选项。
改变剧情的选择 两句台词，各自用 Set Flag 把 choice 设为 1 或 2。之后的台词和问候语用 Flag 条件读取它。
向导 动作 Discover 一个区域并 Travel 到那里。
交谈后的伏击 动作 Fire Trigger，针对该玩家的触发器。参见世界触发器。
每名玩家不同的第一句话 Npc 上的 Greetings，各自带有条件。参见 NPC。

#单人模式和 MMO

两种模式下相同。在 MMO 中，每次选择都在地图服务器上检查和运行；客户端只显示服务器发送的内容。

#常见错误

  • 一句台词之后交谈就结束了。 该台词没有 Reply 也没有 Options。添加一个回答，或一句 Back 台词。
  • 某句台词从不显示。 它的条件不满足。测试时开启 Show When Locked 查看原因。
  • 对话行的动作没有生效。 该行已执行，但其中一个动作被拒绝，因此所有动作都没有执行。原因会显示在玩家头顶。
  • 一次性台词重复出现。 它没有 Set Flag 动作，或 Flag 条件读取的是另一个键。
