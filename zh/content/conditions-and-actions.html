Conditions and actions

此页面尚未翻译，以英文显示。

Conditions are rules a player has to meet, and actions are things done to a player. Quests, NPC options, greetings, dialogue lines and world triggers all use the same lists of them. This page lists every condition and every action with their fields and defaults, story marks (flags), discovered places, and discovery zones.

#What they are

  • A condition (Condition) reads something about the player: level, class, a quest's state, an item carried, a place found, a story mark, the time. A list of conditions is met when all of them are.
  • An action (GameAction) changes the player: give or take items and money, give experience, teach a skill, put a status on, move them, set a story mark, start a quest, set off a world trigger. A list of actions is checked first, then run: if one can't run, none does, so a payment that falls short never leaves half the list done.

Both are picked from a type menu in the inspector, next to each entry of the list. Nested lists (an Any condition inside a list) get their own menu.

#Where they are used

Where Conditions Actions
Quest (Quests) Conditions: who can take it On Accept, On Complete
Any NPC option (NPCs) Conditions: hidden, or greyed out with Show When Locked
NPC greeting Greetings: which text the NPC says first
Dialogue line (Dialogues) Conditions Actions, run on picking
World trigger (World triggers) Conditions: who can set it off Actions, run on whoever set it off

#How conditions read the player

Conditions read a set of facts about the player that exists on the server and on the player's own client. That is how the client can show a locked option and its reason; the server still checks it again before anything happens.

Each condition has a text shown when it isn't met. Every one has a default, like "Needs level 5". Override it with Fail Text.

Field (every condition) What it does Default
Fail Text (failText) Shown when it isn't met. Empty uses the default text. Empty

When a list fails, the first condition not met gives the reason.

#Every condition

#Level

Field What it does Default
Min (min) Lowest level. 1
Max (max) Highest level. 0 means no limit. 0

Default text: "Needs level <min>", "Only up to level <max>" or "Only for levels <min> to <max>".

#Class

Field What it does Default
Classes (classes) The classes. Empty
Except (except) Every class but these. Off

Default text: "Only for <classes>" or "Not for your class".

#Quest

Field What it does Default
Quest (quest) The quest. Empty is always met. None
Check (check) What to ask about it (below). Done
Check Met when Default text
Not Started Never taken nor turned in. "Only before starting <quest>"
Available It can be taken right now. "<quest> has to be available"
Taken Taken, done or not. "Needs <quest> in progress"
In Progress Taken and still missing objectives. "Needs <quest> in progress"
Ready Taken with every objective done. "Finish the tasks of <quest> first"
Done Turned in at least once. "Finish <quest> first"
Not Done Never turned in. "Not after <quest>"
Not Taken Neither taken nor turned in right now. "Not while on <quest>"

#Item

Carries some of an item in the bag, or carries none of it.

Field What it does Default
Item (item) The item. Empty is always met. None
Count (count) How many. 1
Without (without) Met when the player carries fewer than the count. Off

Default text: "Needs <item>", "Needs <item> x<count>" or "Not while carrying <item>". Only the bag counts, not the bank.

#Equipped

Field What it does Default
Item (item) The item. Empty is always met. None
Without (without) Met when it is not worn. Off

Default text: "Wear <item>" or "Take off <item>".

#Currency

Has at least an amount of gold or another currency.

Field What it does Default
Currency (currency) Empty is gold. Empty
Amount (amount) The least the player must have. 100

Default text: "Needs <amount> <currency>". It only reads; to charge, use a Charge Currency action.

#Discovered

Has been to a map, or to a zone by its id.

Field What it does Default
Map (map) The map. None
Zone (zone) A zone's id. Used instead of the map when set. Empty
Place Name (placeName) How the text names it. Empty
Not Yet (notYet) Met while it is still undiscovered. Off

Default text: "Find <place> first" or "Only before finding <place>".

#Map

Is on a map right now.

Field What it does Default
Map (map) The map. Empty is always met. None
Elsewhere (elsewhere) Met anywhere but this map. Off

Default text: "Only in <map>" or "Not in <map>".

#Skill

Field What it does Default
Skill (skill) The skill. Empty is always met. None
Rank (rank) The least rank. 1
Without (without) Met when the player doesn't know it at that rank. Off

Default text: "Needs <skill>", "Needs <skill> rank <rank>" or "Only without <skill>".

#Attribute

Field What it does Default
Attribute (attribute) The attribute. Its total counts: class, spent points and gear. None
Min (min) The least value. 10

Default text: "Needs <min> <attribute>".

#Status

Has a status on, or doesn't: blessed, cursed, disguised.

Field What it does Default
Status (status) The status. None
Without (without) Met when the player doesn't have it. Off

Default text: "Needs <status>" or "Not while <status>".

#Flag

Reads a story mark (see Story marks).

Field What it does Default
Key (key) The mark's name. Empty is always met. Empty
Compare (compare) Equal, Not Equal, At Least or At Most. At Least
Value (value) The number to compare with. A mark never set is 0. 1

Default text: "Not now". Give it a Fail Text when players see it.

#Time

An hour of the game day, like only at night; or real time in UTC, like a weekend event.

Field What it does Default
From Hour (fromHour) First hour, 0 to 23. 0
To Hour (toHour) Hour it stops, 1 to 24, not included. Lower than the start wraps past midnight: 20 to 6 is the night. 24
Real Time (realTime) The game's day and night, or the real time in UTC (for events on real days). Off
Days (days) Real time only. Days of the week it is met. Empty means every day. Empty

Default text: "Not at this hour". The game's hour comes from the world clock. See Day and night.

#Any

Met when at least one of its conditions is. An empty Any is met.

Field What it does Default
Conditions (conditions) The conditions. Empty

Default text: the first inner condition's text.

#All

Met when all of its conditions are. Use it to group conditions inside an Any: "(level 10 and warrior) or has the pass".

Field What it does Default
Conditions (conditions) The conditions. Empty

Default text: "Not now".

#Not

Met when its condition isn't.

Field What it does Default
Condition (condition) The condition. Empty is always met. None

Default text: "Not now".

#Every action

Some actions check before running and give a reason when they can't. Some have a cost, which a dialogue line shows next to its label, like "(15 Gold)".

Action Fields (default) What it does Refuses when
Give Item Item, Amount (1) Puts items in the bag. The bag has no room.
Take Item Item, Amount (1) Takes items from the bag: a delivery, a key used up, a trade-in. Shows as a cost. The player has fewer: "You need <item>".
Give Currency Currency (empty is gold), Amount (100) Adds gold or a currency. Never.
Charge Currency Currency (empty is gold), Amount (100) Takes gold or a currency. Shows as a cost. The player can't pay: "You need <amount> <currency>".
Experience Amount (100) Gives experience. Never.
Points Attribute Points (0), Skill Points (1) Gives points to spend. Never.
Reset Attributes Needs Spent Points (on) Gives back every attribute point the player spent, to spend again. Needs Spent Points is on and nothing was spent: "Spend some attribute points first".
Teach Skill Skill, Rank (1) Teaches a skill within its learning rules. The player can't learn it; the reason comes from the skill's rules.
Add Status Status, Duration in seconds (60), Level (1) Puts a status on the player. Never.
Remove Status Status Takes a status off. Never.
Restore Health (1), Mana (1), shares from 0 to 1 Restores a share of health and mana: a healer, an inn. The player is dead: "Not now".
Travel Map, Position Moves the player to a map and a point, for free. No map: "Leads nowhere".
Set Flag Key, Value (1), Add (off) Sets a story mark, or adds the value to it with Add. Never.
Start Quest Quest Starts a quest, without a Quest option. The quest isn't Available: "You can't take <quest> now".
Drop Quest Quest Drops a quest the player has open, as if abandoned. Never.
Discover Map, Zone (used instead of the map when set), Place Name Marks a map or zone as found, like a guide showing the way. Shows "Discovered: <place>". Never.
Message Text, Color (light yellow) Text over the player's head. Never.
Fire Trigger Trigger Sets off a world trigger on the player's map: an ambush when a quest is taken, a door that opens after a talk. The trigger's own conditions and scope apply. Never refuses the list; the trigger itself may not go off.

Actions run on the server only.

#Story marks

A story mark (a flag) is a named whole number saved on the character. It is 0 until set.

  • Set Flag sets one, or adds to it with Add (to count visits, choices or favors).
  • Flag conditions read them.
  • The GM command /flag key [value] [player] reads or sets one. See GM commands.
  • Personal world triggers keep a mark named trigger.<id> once they went off, which a Flag condition can read.

Examples from the sample: Brann's advice for warriors sets brann_advice to 1 and is only offered while it is 0, so it is given once.

Marks are only sent to their owner. In MMO they are saved by Central in the character's extra data (key flags); in single player, in the character's save.

#Discovered places

Each character keeps a list of the map and zone ids it has been to:

  • Entering a map discovers it, with "Discovered: <map>".
  • Walking into a DiscoveryZone discovers that zone.
  • A Discover action marks one from a dialogue or quest.

Discovered conditions and Explore objectives with a Zone read them. In MMO they are saved by Central (key discovered); in single player, in the character's save.

#Discovery zones

A DiscoveryZone is a named place on a map: a circle on the ground around its object.

Field What it does Default
Zone Id (zoneId) Unique in the whole game: conditions and quests name it. Empty uses the object's name. Empty
Display Name (displayName) The name shown. "Old Ruins"
Radius (radius) Meters around the object, on the ground. 8
Announce (announce) Shows "Discovered" over the player the first time. On

The scene view draws it as a light blue circle. The server checks the zones around each player every half second (Check Interval on the player's PlayerProgress).

To add one: in the map scene, GameObject > Create Empty at the place, Add Component > Discovery Zone, set Zone Id (lower case with underscores, like old_ruins), Display Name and Radius. The sample's Forest ruins are the zone old_ruins, used by the explore objective of "The Old Ruins" and by Brann's dialogue.

#Examples

Goal How
A line only for warriors who haven't heard it yet Conditions: Class Warrior, Flag heard_tip Equal 0. Actions: Set Flag heard_tip.
A paid heal Actions: Charge Currency 15, Restore. The label shows "(15 Gold)".
A trade-in Condition: Item Spore x3 with Show When Locked. Actions: Take Item Spore x3, Give Item Health Potion x2.
A quest with a fee Quest On Accept: Charge Currency 100. The quest isn't taken without the gold.
An ambush when a quest is taken Quest On Accept: Fire Trigger bandit_ambush. See World triggers.
A night only merchant Shop option condition: Time 20 to 6.
A weekend event Time with Real Time on and Days Saturday and Sunday.
Level 10 warriors, or anyone with a pass Any with an All (Level min 10, Class Warrior) and an Item Pass.
A one time attribute reset Quest On Complete: Reset Attributes. The sample's "Second Thoughts" does this.

#For programmers

Inherit Condition (implement Met and DefaultText) or GameAction (implement Run, and optionally Check and Cost). They appear in every type menu at once. Conditions read IPlayerFacts; actions get IPlayerActor, whose Self reaches the player's components. The DevKit's Bounty Board example adds a BountiesDoneCondition. See Conditions and actions in code.

#Common mistakes

  • A Flag condition shows "Not now". That is its default text. Set a Fail Text.
  • An action list does nothing. One action refused (a full bag, not enough gold), so none ran. The reason shows over the player.
  • A Time condition never matches. From Hour equals To Hour, or Days is set without Real Time.
  • Two zones with the same id. Zone ids are game wide, not per map. Keep them unique.
