条件与动作

条件是玩家必须满足的规则，动作是对玩家执行的事情。任务、NPC 选项、问候语、对话台词和世界触发器都使用相同的条件和动作列表。本页列出每个条件和每个动作及其字段和默认值、剧情标记（标记）、已发现的地点以及探索区域。

#它们是什么

  • 条件（Condition）读取玩家的某些信息：等级、职业、任务状态、携带的物品、发现的地点、剧情标记、时间。条件列表在所有条件都满足时才满足。
  • 动作（GameAction）改变玩家：给予或收取物品和金钱、给予经验、传授技能、施加状态、移动玩家、设置剧情标记、开始任务、触发世界触发器。动作列表先检查，再运行：如果有一个无法运行，就都不运行，因此付款不足时绝不会只执行了一半的列表。

两者都在检视面板中从每个列表条目旁的类型菜单中选择。嵌套列表（列表中的 Any 条件）有自己的菜单。

#在哪里使用

位置 条件 动作
任务（任务） Conditions：谁可以接取 On Accept、On Complete
任何 NPC 选项（NPC） Conditions：隐藏，或开启 Show When Locked 时以灰色显示
NPC 问候语 Greetings：NPC 第一句说哪段文字
对话台词（对话） Conditions Actions，选择时运行
世界触发器（世界触发器） Conditions：谁可以触发 Actions，对触发者运行

#条件如何读取玩家

条件读取一组关于玩家的事实，这些事实同时存在于服务器和玩家自己的客户端上。这就是客户端能够显示锁定选项及其原因的方式；在任何事情发生之前，服务器仍会再次检查。

每个条件都有一段不满足时显示的文字。每个都有默认值，例如 "Needs level 5"。用 Fail Text 覆盖它。

字段（每个条件都有） 作用 默认值
Fail Text（failText） 不满足时显示。留空则使用默认文字。 空

列表不满足时，第一个未满足的条件给出原因。

#所有条件

#Level

字段 作用 默认值
Min（min） 最低等级。 1
Max（max） 最高等级。0 表示不限。 0

默认文字："Needs level <min>"、"Only up to level <max>" 或 "Only for levels <min> to <max>"。

#Class

字段 作用 默认值
Classes（classes） 职业。 空
Except（except） 除这些之外的所有职业。 Off

默认文字："Only for <classes>" 或 "Not for your class"。

#Quest

字段 作用 默认值
Quest（quest） 任务。留空则始终满足。 None
Check（check） 询问它的什么（见下文）。 Done
Check 满足条件 默认文字
Not Started 从未接取也从未交付。 "Only before starting <quest>"
Available 现在可以接取。 "<quest> has to be available"
Taken 已接取，无论是否完成。 "Needs <quest> in progress"
In Progress 已接取且仍有未完成的目标。 "Needs <quest> in progress"
Ready 已接取且所有目标都已完成。 "Finish the tasks of <quest> first"
Done 至少交付过一次。 "Finish <quest> first"
Not Done 从未交付过。 "Not after <quest>"
Not Taken 当前既未接取也未交付。 "Not while on <quest>"

#Item

背包中携带一定数量的某物品，或完全不携带。

字段 作用 默认值
Item（item） 物品。留空则始终满足。 None
Count（count） 数量。 1
Without（without） 玩家携带的数量少于该数量时满足。 Off

默认文字："Needs <item>"、"Needs <item> x<count>" 或 "Not while carrying <item>"。只计算背包，不计算仓库。

#Equipped

字段 作用 默认值
Item（item） 物品。留空则始终满足。 None
Without（without） 没有穿戴时满足。 Off

默认文字："Wear <item>" 或 "Take off <item>"。

#Currency

至少拥有一定数量的金币或其他货币。

字段 作用 默认值
Currency（currency） 留空为金币。 空
Amount（amount） 玩家必须拥有的最少数量。 100

默认文字："Needs <amount> <currency>"。它只读取；要收费，请使用 Charge Currency 动作。

#Discovered

去过某张地图，或按 id 去过某个区域。

字段 作用 默认值
Map（map） 地图。 None
Zone（zone） 区域的 id。设置后取代地图。 空
Place Name（placeName） 文字中对它的称呼。 空
Not Yet（notYet） 仍未发现时满足。 Off

默认文字："Find <place> first" 或 "Only before finding <place>"。

#Map

当前在某张地图上。

字段 作用 默认值
Map（map） 地图。留空则始终满足。 None
Elsewhere（elsewhere） 在这张地图以外的任何地方时满足。 Off

默认文字："Only in <map>" 或 "Not in <map>"。

#Skill

字段 作用 默认值
Skill（skill） 技能。留空则始终满足。 None
Rank（rank） 最低等级。 1
Without（without） 玩家没有掌握到该等级时满足。 Off

默认文字："Needs <skill>"、"Needs <skill> rank <rank>" 或 "Only without <skill>"。

#Attribute

字段 作用 默认值
Attribute（attribute） 属性。计算其总值：职业、已分配点数和装备。 None
Min（min） 最小值。 10

默认文字："Needs <min> <attribute>"。

#Status

身上有或没有某个状态：受祝福、被诅咒、伪装中。

字段 作用 默认值
Status（status） 状态。 None
Without（without） 玩家没有它时满足。 Off

默认文字："Needs <status>" 或 "Not while <status>"。

#Flag

读取剧情标记（参见剧情标记）。

字段 作用 默认值
Key（key） 标记的名称。留空则始终满足。 空
Compare（compare） Equal、Not Equal、At Least 或 At Most。 At Least
Value（value） 比较的数字。从未设置的标记为 0。 1

默认文字："Not now"。当玩家会看到它时，给它一段 Fail Text。

#Time

游戏日中的某个时段，例如仅在夜晚；或以 UTC 计的现实时间，例如周末活动。

字段 作用 默认值
From Hour（fromHour） 起始时刻，0 到 23。 0
To Hour（toHour） 结束时刻，1 到 24，不包含。小于起始时刻时跨过午夜：20 到 6 即夜晚。 24
Real Time（realTime） 使用游戏的昼夜，或 UTC 现实时间（用于现实日期的活动）。 Off
Days（days） 仅限现实时间。满足的星期几。留空表示每天。 空

默认文字："Not at this hour"。游戏时刻来自世界时钟。参见昼夜。

#Any

其中至少一个条件满足时满足。空的 Any 是满足的。

字段 作用 默认值
Conditions（conditions） 条件。 空

默认文字：第一个内部条件的文字。

#All

其中所有条件都满足时满足。用它在 Any 中对条件分组："(10 级且为战士) 或持有通行证"。

字段 作用 默认值
Conditions（conditions） 条件。 空

默认文字："Not now"。

#Not

其条件不满足时满足。

字段 作用 默认值
Condition（condition） 条件。留空则始终满足。 None

默认文字："Not now"。

#所有动作

有些动作会在运行前检查，无法运行时给出原因。有些带有费用，对话台词会在其标签旁显示，例如 "(15 Gold)"。

动作 字段（默认值） 作用 何时拒绝
Give Item Item、Amount（1） 把物品放进背包。 背包没有空间。
Take Item Item、Amount（1） 从背包中拿走物品：送货、消耗钥匙、以物换物。显示为费用。 玩家拥有的数量不足："You need <item>"。
Give Currency Currency（留空为金币）、Amount（100） 增加金币或某种货币。 从不。
Charge Currency Currency（留空为金币）、Amount（100） 收取金币或某种货币。显示为费用。 玩家付不起："You need <amount> <currency>"。
Experience Amount（100） 给予经验。 从不。
Points Attribute Points（0）、Skill Points（1） 给予可分配的点数。 从不。
Reset Attributes Needs Spent Points（开启） 退还玩家分配过的所有属性点，供重新分配。 Needs Spent Points 开启且没有分配过点数："Spend some attribute points first"。
Teach Skill Skill、Rank（1） 在其学习规则内传授技能。 玩家无法学习；原因来自技能的规则。
Add Status Status、以秒计的 Duration（60）、Level（1） 为玩家施加状态。 从不。
Remove Status Status 移除一个状态。 从不。
Restore Health（1）、Mana（1），比例从 0 到 1 恢复一定比例的生命值和法力值：治疗师、旅店。 玩家已死亡："Not now"。
Travel Map、Position 免费把玩家移到某张地图的某个点。 没有地图："Leads nowhere"。
Set Flag Key、Value（1）、Add（关闭） 设置剧情标记，或在开启 Add 时把值加上去。 从不。
Start Quest Quest 不通过 Quest 选项直接开始一个任务。 任务不是 Available："You can't take <quest> now"。
Drop Quest Quest 放弃玩家进行中的任务，如同主动放弃。 从不。
Discover Map、Zone（设置后取代地图）、Place Name 把地图或区域标记为已发现，就像向导指路。显示 "Discovered: <place>"。 从不。
Message Text、Color（浅黄色） 在玩家头顶显示文字。 从不。
Fire Trigger Trigger 在玩家所在地图上触发一个世界触发器：接取任务时的伏击、交谈后打开的门。触发器自身的条件和范围适用。 从不拒绝列表；触发器本身可能不会触发。

动作只在服务器上运行。

#剧情标记

剧情标记（标记）是保存在角色上的一个具名整数。设置之前为 0。

  • Set Flag 设置一个标记，或在开启 Add 时累加（用于计算拜访次数、选择或人情）。
  • Flag 条件读取它们。
  • GM 命令 /flag key [value] [player] 读取或设置一个标记。参见 GM 命令。
  • 个人世界触发器在触发后会保留一个名为 trigger.<id> 的标记，Flag 条件可以读取它。

示例中的例子：Brann 给战士的建议会把 brann_advice 设为 1，并且只在它为 0 时提供，因此只会给一次。

标记只发送给其拥有者。在 MMO 中，它们由 Central 保存在角色的额外数据中（键 flags）；在单人模式中，保存在角色的存档中。

#已发现的地点

每个角色保存一份它去过的地图和区域 id 的列表：

  • 进入地图会发现它，并显示 "Discovered: <map>"。
  • 走进 DiscoveryZone 会发现该区域。
  • Discover 动作可以从对话或任务中标记一个。

Discovered 条件和带有 Zone 的 Explore 目标读取它们。在 MMO 中，它们由 Central 保存（键 discovered）；在单人模式中，保存在角色的存档中。

#探索区域

DiscoveryZone 是地图上的一个具名地点：其对象周围地面上的一个圆。

字段 作用 默认值
Zone Id（zoneId） 在整个游戏中唯一：条件和任务通过它指定区域。留空则使用对象的名称。 空
Display Name（displayName） 显示的名称。 "Old Ruins"
Radius（radius） 对象周围地面上的米数。 8
Announce（announce） 第一次时在玩家头顶显示 "Discovered"。 On

Scene 视图把它绘制为浅蓝色圆圈。服务器每半秒检查每个玩家周围的区域（玩家 PlayerProgress 上的 Check Interval）。

添加一个区域：在地图场景中，在该地点 GameObject > Create Empty，Add Component > Discovery Zone，设置 Zone Id（带下划线的小写，例如 old_ruins）、Display Name 和 Radius。示例中 Forest 的遗迹就是区域 old_ruins，被 "The Old Ruins" 的探索目标和 Brann 的对话使用。

#示例

目标 做法
一句只对还没听过的战士说的台词 条件：Class Warrior，Flag heard_tip Equal 0。动作：Set Flag heard_tip。
付费治疗 动作：Charge Currency 15，Restore。标签显示 "(15 Gold)"。
以物换物 条件：Item Spore x3，开启 Show When Locked。动作：Take Item Spore x3，Give Item Health Potion x2。
需要费用的任务 任务 On Accept：Charge Currency 100。没有金币就无法接取任务。
接取任务时的伏击 任务 On Accept：Fire Trigger bandit_ambush。参见世界触发器。
只在夜晚营业的商人 Shop 选项条件：Time 20 到 6。
周末活动 Time，开启 Real Time，Days 为 Saturday 和 Sunday。
10 级战士，或任何持有通行证的人 Any，包含一个 All（Level min 10、Class Warrior）和一个 Item Pass。
一次性的属性重置 任务 On Complete：Reset Attributes。示例中的 "Second Thoughts" 就是这样做的。

#给程序员

继承 Condition（实现 Met 和 DefaultText）或 GameAction（实现 Run，并可选择实现 Check 和 Cost）。它们会立即出现在每个类型菜单中。条件读取 IPlayerFacts；动作获得 IPlayerActor，其 Self 可以访问玩家的组件。DevKit 的 Bounty Board 示例添加了一个 BountiesDoneCondition。参见代码中的条件与动作。

#常见错误

  • Flag 条件显示 "Not now"。 这是它的默认文字。设置一段 Fail Text。
  • 动作列表没有任何效果。 有一个动作被拒绝（背包已满、金币不足），因此都没有运行。原因会显示在玩家头顶。
  • Time 条件从不匹配。 From Hour 等于 To Hour，或设置了 Days 但没有开启 Real Time。
  • 两个区域使用相同的 id。 区域 id 是全游戏范围的，而不是按地图。保持它们唯一。
