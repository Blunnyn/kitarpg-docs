属性与数值

属性是玩家分配的点数（Strength、Intelligence 等）；数值是战斗读取的数字（生命值、威力、暴击几率、移动速度）。本页列出每个数值，解释属性和伤害元素，并逐步说明套件如何把职业、属性、装备和增益相加得到角色的最终数值，结果始终为整数。

#组成部分

  • 数值是每个角色都有的一组固定数字：生命值、法力值、恢复、威力、暴击、治疗、攻击速度、移动速度、负重、经验获取和掉落几率。
  • 伤害元素是伤害的种类，例如 Fire 或 Water。每个角色对每种元素有一个固定伤害加成、一个固定抗性和一个百分比抗性。
  • 属性是资源。属性的每一点会增加一组数值、元素伤害和抗性。职业每级提供属性点，玩家再分配更多，装备也可以增加一些。
  • 修正值（StatModifiers）就是这组数值。职业等级、属性点、装备、套装、宝石、状态、增益和被动技能都使用同一种组合，因此它们中的任何一个都可以提升任何数值、元素、属性或技能等级。

#数值

数值保存在 CharacterStats 中。百分比数值以小数存储：0.05 是 5%。

数值（id） 显示为 作用
Health（maxHealth） 数字 最大生命值。
Mana（maxMana） 数字 最大法力值，由技能消耗。
Health regen（healthRegen） 每秒 每秒恢复的生命值。它在战斗中和战斗外的表现见恢复与死亡。
Mana regen（manaRegen） 每秒 每秒恢复的法力值。
Power（power） 百分比 提高所有元素的伤害。0.1 表示每次命中（包括持续伤害）+10%。
Critical（critChance） 百分比 命中成为暴击的几率。0.05 是 5%。
Crit damage（critDamage） 百分比 暴击时的额外伤害。0.5 表示暴击造成 150% 伤害。
Heals（healing） 数字 加到该角色施放的每次治疗上，在治疗加成之前计算。
Heal bonus（healingBonus） 百分比 提高该角色施放的每次治疗量。0.1 是 +10%。
Attack speed（attackSpeed） 百分比 乘到武器的每秒攻击次数上。0.1 是 +10%。
Move speed（moveSpeed） 数字 每秒米数。
Carry weight（carryWeight） 数字 背包按重量限制时角色能额外携带的重量。
XP gain（experienceGain） 百分比 击杀和任务获得更多经验。0.1 是 +10%。
Loot chance（lootChance） 百分比 提高击杀可掉落的每个物品的几率。0.1 表示每个几率的 +10%，因此 20% 的掉落变为 22%。

没有护甲、物理攻击或魔法攻击数值。防御来自各元素的抗性，进攻来自武器伤害取值、元素伤害和威力。一次命中如何计算见战斗。

#数值名称和图标

上面的名称是默认值。要重命名某个数值或为它设置图标，打开 Game Database > Settings 并在 Stat Display（statDisplay）中添加一个条目：

字段 作用 默认值
Stat（stat） 数值的 id，例如 power 或 maxHealth。 空
Label（label） 玩家看到的名称。留空则保留内置名称。 空
Icon（icon） 显示在 Character 窗口、提示框和物品效果中。 None

Character 窗口（C）把数值分组显示：生命值和法力值；威力、暴击和攻击速度；治疗；移动和负重；经验和掉落。

#伤害元素

元素位于 Game Database > Characters > Elements。用 Create > KitARPG > Damage Element 创建一个。示例中有 Neutral、Earth、Fire、Water 和 Air。

字段 作用 默认值
Id、Display Name、Description、Icon 与所有游戏数据资源相同。
Color（color） 该元素的伤害数字和提示框文字的颜色。也会为标记了 Tint 的特效着色。 白色
Max Resistance（maxResistance） 对该元素生效的最高百分比抗性，从 0 到 1。0.5 表示无论防御者叠加多少抗性，该元素的命中最多只被削减一半。 0.5
Hit Effect（hitEffect） 受到该元素命中者身上的特效，除非技能或武器有自己的特效。 None

在 Game Database > Settings 中：

字段 作用 默认值
Elements（elements） 元素，按 Character 窗口列出的顺序。 空
Default Element（defaultElement） 在没有设置元素的地方使用：元素为空的武器伤害、伤害加成或抗性都算作此元素。留空则使用列表中的第一个。 None
Default Hit Effect（defaultHitEffect） 没有其他特效时，作用在被击中者身上的特效。 None

对每种元素，角色有三个数字：

数字 作用
Damage 加到角色造成的该元素每次命中上，在威力之前计算。
Resistance 从角色受到的该元素每次命中中扣除。
Resistance % 该元素每次命中中被忽略的比例，最高为该元素的 Max Resistance。

#属性

属性位于 Game Database > Characters > Attributes。用 Create > KitARPG > Attribute 创建一个。

字段 作用 默认值
Id、Display Name、Description、Icon 与所有游戏数据资源相同。id 是已保存角色存放其已分配点数时使用的键。
Per Point（perPoint） 一点所增加的内容：一组完整的修正值（见下文）。这里会忽略其 Attributes 列表：一个属性不能提供另一个属性的点数。 空
Max Spent（maxSpent） 玩家在该属性上最多能分配的点数。来自职业和装备的点数不计入。0 表示不限。 0

示例中有五个属性：

属性（id） 每点提供
Vitality（vitality） +10 生命值，+0.2 生命恢复
Strength（strength） +5 负重，+0.5 Earth 伤害，+0.5 Neutral 伤害
Intelligence（intelligence） +4 法力值，+0.08 法力恢复，+0.5 治疗，+0.2% 经验获取，+0.5 Fire 伤害
Luck（luck） +0.2% 暴击，+0.5% 掉落几率，+0.5 Water 伤害
Agility（dexterity） +0.6% 攻击速度，+0.5 Air 伤害

Agility 保留了它还叫 Dexterity 时的 id dexterity，因此改名前保存的角色仍保留其点数。

每点的值可以是小数。它们会先在所有点数上累加再四舍五入（参见整数），因此 7 点 Vitality 提供 0.2 × 7 = 1.4，算作每秒 1 点生命值。

#分配点数

玩家在第一级之后每级获得 Points Per Level 个属性点（在职业上设置）。在 Character 窗口（C）中：

  • 属性旁的 + 添加一个待定点数。Shift + + 添加所有可容纳的点数。
  • 点击属性会打开一个带有 −、+ 和 MAX 的数量选择器。你输入的值会被限制在 0 到可容纳的数量之间（尚未在其他地方待定的可用点数，以及该属性的 Max Spent）。
  • 待定点数在总数上以绿色显示，Points left 随之减少。
  • 按钮变为 CONFIRM n。只有此时点数才会发送给服务器。UNDO 或关闭窗口会丢弃待定点数。

服务器会检查每个请求：属性存在于数据库中，玩家有足够的可用点数，且没有超过 Max Spent。

已分配的点数是永久的。只能通过重置收回：Reset Attributes 游戏动作（用于任务和对话；示例中的任务 Second Thoughts 提供一次免费重置），或带有 Reset Attributes 物品效果的消耗品（示例中的 Scroll of Second Thoughts）。参见物品效果。

#修正值组合

每个数值来源都使用这个组合（StatModifiers）：

字段 作用 默认值
Stats（stats） 加到数值上的固定数量。百分比数值写成小数（5% 写作 0.05）。 全部为 0
Stats Percent（statsPercent） 每个数值总值的百分比，以小数表示。Health 上的 0.1 是总生命值 +10%。Move Speed 上的 -0.4 是减慢 40%。 全部为 0
Damage（damage） 加到某元素每次命中上的固定伤害。元素和数量的列表；元素为空即默认元素。 空
Resistance（resistance） 从某元素每次命中中扣除的固定伤害。 空
Resistance Percent（resistancePercent） 某元素每次命中中被忽略的比例。0.1 是 10%。 空
Attributes（attributes） 加到属性上的点数。在属性的 Per Point 中被忽略。 空
Skills（skills） 在来源生效期间，加到角色已习得的特定技能上的等级。 空
All Skills（allSkills） 加到角色已习得的每个技能上的等级。 0

来自装备的技能等级只会提升角色已经会的技能；它们永远不会传授新技能。用点数学习和提升时仍使用已习得的等级。参见来自装备的技能等级。

#整数

套件中的每项加成都以整数计算，每个百分比都以整数百分点计算。一件装备提供 +7 生命值，永远不会是 +7.5；提供 +3% 暴击，永远不会是 +3.5%。

  • 四舍五入到最接近的整数或整数百分点；0.5 时远离零取整（2.5 变为 3，-2.5 变为 -3）。
  • 每个来源在相加前单独取整。一个属性算作一个来源：其 Per Point 乘以点数，然后取整。因此 3 点 Intelligence、每点 0.5 治疗，合计 1.5，算作 2。
  • 始终为百分比的字段（威力、暴击、暴击伤害、治疗加成、攻击速度、经验获取、掉落几率）即使在 Stats 中也取整为整数百分点。Luck 每点 0.2% 暴击：12 点提供 2.4%，算作 2%。
  • 职业的基础数值是唯一的例外：它们可以保留小数，例如 3.5 米每秒的步行速度。百分比计算之后最终总值又会变为整数，移动速度除外，它保留小数。
  • 提示框显示已经取整后的加成，即使资源中有小数。
提示

用百分比提供速度加成（Stats Percent > Move Speed），而不是固定数量。固定的 +1 米每秒是巨大的跳跃，而更小的值会取整为 0。

#数值如何计算

每当有东西改变角色的数值时，服务器都会重新计算：进入地图、升级、分配或重置点数、更换装备、增益生效或结束、习得被动技能。规则位于 StatFormula 中，你可以在代码中替换它（参见公式）。默认顺序是固定的：

  1. 职业属性点。 对职业 Attributes 中的每个条目，取角色当前等级的数量并取整。
  2. 已分配点数。 玩家在每个属性上分配的点数。
  3. 来源提供的属性点。 每个来源的 Attributes 列表：穿戴的装备（带有其随机值和强化等级）、装备中的宝石、达成的套装加成、角色身上的状态和增益，以及被动技能。
  4. 职业数值。 职业的 Base Stats 加上 Stats Per Level × (等级 − 1)。这些可以保留小数。
  5. 属性。 对每个属性，其 Per Point 乘以第 1 到 3 步得出的总点数，作为一个来源取整。
  6. 来源。 每个来源的固定数值、元素伤害、抗性和技能等级，各自单独取整。所有来源的百分比加成相加。
  7. 百分比。 每个数值按其百分比加成之和增长：total × (1 + percent)。然后每个数值取整为整数或整数百分点，移动速度除外。

属性先计算，是因为它们会增加数值：一枚 +5 Strength 的戒指必须同时提供这 5 点带来的伤害和负重。

生命值和法力值上限是取整后的总值（生命值至少为 1）。当前生命值和法力值保持不变，如果上限降低则削减到新的上限。

#计算示例

一名 10 级 Warrior，在 Strength 上分配了 10 点，穿着一件随机到 +6 Vitality 和 +30 生命值的胸甲，并处于 War Cry 状态下（+15% 威力）。为便于说明，没有穿戴其他东西。

  1. 10 级时的职业点数：Vitality 7 + 2 × 9 = 25，Strength 8 + 2 × 9 = 26，Intelligence 2 + 0.5 × 9 = 6.5，取整为 7，Luck 3 + 0.5 × 9 = 7.5，取整为 8，Agility 4 + 1 × 9 = 13。
  2. 已分配点数：Strength 26 + 10 = 36。
  3. 来源提供的属性点：胸甲提供 +6 Vitality，因此 Vitality 为 25 + 6 = 31。
  4. 职业数值：生命值 90 + 14 × 9 = 216，法力值 20 + 2 × 9 = 38，移动速度 3.5，暴击伤害 0.5。
  5. 属性，各自作为一个来源取整：
    • Vitality 31：生命值 +310，生命恢复 0.2 × 31 = 6.2，算作 6。
    • Strength 36：负重 +180，Earth 伤害 +18，Neutral 伤害 +18。
    • Intelligence 7：法力值 +28，法力恢复 0.56，算作 1，治疗 3.5，算作 4，经验获取 1.4%，算作 1%，Fire 伤害 3.5，算作 4。
    • Luck 8：暴击 1.6%，算作 2%，掉落几率 4%，Water 伤害 4。
    • Agility 13：攻击速度 7.8%，算作 8%，Air 伤害 6.5，算作 7。
  6. 来源：胸甲增加 +30 生命值；War Cry 增加 +15% 威力（这是百分比数值上的固定数量，因此为威力加 0.15）。
  7. 百分比：没有来源带有 Stats Percent 加成，因此没有增长。生命值最终为 216 + 310 + 30 = 556，法力值为 38 + 28 = 66，威力 15%，暴击 2%，暴击伤害 50%。

如果同一角色还拥有 +8% 生命值（Stats Percent）的套装加成，第 7 步会使生命值变为 556 × 1.08 = 600.48，取整为 600。

Character 窗口显示结果：属性及其总值、分组的数值，以及每种元素的伤害、抗性和抗性百分比表格。

#单人模式和 MMO

规则在两种模式下相同，且只在服务器上运行：MMO 中是地图服务器，单人模式中是游戏本身。客户端永远不会自己计算数值。每次重新计算后，服务器把最终数值和每个属性的总值发送给角色的拥有者；其他玩家只能看到血条。

角色只保存玩家分配的点数，作为属性 id 和数量的列表：MMO 中存放在数据库的 Attributes 列中（PostgreSQL 中为 jsonb），单人模式中存放在角色的 JSON 内。职业点数和装备加成永远不会被保存；它们在加载时重新计算。因此重新平衡某个职业或属性会立即改变所有现有角色。

在 MMO 中，Login 不使用 Unity 创建新角色，因此它从 gamedata.json 读取每个职业 1 级时的生命值和法力值。修改基础数值后请重新导出（Play & Servers 在启动服务时会这样做；构建时使用 KitARPG > Export Game Data for Services）。

#提示

  • 给每个属性一个明确的作用和一个元素。玩家一下子就能理解 "Intelligence 是火和法力"。
  • 除非你想要硬性上限，否则让 Max Spent 保持为 0；上限会让一些流派无法实现。
  • 元素抗性很强，因为它们会与百分比抗性叠加。对于玩家会经常面对的元素，把 Max Resistance 保持在 0.5 或更低。

#常见错误

  • 0.4 的加成没有任何效果。 它被取整为 0。请使用整数或更大的百分比。
  • 攻击速度设为 10 导致攻击快得离谱。 在 Stats 中百分比数值是小数：10% 是 0.1。
  • 某个属性被重命名后，角色丢失了点数。 id 被修改了。改回旧的 id；Display Name 可以随意修改。
  • 装备提升了角色不会的技能，结果没有任何效果。 来自装备的技能等级只作用于已习得的技能。
