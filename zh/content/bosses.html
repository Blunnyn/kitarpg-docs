首领

首领是等阶为 Boss 的怪物：它有随生命值下降而触发的阶段、一个狂暴计时器、可以躲在其后的小怪，以及屏幕顶部的血条。本页介绍首领的每个字段、战斗在服务器上如何进行，以及一个分步制作的三阶段首领。

#首领是什么

任何怪物的 Rank（rank）为 Boss 时就成为首领。它的其他一切都与普通怪物相同：数值、攻击、技能、掉落、重生。请先阅读怪物。

Boss 等阶增加了：

  • 阶段（phases）：在其生命值首次降到某个百分比以下时，每场战斗执行一次的事情：喊话、对自己施加状态、施放技能、召唤小怪、在小怪存活期间变得无法被伤害。
  • 狂暴（enrageSeconds、enrageStatus、enrageShout）：战斗一定秒数后它会狂暴。
  • 返回原位时的完全重置：生命值、阶段、小怪、狂暴以及它施加在自己身上的每个状态。
  • HUD 上的首领血条，以及名牌、怪物图鉴和世界地图上的首领颜色。

召唤出的怪物即使等阶为 Boss 也永远不算作首领。

Elite 等阶是较轻的一级：其名牌上的名字为金色并带有 "Elite" 标签，怪物图鉴和地图会为它着色，但它没有阶段、没有狂暴，也没有血条。通过它自己的数值让精英更强。

#在编辑器中的位置

Game Database > World > Monsters，选择该怪物。Rank 卡片包含 Rank、Phases、Enrage Seconds、Enrage Status 和 Enrage Shout。小怪存活期间使用的状态是数据库设置：Game Database > Database > Settings 的 Invulnerability 部分，Boss Guard Status（bossGuardStatus）字段。

#字段

#怪物上

字段 作用 默认值
Rank（rank） Boss 开启本页的所有内容。 Normal
Phases（phases） 按生命值排序；每个阶段每场战斗发生一次。 空
Enrage Seconds（enrageSeconds） 战斗开始多少秒后狂暴；0 表示永不。计时从它开始与某人战斗时开始。 0
Enrage Status（enrageStatus） 狂暴时施加在自己身上的状态，持续到战斗结束。 None
Enrage Shout（enrageShout） 狂暴时在头顶说的话。留空则不说话。 "Enough!"

#每个阶段上

字段 作用 默认值
Below Health（belowHealth） 生命值百分比，1 到 99。生命值第一次降到它以下时阶段开始。 50
Shout（shout） 在头顶说的话，例如 "Rise, my children!"。也显示在首领血条上。 空
Status（status） 施加在自己身上，例如狂暴或护盾。 None
Status Seconds（statusSeconds） 状态持续多久。0 持续到战斗结束。 0
Skill（skill） 无论是否就绪，立即对其当前目标施放。 None
Summon（summon） 它召唤为小怪的怪物。 None
Summon Count（summonCount） 小怪数量。需要 Summon。 0
Invulnerable While Summons Live（invulnerableWhileSummonsLive） 在它召唤的怪物存活期间不受伤害。使用数据库的 Boss Guard Status。 Off

#数据库中

字段 作用 默认值
Boss Guard Status（bossGuardStatus） 当带有 Invulnerable While Summons Live 的阶段的小怪存活时施加在首领身上。它应该是一个无敌状态。示例中是 Guarded（"Untouchable while its servants live"）。留空：阶段会召唤小怪，但首领仍可被攻击。 示例：Guarded

#战斗如何进行

以下一切都在服务器上发生。

  1. 首领选择一个目标时战斗开始。狂暴计时开始，其血条出现在附近玩家的 HUD 上。
  2. 随着生命值下降检查阶段。每个越过 Below Health 的阶段按列表顺序执行一次。一次跨越多个阈值的大伤害会依次执行每一个。一个阶段按以下顺序执行其各部分：喊话、状态、小怪（以及守护状态）、技能。
  3. 小怪出现在首领周围，已瞄准其目标，并站在它这一边战斗。它们是召唤物：不提供经验或掉落，首领死亡或重置时会离开。
  4. 该阶段的最后一只小怪死亡的那一刻，守护会自动解除。
  5. 战斗持续 Enrage Seconds 时狂暴触发一次：先喊话，然后在剩余战斗中施加状态。
  6. 首领死亡： 阶段、狂暴和小怪为下一场战斗重置，它在 Respawn Seconds 后重生。
  7. 如果首领离开原位超过 Leash Range，首领重置：它忘记目标，回满生命值，重新开始其阶段，遣散小怪，并清除自身所有状态。

阶段、狂暴和守护不能被玩家移除：在那里使用的状态请关闭 Removable，就像示例中的 Enraged 和 Guarded 一样。

#首领血条

BossBar 是 HUD 的一部分。它显示距玩家 35 米内（Range）最近的正在战斗的首领，包括其名称、生命值、它施加在自己身上的增益，以及它最后的喊话（显示 4 秒，Shout Seconds）。附近没有首领在战斗时它会隐藏。参见 HUD 与窗口。

#制作带阶段的首领

以下步骤制作一个类似示例中 Mushroom King 的首领。

  1. 制作状态。 在 Combat > Statuses 中制作一个提高威力和攻击速度的 Enraged 状态，关闭 Removable。示例中的提供 +50% 威力、+30% 攻击速度和 +20% 移动速度。检查数据库的 Boss Guard Status 已设为一个无敌状态。

  2. 制作小怪。 任何怪物都可以。示例使用普通的 Mushroom。

  3. 制作首领。 Monsters > + New monster。在 Combat 中把 Rank 设为 Boss，设置较高的 Health（King 有 1,600）及其伤害。在 Rewards 中设置较长的 Respawn seconds（King 为 300）和一个掉落丰厚的掉落表。

  4. 在其卡片的 Skills 下添加技能。King 有 Royal Stomp 和 Spore Burst。

  5. 在 Phases 下添加阶段：

    Below Health Shout 作用
    75 "Rise, my court!" Summon Mushroom，Summon Count 3，开启 Invulnerable While Summons Live
    50 "Breathe it in!" Skill Poison Cloud
    25 "You will rot here!" Status Enraged

  6. 设置狂暴： Enrage Seconds 150，Enrage Status Enraged，Enrage Shout "Enough of this!"。

  7. 在 Status Defense 中保护它免受控制：King 免疫眩晕、定身和沉默，减速持续时间减少 50%，中毒减少 30%。

  8. 让它待在原位： Wander Radius 设小（1.5），Leash Range 与其竞技场相符（16）。

  9. 放置它： 在地图场景中，在首领站立的位置添加一个 Count 为 1、Radius 为 0 的 Monster Spawner。然后在地图卡片上按 Read from scene，让怪物图鉴列出首领及其小怪。参见地图。

  10. 测试它： 走过去，或使用 /spawn mushroom_king 和 /god。观察 75%、50% 和 25% 时的喊话。

提示

一个针对该首领的击杀任务（KillObjective，Monster 为该首领，Count 为 1）以及其掉落表中的任务掉落，能构成一个不错的故事结局。参见任务。

#单人模式和 MMO

首领逻辑在两种模式下相同，并在服务器上运行（单人模式中为主机）。在 MMO 中，血条、名牌和喊话会到达每个能看到首领的客户端。在实例化地图中，每个副本都有自己的首领和自己的阶段，因此每个队伍都从头开始与它战斗。示例中位于 Sunken Crypt 尽头的 Void Herald 就是实例化地图中的首领。

#给程序员

Monster.RunPhase(BossPhase) 是虚方法：重写它以添加你自己的阶段行为。Monster.ServerPhaseStarted（怪物、阶段索引）在阶段开始时通知其他系统。Monster.CallAdds(MonsterData, int) 从你自己的代码召唤小怪。参见重写套件行为和事件。

#常见错误

  • 首领在小怪存活期间从未无敌。 数据库没有 Boss Guard Status，或该状态不是无敌状态。
  • 没有首领血条。 Rank 不是 Boss，首领没有与任何人战斗，或玩家距离超过 35 米。
  • 阶段不再触发。 它们每场战斗触发一次。首领死亡或重置时会恢复。
  • 首领在战斗中重置。 玩家把它拉出了 Leash Range。提高该值，或调整竞技场形状让战斗保持在其中。
  • 两个阶段同时触发。 它们的 Below Health 值太接近，一次攻击跨越了两者。把它们拉开。
