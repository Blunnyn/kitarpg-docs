技能

技能由一个目标、一个范围和一组效果组成：伤害、治疗、增益、状态、推开、复活和召唤，以及施法者如何移动、是否弹射、是否停留在地面或需要引导。本页介绍技能的每个字段、每种技能效果、玩家如何学习和施放技能，以及如何一步步制作一个带范围和状态的技能。

#技能是什么

每个技能回答四个问题：

  • 瞄准谁或哪里：施法者、敌人、盟友，或地面上的一个点。
  • 覆盖什么范围：单个目标、圆形、锥形或直线。
  • 做什么：一组效果。有害效果作用于它到达的敌人；友方效果作用于施法者和它到达的盟友。因此一个技能可以同时伤害你周围的敌人并为你的队伍提供增益。
  • 如何表现：施法时间、动画、投射物、移动、弹射、地面区域、引导。

每个可以随等级成长的数字都是一个等级值：1 级时为 Base Value，之后每级加上 Per Level。Fire Bolt 最小值 12、每级 5，3 级时伤害为 12 + 5 × 2 = 22。

范围是抽象的形状。即时模式以米为单位读取尺寸。

玩家使用技能；怪物也会使用，来自其怪物数据中的 Skills（始终为 1 级，没有施法时间，在就绪且够得着时使用，与其普通攻击共享回合）。参见怪物。

#技能在哪里

Game Database > Combat > Skills 列出每个技能。在那里创建（+ New skill）或用 Create > KitARPG > Skill 创建。当某个职业列出它、某个物品或 NPC 传授或施放它、或某个怪物使用它时，技能就进入了游戏。

在游戏中，Skills 窗口（K）先列出职业的技能，然后是在其他地方学到的技能，每个都带有图标（拖到快捷栏上）、等级、缺少的需求，以及用于提升的 +。技能按钮上的角标显示未分配的点数。技能卡片（提示框）显示当前等级下的消耗、冷却、施法时间、射程、范围、所需武器和每个效果。

#字段

除 Id、Display Name、Description 和 Icon 外：

#Basics

字段 作用 默认值
Max Level（maxLevel） 最高等级。职业可以为自己设置更低的上限。 5
Passive（passive） 永不施放。在技能已习得期间，其 Stat Buff 效果作为永久的数值来源生效。 Off
Target（target） Self、Enemy、Ally 或 Ground。参见目标与范围。 Enemy
Mana Cost（manaCost） 每次施放的法力，按等级。 10，每级 +2
Cooldown（cooldown） 能再次施放前的秒数，按等级。 5
Cast Time（castTime） 效果生效前的秒数，按等级。0 为瞬发。 0
Range（range） 从施法者到目标或点的米数。对 Self 无效。 8
Targets Dead（targetsDead） 只能作用于倒下的盟友，用于复活。 Off

#Area

字段 作用 默认值
Shape（shape） Single、Circle、Cone 或 Line。 Single
Size（size） 圆形半径、锥形长度或直线长度，单位为米，按等级。 3
Width（width） 锥形的角度（度），或直线的宽度（米）。 60

#Requirements

字段 作用 默认值
Weapons（weapons） 只有主手持有这些武器类型之一时才能施放。留空表示任何武器或无武器。 空
Levels Per Rank（levelsPerRank） 从技能解锁的等级算起，每个技能等级之间相隔的角色等级数。 2
Requires（requires） 学习或提升本技能之前，必须已掌握到某个等级的技能（来源不限）：Skill 和 Rank。 空

#Learning outside a class

字段 作用 默认值
Teachable（teachable） 卷轴、书和训练师可以把它传授给职业中没有它的角色。 On
Learnable By（learnableBy） 卷轴或训练师可以传授给哪些职业。留空表示任何职业。 空
Learn Level（learnLevel） 从卷轴或训练师学习它所需的角色等级。之后的等级遵循 Levels Per Rank。 1

#Effects

字段 作用 默认值
Effects（effects） 技能按顺序做的事。用 + 添加条目，然后选择 Pick a type。参见技能效果。 空

#Movement

字段 作用 默认值
Movement（movement） 效果生效前施法者如何到达目标或点：None、Teleport（立即出现在那里）、Dash（沿地面冲刺；墙壁会阻挡）或 Leap（以弧线跳跃并落在那里）。效果在施法者到达的位置周围生效。 None
Move Speed（moveSpeed） 冲刺或跳跃的每秒米数。 16
Leap Height（leapHeight） 跳跃最高点的米数。 1.6
Stop Short（stopShort） 施法者在距目标多少米处停下，以便落在它旁边。 1

被定身的施法者不能冲刺或跳跃，但可以传送。传送和跳跃会落在最近的可行走点上。

#Bounces

字段 作用 默认值
Bounces（bounces） 从第一个目标跳到下一个最近目标的次数，就像连锁闪电或跳弹。治疗技能在盟友之间跳跃。每次跳跃只会跳到视线内的目标。 0
Bounce Range（bounceRange） 弹射能到达的米数。 5
Bounce Keep（bounceKeep） 每次跳跃保留的伤害和治疗比例，从 0 到 1。 0.8

#Zone

字段 作用 默认值
Zone Time（zoneTime） 范围停留在地面上的秒数，每跳再次生效，按等级。0 只生效一次。 0
Zone Tick（zoneTick） 区域每两次生效之间的秒数。 1
Zone Effect（zoneEffect） 区域持续期间在地面上显示，尺寸与区域匹配。留空则改为显示范围特效。 在地面上

#Channel

字段 作用 默认值
Channel Time（channelTime） 施法后效果持续生效的秒数，期间施法片段循环播放，按等级。0 只生效一次。 0
Channel Ticks（channelTicks） 引导期间效果生效的次数。 3

#Look

字段 作用 默认值
Use Weapon Attack（useWeaponAttack） 施法者播放其武器的攻击动画和武器的投射物，就像更强的普通攻击，如果武器使用弹药也会消耗弹药。否则播放每个角色的技能动画。 Off
Cast Effect（castEffect） 施法或引导期间在施法者身上。 在地面上，跟随
Launch Effect（launchEffect） 在其动画的每个命中帧显示在施法者身上。 在右手上
Projectile（projectile） 飞向目标或点；效果在其到达时生效。Prefab、From（发射的挂点）和 Speed（每秒米数）。 无，从右手，20
Area Effect（areaEffect） 范围落下的地方，尺寸与范围匹配。没有时，会绘制一个元素颜色的平面范围轮廓。 在地面上
Hit Effect（hitEffect） 在每个目标身上。留空则使用元素的特效。 None

每个特效生成都有 Prefab、Socket（Body、Floor、Head、RightHand、LeftHand）、Follow（随角色移动）、Lifetime（0 使用其粒子的长度）和 Tint（按元素着色，默认开启）。

播放哪个动画在每个角色的 Character Animations 中设置：一个默认的施法和使用，以及每个技能各一个。参见动画。

#目标与范围

#目标

目标 瞄准 Single 形状时效果作用于谁
Self 无：以施法者为中心。 友方效果作用于施法者。
Enemy 一个敌人。 有害效果作用于目标；友方效果作用于施法者。
Ally 一个盟友或你自己。 友方效果作用于盟友；如果目标不是存活的盟友，则作用于施法者。
Ground 地面上的一个点。 该点 1 米内的所有人。

Self 和 Ally 技能是友方的；Enemy 和 Ground 技能是敌对的。玩家通过点击敌人或地面来瞄准敌对技能。有目标时，服务器会先让施法者走到射程内（俯视角模式）。

#形状

形状 位置 作用于谁
Single 目标。 见上表。
Circle Self 技能以施法者为中心，其他技能以瞄准点为中心。 距中心 Size 米内的所有人。
Cone 从施法者朝瞄准方向。 Size 米内、且在瞄准方向 Width 度以内的所有人。
Line 从施法者朝瞄准方向。 沿前 Size 米、距直线 Width ÷ 2 米以内的所有人。

距离按水平面测量，忽略高度。范围中心看不到的目标（在墙后）会被排除；视线规则见战斗。

在范围中，有害效果作用于每个到达的敌人，友方效果作用于每个到达的盟友，施法者在范围内时也包括在内。

带有投射物的 Line 会穿过路径上的一切：投射物到达每个目标时击中它（卡片上显示 "Goes through everything in its path"）。

#瞄准

玩家按下技能键时，地面上会显示范围预览（或指针下的敌人身上显示一个圆环）；点击或再按一次同一个键施放。Settings > Controls 中有一个选项可以改为立即施放。每种操控模式如何瞄准见操控模式。

#技能效果

效果从菜单中选择：在 Effects 上按 +，然后选择 Pick a type。你自己的效果类也会出现在那里（参见代码中的技能效果）。

每个效果要么是有害的（作用于敌人），要么是友方的（作用于施法者和盟友）。施加增益、状态、推开、复活或召唤的效果每次施放只在第一次命中时生效一次；伤害和治疗在动画的每次命中时生效，并在各次命中之间分摊。

#Damage

有害。造成一种元素的伤害，可选择加上施法者的武器伤害。

字段 作用 默认值
Element（element） 元素。留空则使用默认元素。 None
Min（min） 最低取值，按等级。 8，每级 +4
Max（max） 最高取值，按等级。 12，每级 +5
Weapon Scale（weaponScale） 加上武器的伤害取值，每个乘以该值，按等级。0 忽略武器。0.8 以武器自身的元素加上每个武器取值的 80%。 0

取值经过与普通攻击相同的公式：元素伤害、威力、抗性、暴击。卡片显示 "12 to 18 Fire damage" 和 "+80% of weapon damage"。

#Heal

友方。恢复生命值。

字段 作用 默认值
Amount（amount） 恢复的生命值，按等级，在施法者的治疗和治疗加成之前计算。 20，每级 +10

最终治疗量 = (amount + 施法者的 Heals) × (1 + 施法者的 Heal bonus)，四舍五入。

#Stat Buff

友方，作为减益时为有害。在一段时间内改变数值。用于不需要状态资源的快速数值增益。

字段 作用 默认值
Modifiers（modifiers） 一个完整的修正值组合。每个等级都相同。 空
Duration（duration） 秒数，按等级。 10
Debuff（debuff） 改为降低数值（每个数字取负），作用于敌人。 Off

增益的 id 就是技能的 id：再次施放会替换它。在被动技能上，修正值在技能已习得期间一直生效，Duration 被忽略。

#Apply Status

有害或友方，取决于状态。为每个目标施加一个状态。

字段 作用 默认值
Status（status） 状态。其 Harmful 设置决定它作用于谁。 None
Duration（duration） 秒数，按等级。 5
Chance（chance） 对每个目标生效的几率，从 0 到 1，按等级。 1
Stacks（stacks） 每次生效增加的层数。 1

状态以技能的等级生效，因此状态自身的等级值（每跳伤害、护盾）随技能成长。目标的免疫和抗性适用。

#Remove Status

移除状态：从盟友身上移除减益（净化），或从敌人身上移除增益（驱散）。

字段 作用 默认值
Dispel（dispel） 关闭：从盟友身上净化减益（友方）。开启：从敌人身上驱散增益（有害）。 Off
Only（only） 只移除这些状态。留空则移除任何可移除的状态。 空
With Flags（withFlags） 只移除以这种方式限制持有者的状态，例如 Stun 和 Root。None 表示任何。 None
Count（count） 每个目标移除多少个，从最新的开始。0 全部移除。 0

Removable 关闭的状态永远不会被移除。

#Knockback

有害。把每个目标推开，或以负距离把它拉近。墙壁会阻挡。

字段 作用 默认值
Distance（distance） 米数，按等级。负值拉向施法者，停在它面前。 3
Speed（speed） 每秒米数。 14
From Point（fromPoint） 从技能落点而不是施法者处推开，用于地面上的爆炸。 Off

推开会打断目标正在做的事。不可阻挡的目标无法被移动。

#Revive

友方。让倒下的盟友复活。用在开启了 Targets Dead 的技能上。

字段 作用 默认值
Health（health） 复活时的生命值比例，从 0 到 1，按等级。 0.3，每级 +0.1
Mana（mana） 复活时的法力值比例，从 0 到 1，按等级。 0.2

被复活的玩家不会因那次死亡损失经验。

#Summon

无论技能到达谁，每次施放都只在施法者身上生效一次。在技能落点周围召唤为施法者战斗的怪物。

字段 作用 默认值
Monster（monster） 召唤的怪物。 None
Count（count） 每次施放召唤多少个。 1
Max（max） 施法者同时能拥有多少个由该技能召唤的单位。新召唤出现时最老的一个会离开。 2
Duration（duration） 它们持续的秒数，按等级。0 持续到它们死亡或施法者离开。 30，每级 +5
Level（level） 它们的等级，按等级。0 使用怪物自身的等级。 0

召唤物跟随其主人并攻击附近的敌人。它们的击杀算作主人的；它们不提供掉落。时间结束、死亡或主人死亡或离开时它们会消失。

#一次施放如何进行

  1. 玩家选择一个技能和一个目标或点。客户端发送请求；之后一切由服务器决定。
  2. 服务器检查：技能已习得（以其有效等级），施法者没有正在施法，冷却已结束，法力足够，手持正确的武器类型，有有效的目标，在射程内（有 0.6 米余量）且在视线内，并且没有阻止施法的状态（Stun、Silence）。
  3. 施法。 有 Cast Time 时，施法片段循环播放并显示 Cast Effect。移动、攻击或拾取东西会打断施法且不消耗任何东西。眩晕或沉默也会打断它。
  4. 扣除法力并开始冷却。
  5. 移动（如果有）：传送、冲刺或跳跃。
  6. 使用。 播放使用动画。在每个命中帧，显示 Launch Effect 并发射 Projectile。
  7. 效果在每个命中帧或投射物到达时生效：伤害和治疗在各次命中之间分摊，增益和状态在第一次命中时生效。有 Channel Time 时，它们在引导期间生效 Channel Ticks 次。有 Zone Time 时，范围停留并每 Zone Tick 生效一次。有 Bounces 时，它会继续跳跃。
  8. 显示 Area Effect 和 Hit Effect。

攻击或施法会结束带有 Ends On Action 的状态，例如 Invisible 和到达保护。

#学习技能

#用技能点

  • 角色在第一级之后每级获得 Skill Points Per Level（来自其职业），外加来自 Scroll of Insight 等物品和任务奖励的点数。
  • 解锁等级为 1 的职业技能免费以 1 级开始。
  • 在 Skills 窗口中按 + 花费一点，把技能提升一级。
  • 职业技能的等级 n 需要角色等级 unlockLevel + (n − 1) × levelsPerRank。
  • 等级不能超过职业为该技能设置的 Max Level，也不能超过技能自身的上限。
  • Requires 中的每个技能都必须掌握到其等级。
  • 在职业以外习得的技能，一旦掌握，提升它同样花费点数。

可用点数永远不会被保存：它们按已获得减已花费计算。

#学习职业以外的技能

角色可以从三个来源学习其职业没有的技能：

  • 书和卷轴：带有 Learn Skill 物品效果的消耗品。参见物品。
  • 训练师：NPC 上的 Skill Trainer 选项，带有 Skill、Rank（低于它的已会技能会被提升到该等级）和以金币计的 Price（默认 100）。对已经掌握该技能到该等级、或其职业无法学习它的玩家，该选项会隐藏。参见 NPC。
  • 任务奖励：任务可以传授技能。参见任务。

三者都遵循技能的规则：Teachable 开启，职业在 Learnable By 中（或列表为空），角色等级至少为 Learn Level（第一级之后每级再加上 Levels Per Rank），并掌握 Requires 中的每个技能。职业技能总是可以传授给其职业。

通过这种方式传授的等级不花费点数。之后，该技能像其他技能一样用点数提升。新的主动技能会放到第一个空闲的快捷栏按键上。

示例传授三个没有职业拥有的技能：First Aid（任何职业，3 级，通过书）、Whirlwind（仅限战士，6 级，需要 Cleave 等级 2；通过书或训练师）和 Haste（任何职业，4 级，由 Town 中的 Sela 以 200 金币传授）。

#来自装备和效果的等级

任何修正值组合（装备、套装加成、宝石、状态）都可以为某个技能（Skills）或所有技能（All Skills）增加等级。这些等级：

  • 只作用于角色已习得的技能。
  • 提升技能施放时的等级（其有效等级）：伤害、消耗、冷却、尺寸，一切按等级变化的内容。
  • 不改变已习得的等级，因此学习和需求仍使用已习得的等级。

在示例中，Knight、Ranger 或 Wizard 套装的 3 件分别把 Cleave、Power Shot 或 Fire Bolt 提升一级，整套 Noble 套装把所有技能提升一级。

#快捷栏

快捷栏有 10 个按键（1 到 9 和 0），每个放一个技能或一个物品。从 Skills 窗口拖入技能，从背包拖入物品；在按键之间拖动以移动，拖出快捷栏以清除。新角色开始时快捷栏上有其已习得的技能和职业的初始消耗品。服务器会检查每个按键：栏位存在、物品存在、技能已掌握。生效中的增益及其剩余秒数显示在快捷栏上方，冷却中的按键显示径向遮罩。

#制作一个带范围和状态的技能

本例制作 Frost Wave：一个法师技能，对施法者前方锥形范围内的每个敌人造成水属性伤害并使其减速，并留下持续两秒的冰霜区域。

  1. 打开 Game Database > Combat > Skills 并按 + New skill。在 Id 中输入 frost_wave，在 Display Name 中输入 Frost Wave。写一段 Description 并设置一个 Icon。
  2. Basics。 Max Level 5。Target Enemy。Mana Cost 基础 20，每级 3。Cooldown 基础 8，每级 -0.5（随等级变快）。Cast Time 0.4。Range 8。
  3. Area。 Shape Cone，Size 基础 5、每级 0.5，Width 70 度。
  4. Requirements。 Weapons 留空，让任何武器都能使用。Levels Per Rank 2。
  5. Effects。 按 + 和 Pick a type > Damage：Element Water，Min 基础 10 每级 4，Max 基础 15 每级 5，Weapon Scale 0。
  6. 再按 + 并选择 Apply Status：Status Slowed，Duration 基础 3 每级 0.5，Chance 1，Stacks 1。
  7. Zone。 Zone Time 2，Zone Tick 1。锥形范围停留在施放处，在两秒内每秒再次生效。每次生效都会再次应用所有效果，因此停留在其中的敌人会再次受到伤害，其 Slowed 也会被刷新。
  8. Look。 Cast Effect：示例的施法光环。Area Effect：示例的范围爆发，或留空以显示 Water 颜色的平面轮廓。
  9. 把它交给职业：打开 Classes > Mage，把 Frost Wave 加入 Skills，Unlock Level 为 8。
  10. 可选：在法师的玩家模型中打开 Character Animations > Skills，添加 Frost Wave 及其自己的 Use 片段和命中时机。没有它时播放默认的技能动画。
  11. 用 8 级或更高的法师进入游戏（以 GM 身份使用 /level），在 Skills 窗口（K）中学习它，放到快捷栏上，并对一群史莱姆施放。卡片显示 "Cone of 5 m, 70°"、"Stays 2s, hitting every 1s"、伤害以及 "Slowed for 3s"。

#圆形范围的友方技能

示例中的 War Cry：Target Self，Shape Circle，Size 6，一个 Stat Buff 效果（+15% 威力，10 秒，每级 +2）。6 米内的每个盟友（包括施法者）都会获得该增益。

#需要引导的地面技能

示例中的 Flame Burst：Target Ground，Shape Circle，Size 3，Range 10，Cast Time 0.8，一个 Damage 效果（火，6 到 9），Channel Time 1.5，Channel Ticks 3：火焰在一秒半内在你指向的地方落下三次。

#单人模式和 MMO

技能在两种模式下都在服务器上运行：MMO 中是地图服务器，单人模式中是游戏本身。客户端只发送哪个技能以及哪个目标或点；地面点被限制在技能的射程内。

  • 保存。 已习得的等级（以及哪些是免费传授的）和快捷栏随角色保存：MMO 中为 Skills 和 Hotbar 列，单人模式中在角色的 JSON 内。来自物品的额外技能点放在角色的 Extra 数据中。
  • 冷却以结束时间的形式只向拥有者发送一次，而不是每秒发送。
  • 目录。 在 MMO 中，Login 从 gamedata.json 把每个技能（id、名称、最高等级、是否被动、拥有它的职业）复制到 skills 表中。Play & Servers 在启动服务时导出它；构建时使用 KitARPG > Export Game Data for Services。

#提示

  • 在 Cooldown 上使用负的 Per Level，让升级有回报感，而不必无限提高伤害。
  • 把眩晕或减速放在状态中，而不是放在技能中，这样免疫和抗性就可以指定它。
  • 混合效果：同一个 Enemy 技能上的伤害效果和友方 Stat Buff 会伤害目标并为施法者提供增益。

#常见错误

  • 技能对敌人没有任何效果。 它唯一的效果是友方的（Heal、没有 Debuff 的 Stat Buff、增益状态），因此它作用于施法者。
  • Ground 技能显示 "No target"。 当前操控模式要求敌对技能有目标；瞄准一个敌人，或查看操控模式。
  • 技能无法用弓施放。 Weapons 列出的是其他类型。
  • 装备给某技能 +1，却没有任何变化。 角色还没有习得该技能。
  • 被动技能没有任何效果。 被动技能只应用其 Stat Buff 效果。
