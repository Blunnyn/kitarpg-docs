NPC

NPC 是玩家点击以交谈的人或物：它向玩家打招呼，并列出商店、旅行、任务、对话、仓库或可以拉动的拉杆等选项。本页介绍 Npc 组件、每种选项及其字段、带条件的问候语和选项，以及交谈在服务器上如何进行。

#NPC 是什么

NPC 是地图场景中带有 Npc 组件和碰撞体的对象。它不是网络对象：客户端和地图服务器都会随场景加载它，请求通过其 id 指定它。服务器会根据玩家所站位置旁的 NPC 检查每个请求。

NPC 有：

  • 一个 id、一个名称和一句问候语，
  • 随条件变化的问候语，
  • 一个选项列表：玩家可以选择的台词。

同一个组件也可以制作不是人的东西：示例中的 Strange Altar 是一个没有问候语、只有一个 Trigger 选项的 Npc，因此点击它会立即生效。

#在编辑器中的位置

在场景中选择 NPC 的对象。Npc 检视面板显示其字段，然后是一行 Add option，每种选项一个按钮（Shop、Teleport、Skill Trainer、Quest、Dialogue、Trigger、Bank、Market、Guild Bank、Guild Found、Guild Hall、Collector、Forge、Mail，以及你自己的任何选项）。其下方，每个选项一行，显示其类型和标签，以及一个 Remove 按钮。

检视面板会发出警告：

  • 对象及其子对象上没有碰撞体时："Add a collider so players can click it."（添加碰撞体，让玩家可以点击它。）
  • 列表为空时："No options yet: players can talk to it but there is nothing to pick."（还没有选项：玩家可以与它交谈，但没有可选的内容。）

选中 NPC 时，Scene 视图中会以黄色圆圈绘制其交谈范围。

#Npc 组件

字段 作用 默认值
Npc Id（npcId） 在其地图上唯一。任务（TalkObjective）和请求通过它指定 NPC。留空则使用对象的名称。 空
Display Name（displayName） 显示在交谈窗口顶部。 "Villager"
Greeting（greeting） 与它交谈时显示。留空且只有一个选项时，会直接打开该选项。 "Welcome, traveler."
Talk Range（talkRange） 玩家必须距离 NPC 多少米以内才能交谈和交易。会额外增加半米余量，以容纳玩家请求时迈出的一步。 3
Greetings（greetings） 对满足条件的玩家改说的问候语；第一个符合的胜出。每条有 Text 和 Conditions。 空
Options（options） 它提供的台词。 空

同一张地图上两个 NPC 使用相同 id 是错误：只有一个会回应，控制台会警告，Project Check 也会报告。

#可选组件

这些是独立的组件；示例为其 NPC 添加了它们。

组件 作用
NpcQuestMarker 为本地玩家显示在头顶的标记：可接任务为黄色 "!"，可交任务为黄色 "?"，进行中的任务为灰色 "?"。字段：Height（2.45）、Ready Color、Waiting Color、Refresh Seconds（0.5）。它只考虑玩家能够到达的选项。
Nameplate 头顶的名字，带有一个 TextMeshPro 标签。
CharacterOutfit 加 ModularCharacter 为永不换装的 NPC 给体素身体穿上固定服装（头发、一套装备、一顶帽子）。
CharacterAnimations 播放待机片段。

#所有选项共有的字段

每个选项都有以下字段：

字段 作用 默认值
Label（label） 按钮文字。留空则使用该选项的默认文字，例如 "Trade" 或 "Travel to Forest (10 Gold)"。 空
Required Level（requiredLevel） 对低于此等级的角色隐藏。 0
Conditions（conditions） 只要有一项不满足就隐藏：帮助店主后才开放的商店、只针对某个职业的台词。参见条件与动作。 空
Show When Locked（showWhenLocked） 条件不满足时以灰色显示并附上原因，而不是隐藏。 Off

当选项所属的模块在 Modules 中关闭时，或其自身规则这样规定时（例如没有公会的玩家看不到公会仓库），选项也会隐藏。

#每种选项

#Shop

打开数据库 Shops 列表中的一个商店。

字段 作用 默认值
Shop（shop） 要打开的 ShopData。没有时选项会隐藏。 None

默认标签："Trade"。在地图运行期间，库存按 NPC 保存。关于商店的一切见 NPC 商店。

#Teleport

收取费用，把玩家带到本地图或其他地图的某个地方。

字段 作用 默认值
Map（map） 目的地。没有时选项会隐藏。 None
Position（position） 玩家在那里出现的位置。 0, 0, 0
Price（price） 花费的金币。0 为免费。 0

默认标签："Travel to <map>"，有费用时加上 "(<price> Gold)"。金币先被扣除，如果移动到其他地图失败会退还。

#Skill Trainer

以金币传授一个技能，即使不属于玩家的职业，但需在技能的学习规则之内。

字段 作用 默认值
Skill（skill） 它传授的技能。 None
Rank（rank） 它传授的等级。低于它的已会技能会被提升到该等级。 1
Price（price） 金币。 100

默认标签："Learn <skill> (<price> Gold)"。该选项对职业无法学习该技能的玩家，以及已经掌握到该等级的玩家隐藏。当技能自身的要求未满足时（等级、所需技能），原因会显示在玩家头顶，且不收取任何费用。参见技能。

#Quest

发放任务、在完成时收回，或两者兼有。每个任务一个选项。

字段 作用 默认值
Quest（quest） 任务。 None
Offers（offers） 玩家可以在这里接取该任务。 On
Completes（completes） 玩家在这里交付该任务。 On

它只在有事可做时显示：任务可接且该选项提供它，或任务进行中且该选项可完成它。其标签显示玩家的进度：可接时为黄色 "!"，可交付时为黄色 "?" 和 "(complete)"，未完成时为灰色 "?" 和 "(in progress)"。选择它会打开任务窗口。参见任务。

对于交给另一个人的任务，让发布者的 Completes 关闭，让接收者的 Offers 关闭，就像示例中的 "A Letter for Sela" 在 Old Tomas 和 Sela 之间所做的那样。

#Dialogue

一句对话。选择它会运行其动作，然后 NPC 回答并提供接下来的台词。嵌套它们即可制作分支对话。

字段 作用 默认值
Reply（reply） NPC 的回答。留空且之后没有台词时，会结束交谈。 空
Actions（actions） 选择时、在回答之前运行。如果有一项无法执行，会告诉玩家原因，且都不会运行。 空
Options（options） 回答之后提供的台词。任何类型的选项，也包括对话台词。 空
Back To Start（backToStart） 之后回到问候语，就像一句 Back 台词。 Off

默认标签："..."，或开启 Back To Start 时为 "Back"。当其动作需要收费时，价格会加到标签上，例如 "Can you patch me up? (15 Gold)"。关于对话的一切见对话。

#Trigger

按 id 触发一个世界触发器。

字段 作用 默认值
Trigger（trigger） 本地图上触发器的 id。 空

默认标签："Use"。在带有 Npc、没有问候语且只有这个选项的对象上，点击该对象会立即触发：拉杆、祭坛、宝箱。当触发器的条件不满足时，原因会显示在玩家头顶（"The stone is cold and silent."）。

#Bank

打开玩家的账号仓库。默认标签："Bank"。没有自己的字段。模块：Bank。参见背包与仓库。

#Market

打开市场，玩家在那里互相出售。默认标签："Market"。模块：Market。参见市场。

#Guild Bank

为职位允许使用的成员打开公会仓库。默认标签："Guild bank"。对没有公会的玩家隐藏。模块：Guilds。参见公会。

#Guild Found

在这里创建公会：打开徽章选择器，或在游戏没有徽章时打开公会窗口。默认标签："Found a guild"。对已在公会中的玩家隐藏，当 Game Database > Settings > Guild Found At 为 Window（只能从公会窗口创建）时也隐藏。模块：Guilds。

#Guild Hall

公会会馆的大门。

字段 作用 默认值
Act（act） Enter：把成员带入其公会的会馆。Buy：用公会仓库中的金币购买会馆。 Enter

默认标签："Enter the guild hall"，或 "Buy the guild hall (<price> Gold from the guild bank)"。数据库中没有公会会馆地图时隐藏；对没有公会的玩家隐藏；对没有会馆的公会隐藏 Enter；对已有会馆的公会或职位缺少 Hall 权限的成员隐藏 Buy。模块：Guilds。

#Collector

在收税员位置要做的一件事。放在同时带有 CollectorSpot 组件的 NPC 上。

字段 作用 默认值
Act（act） Place 放置公会的收税员（标签显示费用），Collect 收取它（标签显示其金币、物品和经验），或 Attack 攻击其他公会的收税员。 Place

每个操作只在适用时显示；一个位置通常三者都有。仅限在线。模块：Collectors。参见收税员。

#Forge

打开铁匠的锻造台：强化装备、分解装备、镶嵌宝石。默认标签："Forge"。模块：Forge。参见锻造。

#Mail

打开玩家的邮箱。默认标签："Mail"。在 Game Settings > Mail > Mail Anywhere 关闭时有用。模块：Mail。参见邮件。

#带条件的问候语

Greetings 改变 NPC 第一句说的话。第一个所有条件都满足的条目胜出；没有满足的则使用普通的 Greeting。

示例中的 Captain Hale 有两条：

  1. "There's the one who dethroned a king. Drinks are on the town tonight."，带有一个针对 "Long Live the King?"、设为 Done 的 QuestCondition。
  2. "Back from the ruins already? Tell me what you saw out there."，带有一个针对 "The Old Ruins"、设为 Taken 的 QuestCondition。

按从最具体到最不具体的顺序排列它们。

#放置 NPC

  1. 打开地图场景。
  2. 把一个角色模型拖入场景，或制作一个以模型为子对象的空对象。为对象命名，例如 Herbalist。
  3. Add Component > Npc。把 Npc Id 设为 herbalist，Display Name 设为 Hanna，并设置一句 Greeting。
  4. Add Component > Capsule Collider 并让它贴合身体，让玩家可以点击。
  5. 可选：Add Component > Npc Quest Marker 显示任务标记，并添加一个带 TextMeshPro 子对象的 Nameplate，在头顶显示名字。
  6. 在 Npc 检视面板中，为每句台词按 Add option 下的按钮，并填写其字段。
  7. 保存场景。在服务器上，NPC 不需要其他步骤：它们随场景加载。

商店 NPC 的分步操作见 NPC 商店。

#交谈如何进行

  1. 玩家点击 NPC（或使用键盘操控时在附近按 F）。游戏模式让玩家走到它身边。
  2. 进入范围后，服务器开始交谈。这也会为玩家进行中的任务计入针对该 NPC 的任何 TalkObjective。
  3. 服务器发送问候语以及该玩家能看到的选项，锁定的选项以灰色显示并附上原因。没有问候语文字且只有一个可选选项时，该选项会立即运行。
  4. 玩家选择一个选项。服务器检查玩家仍在范围内、存活、每秒请求不超过 10 次，且该选项对其提供，然后运行它。
  5. 走开或按 Escape 会关闭窗口。

每项检查都在服务器上。被修改过的客户端无法选择隐藏的选项、锁定的选项，或不在其身边的 NPC 的选项。

#单人模式和 MMO

两种模式下相同。在 MMO 中，NPC 存在于其地图的地图服务器上，以及每个加载该场景的客户端上。商店库存按地图服务器（和按 NPC）计算，地图服务器重启时重新开始。在实例化地图中，每个副本都有自己的 NPC。

#给程序员

继承 NpcOption 来添加你自己的选项：设置 DefaultLabel，重写 Run(Npc, PlayerCharacter)（仅服务器），并可选择重写 AvailableTo、LabelFor 和 Module。检视面板会立即为它显示一个按钮。DevKit 的 Bounty Board 示例添加了一个 BountyOption。参见 NPC 选项。

#常见错误

  • 点击没有反应。 没有碰撞体，或碰撞体所在的层被镜头的点击忽略。
  • "Too far"。 Talk Range 小于玩家停下的位置。把它稍微调大。
  • 某个选项从不显示。 它的条件不满足（开启 Show When Locked 查看原因），它的模块已关闭，或某个必填字段（商店、地图、任务）为空。
  • 交谈目标没有计数。 任务的 Npc Id 与 NPC 的 id 不匹配，或任务是在交谈之后才接的。再交谈一次。
  • 两个 NPC 像一个一样回应。 它们在同一张地图上共用一个 id。
