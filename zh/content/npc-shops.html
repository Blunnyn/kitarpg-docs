NPC 商店

NPC 商店是一个 ShopData 资源，列出 NPC 出售什么、价格多少、使用哪种货币，以及可选的、会随时间补充的有限库存。本页介绍商店的每个字段、购买、出售和回购、库存如何运作，以及分步制作带商店的 NPC。

#商店是什么

商店有两部分：

  • 商店数据（ShopData，Game Database > Items > Shops）：它的货币、条目以及是否收购玩家的物品。
  • NPC 上打开它的 Shop 选项。多个 NPC 可以共用一份商店数据，各自有自己的库存。

示例中有八个商店：炼金术士（Mira）、武器库（Brann）、帽子商人（Pip）、裁缝（Doran）、鞋匠（Wren）、奥术师（Selis）、铁匠（Garrick）以及公会登记员（Edda，出售公会章程）。

商店以金币或其他游戏内货币出售。以付费货币出售的游戏内商城是另一个系统：参见商城。

#在编辑器中的位置

Game Database > Items > Shops。+ New shop 在数据库旁的 Shops 文件夹中创建一个商店，并把它加入数据库的 shops 列表。你也可以使用 Create > KitARPG > Shop。条目以行显示，带有每个物品的图标。

#字段

#商店

字段 作用 默认值
Id、Display Name、Description、Icon 所有数据库资源共有。 来自文件名
Currency（currency） 它以什么收费。留空为金币。付费货币在 Project Check 中是错误：付费货币只能在游戏内商城消费。 空（金币）
Items（items） 它出售什么，按窗口列出的顺序。 空
Buys Items（buysItems） 玩家可以在这里出售自己的物品换取金币。只在 Game Settings 允许玩家向 NPC 出售时有效。 On
Buyback Slots（buybackSlots） 每名玩家最近卖出的物品，在离开商店之前可以按卖出所得的价格买回。0 关闭此功能。 10

#每个条目

字段 作用 默认值
Item（item） 它出售的东西。Project Check 会对没有物品的条目发出警告。 None
Price（price） 单个的价格，以商店的货币计。0 使用物品的购买价格。 0
Stock（stock） 它有多少个。0 表示永不售罄。 0
Restock Minutes（restockMinutes） 售出一些后补回一个所需的分钟数。0 表示只在地图重启时补满。 5

物品的购买价格是其 Buy Price（buyPrice），Buy Price 为 0 时为其 Sell Price（sellPrice）的四倍。参见物品。

#在 Game Settings 中

字段 作用 默认值
Players Sell To Npcs（playersSellToNpcs，Game Settings > Economy） 商店收购玩家带来的东西。关闭时，不能向 NPC 出售任何东西：物品在玩家之间、在市场或在锻造台流转，掉落永远不会变成金币。单个商店仍可以通过关闭 Buys Items 自行拒绝。 Off

只有当商店的 Buys Items 和游戏的 Players Sell To Npcs 都开启时，商店才会收购。按默认设置，没有商店收购。

#购买

商店窗口列出每个条目的图标、名称、价格，有限条目还会显示剩余库存，以及一个 Buy 按钮。

  • Buy 或在条目上右键购买一个。
  • 按住 Shift 购买一组：最多到物品的最大堆叠数，或剩余的库存。
  • 服务器检查条目存在、有库存、玩家能用商店的货币支付价格乘以数量，且背包有空间。
  • 错误会显示在窗口中："You can't afford that."、"Sold out. Come back later."、"You're too far away."，或背包自身的原因。

每次购买都会写入游戏日志（ShopBuy），包含商店、物品、数量和价格。

#出售

当商店收购时，打开它也会在旁边打开背包，商店打开期间背包用于出售：

  • 右键点击背包物品出售它，或把它拖到商店上。背包的提示行会显示其他方式（双击，Shift 出售一个，Ctrl 出售全部）。
  • 一组物品会询问出售多少个。
  • 玩家获得物品的 Sell Price 乘以数量，无论商店使用哪种货币，始终以金币支付。
  • Sell Price 为 0 的物品和任务物品不能出售："Nobody would buy that."
  • 商店不收购时："This shop doesn't buy items."

每次出售都会写入游戏日志（ShopSell）。

#回购

每次出售的物品会放到玩家回购行的最前面，最多 Buyback Slots 个。右键点击其中一个，可以用玩家当时获得的金币把它买回。物品会原样返回，带着其随机加成和强化。每次打开商店时回购行都是空的。

#库存

  • 在地图运行期间，库存按 NPC 保存。使用同一份商店数据的两个 NPC 有各自的库存。
  • 有限条目开始时是满的（Stock）。一旦售出一个，计时开始：每 Restock Minutes 补回一个，直到该条目再次满额。
  • Restock Minutes 为 0 时，售出的物品只在地图服务器重启时才会补回。
  • 地图上的所有人共享某个 NPC 的库存。在 MMO 中，每个地图服务器以及实例化地图的每个副本都有自己的库存。

示例中的武器库以 1 到 3 的库存出售较好的武器，每 5 到 10 分钟补充："The good pieces sell out."

#放置带商店的 NPC

本例制作一个出售药水和一种稀有药剂的草药师。

  1. 制作商店。 Game Database > Items > Shops > + New shop。把它重命名为 Herbalist。

  2. Currency 留空（金币）。

  3. 在 Items 中添加条目：

    物品 Price Stock Restock Minutes
    Health Potion 20 0 5
    Mana Potion 20 0 5
    Antidote 0（使用其购买价格） 0 5
    Fortitude Elixir 45 3 10

  4. 如果你的游戏允许玩家向 NPC 出售，保持 Buys Items 开启。

  5. 放置 NPC。 打开地图场景。添加角色模型并把对象命名为 Herbalist。

  6. Add Component > Npc。Npc Id 为 herbalist，Display Name 为 Hanna，Greeting 为 "Herbs for every ache."。

  7. Add Component > Capsule Collider 并让它贴合身体。

  8. 在 Npc 检视面板中，按 Add option 下的 Shop。在新选项的 Shop 中选择 Herbalist。Label 留空则显示 "Trade"，或输入 "Browse herbs"。

  9. 保存场景并按 Play。点击 Hanna，然后点击 Trade。

只有一个选项且 Greeting 为空时，点击 NPC 会直接打开商店。

#稍后才开放的商店

给 Shop 选项设置 Conditions，例如一个针对 "Help Hanna"、设为 Done 的 QuestCondition，并开启 Show When Locked，这样在此之前玩家会看到灰色的 "Trade (Finish Help Hanna first)"。参见条件与动作。

#对话中的商店

Shop 选项可以放在某句对话台词的 Options 中，这样商店会在交谈之后打开。

#使用其他货币的商店

把 Currency 设为你游戏中的某种货币，例如来自任务的代币。价格以该货币计；出售仍然支付金币。参见货币。

#单人模式和 MMO

规则相同。在 MMO 中，地图服务器检查每次购买和出售；客户端只发出请求。库存存在于地图服务器上，因此在该地图服务器重启时重新开始。

#给程序员

PlayerInteraction.ServerBuy、ServerSell 和 ServerBuyBack 是虚方法：重写它们来改变价格（为公会打折、按声望定价）或添加规则。ShopWindow.Describe 把错误码转为文字；重写它来翻译这些文字。参见重写套件行为。

#常见错误

  • 玩家无法出售任何东西。 Game Settings 中的 Players Sell To Npcs 关闭了，这是默认值。开启它，或有意保持关闭，并引导玩家使用市场和锻造。
  • 某个物品的价格是你预期的四倍。 条目的 Price 为 0 且物品没有 Buy Price，因此它使用出售价格的四倍。
  • 库存从不补充。 Restock Minutes 为 0。
  • Project Check 报告关于付费货币的错误。 商店以付费货币收费。这类商品请使用游戏内商城。
