Chat

此页面尚未翻译，以英文显示。

The chat box, its channels, every slash command, the word filter, mutes, reports and the limits the server enforces. It also explains how chat travels between maps in an MMO and what is left in single player.

#What it is

The chat is the box at the bottom left of the HUD. Players type lines to people near them, on the same map, on the whole server, in private, to their party, their guild or their alliance. The game also writes system lines there: "Letter sent to Ana.", "Ana is online.", errors from requests.

  • It is the Chat module (PlayerChat on the player prefab, ChatWindow in the HUD).
  • Say and Map lines are handled by the map server. World, Whisper to another map, Party, Guild and Alliance lines go through Central in an MMO.
  • The server checks every line: length, pace, mutes, the blocked word list and your own filter code.
  • With the module off, players can't chat, but slash commands such as /help and GM commands keep working.

#Where it is in the editor

What Where
Turn it on or off KitARPG > Modules, module Chat. See Modules.
Blocked words, filter mode, chat logging KitARPG > Game Settings, cards Chat filter and Logs. See Game Settings.
Say range, line length, pace, report evidence The PlayerChat component on each player prefab.
The chat box, colors, line count ChatWindow in the HUD prefab. See HUD and windows.
Hiding the chat on phones TouchChatButton on the touch controls. See Touch controls.

#Channels

Channel Who hears it Shown as Color in the sample
Say Players in the same map scene within Say Range (30 m). Name: text Off white
Map Everyone in the same map scene. [Map] Name: text Orange
World Everyone online on every map. [World] Name: text Light blue
Whisper One player, by name, on any map. Name whispers: text and, for you, To Name: text Pink
Party Your party members online, on any map. [Party] Name: text Blue
Guild Your guild members online, on any map. [Guild] Name: text Green
Alliance Every online member of every guild in your guild's alliance. [Alliance] Name: text Pale blue
System Only you. Lines from the game. The text Gold

Each copy of an instanced dungeon is its own scene, so Say and Map in a dungeon only reach your copy. See Dungeons.

Errors you may see:

Situation Message
Party line without a party "You are not in a party."
Guild line without a guild "You are not in a guild."
Alliance line without an alliance "Your guild is in no alliance."
Whisper to yourself "Talking to yourself?"
Whisper to someone not online "Name is not online."

#Using the chat as a player

#Typing

  • Press Enter (or keypad Enter), or click anywhere in the chat box, to start typing. The box turns darker while you type, so it is clear where the keys go.
  • Enter sends the line and stops typing.
  • Esc clears the line and stops typing.
  • A plain line goes to the current channel, shown on the channel button left of the field. Click that button to cycle Say, Map, World, Party, Guild, Alliance.
  • A line starting with / is a command.

While you type, game keys don't fire (for example N doesn't open the mailbox).

#Names in the chat

Player names are links:

  • Left click a name to start a whisper to them (/w Name is typed for you).
  • Right click a name to open the player menu: whisper, trade, invite to party, add friend, invite to guild, duel, report. See HUD and windows.

Clicking your own name does nothing.

#What the box keeps

The box keeps the last Max Lines (100) lines. It is hidden while no character is in the world (title, character select, loading). Switching to another character clears it.

#Slash commands

Commands handled by the chat box:

Command Aliases What it does
/s text /say Say. Without text, makes Say the default channel.
/m text /y, /map Map. Without text, makes Map the default channel.
/g text /world World. Without text, makes World the default channel.
/p text /party Party. Without text, makes Party the default channel.
/gu text /guild Guild. Without text, makes Guild the default channel.
/al text /alliance Alliance. Without text, makes Alliance the default channel.
/w Name text /whisper, /tell Whispers one player.
/r text /reply Whispers the last player who whispered you. "Nobody to reply to yet." if nobody has.
/invite Name Invites a player to your party. See Friends and parties.
/leave Leaves your party.
/kick Name Removes a member (leader only).
/promote Name /lead Makes a member the leader (leader only).
/friend Name Sends a friend request, or accepts theirs.
/unfriend Name Removes a friend or a request.
/trade Name Asks a player to trade. See Trade.
/ginvite Name Invites a player to your guild. See Guilds.
/gm /panel Opens the GM panel, if your account may use it. See GM tools.

Anything else starting with / goes to the server:

Command Who What it does
/help (/commands) Everyone Lists the chat commands, then every GM command your account's level allows, with its level.
/report Name reason Everyone Reports a player to the moderators. MMO only.
GM commands Moderators and up /mute, /kick, /ban and the rest. See GM commands.
注意

/g is the World channel, not guild. Guild is /gu.

#Limits the server enforces

#PlayerChat (player prefab)

Field What it does Default
Say Range (sayRange) Meters a Say line carries. 30
Max Length (maxLength) Characters per line. Longer lines are cut. 200
Burst (burst) Lines allowed in a row; one comes back every second. 5
Report Lines (reportLines) Lines the player saw lately that go with a report they send. 30
Report Cooldown (reportCooldown) Seconds between two reports from one player. 60

With the defaults a player can send 5 lines at once, then one a second. Past that: "You are talking too fast." Slash commands share the same allowance and answer "You are typing too fast." A server command line can be at most 300 characters.

On top of that, every client command on the map server spends from a per connection budget (30 a second, bursts of 60). A client far over it is disconnected for flooding.

#Cleaning

Before anything else, the server cleans each line: it trims spaces, turns control characters into spaces, and breaks every < so no rich text tag can open. A player who types <color=red> sees it printed as written, in everyone's chat. Names are cleaned the same way and cut at 32 characters.

#Word filter

The word filter blocks words you list. It runs on the server for chat lines, mail subjects and texts, and guild notices. Guild names with a blocked word are refused.

#Game Settings, card Chat filter

Field What it does Default
Blocked Words (blockedWords) Words nobody may say, one per entry. End one with * to also catch words that start with it. Empty
Blocked Words File (blockedWordsFile) A text asset with more blocked words, one per line, for long lists. Lines starting with # are comments. None
Chat Filter Mode (chatFilterMode) Mask turns blocked words into asterisks. Block drops the whole line and tells the sender "That line has words this game doesn't allow." Mask

How words are matched:

  • Whole words only. With ass blocked, "class" and "passage" are safe.
  • An entry ending in * also catches longer words: darn* catches "darn", "darned" and "darnit".
  • Case doesn't matter.
  • Digits and symbols standing in for letters are read as letters: 0→o, 1→i, 3→e, 4 and @→a, 5 and $→s, 7→t. So d4rn and @ss are caught.
  • Mail always masks, even in Block mode, so a letter is never dropped.

The list is read once per run. If you edit it during Play, the change applies the next time you press Play.

#Your own filter

Code can change or drop lines after the word filter with SocialHub.Filter: return a changed line, or null to drop it. Use it for a custom mute list, links, or a spam rule. See Events.

#Mutes

A moderator mutes a player with /mute Name minutes (10 minutes if no number is given, 0 lifts it). The muted player reads "You can't chat for 10 minutes." and every line they try gets "You are muted." The mute is stored on the character (flag chat.muted), so it survives logging out and changing maps. Moderators can't mute someone of their own level or higher. See GM commands.

#Reports

A player reports another with /report Name reason, or by right clicking them (in the world or in the chat) and picking Report, which asks "What happened?".

  • The report carries the last Report Lines (30) lines the reporter saw, with times and channels, as evidence.
  • One report every Report Cooldown (60) seconds per player: "Wait a moment before sending another report." Central also allows at most 10 reports a day per player.
  • The reporter reads "Thanks. Your report on Name went to the moderators."
  • You can't report yourself.
  • Reports need an online server. In single player: "Only on an online server."

Moderators read them with /reports. See Game log and reports.

#Logging chat

Log Chat (logChat, card Logs in Game Settings, off by default) writes every chat line to the game log as chat.line, with its channel and whisper target. Reports always carry the lines around them, even with it off. See Game log and reports.

警告

Logging every line stores private whispers in your database. Check what your privacy policy and local law allow before you turn it on.

#Single player and MMO

Single player MMO
Say, Map On the one map, as usual. Handled by the map server.
World Reaches everyone on the map (in single player, only you). Central sends it to every map.
Whisper Only to a player on the same map. Otherwise "Name is not online." The map looks for the player locally first, then asks Central, which finds them on any map.
Party, Guild, Alliance No parties or guilds, so nothing to send. Central sends the line to every online member, grouped by map.
Reports "Only on an online server." Sent to Central.

#Step by step

#Block a list of words

  1. Create a text file in your project, for example Assets/Game/BlockedWords.txt.
  2. Write one word per line. End a word with * to catch longer words. Start a line with # to leave a comment.
  3. Open KitARPG > Game Settings, card Chat filter, and drag the file into Blocked Words File.
  4. Pick Chat Filter Mode: Mask or Block.
  5. Press Play and type a blocked word to test.

The filter runs on the server, so rebuild your map servers after changing the list.

#Make Say reach farther

  1. Open each player prefab (the sample has PlayerMale, PlayerFemale and PlayerPanda in Samples/Starter/Prefabs).
  2. On PlayerChat, set Say Range, for example to 50.

#Change chat colors

Select the chat box in the HUD prefab and change the colors on ChatWindow (Say Color, Map Color, World Color, Whisper Color, Party Color, Guild Color, Alliance Color, System Color). These are client only.

#Common mistakes

  • Typing /g hello to talk to the guild. That is World. Use /gu.
  • The filter doesn't catch a word. It must be a whole word, or end the entry with *. Changes made during Play wait for the next run.
  • "You are talking too fast." More than 5 lines in a row. Raise Burst on PlayerChat if your game needs it.
  • World chat reaches only one map. The map server isn't connected to Central. Check Play and Servers.
  • Different settings on different player prefabs. PlayerChat lives on each prefab. Change all of them.
