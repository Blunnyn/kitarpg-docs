游戏系统

聊天

聊天框、它的频道、所有斜杠命令、屏蔽词过滤、禁言、举报以及服务器强制执行的限制。本页还说明在 MMO 中聊天如何在地图之间传递，以及单人模式中保留了哪些功能。

#它是什么

聊天是 HUD 左下角的框。玩家可以向附近的人、同一地图、整个服务器、私聊、自己的队伍、公会或联盟发送消息。游戏也会在这里写入系统消息："Letter sent to Ana."、"Ana is online."、请求返回的错误。

  • 它是 Chat 模块（玩家预制体上的 PlayerChat，HUD 中的 ChatWindow）。
  • Say 和 Map 消息由地图服务器处理。在 MMO 中，World、发往其他地图的 Whisper、Party、Guild 和 Alliance 消息经过 Central。
  • 服务器检查每一行：长度、频率、禁言、屏蔽词列表以及你自己的过滤代码。
  • 模块关闭时，玩家无法聊天，但 /help 等斜杠命令和 GM 命令仍然可用。

#在编辑器中的位置

内容 位置
开启或关闭 KitARPG > Modules，模块 Chat。参见模块。
屏蔽词、过滤模式、聊天记录 KitARPG > Game Settings，卡片 Chat filter 和 Logs。参见 Game Settings。
Say 范围、行长度、频率、举报证据 每个玩家预制体上的 PlayerChat 组件。
聊天框、颜色、行数 HUD 预制体中的 ChatWindow。参见 HUD 与窗口。
在手机上隐藏聊天 触控操作上的 TouchChatButton。参见触控操作。

#频道

频道 谁能看到 显示为 示例中的颜色
Say 同一地图场景中、Say Range（30 米）以内的玩家。 Name: text 米白色
Map 同一地图场景中的所有人。 [Map] Name: text 橙色
World 所有地图上的所有在线玩家。 [World] Name: text 浅蓝色
Whisper 按名字指定的一位玩家，可在任何地图。 Name whispers: text，你自己看到 To Name: text 粉色
Party 你的在线队伍成员，可在任何地图。 [Party] Name: text 蓝色
Guild 你的在线公会成员，可在任何地图。 [Guild] Name: text 绿色
Alliance 你的公会所在联盟中所有公会的每位在线成员。 [Alliance] Name: text 淡蓝色
System 只有你。来自游戏的消息。 文本本身 金色

副本地下城的每个副本都是独立的场景，所以地下城中的 Say 和 Map 只会发送到你所在的副本。参见地下城。

你可能看到的错误：

情况 消息
没有队伍时发送队伍消息 "You are not in a party."
没有公会时发送公会消息 "You are not in a guild."
没有联盟时发送联盟消息 "Your guild is in no alliance."
私聊自己 "Talking to yourself?"
私聊不在线的人 "Name is not online."

#作为玩家使用聊天

#输入

  • 按 Enter（或小键盘 Enter），或点击聊天框中的任意位置开始输入。输入时聊天框会变暗，让你清楚按键输入到哪里。
  • Enter 发送这一行并停止输入。
  • Esc 清空这一行并停止输入。
  • 普通文本发送到当前频道，当前频道显示在输入框左侧的频道按钮上。点击该按钮可在 Say、Map、World、Party、Guild、Alliance 之间循环切换。
  • 以 / 开头的一行是命令。

输入时，游戏按键不会触发（例如 N 不会打开邮箱）。

#聊天中的名字

玩家名字是链接：

  • 左键点击名字，开始私聊对方（会自动输入 /w Name ）。
  • 右键点击名字，打开玩家菜单：私聊、交易、邀请入队、添加好友、邀请入公会、决斗、举报。参见 HUD 与窗口。

点击自己的名字没有反应。

#聊天框保留的内容

聊天框保留最近 Max Lines（100）行。当没有角色在世界中时（标题、角色选择、加载），它是隐藏的。切换到另一个角色会清空它。

#斜杠命令

由聊天框处理的命令：

命令 别名 作用
/s text /say Say。不带文本时，将 Say 设为默认频道。
/m text /y、/map Map。不带文本时，将 Map 设为默认频道。
/g text /world World。不带文本时，将 World 设为默认频道。
/p text /party Party。不带文本时，将 Party 设为默认频道。
/gu text /guild Guild。不带文本时，将 Guild 设为默认频道。
/al text /alliance Alliance。不带文本时，将 Alliance 设为默认频道。
/w Name text /whisper、/tell 私聊一位玩家。
/r text /reply 私聊最后一位私聊你的玩家。如果还没有人私聊过你，显示 "Nobody to reply to yet."。
/invite Name 邀请一位玩家加入你的队伍。参见好友与队伍。
/leave 离开你的队伍。
/kick Name 移除一名成员（仅队长）。
/promote Name /lead 让一名成员成为队长（仅队长）。
/friend Name 发送好友请求，或接受对方的请求。
/unfriend Name 删除好友或请求。
/trade Name 请求与一位玩家交易。参见交易。
/ginvite Name 邀请一位玩家加入你的公会。参见公会。
/gm /panel 如果你的账号有权限，打开 GM 面板。参见 GM 工具。

其他以 / 开头的内容都会发送到服务器：

命令 谁 作用
/help（/commands） 所有人 列出聊天命令，然后列出你账号等级允许的每条 GM 命令及其等级。
/report Name reason 所有人 向管理员举报一位玩家。仅 MMO。
GM 命令 Moderator 及以上 /mute、/kick、/ban 等。参见 GM 命令。
注意

/g 是 World 频道，不是公会。公会是 /gu。

#服务器强制执行的限制

#PlayerChat（玩家预制体）

字段 作用 默认值
Say Range（sayRange） Say 消息传播的米数。 30
Max Length（maxLength） 每行的字符数。更长的行会被截断。 200
Burst（burst） 允许连续发送的行数；每秒恢复一行。 5
Report Lines（reportLines） 玩家发送举报时，随附的最近看到的行数。 30
Report Cooldown（reportCooldown） 同一玩家两次举报之间的秒数。 60

使用默认值时，玩家可以一次发送 5 行，之后每秒一行。超过就会显示 "You are talking too fast."。斜杠命令共用同一额度，超过时显示 "You are typing too fast."。服务器命令行最多 300 个字符。

此外，地图服务器上的每个客户端命令都会消耗每个连接的预算（每秒 30 次，突发 60 次）。远远超出的客户端会因刷屏被断开连接。

#清理

服务器首先清理每一行：去掉首尾空格，把控制字符变成空格，并拆开每个 <，使任何富文本标签都无法生效。玩家输入 <color=red>，所有人的聊天中都会按原样显示。名字也以同样的方式清理，并截断到 32 个字符。

#屏蔽词过滤

屏蔽词过滤会屏蔽你列出的词。它在服务器上运行，作用于聊天消息、邮件标题和正文，以及公会公告。包含屏蔽词的公会名会被拒绝。

#Game Settings，卡片 Chat filter

字段 作用 默认值
Blocked Words（blockedWords） 任何人都不能说的词，每个条目一个。以 * 结尾时，也会匹配以它开头的词。 空
Blocked Words File（blockedWordsFile） 包含更多屏蔽词的文本资源，每行一个，用于长列表。以 # 开头的行是注释。 无
Chat Filter Mode（chatFilterMode） Mask 把屏蔽词变成星号。Block 丢弃整行，并告诉发送者 "That line has words this game doesn't allow."。 Mask

匹配方式：

  • 只匹配完整单词。屏蔽 ass 时，"class" 和 "passage" 不受影响。
  • 以 * 结尾的条目也匹配更长的词：darn* 匹配 "darn"、"darned" 和 "darnit"。
  • 不区分大小写。
  • 代替字母的数字和符号会被当作字母读取：0→o、1→i、3→e、4 和 @→a、5 和 $→s、7→t。所以 d4rn 和 @ss 也会被匹配。
  • 邮件总是使用遮蔽，即使在 Block 模式下也是如此，因此信件绝不会被丢弃。

列表每次运行只读取一次。如果你在 Play 中修改它，改动会在下次按 Play 时生效。

#你自己的过滤器

代码可以用 SocialHub.Filter 在屏蔽词过滤之后修改或丢弃消息：返回修改后的行，或返回 null 丢弃它。可用于自定义禁言列表、链接或垃圾消息规则。参见事件。

#禁言

管理员用 /mute Name minutes 禁言一位玩家（不给数字时为 10 分钟，0 解除禁言）。被禁言的玩家会看到 "You can't chat for 10 minutes."，之后尝试发送的每一行都会得到 "You are muted."。禁言保存在角色上（标记 chat.muted），所以登出和切换地图后依然有效。管理员不能禁言与自己同级或更高级别的人。参见 GM 命令。

#举报

玩家可以用 /report Name reason 举报另一位玩家，或者右键点击对方（在世界中或聊天中）并选择 Report，它会询问 "What happened?"。

  • 举报会附带举报者最近看到的 Report Lines（30）行，包含时间和频道，作为证据。
  • 每位玩家每 Report Cooldown（60）秒只能举报一次："Wait a moment before sending another report."。Central 还限制每位玩家每天最多举报 10 次。
  • 举报者会看到 "Thanks. Your report on Name went to the moderators."。
  • 你不能举报自己。
  • 举报需要在线服务器。在单人模式中显示："Only on an online server."。

管理员用 /reports 查看举报。参见游戏日志与举报。

#记录聊天

Log Chat（logChat，Game Settings 中的卡片 Logs，默认关闭）会把每一条聊天消息以 chat.line 写入游戏日志，包含频道和私聊对象。即使它是关闭的，举报也总会附带周围的消息。参见游戏日志与举报。

警告

记录每一行会把私聊内容存入你的数据库。开启前请确认你的隐私政策和当地法律允许这样做。

#单人模式与 MMO

单人模式 MMO
Say、Map 在唯一的地图上，照常工作。 由地图服务器处理。
World 发送给地图上的所有人（在单人模式中只有你）。 Central 把它发送到每张地图。
Whisper 只能发给同一地图上的玩家。否则显示 "Name is not online."。 地图先在本地查找该玩家，然后询问 Central，由 Central 在任意地图上找到对方。
Party、Guild、Alliance 没有队伍或公会，所以没有可发送的对象。 Central 把消息发送给每位在线成员，按地图分组。
举报 "Only on an online server." 发送到 Central。

#分步操作

#屏蔽一组词

  1. 在项目中创建一个文本文件，例如 Assets/Game/BlockedWords.txt。
  2. 每行写一个词。词以 * 结尾可匹配更长的词。以 # 开头的行是注释。
  3. 打开 KitARPG > Game Settings 的卡片 Chat filter，把文件拖到 Blocked Words File。
  4. 选择 Chat Filter Mode：Mask 或 Block。
  5. 按 Play，输入一个屏蔽词进行测试。

过滤器在服务器上运行，所以修改列表后要重新构建地图服务器。

#让 Say 传得更远

  1. 打开每个玩家预制体（示例中 Samples/Starter/Prefabs 里有 PlayerMale、PlayerFemale 和 PlayerPanda）。
  2. 在 PlayerChat 上设置 Say Range，例如设为 50。

#修改聊天颜色

在 HUD 预制体中选中聊天框，在 ChatWindow 上修改颜色（Say Color、Map Color、World Color、Whisper Color、Party Color、Guild Color、Alliance Color、System Color）。这些只在客户端生效。

#常见错误

  • 输入 /g hello 想和公会说话。 那是 World。请用 /gu。
  • 过滤器没有匹配到某个词。 它必须是完整单词，或者让条目以 * 结尾。在 Play 中做的修改要到下次运行才生效。
  • "You are talking too fast." 连续发送超过 5 行。如果你的游戏需要，提高 PlayerChat 上的 Burst。
  • World 聊天只到达一张地图。 地图服务器没有连接到 Central。检查 Play and Servers。
  • 不同玩家预制体上的设置不同。 PlayerChat 位于每个预制体上。要全部修改。
