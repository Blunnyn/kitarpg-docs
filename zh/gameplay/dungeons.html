地下城

副本地图，即地下城，为每个队伍或每个单独的玩家提供一份自己的地图副本，有自己的怪物和首领。本页介绍副本对玩家和服务器的运作方式、所有设置，以及如何一步步制作地下城。

#玩家视角

地下城看起来和其他地图一样。你穿过它的传送门（在示例中，位于森林遗迹的西边），到达它的出生点。不同的是还有谁在那里：

  • 在队伍中 时，你和队友共享一个副本，即使你们在不同时间进入。
  • 单独一人 时，你会得到自己的副本。

其他玩家永远看不到你的副本，你也看不到他们的。你副本中的怪物、首领和掉落都属于你。

所有人离开后，副本会保留一段时间（默认 5 分钟），让你可以回来，例如在死亡之后。之后它会关闭，下次你进入时会得到一个全新的副本。

当你在地下城中重新登录时，你会出现在副本的出生点，而不是你保存的位置。

#设置

每张地图的地下城设置在 Game Database（Maps）的 Instances 部分。

字段 作用 默认值
Instanced（instanced） 每个队伍或每个单独的玩家获得自己的副本。仅在线 关
Instance Spacing（instanceSpacing） 地图服务器上副本之间的米数，使它们永远看不到彼此 1,000
Empty Minutes（emptyMinutes） 最后一名玩家离开后副本保留的分钟数 5

#运作方式

#你会得到哪个副本

Central 在发放进入地图的票据时选择副本：队伍中的玩家为 party-<id>，单独的玩家为 solo-<id>。副本随票据一起发送，地图服务器把玩家放到那里。它从不随角色保存。

#在地图服务器上

地图服务器在一个进程中运行该地图的所有副本：

  • 它启动时加载的场景只是模板。模板的刷怪点保持空闲，所以没有怪物。
  • 每个副本都是再次加载的同一个场景，沿 X 轴移动 index × Instance Spacing 米。副本相距很远，所以兴趣网格、视线和怪物 AI 都不需要特殊处理。
  • 每个副本都有自己的 NavMesh，由模板的数据生成。
  • 怪物留在生成它们的刷怪点所在的场景中。
  • 玩家总是从其副本的 SpawnPoint 进入。
  • 副本清空 Empty Minutes 分钟后关闭：它的网络对象被销毁，NavMesh 被移除，场景被卸载。

#在客户端上

客户端在角色出现之前得到副本的偏移量，并把自己的场景移动同样的距离，使位置一致。客户端不使用 NavMesh。

#分步操作：制作地下城

  1. 制作场景。 复制一张示例地图（例如 Forest），或者制作你自己的场景，包含一个 SpawnPoint 和烘焙好的 NavMeshSurface。添加 MonsterSpawner 和一个首领。地下地图通常不加 DayNightCycle（示例的地穴没有）。
  2. 添加地图。 Game Database > Maps > New map，在 Scene 中选择场景，并开启 Instanced。将 Empty Minutes 设为允许玩家返回的时长。
  3. 连接它。 在玩家来的地图中添加一个 Portal，其 Target Map 为地下城的 id，Target Position 在地下城内部。在地下城中添加一个返回的传送门。参见地图。
  4. 填充图鉴。 在地图的卡片上按 Read from scene，让图鉴知道它的怪物。
  5. 在 Central 中注册地图。 每张地图在自己的端口上作为单独的地图服务器运行。在你的电脑上，Play & Servers 启动服务时会为数据库中的每张地图分配一个端口。在服务器上，把地图的 id 和一个空闲端口添加到 Central 的 Maps 设置和 Docker Compose 中。参见启动器和 Docker。
  6. 重新构建地图服务器。 构建会从 Game Database 中获取每张地图的场景。构建缺少某张地图的场景时，Play & Servers 会发出警告。
  7. 试一试，在 MMO 中用两名玩家：在队伍中时他们共享一个副本；单独时则不共享。参见 Play & Servers。

示例的 Sunken Crypt（crypt，端口 7779）有带柱子的房间、史莱姆、蘑菇，最深处是 Giant Slime。

#单人模式与 MMO

单人模式 MMO
副本 无：副本地图就是普通地图，因为单人世界本身就是一个副本 每个队伍或单独玩家一个
Empty Minutes 不使用 使用

副本只存在于专用地图服务器上。在编辑器中，以服务器方式运行地图来测试副本（Play & Servers）。

#公会大厅

公会大厅使用同一套系统：大厅地图是副本地图，每个购买了大厅的公会获得副本 guild-<id>。Central 只允许该公会的成员（以及在允许时，同盟公会的成员）进入。

#提示

  • 给地下城设置足够长的 Empty Minutes，让玩家死亡后能从出生点跑回来。
  • 让 Instance Spacing 远大于地图的尺寸。默认的 1,000 米适合任何普通地图；更大的地图需要调高它。
  • 带阶段和守卫的首领在副本中和其他地方一样工作。参见首领。

#常见错误

  • 玩家进入时被送回登录界面。 地图没有在 Central 中注册，或者地图服务器的构建中没有它的场景。检查 Play & Servers 并重新构建。
  • 队伍成员进入了不同的副本。 有人在加入队伍之前就进入了。Central 在发放票据时选择副本：先组队，再进入。
  • 所有人共享地下城。 Instanced 已关闭，或者你在单人模式中测试。
  • 模板中有怪物。 用 MonsterSpawner 在地下城中放置怪物。模板场景的刷怪点保持空闲，每个副本的刷怪点填充该副本。
