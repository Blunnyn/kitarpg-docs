游戏系统

触控操作

手机和平板通过屏幕上的控件来玩 KitARPG：一个摇杆、一个 Attack 按钮、技能和药水按钮、一个 Activate 按钮，以及对世界的触摸。本页介绍触控操作何时出现、在每种操作模式下如何游玩、预制体上的每个组件和字段，以及如何修改布局。

#触控操作是什么

触控操作是由预制体 TouchControls.prefab 创建的一个画布，像 HUD 一样在游戏启动时创建一次，并在切换地图时保留。使用触控操作时，操作模式读取摇杆、按钮和对世界的触摸，而不是鼠标和按键。它们在全部三种操作模式中都能使用。

使用触控操作时鼠标会被忽略。在手机上，Unity 会在第一根手指下移动一个模拟鼠标，否则角色会朝摇杆下方走去。

#开启触控操作

打开 KitARPG > Game Settings 的 Interface 部分。

字段 作用 默认值
Input Layout（inputLayout） 游戏使用什么来操作（见下表）。 Auto
Touch Controls Prefab（touchControlsPrefab） 包含屏幕控件的画布。留空：没有触控操作。 示例：Samples/Starter/Prefabs/TouchControls.prefab
Input Layout 作用
Auto 在手机和平板上（包括 Device Simulator）使用触控操作。其他地方使用鼠标和按键。
Mouse And Keys 从不显示触控操作。
Touch 始终显示触控操作。游戏按键不起作用：行走、攻击、闪避、交互和快捷栏按键。
Touch And Keys 显示触控操作，同时保留键盘功能。适用于带键盘的平板，也可以在编辑器中试用触控操作。

布局在游戏启动时决定：在 Play 模式下更改它，要到下一次 Play 才会生效。

注意

触控操作是客户端功能。服务器对触控玩家的检查与对鼠标玩家完全相同，因此单人模式和 MMO 的行为一致。服务器构建永远不会创建它们。

#在编辑器中试用

  1. 把 Input Layout 设为 Touch And Keys。
  2. 按 Play 并登录。你的角色进入世界后控件就会出现。
  3. 鼠标充当手指：拖动摇杆、点击按钮、在世界上拖动。

或者保持 Auto，把 Game 视图切换到 Simulator 并选择一款手机：这时游戏会被视为移动设备。

#用触控游玩

#示例布局

部件 位置 作用
Move stick 左下 行走。拇指落在其区域内任何地方时，摇杆就出现在那里，松开后回到原位。未触摸时半透明。
Chat 按钮 左侧，摇杆上方 显示或收起聊天。聊天一开始是收起的；红色徽标统计期间收到的消息行数（超过 99 显示 99+）。
Attack 右下，较大 攻击（见下面各模式的表格）。
Skill 1 到 4 围绕 Attack 呈弧形排列：1 在左下，2 在左侧，3 和 4 在上方 快捷栏格子 1 到 4。显示技能图标、递减的冷却及其秒数。未学会或法力不足时变灰。
Consumable 弧形的左上 快捷栏格子 5，用于药水等消耗品。显示背包中剩余的数量。
Activate 右边缘，弧形上方 只有在 4 米内有掉落物或 NPC 时才出现。拾取最近的掉落物或与最近的 NPC 对话，与 F 相同。
X（取消区域） Skill 4 上方 只在你从技能按钮拖动时出现。在它上方松开会取消施放。
世界 其他所有地方 点按、拖动和双指缩放（见下文）。

当窗口、聊天输入框、对话框、设置、游戏菜单或加载画面打开时，控件会隐藏，关闭后再出现。它们的画布位于 HUD 下层，所以游戏窗口会盖住它们。

示例布局中没有闪避按钮。仅使用 Touch 时，自由摄像机和第三人称的玩家在你添加闪避按钮之前无法闪避（见添加按钮）。

#技能和消耗品按钮

  • 点按技能：对准星已经覆盖的敌人施放（第三人称），否则对技能射程加 2 米内最近的敌人施放。周围没有敌人时，向角色前方施放，最远 4 米。对自己和队友的技能按通常方式施放。
  • 从技能按钮拖动：改为瞄准。拖动会映射到摄像机所见的角色周围地面；拖动 160 像素（以 1080p 计）达到技能的完整射程。技能的范围预览会跟随。松开即在那里施放。
  • 取消拖动：在 X 上方松开，或回到按钮上松开（距起点不到 24 像素）。
  • 点按消耗品：使用它。拖动消耗品也会显示 X；在其他地方松开则使用它。
  • 按住按钮不动 0.6 秒，或点按一个空按钮：打开选择器。

触控按钮与电脑上按键使用的是同一个快捷栏。手机上的格子 1 就是桌面上的格子 1，所以角色在不同设备间保持相同的配置。客户端在发送前检查是否已学会、冷却、施法状态和法力，服务器会再次检查所有内容（见技能）。

#格子选择器

选择器是游戏上方的一个面板，标题为 "Choose a skill"（或 "Choose a consumable"），下面是一个图标网格：

  • 技能按钮列出角色能施放的所有技能：目前已学会的职业技能，加上在职业之外学会的技能。被动技能不在其中。
  • 消耗品按钮列出背包中的消耗品，以及每种的总数。
  • 按钮当前持有的条目带有金色圆环。
  • 选择一个位于其他格子上的条目会交换两者，所以不会有重复显示。
  • Empty this button 清空按钮。X 或 Escape 关闭选择器。

#俯视角模式下的触控

触摸 结果
摇杆 相对于摄像机朝该方向行走，与 WASD 完全一样。
一根手指按在世界上 与点击相同：攻击那里的怪物或敌对玩家、拾取掉落物、与 NPC 对话，或走到那里。
手指一直按在世界上 持续朝那里行走。第二根手指会停止行走，并转为双指缩放。
触摸一个非敌对的其他玩家 打开玩家菜单（没有右键）。
Attack 攻击 10 米内最近的敌人。按住时，当前目标倒下后会转向下一个。
双指缩放 缩放。

#自由摄像机和第三人称下的触控

触摸 结果
摇杆 相对于摄像机行走。推到一半时以一半速度行走。
一根手指在世界上拖动 在其 Camera Settings 允许的范围内转动摄像机。在第三人称下，准星始终显示。
点按世界 拾取那里的掉落物，与那里的 NPC 或收税官对话；否则打开那里玩家的菜单。
Attack 挥向准星覆盖的目标（第三人称），否则挥向攻击范围加 2 米内最近的敌人。按住时持续挥砍。
双指缩放 在摄像机的缩放范围内缩放。

在触屏上的自由摄像机模式中没有指针，所以挥砍和技能会自行寻找目标：最近的敌人，或正前方。

#预制体

KitARPG > Starter > Build Scenes and Prefabs 在 Samples/Starter/Prefabs/TouchControls.prefab 不存在时创建它，并在 Touch Controls Prefab 字段为空时把它赋给该字段。已有的预制体永远不会被替换，所以你的修改在重建示例后仍会保留。

它的部件是 Samples/Starter/Prefabs/UI 中的嵌套预制体：

预制体 用于
Touch Stick 移动摇杆
Touch Button Attack 和 Activate
Touch Skill Button 四个技能按钮和消耗品按钮
Touch Slot Picker 选择器

修改一次 Touch Skill Button，五个按钮都会跟着改变。打开 TouchControls.prefab 可以移动、调整大小、修改样式或删除任何部件。

根画布以 1920 × 1080 为参考随屏幕尺寸缩放，宽度和高度各按一半匹配，排序顺序为 9，位于 HUD 下层。

提示

旧版本套件制作的预制体会由套件更新 Touch controls: skills 1 to 4 and potion on 5 重新排列，该更新列在 Overview 中。它把技能 1 到 4 和药水放在 Attack 周围，并移除旧的 Dodge 按钮。见更新套件。

#组件

所有组件都在 Runtime/Client/Touch 中（命名空间 Blunnyn.KitARPG.Client）。

#TouchControls

位于预制体的根节点上。它收集每个部件的输入，并让桌面版 HUD 围绕控件排布。

字段 作用 默认值
Group（group） 在窗口、聊天或对话框打开时隐藏控件的 Canvas Group。留空：使用同一对象上的那个。 根节点的
Look Speed（lookSpeed） 在世界上拖动时摄像机转动的速度。乘以摄像机的灵敏度和玩家的鼠标灵敏度。 1
Pinch Speed（pinchSpeed） 每 100 像素双指缩放对应的缩放米数。 1.5
Hud Changes（hudChanges） 鼠标和按键用的 HUD 如何围绕控件调整（见下文）。 示例列表

每个 Hud Change 按 HUD 预制体下的路径找到 HUD 的一个部件，并在使用触控操作时修改它。关闭触控操作后一切恢复原样。

字段 作用 默认值
Path（path） HUD 下的路径，例如 HUD/Chat Window/Chat。找不到的路径会记录一条警告。 空
Hide（hide） 使用触控操作时隐藏。 关闭
Move（move） 应用下面的锚点、轴心、位置和缩放。 关闭
Anchor（anchor） 移动后部件的锚点。 (0.5, 0.5)
Pivot（pivot） 移动后部件的轴心。 (0.5, 0.5)
Position（position） 锚定位置。 (0, 0)
Scale（scale） 缩放，至少 0.1。 1

示例列表隐藏桌面快捷栏格子 Hotbar 1 到 Hotbar 10 和 Hint 行，把玩家 HUD 移到底部中央并缩放到 85%，把聊天移到左侧 Chat 按钮上方并缩放到 75%。如果你在 HUD 中重命名或移动了部件，要更新这些路径。见 HUD 与窗口。

#TouchStick

一个拇指摇杆，在每个方向上写入 -1 到 1 的轴值。

字段 作用 默认值
Axis（axis） 写入的轴。各模式用 Move 来行走。 Move
Background（background） 摇杆头在其中移动的圆环。 在预制体中设置
Knob（knob） 摇杆头。 在预制体中设置
Radius（radius） 摇杆头离中心最远的距离，以画布单位计。 90（示例中为 92）
Dead Zone（deadZone） 半径中视为没有推动的比例，0 到 0.9。超过后推动从零开始计算，所以轻微倾斜会慢慢行走。 0.15
Floating（floating） 摇杆出现在拇指落下的位置，而不是固定不动。 开启
Idle Alpha（idleAlpha） 未触摸时的不透明度。 0.5

触摸摇杆对象矩形内的任何位置都会抓住它。在示例中，该区域位于左下角，大小为 560 × 480。

#TouchButton

各模式按其 id 读取的按钮。

字段 作用 默认值
Id（id） Attack、Dodge、Interact，或你自己的代码读取的 id。 Attack
Show（show） Always，或 Near Interactable：只有在 Near Range 内有掉落物或 NPC 时显示。 Always
Near Range（nearRange） Near Interactable 的米数。 4
Face（face） 按住时缩小的图形。 在预制体中设置
Pressed Scale（pressedScale） 按住时图形的缩放，0.5 到 1。 0.9
On Press（onPress） 按下时触发的事件，用于挂接方法，而不需要编写读取 id 的代码。 空

每个 id 的作用：

Id 俯视角 自由摄像机和第三人称
Attack 攻击 10 米内最近的敌人；按住时转向下一个 挥向准星指向的敌人或范围内最近的敌人；按住时持续挥砍
Dodge 无 闪避
Interact 拾取 4 米内最近的东西或与之对话 相同

#TouchSkillButton

施放一个快捷栏格子中的技能或使用其中的物品。

字段 作用 默认值
Slot（slot） 快捷栏格子，从 0 开始。格子 0 是电脑上的 1 键。 0
Holds（holds） Skills、Consumables 或 Anything。格子中其他类型的内容显示为空。 Skills
Icon（icon） 显示技能或物品的图像。 在预制体中设置
Cooldown（cooldown） 随冷却递减的填充图像。 在预制体中设置
Cooldown Label（cooldownLabel） 剩余秒数：10 以下显示一位小数，以上显示整秒。 在预制体中设置
Amount Label（amountLabel） 背包中该物品的剩余数量。 在预制体中设置
Cancel Area（cancelArea） 拖动时显示；在它上方松开不会做任何事。 示例中的 X
Face（face） 按住时缩小的图形。 在预制体中设置
Aim Radius（aimRadius） 达到技能完整射程所需的拖动像素（以 1080p 计）。 160
Aim Start（aimStart） 触摸从点按转为瞄准之前的拖动像素（以 1080p 计）。 24
Tap Reach（tapReach） 超出技能射程多少米内，点按仍能找到敌人。 2
Pick Seconds（pickSeconds） 按住不动多少秒打开选择器。0：只有空按钮会打开它。 0.6
Unusable（unusable） 技能无法施放或物品用完时图标的色调。 灰色

#TouchSlotPicker

填充技能按钮的面板。每个条目是模板按钮的一个副本。

字段 作用 默认值
Panel（panel） 选择时显示。给它一个背景遮罩，让触摸不会传到游戏中。 在预制体中设置
Title（title） "Choose a skill" 或 "Choose a consumable"。 在预制体中设置
List（list） 条目放置的位置，通常是一个网格。 在预制体中设置
Entry Template（entryTemplate） 为每个条目复制的按钮。需要一个子对象 Icon 图像和一个 Name 标签；Amount 是可选的。 在预制体中设置
Current Color（currentColor） 按钮当前持有条目的颜色。 金色
Clear Button（clearButton） 清空按钮。 Empty this button
Close Button（closeButton） 关闭选择器。 X

#TouchChatButton

字段 作用 默认值
Start Hidden（startHidden） 聊天一开始是收起的。 开启
Badge（badge） 有未读消息行时显示。 在预制体中设置
Badge Label（badgeLabel） 数量。 在预制体中设置
Face（face） 聊天显示时变亮的图像。 在预制体中设置
Open Color（openColor） 聊天显示时图像的颜色。 浅金色

触控操作消失时，聊天会像在桌面上一样恢复。

#TouchLookArea

一个覆盖整个屏幕的透明图像，位于所有其他控件后面。它把对世界的触摸转换为输入：

  • 一根手指拖动写入 Look 轴（在自由摄像机和第三人称下转动摄像机）。
  • 两根手指捏合写入 Zoom 轴（在所有模式下缩放）。
  • 短暂的触摸是点按。
  • 停留在世界上的手指是按压，俯视角模式会朝它行走。
字段 作用 默认值
Tap Travel（tapTravel） 手指移动多少像素（以 1080p 计）内仍算作点按。 18
Tap Seconds（tapSeconds） 触摸持续多少秒内仍算作点按。 0.35

#TouchModes

让一个部件只在某些操作模式下保留。把它放在在某种模式中没有意义的按钮上，比如俯视角模式下的 Dodge。

字段 作用 默认值
Modes（modes） 显示此部件的模式：TopDown、FreeCamera、ThirdPerson。留空：全部模式。 空

#修改布局

#移动按钮或调整其大小

  1. 打开 Samples/Starter/Prefabs/TouchControls.prefab。
  2. 选中 Actions 下的部件（Attack、Activate、技能按钮、X）或根节点下的部件（Move Stick、Chat Button）。
  3. 移动或调整它的 Rect Transform。在 1920 × 1080 参考下，按钮宽度至少保持约 100 个单位，让拇指能按到。

#添加按钮

为自由摄像机和第三人称的玩家添加一个闪避按钮：

  1. 打开 TouchControls.prefab。
  2. 把 Prefabs/UI/Touch Button 拖到 Actions 下并摆放好。
  3. 把它的 Id 设为 Dodge，标签设为 "Dodge"。
  4. 添加一个 TouchModes 组件，Modes 设为 FreeCamera 和 ThirdPerson，让它在俯视角模式下隐藏。

#添加技能按钮

  1. 复制 Actions 下的一个技能按钮。
  2. 把 Slot 设为下一个快捷栏格子（第 6 个格子为 5），并按需设置 Holds。
  3. 把它的 Cancel Area 设为 X。

#供你自己的代码使用的按钮

给 TouchButton 一个你自己的 id 并读取它，或者把一个方法挂到 On Press 上：

if (TouchControls.Down("Jump")) Jump();      // pressed this frame
if (TouchControls.Held("Block")) Block();    // held
Vector2 move = TouchControls.Axis("Move");   // the stick

在读取你自己的按键之前检查 GameInstance.KeysOn，这样在仅使用 Touch 时它们保持关闭。见代码中的游戏模式。

#常见错误

  • 编辑器中不显示触控操作。 Input Layout 为 Auto，而 Game 视图不是 Simulator。使用 Touch And Keys，或使用 Simulator。
  • 手机上不显示触控操作。 Touch Controls Prefab 为空，或 Input Layout 为 Mouse And Keys。
  • 修改 HUD 后，某个 HUD 部件与控件重叠。 某个 Hud Change 路径不再匹配。在 Console 中查找 "Touch controls: no ... in the HUD" 并修正路径。
  • 手机上无法闪避。 示例没有闪避按钮；按上文所示添加一个。
  • 技能按钮一直是空的。 它们显示快捷栏中的内容。按住按钮或点按空按钮来选择技能，或者先在电脑上把技能放到快捷栏格子 1 到 4。
  • 键盘不起作用了。 Input Layout 为 Touch，它按设计会关闭游戏按键。带键盘的平板请使用 Touch And Keys。
  • 在 Play 模式下修改布局。 布局在游戏启动时读取。停止后再按 Play。
