游戏系统

玩家设置

玩家在 Settings 窗口中修改图形、声音、界面和操作，并通过游戏菜单离开世界、更换角色或退出游戏。本页介绍这两者、每个选项及其默认值、设置保存在哪里、声音和音乐如何跟随音量通道，以及如何添加你自己的选项。

#游戏菜单

按 Esc（没有窗口打开时）或点击右上角图标栏中的齿轮。菜单包含：

按钮 作用
Resume 关闭菜单
Settings 打开 Settings 窗口
Change character 离开世界，回到角色选择。在单人模式下显示为 Save and leave
Sign out 回到登录界面。仅限 MMO
Quit game 关闭游戏

离开、退出登录和退出游戏都会要求确认（"Leave the world and go back to your characters?"、"Sign out and go back to the login screen?"、"Quit the game?"）。角色处于战斗中时，提问会加上 "You are in combat."

Esc 先关闭打开的窗口或弹窗，只有在没有任何东西打开时才打开菜单。你在聊天中输入、回答确认框或打开 Settings 时，它不会打开菜单。见 HUD 与窗口。

Show FPS 开启时，游戏菜单还会在左上角显示帧数计数器。

#Settings 窗口

从游戏菜单打开，或用标题画面上的 Settings 按钮打开。它每页一个标签页：Graphics、Audio、Interface，以及在操作模式添加选项时出现的 Controls。更改会立即生效。每个标签页都有一个 Reset 按钮，会询问 "Put the page settings back as they came?"。

#设置保存在哪里

设置属于这台电脑，而不是账号：不会发送任何东西到服务器。窗口关闭或游戏退出时，它们以 JSON 格式保存到 PlayerPrefs 的 KitARPG.Options 键下。Controls 选项使用它们自己的 PlayerPrefs 键。

#Graphics

选项 选择 默认值
Display 全屏、独占全屏（仅 Windows）或窗口化。编辑器中不显示 当前模式
Resolution 屏幕支持的分辨率。编辑器中不显示 当前分辨率
Quality 项目的画质等级。下面几行会进一步调整它 项目当前等级
Vertical sync 与屏幕刷新率同步。防止画面撕裂；帧率限制会被忽略 开启
Frame limit 30、60、120、144、240 FPS 或 Unlimited Unlimited
Render scale 50% 到 150%，步长为 5。越低绘制的像素越少：更快，更柔和 100%
Anti-aliasing Off、2x、4x、8x（MSAA） 4x
Shadows Off、Low、Medium、High（阴影距离和阴影贴图分辨率） Medium
Textures Full、Half、Quarter Full
Post-processing 泛光、调色等 开启

URP 选项应用于运行时创建的渲染管线资源副本，因此你项目中的资源永远不会被写入。在编辑器中，退出 Play 会恢复画质等级和管线。后处理按摄像机关闭，原本就关闭了后处理的摄像机保持关闭。

#Audio

选项 作用 默认值
Master 调整所有声音的音量 80%
Music 标题和地图音乐 60%
Effects 战斗和世界音效 100%
Interface 按钮和提示音 100%
Ambience 场景中的固定声音，比如瀑布 80%
Mute in background 其他窗口获得焦点时没有声音 开启

音量从 0 到 100%，步长为 5。

#Interface

选项 作用 默认值
Interface scale 70% 到 150%。缩放所有随屏幕尺寸缩放的画布 100%
Damage numbers 在受到伤害的对象上方显示数字 开启
Player names 在玩家上方显示名字。你自己的名字只在俯视角模式下显示，因为在摄像机位于身后的模式中，它会挡住准星 开启
Monster health bars 怪物上方的血条 开启
Show FPS 左上角的帧数计数器 关闭

#Controls

操作模式会添加这个标签页。见操作模式。

选项 模式 选择 默认值
Movement 俯视角 Click and keys、Click only、Keys only 游戏设定的选择
Skills 全部 先显示范围再点击；或 Cast at once 先显示范围再点击
Mouse sensitivity 自由摄像机、第三人称 20% 到 300% 100%
Invert mouse 自由摄像机、第三人称 开或关 关闭
Turn with the camera 第三人称 角色朝向摄像机看的方向，以便横向移动 关闭

#声音和音乐

#音乐

字段 位置 作用
Title Music（titleMusic） Game Settings > Interface 在标题画面循环播放
Music（music） Game Database 中的每张地图 玩家在该地图上时循环播放。留空：继续播放之前的音乐

音乐在曲目之间用 1.5 秒淡入淡出，并跟随 Music 音量。

#音效

套件播放的所有声音都通过 GameAudio，音量为其通道音量乘以主音量：

  • GameAudio.PlayAt(clip, position, channel) 用于世界中的声音（默认为 Effects）。
  • GameAudio.Play(clip, channel) 用于没有位置的声音，比如按钮或升级（默认为 Interface）。

#场景中的环境声音

对于场景中固定的 AudioSource（火堆、河流），在它旁边添加一个 SoundChannelSource：

字段 作用 默认值
Channel（channel） Effects、Music、Interface 或 Ambience Ambience
Volume（volume） 音源自身的音量，0 到 1，在玩家设置之前应用 1

它让音源保持在其通道的音量，并跟随 Settings 中的更改。

#分步操作：添加你自己的选项

选项通过代码用 ClientOptions.Add 添加。窗口根据三个模板（下拉菜单、滑块和开关）构建各行，所以新选项不需要做任何 UI 工作。使用一个尚不存在的页面名称会添加一个标签页。

using Blunnyn.KitARPG.Client;
using UnityEngine;

public static class CameraShakeOption
{
    const string Pref = "Game.CameraShake";

    public static bool On => PlayerPrefs.GetInt(Pref, 1) == 1;

    [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterSceneLoad)]
    static void Register()
    {
        ClientOptions.Add(new ToggleOption
        {
            page = ClientOptions.Interface,
            label = "Camera shake",
            hint = "Shakes the camera on heavy hits.",
            get = () => On,
            set = on => PlayerPrefs.SetInt(Pref, on ? 1 : 0),
            reset = () => PlayerPrefs.DeleteKey(Pref),
        });
    }
}
类型 字段
ToggleOption get、set
SliderOption min、max（100）、step（5）、get、set、format（默认加上 %）
ChoiceOption choices、get、set
全部 page、label、hint、available（返回否时隐藏该选项）、reset（用于标签页的 Reset 按钮）

选项列表在每次 Play 开始时清空，所以像上面那样的 RuntimeInitializeOnLoadMethod 每次运行只注册一次，无论是否进行域重载。如果你改为在组件的 OnEnable 中添加选项，要像套件的操作模式那样先检查 ClientOptions.All.Contains(option)，否则每张地图都会再添加一次。见菜单与设置选项和域重载。

#修改窗口样式

游戏菜单（GameMenu）和 Settings 窗口（SettingsWindow）与其他窗口一样位于 HUD 预制体中。Settings 窗口有一个为每页复制的 Tab Template、标签页颜色（Tab On、Tab Off），以及三个行模板：一个 Label、一个 Hint 和一个 Value 下拉菜单；一个 Label、一个 Hint、一个 Value 滑块和一个 Amount 标签；一个 Label、一个 Hint 和一个 Value 开关。修改样式时保留这些子对象的名字。见 HUD 与窗口。

#单人模式与 MMO

两种模式下设置的工作方式相同。Sign out 只在 MMO 中出现，Change character 在单人模式下显示为 Save and leave。

#常见错误

  • 图形设置改了我项目的 URP 资源。 不会：游戏使用的是副本。如果 Play 之后编辑器中的画质看起来不对，检查 Project Settings 中项目的画质等级。
  • 某个声音不受音量滑块影响。 它是用普通的 AudioSource 或 PlayClipAtPoint 播放的。使用 GameAudio，或添加一个 SoundChannelSource。
  • 我的选项显示了两次。 它是从一个在每张地图上都会运行的组件中添加的。添加前先检查 ClientOptions.All.Contains。
