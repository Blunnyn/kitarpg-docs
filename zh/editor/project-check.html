Project Check

此页面尚未翻译，以英文显示。

Project Check looks through your project for problems that break the game, its saves or its builds: broken references, repeated ids, prefabs that can't go over the network, missing scenes, shop offers the game can't sell and more. It lists what it finds by area, with a button to select the cause and, for many problems, a button that fixes it. It also runs before every build.

#Where it is

  • KitARPG > Project Check (opens the page and runs a full check), or
  • the Project Check page in the KitARPG window (Ctrl/Cmd+Shift+K), under Project.

The sidebar shows the number of errors in red, or of warnings in orange when there are no errors. Overview shows the same result on its project check tile.

#When it runs

When What it checks
The KitARPG window opens Everything except the inside of map scenes, a moment after opening, so the window stays quick
KitARPG > Project Check or Check again Everything, including opening each map's scene on the side to check its contents
Before every build Everything except the inside of map scenes. Stops the build on errors unless you turn that off
After pressing a fix button Everything again

Checking scenes opens each map scene additively and closes it again if it wasn't open, so it takes longer in a big project.

#The page

Three tiles show the counts:

Tile Means
errors: break the game or its saves Fix these. Builds stop on them
warnings: worth a look The game runs, but something is probably not what you want
notes Information, such as items without icons or data the game can't reach

Under them:

  • Check again runs a full check.
  • Show notes: notes are hidden until you tick this.
  • Stop builds on errors (on by default): the check before each build stops the build when it finds errors. The choice is saved in your editor preferences.

Then the findings, one card per area, with the area name and a count. The card's color is its worst finding. Each finding has a colored dot, the message and up to two buttons:

  • Select selects and pings the asset, prefab or scene it is about.
  • A fix button, such as Add it or Use starter scenes, that fixes it. Assets are saved after the fix and the check runs again.

When nothing is found: "No problems found. The project is ready to play and build." (or how many notes are hidden).

#Every check

The checks run in this order. The tables list each message, its level, what it means and how to fix it. Messages show the real names of your assets in place of the ....

#Updates

Level Message Meaning and fix
Warning "Update title is missing. What it changes" The kit has something your game doesn't have yet. Apply adds only what is missing. See Updating the kit

#Input and Settings

Level Area Message Meaning and fix
Warning Input "...'s EventSystem has the UI module of the other input system, so menus may not take clicks." The scene's EventSystem uses the Input Manager module in a project that uses the Input System, or the other way around. Fix scenes swaps the module in every scene that needs it
Warning Settings "... overrides Game Settings on its Game Instance (fields), so changes in Game Settings don't reach that scene." The scene changed values on its copy of the network prefab. Fix scenes reverts those overrides so the scene uses Game Settings

Fix scenes asks to save open scenes first, fixes each scene, saves it and reopens what you had open.

#Text

Level Message Meaning and fix
Error "TextMesh Pro's essential resources aren't in the project, so every label in the kit's UI and sample has no font." Import TMP Essentials imports them

#Database

Level Message Meaning and fix
Error "No game database. Put one on the GameInstance of the network prefab, or build the starter sample." Build sample builds the starter sample, which brings one. Or set yours in Game Settings
Error Each problem the database reports, such as "Two player models use the id '...'", "Player model '...' has no classes, so nobody can pick it.", "'...' is used by both ... and ...", "... has no id.", "Map '...' has no scene.", "No damage elements: hits without an element can't be dealt or resisted.", "... is in Player Models but has no PlayerModel component." Open the Game Database and fix the entry named
Error "No start map: new characters have nowhere to appear." Set Start Map in the Game Database's Settings
Error "No gold currency: gold shows without a name or icon." Set Gold in the Game Database's Settings

#Ids

Level Message Meaning and fix
Error "... has no id, so saves can't point at it." Use the name makes an id from the asset's name
Warning "... has the id '...'. Ids read best as lowercase letters, digits, - and _." Rename the id, unless players already saved it
Error "... and ... are both Type '...'. Only one will be found." Two assets of the same kind share an id. Change one. Different kinds may share an id

#Unused data

Level Message Meaning and fix
Note "... (Type) isn't reached from the game database, so the game won't know it. List it in the database or reference it from something that is." The asset exists in the project but never in the game. Make entries from the Game Database page, or use its Collect referenced button after linking them

#Items

Level Message Meaning and fix
Warning "... stacks up to N but has random bonuses. Each copy keeps its own rolls, so copies never stack. Make the bonuses fixed or set Max Stack to 1." Make bonuses fixed turns each random bonus into a fixed one at the middle of its range

#References

Level Message Meaning and fix
Error "...: 'field' points at something that was deleted." A field shows "Missing" in the Inspector. Pick something else or clear it. Checked on every game data asset, and on every component in map scenes
Error "... has an effect or condition whose class no longer exists." A skill effect, item effect, condition or action was deleted or renamed in code. Restore the class, or remove the entry
Warning "Loot table ... has a drop with no item." Set the item or remove the drop
Warning "Shop ... has an entry with no item." Set the item or remove the entry
Error "...: ... has an option whose class no longer exists." An NPC in a map scene has an option whose class is gone

#Quests

Level Message Meaning and fix
Warning "Quest ... hands out ..., which isn't a quest item. It can be traded or sold, and then the quest can't be given up. Tick Quest Item on it." Giving up a quest takes its start items back. Tick Quest Item on the item

#Icons

Level Message Meaning and fix
Note "... has no icon." Render icons renders an icon for every item without one

#Shop

Level Message Meaning and fix
Error "Shop ... charges in ..., a premium currency. Premium currency is only spent at the in-game shop." An NPC shop uses the premium currency. Set it to gold or another normal currency
Error "Player model ... has no PlayerShop, so the shop can't open for it." Shown when the game has a premium currency. Apply the kit update "Shop on the player prefabs"
Error "... can't be read: ..." The shop catalog file isn't valid JSON
Warning "Shop offer ... problem. The Shop service skips it." The offer breaks a catalog rule, such as no id, no price or no items. Fix it on the Shop page
Warning "Two shop offers use the id '...'." Give one a new id
Warning "Shop offer ... charges in '...', which isn't a premium currency of the game database." Tick Premium on that currency, or build the starter sample for Gems
Warning "Shop offer ... sells '...', which the game database doesn't have." Fix the item or add it to the database
Warning "Shop offer ... sells a quest item, ..." Remove it from the offer

The shop checks read the catalog the Shop page edits (UserSettings/KitARPG/shop-conf.json), or the sample that comes with the Shop service when there is none. Catalog problems are warnings because the catalog belongs to the Shop service, not to the game's build.

#Guilds

Level Message Meaning and fix
Error "The guild hall map ... isn't instanced, so every guild would share one hall." Make it instanced ticks Instanced on the map
Error "The guild hall map ... isn't in the game database's maps, so no map server runs it." Add the map to the Maps list
Warning "The founding item ... is a quest item." Pick another item for founding guilds

#Network and Scripts

Level Area Message Meaning and fix
Error Network "Player model ... has no NetworkIdentity." Add it adds the component to the prefab
Error Network "Monster ... has no prefab, so it can't spawn." Set the monster's prefab
Error Network "..., the prefab of ..., has no NetworkIdentity." Add it
Error Network "..., the prefab of ..., has no Monster component." Add the Monster component to the prefab, or make it with the New monster assistant
Error Scripts "... has N missing script(s)." A prefab in Assets/Blunnyn or Assets/Game has components whose script is gone. Remove them in the prefab
Error Network "... has Component but no NetworkIdentity." A prefab has a networked component without a NetworkIdentity on it or a parent. Add it
Warning Network "... lists an empty spawnable prefab." The network manager prefab has an empty slot in its spawnable prefabs. Remove it
Error Network "... is spawnable in ... but has no NetworkIdentity." Add a NetworkIdentity to that prefab

#Scenes

Level Message Meaning and fix
Error "Build Settings has no scenes." Use starter scenes
Error "Build Settings lists ..., which doesn't exist." Remove the entry in File > Build Profiles
Warning "The first scene is ...; the kit starts at Title." Use starter scenes, or move Title to the top
Error "Map '...' names no scene. Pick its scene in the Game Database, on the map's page." Set the map's Scene
Error "Map '...' uses the scene '...', and no scene has that name. Make it, or fix the name on the map's page." Make the scene or fix the name
Error "Map '...' uses the scene '...', which isn't in Build Settings. Builds add it anyway; Play in the editor needs it listed." Add map scenes adds every map scene to Build Settings
Error "... has no SpawnPoint; players arriving at '...' have nowhere to stand." Add a Spawn Point to the scene. Full check only
Error "...: ... has N missing script(s)." An object in a map scene has missing scripts. Full check only
Error "...: ... and ... share the NPC id '...', so the server can't tell them apart." Give each NPC its own id. Full check only
Warning "...: spawner ... has no monster." Set the spawner's monster. Full check only

"Full check only" findings come from opening the scenes, so they show after Check again or KitARPG > Project Check, not in the quick check when the window opens.

#Validator

Level Message Meaning
Error "A check failed: ..." A check itself threw an error. The full error is in the Console

#Before every build

Every build, from the kit's menus or Unity's own Build window, runs the check first without opening scenes. When it finds errors and Stop builds on errors is on, it logs each error to the Console with [KitARPG] and stops the build with "KitARPG found N problem(s) in the project. See the Console or KitARPG > Project Check. The check can be turned off there."

警告

Turning off Stop builds on errors lets broken builds through. Use it only to test a build while you know what is wrong.

The kit also checks that each build only carries the code it should. That check is separate; see KitARPG > Check Build Separation in Menus and Security.

#Step by step: get to zero errors

  1. Open KitARPG > Project Check. It runs the full check.
  2. Work through the red cards first. Press the fix button where there is one; otherwise press Select and fix the asset by hand.
  3. Press Check again.
  4. Read the warnings. Fix the ones that matter to your game.
  5. Tick Show notes now and then to find data the game can't reach and items without icons.

#Adding your own checks

Add a method to ProjectValidator.Checks from an editor script, and it runs with the others, before builds too. Create > KitARPG > Scripts > Validator Check (Editor) makes a starting script. See Editor extensions.
