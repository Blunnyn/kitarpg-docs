Project Check

Project Check（项目检查）在你的项目中查找会破坏游戏、存档或构建的问题：失效的引用、重复的 id、无法通过网络传输的预制体、缺失的场景、游戏无法出售的商城商品等。它按领域列出发现的问题，提供选中原因的按钮，许多问题还有修复按钮。它也会在每次构建前运行。

#在哪里

  • KitARPG > Project Check（打开页面并运行完整检查），或
  • KitARPG 窗口（Ctrl/Cmd+Shift+K）中 Project 下的 Project Check 页面。

侧边栏以红色显示错误数，没有错误时以橙色显示警告数。Overview 的 project check 磁贴显示同样的结果。

#何时运行

时机 检查什么
KitARPG 窗口打开时 除地图场景内部外的所有内容，在打开后片刻运行，以保持窗口响应迅速
KitARPG > Project Check 或 Check again 所有内容，包括在后台打开每张地图的场景以检查其内容
每次构建前 除地图场景内部外的所有内容。发现错误时中止构建，除非你关闭了这个选项
按下修复按钮后 再次检查所有内容

检查场景时会以叠加方式打开每个地图场景，如果它原本没有打开则再关闭，因此在大项目中需要更长时间。

#页面

三个磁贴显示计数：

磁贴 含义
errors: break the game or its saves 修复这些。构建会因它们中止
warnings: worth a look 游戏可以运行，但某些东西可能不是你想要的
notes 信息，例如没有图标的物品或游戏无法访问的数据

其下方：

  • Check again 运行完整检查。
  • Show notes：勾选之前提示是隐藏的。
  • Stop builds on errors（默认开启）：每次构建前的检查发现错误时会中止构建。该选择保存在你的编辑器偏好设置中。

然后是检查结果，每个领域一张卡片，带有领域名称和计数。卡片的颜色取决于其中最严重的结果。每条结果有一个彩色圆点、消息以及最多两个按钮：

  • Select 选中并高亮它涉及的资源、预制体或场景。
  • 修复按钮，例如 Add it 或 Use starter scenes，用于修复它。修复后资源会被保存，检查会再次运行。

没有发现问题时："No problems found. The project is ready to play and build."（未发现问题。项目已可以游玩和构建。）（或显示隐藏了多少条提示）。

#所有检查

检查按以下顺序运行。表格列出每条消息、其级别、含义和修复方法。消息中的 ... 会显示你资源的真实名称。

#Updates

级别 消息 含义和修复
警告 "Update title is missing. What it changes" 套件有你的游戏还没有的东西。Apply 只添加缺失的部分。参见更新套件

#Input 和 Settings

级别 领域 消息 含义和修复
警告 Input "...'s EventSystem has the UI module of the other input system, so menus may not take clicks." 在使用 Input System 的项目中，场景的 EventSystem 使用了 Input Manager 模块，或者反过来。Fix scenes 在每个需要的场景中替换该模块
警告 Settings "... overrides Game Settings on its Game Instance (fields), so changes in Game Settings don't reach that scene." 场景修改了其网络预制体副本上的值。Fix scenes 还原这些覆盖，使场景使用 Game Settings

Fix scenes 会先要求保存已打开的场景，然后修复每个场景并保存，再重新打开你原来打开的场景。

#Text

级别 消息 含义和修复
错误 "TextMesh Pro's essential resources aren't in the project, so every label in the kit's UI and sample has no font." Import TMP Essentials 导入它们

#Database

级别 消息 含义和修复
错误 "No game database. Put one on the GameInstance of the network prefab, or build the starter sample." Build sample 构建入门示例，示例会带来一个数据库。或在 Game Settings 中设置你自己的
错误 数据库报告的每个问题，例如 "Two player models use the id '...'"、"Player model '...' has no classes, so nobody can pick it."、"'...' is used by both ... and ..."、"... has no id."、"Map '...' has no scene."、"No damage elements: hits without an element can't be dealt or resisted."、"... is in Player Models but has no PlayerModel component." 打开 Game Database 并修复所指的条目
错误 "No start map: new characters have nowhere to appear." 在 Game Database 的 Settings 中设置 Start Map
错误 "No gold currency: gold shows without a name or icon." 在 Game Database 的 Settings 中设置 Gold

#Ids

级别 消息 含义和修复
错误 "... has no id, so saves can't point at it." Use the name 由资源名称生成 id
警告 "... has the id '...'. Ids read best as lowercase letters, digits, - and _." 重命名 id，除非玩家已经保存了它
错误 "... and ... are both Type '...'. Only one will be found." 同类的两个资源共用一个 id。修改其中一个。不同类型可以共用 id

#Unused data

级别 消息 含义和修复
提示 "... (Type) isn't reached from the game database, so the game won't know it. List it in the database or reference it from something that is." 该资源存在于项目中，但从未进入游戏。从 Game Database 页面创建条目，或在关联它们之后使用其 Collect referenced 按钮

#Items

级别 消息 含义和修复
警告 "... stacks up to N but has random bonuses. Each copy keeps its own rolls, so copies never stack. Make the bonuses fixed or set Max Stack to 1." Make bonuses fixed 把每项随机加成变为其范围中间值的固定加成

#References

级别 消息 含义和修复
错误 "...: 'field' points at something that was deleted." 某个字段在 Inspector 中显示 "Missing"。选择其他东西或清空它。对每个游戏数据资源以及地图场景中的每个组件都会检查
错误 "... has an effect or condition whose class no longer exists." 某个技能效果、物品效果、条件或动作在代码中被删除或重命名。恢复该类，或删除该条目
警告 "Loot table ... has a drop with no item." 设置物品或删除该掉落项
警告 "Shop ... has an entry with no item." 设置物品或删除该条目
错误 "...: ... has an option whose class no longer exists." 地图场景中某个 NPC 的选项所属的类已不存在

#Quests

级别 消息 含义和修复
警告 "Quest ... hands out ..., which isn't a quest item. It can be traded or sold, and then the quest can't be given up. Tick Quest Item on it." 放弃任务会收回其初始物品。在该物品上勾选 Quest Item

#Icons

级别 消息 含义和修复
提示 "... has no icon." Render icons 为每个没有图标的物品渲染图标

#Shop

级别 消息 含义和修复
错误 "Shop ... charges in ..., a premium currency. Premium currency is only spent at the in-game shop." 某个 NPC 商店使用了付费货币。把它设为金币或其他普通货币
错误 "Player model ... has no PlayerShop, so the shop can't open for it." 游戏有付费货币时显示。应用套件更新 "Shop on the player prefabs"
错误 "... can't be read: ..." 商城目录文件不是有效的 JSON
警告 "Shop offer ... problem. The Shop service skips it." 该商品违反了目录规则，例如没有 id、没有价格或没有物品。在 Shop 页面中修复
警告 "Two shop offers use the id '...'." 给其中一个新的 id
警告 "Shop offer ... charges in '...', which isn't a premium currency of the game database." 在该货币上勾选 Premium，或构建入门示例以获得 Gems
警告 "Shop offer ... sells '...', which the game database doesn't have." 修正物品或把它加入数据库
警告 "Shop offer ... sells a quest item, ..." 把它从商品中移除

商城检查读取 Shop 页面编辑的目录（UserSettings/KitARPG/shop-conf.json），没有时读取 Shop 服务自带的示例。目录问题是警告，因为目录属于 Shop 服务，而不属于游戏构建。

#Guilds

级别 消息 含义和修复
错误 "The guild hall map ... isn't instanced, so every guild would share one hall." Make it instanced 在该地图上勾选 Instanced
错误 "The guild hall map ... isn't in the game database's maps, so no map server runs it." 把该地图加入 Maps 列表
警告 "The founding item ... is a quest item." 为创建公会选择其他物品

#Network 和 Scripts

级别 领域 消息 含义和修复
错误 Network "Player model ... has no NetworkIdentity." Add it 把该组件添加到预制体上
错误 Network "Monster ... has no prefab, so it can't spawn." 设置怪物的预制体
错误 Network "..., the prefab of ..., has no NetworkIdentity." Add it
错误 Network "..., the prefab of ..., has no Monster component." 把 Monster 组件添加到预制体上，或用 New monster 向导创建它
错误 Scripts "... has N missing script(s)." Assets/Blunnyn 或 Assets/Game 中的某个预制体有脚本已丢失的组件。在预制体中移除它们
错误 Network "... has Component but no NetworkIdentity." 某个预制体有网络组件，但它自身或父对象上没有 NetworkIdentity。Add it
警告 Network "... lists an empty spawnable prefab." 网络管理器预制体的可生成预制体中有一个空位。移除它
错误 Network "... is spawnable in ... but has no NetworkIdentity." 为该预制体添加 NetworkIdentity

#Scenes

级别 消息 含义和修复
错误 "Build Settings has no scenes." Use starter scenes
错误 "Build Settings lists ..., which doesn't exist." 在 File > Build Profiles 中移除该条目
警告 "The first scene is ...; the kit starts at Title." Use starter scenes，或把 Title 移到最前
错误 "Map '...' names no scene. Pick its scene in the Game Database, on the map's page." 设置地图的 Scene
错误 "Map '...' uses the scene '...', and no scene has that name. Make it, or fix the name on the map's page." 创建该场景或修正名称
错误 "Map '...' uses the scene '...', which isn't in Build Settings. Builds add it anyway; Play in the editor needs it listed." Add map scenes 把每个地图场景加入 Build Settings
错误 "... has no SpawnPoint; players arriving at '...' have nowhere to stand." 在场景中添加一个 Spawn Point。仅完整检查
错误 "...: ... has N missing script(s)." 地图场景中的某个对象有丢失的脚本。仅完整检查
错误 "...: ... and ... share the NPC id '...', so the server can't tell them apart." 给每个 NPC 自己的 id。仅完整检查
警告 "...: spawner ... has no monster." 设置刷怪点的怪物。仅完整检查

"仅完整检查"的结果来自打开场景，因此在 Check again 或 KitARPG > Project Check 之后才显示，窗口打开时的快速检查中不会出现。

#Validator

级别 消息 含义
错误 "A check failed: ..." 某项检查本身抛出了错误。完整错误在 Console 中

#每次构建前

每次构建，无论来自套件的菜单还是 Unity 自己的 Build 窗口，都会先运行检查（不打开场景）。当它发现错误且 Stop builds on errors 开启时，会把每个错误以 [KitARPG] 记录到 Console，并以 "KitARPG found N problem(s) in the project. See the Console or KitARPG > Project Check. The check can be turned off there." 中止构建。

警告

关闭 Stop builds on errors 会让有问题的构建通过。只在你清楚问题所在、只是想测试构建时使用。

套件还会检查每个构建只携带它应有的代码。那是另一项检查；参见菜单中的 KitARPG > Check Build Separation 以及安全。

#分步操作：做到零错误

  1. 打开 KitARPG > Project Check。它会运行完整检查。
  2. 先处理红色卡片。有修复按钮的就按下；否则按 Select 并手动修复该资源。
  3. 按 Check again。
  4. 阅读警告。修复对你的游戏重要的那些。
  5. 不时勾选 Show notes，找出游戏无法访问的数据和没有图标的物品。

#添加你自己的检查

在编辑器脚本中向 ProjectValidator.Checks 添加一个方法，它就会与其他检查一起运行，构建前也会运行。Create > KitARPG > Scripts > Validator Check (Editor) 会生成一个起始脚本。参见编辑器扩展。
