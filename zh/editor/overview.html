Overview

Overview（概览）是 KitARPG 窗口的第一个页面。它告诉你项目是否已可以游玩，按顺序列出剩下要做的事并为每一步提供按钮，还把 Play 和最常用的工具集中在一处。

#在哪里

打开 KitARPG 窗口（KitARPG > Open KitARPG 或 Ctrl/Cmd+Shift+K），在侧边栏顶部选择 Overview。有等待应用的套件更新时，侧边栏会在 Overview 旁显示其数量。

#页头

页面以标题 "KitARPG" 和一行 "Everything for your game in one place. Pick a page on the left, or start here."（游戏所需的一切都在这里。在左侧选择一个页面，或从这里开始。）开头。其下方：

  • Version，后面是你安装的套件版本。
  • What's new，一个链接，打开列出每个版本（最新的在前）的更新日志窗口。从 KitARPG > What's New 也会打开同一个窗口。

#To do

当你的项目距离可玩还差某些东西时，会出现一张标题为 To do 的橙色卡片，附有一行 "In order. Each button does that step."（按顺序。每个按钮完成对应的一步。）每一行有一个指示灯、一个标题、一行详情和一个按钮。从上到下逐一完成。

没有剩余事项时，卡片会被一行绿色文字取代：

  • 单人模式："Everything is ready to play."
  • MMO："Everything is ready: services up, map server current, nothing missing."

可能出现的行，按列出顺序：

行 何时显示 按钮 按钮的作用
1 kit update 或 N kit updates 套件添加了你的游戏还没有的东西。详情会列出每项更新，并说明你手动修改的内容会保留 Apply 显示一个对话框，列出每项更新及其具体改动，然后按顺序应用它们。参见更新套件
N problem(s) in the project 上次项目检查发现了错误。"Builds stop on them."（构建会因它们中止。） Review 打开 Project Check
Build the services 仅 MMO。Login、Central、Shop 和启动器尚未编译。构建期间，详情显示 "Building..."，按钮隐藏 Build 对服务解决方案运行 dotnet build
The services didn't build 仅 MMO。上次构建失败。详情显示错误行 Try again 再次构建
Build the map server 仅 MMO，当至少有一张地图从地图服务器构建运行，并且该构建缺失、缺少某张地图的场景，或比构建它所用的某个脚本、场景或程序集定义更旧时显示。详情会说明是哪种情况。如果服务正在运行，还会加上 "Restart the services after it." Build 为你编辑器所在平台（Mac 或 Windows）构建地图服务器
Start the services 仅 MMO。服务已构建但未运行 Start 在本机启动 Login、Central 和地图
Restart the services 仅 MMO，警告。服务运行的代码或地图服务器比当前构建的旧 Restart 停止服务并重新启动
No map reached Central 仅 MMO，错误。Central 已响应超过 25 秒，但没有任何地图注册。玩家无法进入 Build 或 Open 地图服务器构建过期时显示 Build；构建后重启。否则 Open 前往 Play & Servers，其日志会说明原因
Start the shop 仅 MMO。项目中有 Shop 服务，启动器设置中商城已开启，In-game shop 模块已开启，服务已构建但未运行 Start 单独启动 Shop 服务。参见 Shop
提示

服务和地图服务器相关的行与 Play & Servers 所做的检查相同，只是集中在一个列表里。如果你想看完整的详情，请改为在 Play & Servers 中操作。

#状态磁贴

To do 卡片下方有四个磁贴。点击磁贴可打开对应页面。

磁贴 取值 打开
How the game runs Single player、MMO，没有设置资源时为 Not set Play & Servers
Services 单人模式中为 Not needed；MMO 中为 Running（Login 和 Central 有响应）、Starting 或 Stopped Play & Servers
Project check 首次检查运行时为 ...，或 N errors、N warnings、All good Project Check
Modules on 11 of 15 样式的计数，找不到 Game Instance 时为 None Modules

#Play

Play 卡片随模式变化：

模式和状态 卡片文字 按钮
单人模式 "The editor hosts the world and plays it." ▶ Play 打开 Title 场景并以单人游戏进入 Play 模式
MMO，服务已停止 "Start the services, then play as a client." Start services 打开 Play & Servers，在那里启动服务。Play with two players
MMO，服务正在运行 "The services are up. Play joins them as a client." ▶ Play 打开 Title 场景并作为本地服务的客户端游玩。Play with two players

Play with two players 会打开第二个编辑器，并用测试账号让两边都登录。它需要 Unity 的 Multiplayer Play Mode 包，在 Play 模式下显示为灰色。参见双人游玩。

编辑器已在 Play 模式时，以及 MMO 中服务已停止时，▶ Play 显示为灰色。

#Game data

Game data 卡片显示你的游戏数据库路径和六个计数：Classes、Skills、Items、Monsters、Quests 和 Maps。计数包括数据库通过引用访问到的条目，而不仅是其列表中的条目。

如果数据库有问题，一行橙色文字会显示 "N problem(s) in the data. The database page lists them."（数据中有 N 个问题。数据库页面会列出它们。）

按钮：

  • Open the database 打开 Game Database。
  • Game settings 打开 Game Settings。

当项目还没有游戏数据库时，卡片显示 "No game database yet." 并提供 Open the game database，你可以在那里创建一个。

#Tools

工具 按钮 作用
Starter sample Build sample 或 Start over 构建入门示例：Title、Town 和 Forest 场景、一个副本、网络预制体、玩家预制体、整个界面和示例数据。示例已存在时，按钮显示为 Start over 并会先询问，因为它会从头重新制作示例的场景、预制体和数据，对它们的修改会丢失。你在其他位置的资源会保留
Game data for the services Export 把 gamedata.json 写入服务源码的 Login 文件夹，供你手动运行的服务使用。Play & Servers 每次启动服务时都会写入自己的副本，因此本地游玩不需要这个
Item icons Render icons 为每个没有图标的物品渲染图标。与 KitARPG > Render Missing Item Icons 相同
Setup wizard Open 再次运行最初的步骤：游戏的运行方式，然后一键完成图形、字体和示例场景
Documentation Open 在浏览器中打开本文档，使用包内的副本（Documentation/Web），当编辑器语言为英语、西班牙语、葡萄牙语或中文时使用该语言。可离线使用。与 KitARPG > Documentation 相同
警告

Start over 不是获取新版套件所添加内容的方式。它会重建示例，并丢失你对示例 HUD、预制体、场景和数据所做的每项修改。请改用 To do 卡片中的套件更新：它们只添加缺失的东西。

#单人模式和 MMO

  • 在单人模式中，To do 卡片只显示套件更新和项目错误。没有需要设置的服务、地图服务器或商城。
  • 在 MMO 中，该卡片会引导你构建服务、构建地图服务器、启动服务和启动商城。

#常见错误

  • 构建新地图后出现 "No map reached Central"。 地图服务器构建中还没有新场景。按 Build，等待构建完成，然后重启服务。
  • Services 磁贴一直停在 Starting。 打开 Play & Servers 查看日志。端口被占用或缺少 .NET 10 SDK 是常见原因。
  • Project check 长时间显示 "..."。 检查在窗口打开时运行一次。非常大的项目需要几秒钟；这次快速检查不会打开场景。
