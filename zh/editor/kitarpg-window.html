编辑器

KitARPG 窗口

KitARPG 窗口把套件的所有工具集中在一处：左边是带有各个页面的侧边栏，右边是打开的页面。本页解释窗口如何运作、每个页面的用途，以及侧边栏角标的含义。

#打开窗口

可以用以下任一方式：

  • Unity 菜单栏中的 KitARPG > Open KitARPG。
  • 快捷键 Ctrl/Cmd+Shift+K。
  • 任一页面菜单：KitARPG > Play and Servers、KitARPG > Game Database、KitARPG > Game Settings、KitARPG > Modules、KitARPG > Shop 和 KitARPG > Project Check 会打开窗口并定位到该页面。

该窗口是一个普通的 Unity 编辑器窗口，标题为 "KitARPG"。你可以像其他窗口一样把它停靠在 Inspector 或 Scene 视图旁边。它的最小尺寸是 560 x 420 像素。

Setup Wizard 完成时会自动打开该窗口。参见 Setup wizard。

#侧边栏

侧边栏顶部显示 "KitARPG" 和 "by Blunnyn"。下面是分为三组的页面：

分组 页面 用途
（无标题） Overview 项目的进展、To do 列表、Play 以及常用工具的快捷方式
（无标题） Play & Servers 单人模式或 MMO、运行各自的步骤、服务及其日志
Game Game Database 游戏的每个职业、物品、技能、怪物、任务和地图
Game Game Settings 游戏玩法：背包、掉落、战斗、恢复、死亡、聊天、昼夜、邮件
Game Shop 游戏内商城：Shop 服务、其商品和真实货币产品
Game Modules 开启或关闭套件的整个系统
Project Project Check 失效的引用、重复的 id、网络预制体以及地图需要的场景

在侧边栏底部的细线下方，Setup wizard 按钮会在独立窗口中打开 Setup wizard。向导和 PostgreSQL 设置是仅有的以独立窗口打开的套件工具。

#折叠侧边栏

侧边栏右上角的小按钮可以折叠它：

  • «（提示 "Icons only"）把侧边栏缩小为图标。把鼠标悬停在图标上可以看到页面名称。
  • »（提示 "Show names"）恢复显示名称。

该选择保存在你的编辑器偏好设置中，因此在每个项目中以及重启 Unity 后都保持不变。

#角标

有些页面会在名称旁显示一个小胶囊标签。侧边栏折叠时，它会变成图标上的彩色圆点。

页面 角标 含义
Overview 橙色数字 等待应用的套件更新。参见更新套件
Play & Servers 绿色 On MMO 模式，且 Login 和 Central 都有响应
Play & Servers ... MMO 模式，服务已启动但 Login 或 Central 尚未响应
Game Database 橙色数字 游戏数据中的问题，例如两个条目 id 相同，或某个模型没有职业
Shop 绿色 On 本机上的 Shop 服务有响应
Modules 11/15 样式 开启了多少模块，仅在至少有一个关闭时显示
Project Check 红色数字 上次检查发现的错误
Project Check 橙色数字 上次检查发现的警告，在没有错误时显示

没有角标表示该页面没有需要你处理的事情。

#页面区域

大多数页面绘制在一个居中、最宽 860 像素、整体滚动的列中。Game Database 使用整个宽度来显示它的三栏。

窗口打开时，页面每秒刷新约十次，因此服务指示灯、角标和计数会自动更新。搜索项目比较慢，所以需要查找资源的页面（网络预制体、游戏数据库、套件更新）每隔几秒才查找一次，而不是每帧都查找。

在本次编辑器会话期间，窗口会记住你上次打开的页面。Unity 重启后，它会打开 Overview。

#页面的外观

每个页面都使用相同的元素，所以你只需学一次：

  • 卡片：带有标题和下方一行简短说明的圆角框。金色边框的卡片是现在要处理的；橙色的则需要注意。

  • 状态行：一个彩色指示灯、一个标题、一行详情，右侧通常还有一个按钮。指示灯的含义：

    指示灯 含义
    绿色带勾号 已完成或正在运行
    橙色带 ! 警告
    红色带 ! 错误
    金色，闪烁 正在工作，例如构建或启动中
    灰色 待处理、已关闭或不需要；详情行会说明是哪种

  • 胶囊标签：小标签，例如 Done、To do、Locked 或一个计数。

  • 开关：开启和关闭的切换，在 Modules 和 Shop 中使用。

  • 主按钮以金色强调色填充；次按钮只有轮廓。

游戏数据资源在普通的 Inspector 中也使用同样的卡片：每个 GameData 资源都会显示一个包含其图标、名称、类型和 id 的标题，每组字段开始处是一张新卡片。

#添加你自己的页面

页面是编辑器程序集中继承自 KitPage 的类。窗口会自动找到每个这样的类并把它加入侧边栏，按其 Group 和 Order 排序。Create > KitARPG > Scripts > KitARPG Window Page (Editor) 会生成一个起始脚本。参见编辑器扩展。

#常见错误

  • 脚本出错后窗口打开为空或停在错误的页面。 先修复 Console 中的编译错误；脚本编译完成后窗口才能找到它的页面。
  • 在 Play 中修改无法保存。 Game Settings 和 Modules 在 Play 模式下显示为灰色。先停止 Play 再修改。
