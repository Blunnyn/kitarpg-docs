Game Settings

Game Settings（游戏设置）保存你游戏中不属于某个物品、怪物或地图的规则：操控模式、界面、背包、掉落、经济、游戏内商城、服务器倍率、战斗、恢复、死亡、聊天过滤、日志、昼夜、邮件和 GM 命令。本页列出每项设置及其默认值。

#在哪里

  • KitARPG > Game Settings，或
  • KitARPG 窗口（Ctrl/Cmd+Shift+K）中的 Game Settings 页面。

#设置保存在哪里

这些设置是网络预制体上 Game Instance 组件（GameInstance）的字段。在入门示例中，该预制体是 KitNetwork。客户端和服务器构建都携带它，因此两者始终一致。

页面会自动找到该预制体。顶部一行显示 "Saved in KitNetwork."（预制体的名称），并附有两个按钮：

  • Select prefab 在 Project 窗口中选中并高亮该预制体。
  • Modules 打开 Modules 页面。模块开关属于同一个组件，但在那里编辑。

每次修改都会立即保存预制体。没有 Apply 按钮。

如果找不到 Game Instance，页面会显示 No GameInstance found（"It sits on the network prefab. Build the starter sample, or add one."，即它位于网络预制体上。请构建入门示例或添加一个。）以及 Open the setup wizard。

警告

在 Play 模式下无法更改设置。字段显示为灰色，页面提示 "Stop Play to change the settings."。请先停止 Play。

注意

如果某个场景中的 Game Instance 带有覆盖值，它不会看到你在这里所做的修改。Project Check 会报告（"... overrides Game Settings on its Game Instance"），Fix scenes 会移除这些覆盖。参见 Project Check。

#设置项

页面以卡片显示字段，每组一张。下面的默认值是新建 Game Instance 的初始值；入门示例会为你填好预制体和资源字段（HUD、触屏操控、镜头、商城美术）。

#Game

字段 作用 默认值
Database（database） 游戏读取的游戏数据库。参见 Game Database None

#Game mode

字段 作用 默认值
Control Mode（controlMode） 游戏的玩法：Top-down (click or keys)，暗黑破坏神风格；Free camera (cursor, right button turns)；或 Third person (crosshair aim)，由鼠标转向。服务器和客户端必须一致：地图会拒绝其他模式的客户端。你的代码注册的模式也会显示在列表中 Top-down
Third Person Camera（thirdPersonCamera） 第三人称模式的 Camera Settings 资源。可在游玩时编辑以试验效果；修改会保留 None
Free Camera（freeCamera） 自由视角模式的 Camera Settings 资源。可在游玩时编辑以试验效果；修改会保留 None

参见操控模式。

#Interface

字段 作用 默认值
Hud Prefab（hudPrefab） 包含 HUD 和游戏窗口的 Canvas。在客户端上创建一次并在地图之间保留。留空：由场景自带 None
Input Layout（inputLayout） 用什么来玩游戏。Auto：手机和平板上用触屏，其他设备用鼠标和键盘。Mouse And Keys。Touch：只有屏幕控件，游戏按键关闭。Touch And Keys：显示触屏控件并保持键盘可用，适用于带键盘的平板或在编辑器中试用 Auto
Touch Controls Prefab（touchControlsPrefab） 包含屏幕控件的 Canvas，像 HUD 一样在地图之间保留 None
Item Details On Hover（itemDetailsOnHover） 指向物品时显示其数值。关闭：点击物品才能看到 Off
Title Music（titleMusic） 在标题界面循环播放。每张地图在 Game Database 中设置自己的音乐 None

参见 HUD 与窗口和触屏操控。

#Bag

字段 作用 默认值
Bag Mode（bagMode） Slots：固定数量的格子。Weight：任何东西都能放，直到达到随负重数值增长的重量上限 Slots
Bag Slots（bagSlots） Slots 模式下背包的格子数 40
Weight Mode Slots（weightModeSlots） Weight 模式：背包能容纳的不同堆叠数，使其不会无限增长 200
Carry Weight（carryWeight） Weight 模式：任何人都能携带的重量。装备和属性会增加负重数值 1000
Bank Slots（bankSlots） 仓库的格子数，账号的所有角色共享。它没有重量限制 80

参见背包与仓库。

#Loot

字段 作用 默认值
Loot Mode（lootMode） 玩家如何获得怪物的掉落。Ground：每个物品落在怪物旁边。Corpse：物品留在尸体中，点击尸体打开拾取窗口。Automatic：物品直接进入背包，放不下的落在地上。只有获得击杀的玩家能看到 Ground
Auto Gold（autoGold） 金币直接给玩家。关闭：金币像物品一样掉落，在地上或尸体中 On

参见掉落。

#Economy

字段 作用 默认值
Players Sell To Npcs（playersSellToNpcs） 商店收购玩家带来的东西。关闭：不能向 NPC 出售任何东西；物品在玩家之间、在市场或在锻造台流转，掉落永远不会变成金币。单个商店仍可自行拒绝 Off
Market Fee Percent（marketFeePercent） 在市场上架一件商品需支付的标价百分比，至少为 1。它会把金币移出游戏。0 到 50 2

参见 NPC 商店和市场。

#Shop

字段 作用 默认值
Shop Art（shopArt） 游戏内商城卡片和横幅的图片，按商品指定的键查找。你第一次选择图片时，Shop 页面会创建一个 None
Shop Top Up Url（shopTopUpUrl） 玩家购买付费货币的页面，由其余额旁的 + 打开。留空则隐藏该按钮 空
Shop Auto Take（shopAutoTake） 商城购买和赠礼到达时直接进入背包。关闭时或背包已满时，它们留在邮件中等待 On

参见 Shop 页面和商城。

#Rates

字段 作用 默认值
Experience Rate（experienceRate） 在整个服务器上，击杀和任务获得的经验乘以该值。2 为双倍 1
Loot Rate（lootRate） 每个物品的掉落几率乘以该值。2 表示掉落频率翻倍，最高为必定掉落 1
Gold Rate（goldRate） 怪物掉落的金币乘以该值 1

它们都不能低于 0。GM 可以用 /rates 命令在这些倍率之上举办限时倍率活动。参见 GM 命令。

#Combat

字段 作用 默认值
Line Of Sight（lineOfSight） 什么能阻止攻击、技能和怪物穿墙看到目标。Off：可以穿过任何东西。Nav Mesh：NavMesh 中的空洞会阻挡（墙壁、房屋、树干）；不需要碰撞体。Colliders：视线阻挡层上的碰撞体会阻挡 Nav Mesh
Sight Blockers（sightBlockers） Colliders 模式：阻挡视线的层。角色永远不会阻挡 Default 层
Heal Threat（healThreat） 治疗怪物正在战斗的对象时，每治疗一点所获得的怪物仇恨比例 0.5
Threat Switch（threatSwitch） 当另一名战斗者的仇恨超过当前目标的仇恨达到这个倍数时，会吸引怪物的注意。小于 1 的值按 1 计 1.1
Monsters Sleep Unseen（monstersSleepUnseen） 没有任何玩家能看到的怪物会停止思考，直到有玩家靠近。在大地图上节省服务器时间 On

参见战斗。

#Recovery

字段 作用 默认值
Combat Seconds（combatSeconds） 玩家在最后一次受到或造成攻击（包括未命中和被格挡的攻击）后保持战斗状态的秒数 6
Regen In Combat（regenInCombat） 战斗中继续恢复生命值和法力值。关闭：等到战斗结束 On
Out Of Combat Regen（outOfCombatRegen） 战斗外的恢复乘以该值。3 表示两场战斗之间恢复速度为三倍 1
Level Up Restores Health（levelUpRestoresHealth） 升级时回满生命值 On
Level Up Restores Mana（levelUpRestoresMana） 升级时回满法力值 On

#Death

字段 作用 默认值
Death Experience Loss（deathExperienceLoss） 玩家在重生点复活时失去的经验，占当前等级所需经验的百分比。永远不会降级，盟友的复活可以免除损失。0 到 100 5
Pvp Death Costs Experience（pvpDeathCostsExperience） 被其他玩家杀死的玩家也会损失经验。决斗永远没有损失 Off
Respawn Health（respawnHealth） 玩家在重生点复活时的生命值百分比。1 到 100 100
Respawn Mana（respawnMana） 玩家在重生点复活时的法力值百分比。0 到 100 100

参见恢复与死亡。

#Chat filter

字段 作用 默认值
Blocked Words（blockedWords） 任何人都不能说的词，每个条目一个。以 * 结尾则同时拦截以它开头的词 空
Blocked Words File（blockedWordsFile） 更多屏蔽词，每行一个，用于长列表。一个文本资源 None
Chat Filter Mode（chatFilterMode） Mask 用星号遮盖屏蔽词；Block 丢弃整行 Mask

参见聊天。

#Logs

字段 作用 默认值
Log Loot From（logLootFrom） 此稀有度或更高的掉落会记入游戏日志：Common、Magic、Rare、Epic 或 Legendary Rare
Log Chat（logChat） 每行聊天也记入游戏日志。举报始终会附带其前后的聊天行 Off

参见游戏日志与举报。

#Day and night

字段 作用 默认值
Day Minutes（dayMinutes） 一个完整游戏日持续的现实分钟数。0 会让时钟停在固定时刻 48
Day Start Hour（dayStartHour） 时钟开始的时刻，用于让游戏日相对现实时间偏移。0 到 24 8
Fixed Hour（fixedHour） 时钟不走时显示的时刻。0 到 24 12
Night From（nightFrom） 夜晚从这个时刻开始 20
Night To（nightTo） 夜晚在这个时刻结束 6

Day and night 模块关闭时，始终是固定时刻。参见昼夜。

#Mail

字段 作用 默认值
Mail Anywhere（mailAnywhere） 在任何地方阅读和发送邮件。关闭：只能在带有邮箱选项的 NPC 处 On
Mail Postage（mailPostage） 寄一封信所需的金币 10
Mail Postage Per Item（mailPostagePerItem） 每附带一个物品额外需要的金币 5
Mail Items（mailItems） 一封信能携带的物品数。Central 的 MaxMailItems 设置应与之一致 5

参见邮件。

#Commands

字段 作用 默认值
Single Player Commands（singlePlayerCommands） 在单人世界中，玩家可以像使用作弊码一样使用所有 GM 命令。在线时由账号的职位决定 On
Gm Command Levels（gmCommandLevels） 每个命令要求的 GM 等级（当不同于其默认值时）。每个条目有 Command（不带斜杠的名称，例如 item）和 Level：1 玩家、2 版主、3 游戏管理员、4 管理员。更改职位（/role）始终需要 4 空

参见 GM 工具。

#分步操作：更改一项设置

  1. 如果 Play 模式正在运行，先停止它。
  2. 打开 KitARPG > Game Settings。
  3. 找到对应卡片并修改字段。预制体会自动保存。
  4. 单人模式：按 Play；修改即生效。
  5. MMO：在 Play & Servers 中重新构建地图服务器并重启服务，因为地图服务器从其构建运行。你分发的客户端也需要新的构建。

#单人模式和 MMO

  • 在单人模式中，游戏直接从构建中的预制体读取这些设置。
  • 在 MMO 中，地图服务器执行游戏规则（掉落、倍率、战斗、恢复、死亡、邮费），客户端使用界面设置。两者都从各自构建中读取同一个预制体，因此修改设置后两者都要重新构建。操控模式在两端必须一致。
  • 少数值在服务中有对应的设置，例如 Mail Items 和 Central 的 MaxMailItems。参见配置。

#提示

  • 先在单人模式中试验倍率和恢复值；它几秒内就能启动。
  • 使用 Gm Command Levels 让版主使用默认仅限管理员的命令，无需修改代码。
  • 对于硬核服务器，把 Death Experience Loss 设高，并开启 Pvp Death Costs Experience。

#常见错误

  • 在场景中而不是在预制体上编辑 Game Instance。 场景会保留一个覆盖值，Game Settings 将无法再影响它。Project Check 会找到它。
  • 修改设置后用旧的地图服务器构建测试。 服务器仍是旧值。请重新构建。
  • 客户端和服务器构建的操控模式不同。 地图会以模式不匹配为由拒绝客户端。
