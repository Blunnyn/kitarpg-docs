快速入门：单人模式

从完成 Setup Wizard 到在示例城镇中四处走动、战斗、存档，再到构建一个可以交给朋友的游戏。单人模式不需要 Unity 以外的任何东西。

#单人模式是什么

在单人模式中，游戏自己托管自己的世界。玩家的电脑同时是客户端和地图服务器，角色保存在这台电脑上的一个 SQLite 文件中。没有登录界面，没有 Login 或 Central 服务，也没有需要设置的数据库。地图、数据和代码与 MMO 相同，因此游戏以后可以变成 MMO。

#分步操作：在编辑器中游玩

  1. 用 KitARPG > Open KitARPG 或 Ctrl/Cmd+Shift+K 打开 KitARPG 窗口。

  2. 进入 Play & Servers。

  3. 在顶部确认选中的是 Single player 卡片。如果选中的是 MMO，点击 Single player。

  4. Step 1, Check the project. 两行必须是绿色：

    行 正常情况 否则
    Scenes in Build Settings 第一个场景是 Title。该行会列出场景 按下 Use starter scenes
    SQLite library for this platform "Found in Plugins/SQLite." 该行会指出缺失的文件。勾选 Plugins/SQLite 重新导入 KitARPG 包

  5. Step 2, Play. 按下 Play single player。编辑器打开 Title 场景，并同时以客户端和服务器身份进入 Play 模式。你也可以按 Overview 中的 Play，或在打开 Title 场景时按 Unity 自己的 Play 按钮。

  6. 标题界面打开 Characters 列表，第一次是空的。

  7. 按下 New。New character 面板打开。

  8. 填写：

    字段 怎么做 规则
    Name 输入一个名字 3 到 16 个字母或数字，以字母开头。每个名字唯一
    Look 点击一个身体：示例中有男性、女性或熊猫 3D 预览会随之变化
    Class 从列表中选择 只显示所选身体可以担任的职业。示例中男性和女性可以是 Warrior、Hunter 或 Mage；熊猫是 Monk
    Hair 选择一种发型 保留自己毛发的身体（例如熊猫）不提供发型

  9. 按下 Create。角色出现在列表中。Back 不创建并返回。

  10. 选中角色并按下 Play。显示加载画面后，你就来到了示例的起始地图 Town。

你最多可以保留 6 个角色（Game Database 的 maxCharactersPerAccount，默认 6）。Delete 会在确认后删除选中的角色。

#游戏中的最初几分钟

示例默认使用俯视角操控模式。

要做的事 操作
行走 点击地面，或按住按钮持续朝指针方向行走。WASD 和方向键也可以行走
攻击 点击怪物。Space 攻击 10 米内最近的敌人
拾取掉落 点击它，或在附近按 F
与 NPC 交谈 点击它，或在附近按 F
使用技能 按下它在快捷栏上的按键（1 到 9、0）。范围技能会先显示形状：点击或再按一次该键施放，右键或 Esc 取消
打开背包 I
查看角色并分配点数 C
查看技能 K
阅读任务 L
打开世界地图 M
打开菜单 Esc，或齿轮图标

所有按键见按键。

#在示例中可以尝试的事

  • 与头顶有黄色 ! 的 NPC 交谈来接任务。
  • 穿过传送门前往 Forest，与史莱姆、蘑菇和狼战斗。
  • 找到 Sunken Crypt，一个带有首领的实例化副本。
  • 打开各个商店：盔甲、帽子、衣服、鞋子、武器和药水。
  • 按 B 打开怪物图鉴。

#作弊：单人模式中的 GM 命令

在单人模式中，玩家可以像使用作弊码一样使用所有 GM 命令，因为 Game Settings > Commands > Single Player Commands（singlePlayerCommands）默认是开启的。在聊天中输入它们（先按 Enter）：

/gold 10000
/level 20
/item health_potion 20
/god
/spawn slime 5

/help 会列出全部命令。完整列表见 GM 命令。如果你发布的游戏不应允许作弊，发布前请关闭 Single Player Commands。

#存档

游戏会自动存档：每 60 秒、切换地图时和离开时。在单人模式中，游戏菜单（Esc）有 Save and leave（保存并返回角色列表）和 Quit。

项目 路径
存档文件名 savegame.db，在 KitARPGSettings.asset > Save File（saveFile）中设置
文件夹 Unity 为你的项目提供的持久化数据文件夹：Mac 上是 ~/Library/Application Support/<Company>/<Product>，Windows 上是 %USERPROFILE%\AppData\LocalLow\<Company>\<Product>

Company 和 Product 是 Project Settings > Player 中的名称。Play & Servers 在第 2 步的 Save data 下显示完整路径：

按钮 作用
Show folder 在 Finder 或资源管理器中打开该文件夹
Delete save data 确认后删除编辑器保存的所有单人模式角色。游玩时不可用
警告

同一台电脑上，编辑器和同一项目的构建使用同一个持久化数据文件夹。在编辑器中按 Delete save data 也会删除你电脑上该构建的角色。

#单人模式中不可用的功能

需要其他玩家或服务器的系统会回答 "Only on an online server." 或被隐藏：

  • 好友、队伍、公会、联盟和收税员；
  • 邮件和市场；
  • 游戏内商城；
  • 举报，以及读取数据库的管理命令（/ban、/reports、/closereport、/logs、/role、/audit）。

其他一切都可用：战斗、技能、物品、仓库、锻造、任务、对话、副本、昼夜、怪物图鉴。

#Step 3: Build the game

  1. 在 Play & Servers 中打开 Step 3, Build the game。
  2. 按下 Build for Mac 或 Build for Windows。它们与 KitARPG > Starter > Build Mac Single Player 和 Build Windows Single Player 相同。
  3. Project Check 会先运行，有错误时会中止构建。
  4. 构建输出到 Builds/Starter/MacSinglePlayer/KitARPG.app 或 Builds/Starter/WindowsSinglePlayer/KitARPG.exe。Builds 文件夹位于你的 Unity 项目文件夹旁边，而不是里面。

该构建携带服务器代码和本地存档，因此游戏可以自己托管自己。它的场景来自 Game Database 中的地图；你无需编辑构建列表。把整个构建文件夹交给玩家。

提示

用 IL2CPP 制作的 Windows 构建必须在 Windows 上制作，Mac 构建必须在 Mac 上制作。

#常见错误

错误 会发生什么 解决办法
打开其他场景时按下 Unity 的 Play 游戏在该场景中启动，没有标题界面 打开 Title，或使用 Play single player
在 Play 期间修改 Game Settings 字段被锁定 先停止 Play
选择身体不能担任的职业 职业列表只提供有效的职业；被修改过的客户端会被拒绝 在玩家模型中把该职业添加到模型上
期待使用邮件或队伍 "Only on an online server." 在 Play & Servers 中切换到 MMO
