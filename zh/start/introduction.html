入门

简介

KitARPG 是一个用于制作 MMO-lite 风格在线动作 RPG 的 Unity 套件：共享的城镇、实例化副本、公会、交易，以及背后一套真正的服务器。本页说明这个套件是什么、如何构成、适合谁使用，以及如何阅读本手册。

#KitARPG 是什么

KitARPG 由 Blunnyn 发布，为你提供一个完整、可玩的动作 RPG，你可以把它改造成自己的游戏。它面向热爱 RPG 的人，从从未写过一行代码的新手到经验丰富的开发者都适用。

导入后你会得到：

  • 一个入门示例，导入几分钟后就能玩：一座城镇、一片森林、一个副本（Sunken Crypt）、怪物、首领、任务、商店以及完整的界面。
  • 编辑器工具，让你无需代码就能修改游戏：KitARPG 窗口及其 Game Database、Game Settings、Modules、Play & Servers 和 Project Check 页面，外加用于新建玩家模型和新怪物的分步向导。
  • 服务器：Login、Central 和可选的 Shop，用 .NET 10 编写，外加一个一键启动全部服务的启动器。
  • DevKit，供你想写代码时使用：模板、事件、虚方法，以及一个在不修改套件的前提下完成的完整示例功能。

#同一个游戏的两种运行方式

同一个 Unity 项目和同一批场景可以用两种方式运行。你在 Setup Wizard 中选择其一，之后也可以在 Play & Servers 中更改。

模式 谁运行什么 存档 你需要什么
单人模式 游戏自己托管自己的世界。玩家的电脑同时是客户端和服务器 玩家电脑上的一个 SQLite 文件 只需 Unity
MMO 玩家登录到你的服务器：一个 Login 服务、一个 Central 服务，以及每张地图一个 Unity 服务器 一个数据库：单台电脑上用 SQLite，生产环境用 PostgreSQL Unity 和 .NET 10 SDK

两种模式下的地图代码完全相同。单人游戏以后可以变成 MMO：你切换模式、构建服务器，并保留你做的每张地图、每个物品和每个任务。

#一次 MMO 会话如何运作

玩示例不需要了解这些，但出问题时会有帮助。

  1. 登录。 客户端通过 HTTP（生产环境为 HTTPS）把用户名和密码发给 Login 服务。Login 校验密码哈希，并返回一个短时有效的令牌和角色列表。
  2. 选择角色。 客户端请求 Central 用某个角色进入游戏。Central 返回该角色所在地图服务器的地址，以及一张只能使用一次、30 秒后过期的票据。
  3. 进入地图。 客户端用 Mirror（UDP，KCP 传输）连接地图服务器并出示票据。地图向 Central 核验票据，加载角色并生成它。
  4. 游玩。 客户端只发出请求，一切由服务器决定。地图每 60 秒、角色离开时以及切换地图时保存角色。
  5. 切换地图。 传送门保存角色并向 Central 请求下一张地图的票据。如果那张地图的服务器尚未运行，Central 会启动它。客户端显示加载画面并连接新地图。

每个账号只有一个会话：如果有人用同一账号再次登录，旧会话会被关闭。Architecture 页面有更深入的介绍。

#设计原则

这些选择贯穿整个套件。了解它们能解释你会看到的许多行为。

  • 服务器说了算。 每个操作都是一个请求。伤害、掉落、价格、交易和任务进度都在服务器上计算。被修改过的客户端得不到任何好处。
  • 每个物品副本只有一个所有者。 在 MMO 中，物品存放在一张表里，每个副本恰好属于一个角色、账号、公会、信件、收税员或市场挂单。所有者之间的转移在数据库事务中完成，因此物品无法被复制。
  • 用数据，不用代码。 职业、物品、技能、怪物、任务和地图都是在 Game Database 中编辑的资源。每个都有一个文本 id，例如 fire_bolt，创建后永不更改。
  • 套件保持只读。 你把自己的内容和代码放在自己的文件夹里。套件更新会添加新版本带来的内容，而不会覆盖你改过的东西。
  • 整数。 数值加成始终是整数，百分比是整数点。
  • 构建只携带属于自己的代码。 MMO 客户端不含服务器代码、GM 命令、本地存档或密钥。编辑器在每次构建前都会检查这一点。

#约定

  • 菜单路径用粗体和 > 表示：KitARPG > Setup Wizard。
  • 字段名用代码格式：autoGold。检视面板显示的标签用斜体，第一次出现时附上字段：Auto Gold（autoGold）。
  • 按键写作 Ctrl/Cmd+Shift+K：Windows 和 Linux 上是 Ctrl，Mac 上是 Cmd。
  • 以 Assets/ 开头的路径在你的 Unity 项目内。UserSettings/KitARPG/ 也在项目文件夹内，与 Assets 相邻，永远不会随包发布。
