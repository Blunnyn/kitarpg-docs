入门

功能

KitARPG 的全部功能，按领域分组，并附上解释每一部分的页面链接。可以用它来确认套件是否覆盖了你的游戏所需。

#游戏

#模式与平台

功能 你得到什么 页面
单人模式和 MMO 同样的场景和代码既可以作为自托管、存档在玩家电脑上的单人游戏运行，也可以作为带有 Login、Central 和地图服务器的 MMO 运行 简介
三种操控模式 俯视角（点击移动，可选键盘操作，暗黑破坏神风格）、自由视角（光标瞄准，右键转动镜头）和第三人称（准星瞄准、客户端预测、闪避） 操控模式
触屏操控 屏幕摇杆、Attack 按钮、呈弧形排列的技能按钮 1 到 4、一个消耗品按钮、Activate、拖动瞄准技能、双指缩放 触屏操控
输入 支持 Input System 包或旧的 Input Manager，以项目使用的为准 按键
平台 为 Mac 和 Windows 构建（客户端和单人模式），为 Mac、Windows 和 Linux（Docker）构建地图服务器 构建

#角色

  • 模块化角色，基于共享的人形骨骼，分为头部、头发、胸部、手部、腿部和脚部区域。示例中有男性、女性和熊猫三种身体、三种发型以及数百件体素风格的装备部件，全部使用同一个材质。
  • 玩家模型，带有每种外观可选的职业。服务器会拒绝模型不提供的职业。参见玩家模型。
  • 职业，带有每级的属性和数值、初始技能和初始物品。示例中有 Warrior、Hunter、Mage 和 Monk（Monk 就是熊猫）。参见职业。
  • 属性和数值，每级可分配点数，加成为整数。示例中有 Strength、Agility、Intelligence、Vitality 和 Luck。参见属性与数值。
  • 按武器类型和按技能划分的动画，带有每次命中生效的时刻，以及可选的上半身遮罩，让角色可以边走边攻击和施法。

#战斗

  • 由服务器裁定的即时战斗，带有伤害元素和抗性（示例中有 Neutral、Fire、Water、Earth 和 Air）。
  • 技能，带有目标和范围形状（圆形、锥形、直线），每个等级的消耗、冷却和施法时间，以及一系列效果：伤害、治疗、护盾、持续伤害、状态、推开与拉近、召唤、复活、弹射、穿透、区域等。参见技能。
  • 状态（增益和减益），例如中毒、燃烧、流血、眩晕、定身、减速、沉默、护盾、隐身和无敌，并带有免疫和抗性。参见状态与增益。
  • 施法前的范围预览，并可选择立即施放。
  • 视线、潜行、仇恨，以及在没人看得到时进入休眠的怪物。
  • 会游荡、追击、返回原位并协助同伴的怪物；Normal、Elite 和 Boss 三种等阶；带有阶段、狂暴和首领血条的首领。参见怪物和首领。
  • 战斗中与战斗外的恢复、死亡惩罚和重生规则。参见恢复与死亡。

#物品与装备

  • 示例中有 16 种武器类型（剑、巨剑、长矛、弓、斧、锤、戟、镰刀、弩、魔杖、法杖、权杖、法典、法球、匕首和拳套），以及盾牌、帽子、披风、护身符、戒指、胸甲、手套、腿甲、靴子、弹药、消耗品、宝石、资源和任务物品。参见物品。
  • 每个副本的随机加成：装备上的每项加成在每个副本中都会在最小值和最大值之间随机取值。
  • 套装、用符文强化（每一步可能成功、失败、掉级或损坏该装备）、宝石镶孔、弹药和双持。参见套装、强化与镶孔。
  • 只改变外观的时装。
  • 带有效果的消耗品：治疗，经验、等级、点数和回城卷轴，施放技能的卷轴，传授技能的书。
  • 按格子或按重量计算的背包，带有超重机制，并以仓库作为后备，确保任何东西都不会丢失。参见背包与仓库。
  • 货币：金币加上其他任意货币，以及用于游戏内商城的付费货币。参见货币。

#世界

  • 地图由 Game Database 条目加场景组成，通过传送门和传送 NPC 相连。参见地图。
  • 实例化副本：每个队伍或每个单独的玩家都有自己的副本。示例中有 Sunken Crypt。参见副本。
  • 昼夜，带有游戏时钟、夜间灯光以及只在白天或夜晚生成的怪物。参见昼夜。
  • 世界触发器和剧情标记，可以是个人的，也可以对所有人生效。参见世界触发器。
  • 探索区域、小地图和世界地图。
  • 怪物图鉴，记录每种怪物栖息在哪里、掉落什么。参见怪物图鉴。

#任务与 NPC

  • 任务，带有 Kill、Collect、Talk、Explore 和 Trigger 目标、任务链、每日任务、任务专属掉落、需求、奖励以及 NPC 头顶的任务标记。参见任务。
  • 条件和动作，可以锁定和奖励任何东西：任务、对话台词、NPC 选项。参见条件与动作。
  • 分支对话。参见对话。
  • 带有选项的 NPC：商店、传送、任务、对话、技能训练师、仓库、公会仓库、创建公会、公会会馆、邮件、市场、锻造、收税员位置和触发器。参见 NPC 和 NPC 商店。

#社交

系统 玩家能做什么 页面
聊天 附近、地图、世界、私聊、队伍、公会和联盟频道，带有敏感词过滤 聊天
好友 查看谁在线、在哪里 好友与队伍
队伍 最多 5 名玩家，共享经验，进入同一个副本 好友与队伍
交易 面对面交易物品和金币，双方锁定并确认 交易
邮件 附带金币和最多 5 个物品的信件，也可以发给离线玩家 邮件
公会 带权限的职位、等级、公会仓库、徽章、历史、拥有自己频道的联盟、公会会馆 公会
收税员 公会把它们放在地图上；它们从附近狩猎所得中抽取一部分，并且可以被攻击 收税员
PvP 和决斗 随处决斗；在区域内或整张地图上 PvP PvP 与决斗

#经济

  • 默认不能把东西卖给 NPC，因此物品在玩家之间流通。
  • 在锻造台把物品分解成符文。参见锻造。
  • 玩家市场，卖家通过邮件收款。参见市场。
  • 服务器的经验、掉落和金币倍率，以及限时倍率活动。
  • 可选的游戏内商城，有自己的付费货币，作为独立服务运行，带有分类、搜索、横幅、角标、商品页、赠送以及通过 webhook 进行的真实货币支付。参见商城和 Shop 服务。

#管理

  • 四个 GM 等级：Player、Moderator、Game Master 和 Admin。
  • 在聊天中输入的斜杠命令和游戏内 GM 面板（F8）。参见 GM 命令。
  • 每条管理命令在运行前都会记录到 gm_audit 表中。
  • 记录客服所需信息的游戏日志、玩家举报和聊天过滤。参见游戏日志与举报。

#编辑器

工具 作用 页面
KitARPG 窗口（Ctrl/Cmd+Shift+K） 所有工具集中在一个带侧边栏的窗口里 KitARPG 窗口
Overview 一份列出开玩前还差什么的待办清单、一个 Play 按钮、计数和常用工具 Overview
Play & Servers 单人模式或 MMO，分步进行，附带服务及其日志 Play & Servers
Game Database 每个职业、物品、技能、怪物、任务和地图，附带新建模型和怪物的向导 Game Database
Game Settings 游戏的玩法设置，以卡片形式呈现 Game Settings
Modules 开启和关闭整个系统 Modules
Shop 编辑并发布游戏内商城的商品目录 Shop 页面
Project Check 查找失效的引用、重复的 id、网络问题和缺失的场景；在每次构建前运行 Project Check
Setup Wizard 从导入到开玩只需两步 Setup Wizard
套件更新 添加新版套件带来的内容，而不覆盖你的修改 更新套件
双人游玩 两个编辑器、两个测试账号、一次点击 快速入门：MMO
Play 模式测试 套件自带的测试，可从菜单或命令行运行 故障排除

#服务器

  • 基于 .NET 10 的 Login（账号、登录、角色）、Central（会话、票据、聊天、好友、队伍、公会、邮件、市场；启动地图服务器）以及可选的 Shop。参见服务。
  • 生产环境用 PostgreSQL，单台电脑上用 SQLite，二者位于同一个数据层之后。参见数据库。
  • 用 Argon2id 哈希的密码、短时有效的签名令牌、只能使用一次的 "Remember me" 令牌、频率限制以及密码错误后的账号锁定。
  • 一键启动全部服务的启动器，可带窗口或无界面运行。参见启动器。
  • 带有 Caddy 提供 HTTPS 的 Docker Compose，以及 Linux 地图服务器构建。参见 Docker。
  • Login 和 Central 的模块，让你无需修改服务就能扩展它们。参见服务模块。

#DevKit

  • 你的代码放在由 Create > KitARPG > Scripts 创建的你自己的程序集中。
  • 模板涵盖技能效果、物品效果、条件、游戏动作、任务目标、NPC 选项、玩家系统、网络消息、GM 命令、游戏日志监听器、战斗和数值公式、保存的玩家数据、玩家系统重写、物品和玩家菜单项、设置选项、验证检查、KitARPG 窗口页面以及套件更新。参见模板。
  • 服务器和客户端上的静态事件，以及窗口、玩家系统、怪物和 NPC 上的虚方法。
  • 按角色保存你自己的数据，向 Central 发送你自己的消息。
  • 一个完整的示例 Bounty Board（悬赏板），在不修改套件的前提下完成。参见示例：悬赏板。
  • 每个公开类型的 API 参考，位于 Documentation/API。
