入门

安装

如何把 KitARPG 导入 Unity 项目、导入带来了什么、编辑器第一次打开时会发生什么，以及如何修复出错的导入。完成后由 Setup Wizard 接手。

#开始之前

  • 用 Unity Hub 安装 Unity **6000.6.0f1（Unity 6.6）**或更新版本。参见系统要求。
  • 决定是新建一个新项目（推荐），还是导入到现有项目。
  • 如果你打算在电脑上试玩 MMO，现在就安装 .NET 10 SDK。也可以以后再装。
提示

导入前先把项目纳入版本控制（Git 或 Unity Version Control）。这样之后的每一步，包括套件更新，都可以安全地撤销。

#分步操作：新项目

  1. 打开 Unity Hub 并按下 New project。
  2. 选择 Unity 6000.6.0f1 或更新版本作为编辑器版本。
  3. 选择一个模板。任何 3D 模板都可以，包括空的 Universal 3D 模板。套件会安装它需要的东西。
  4. 为项目命名并按下 Create project。等待编辑器打开。
  5. 打开 Window > Package Manager。
  6. 在左栏打开 My Assets（你需要用购买套件的 Unity 账号登录）。
  7. 找到 KitARPG，按下 Download，然后按 Import。
  8. Import Unity Package 窗口会列出所有文件。保持全部勾选并按下 Import。
  9. Unity 导入文件，然后安装套件声明的 Unity 包（URP、AI Navigation、uGUI、Input System、Test Framework）。它可能会编译几次。
  10. 如果 Unity 询问是否启用新的 Input System 后端并重启，你可以选是或否。套件两种输入都支持。选是会重启编辑器。
  11. 编辑器稳定下来后，KitARPG Setup 窗口会自动打开。继续进行 Setup Wizard。

#包的内容

在你项目中的路径 是什么
Assets/Blunnyn/KitARPG/ 套件本身：运行时代码、编辑器工具、模式、DevKit、示例、测试、插件和文档
Assets/Blunnyn/KitARPG/Services.zip .NET 服务（Login、Central、Shop、Data、Hosting、Modules、Launcher、测试和示例）的源代码
Assets/Blunnyn/Art/ 体素美术：角色、装备、武器、怪物、动画和图标
Assets/Mirror/ 网络库 Mirror，带 KCP 传输
Assets/ScriptTemplates/ Mirror 的脚本模板

完整的结构见项目结构。

警告

如果你的项目在其他文件夹中已经有 Mirror，你会得到两份副本，并出现类型重复的错误。只保留一份 Mirror：套件附带的 Assets/Mirror 是套件经过测试的版本。

#编辑器第一次打开时会发生什么

导入后会自动运行几件事。其中一些你会在 Console 中看到。

#解压服务

.unitypackage 只能携带资源，所以 .NET 服务以 Services.zip 的形式提供。编辑器第一次加载时，套件会把它解压到：

Assets/Blunnyn/KitARPG/Services~

Unity 永远不会导入名称以 ~ 结尾的文件夹，因此服务的 C# 文件不会进入你的游戏。Console 会显示：

[KitARPG] Services <version> unpacked to .../Assets/Blunnyn/KitARPG/Services~.

zip 中带有一个 kit-services.version 文件。只有当 zip 的版本与已解压的版本不同时（例如导入更新的套件后），套件才会再次解压。

注意

如果在你的 Unity 项目文件夹旁边或内部存在一个包含 KitARPG.Services.slnx 的 Services 文件夹，套件会使用它，而不动 zip。Play & Servers 会在 Services source 一行显示正在使用的文件夹，并提供 Browse 按钮来选择其他文件夹。

#打开 Setup Wizard

向导在每个项目中只打开一次，除非存在文件 UserSettings/KitARPG/setup-done。它在批处理模式下或 Multiplayer Play Mode 的第二个编辑器中永远不会打开。你随时可以从 KitARPG > Setup Wizard 再次打开它。

#套件记住自己的版本

套件把自己的版本写入 UserSettings/KitARPG/seen-version。首次导入时不会发生其他事情。以后导入更新的套件时，What's New 窗口会打开一次并显示更新日志。参见更新套件。

#导入到现有项目

你可以把 KitARPG 添加到已有的项目中。请先检查以下几点：

检查项 原因
Unity 6000.6.0f1 或更新 套件在更旧的版本上无法编译
项目使用 URP，或你准备切换 Setup Wizard 会把 URP 设为 Graphics 和每个质量等级的渲染管线。你自己的内置管线材质需要转换
没有其他 Mirror 副本 两份副本会冲突
Build Settings 向导会把场景列表替换为入门场景，Title 在最前。请先记下你自己的场景
颜色空间 向导会设置为 Linear

向导只修改项目设置（渲染管线、颜色空间、Build Settings）和入门示例。它永远不会改动你自己的资源。

#检查导入是否成功

完成向导后，以下各项都应成立：

  • Console 中没有红色错误。
  • 菜单栏中有 KitARPG 菜单。
  • Ctrl/Cmd+Shift+K 能打开 KitARPG 窗口。
  • 该窗口中的 Overview 显示 "Everything is ready"，或只列出你尚未完成的 MMO 步骤。
  • Project Check 没有显示错误。

#导入出错时

症状 原因 解决办法
数百个提到 UnityEngine.Rendering.Universal 的编译错误 URP 没有安装 打开 Window > Package Manager，安装 Universal RP 17.6.0，然后重新打开项目
关于 Unity.AI.Navigation 或 NavMeshSurface 的错误 AI Navigation 没有安装 从 Package Manager 安装 AI Navigation 2.0.14
按 Play 时你自己的脚本抛出关于 UnityEngine.Input 的 InvalidOperationException 项目只使用 Input System，而你的脚本直接调用了 Input 改为调用 KitInput。套件自己的代码已经这样做了
关于 Mirror 类型重复的错误 有两份 Mirror 删除其中一份
Setup Wizard 没有打开 它在这个项目中运行过，或编辑器处于批处理模式 打开 KitARPG > Setup Wizard
缺少 Services~ 编辑器尚未加载完成，或 Services.zip 没有被导入 等待编译完成，或勾选 Services.zip 重新导入包
SQLite 库提示 "Missing ... Import the KitARPG package again." 你所用平台的 SQLite 插件没有被导入 勾选 Plugins/SQLite 重新导入包

更多内容见故障排除。

#卸载

要从项目中移除套件，删除 Assets/Blunnyn、Assets/Mirror、Assets/ScriptTemplates、Assets/Settings/Resources/KitARPGSettings.asset 和 UserSettings/KitARPG。它安装的 Unity 包会保留；如果你不用它们，可以从 Package Manager 中移除。

重要

UserSettings/KitARPG 保存着 MMO 的本地数据库、启动器的密钥、测试账号和本地商城目录。删除它会删除你在本地创建的所有账号和角色。
