Setup Wizard

Setup Wizard（设置向导）用两步把刚导入的项目变成可玩的项目：选择游戏的运行方式，然后按下一个按钮，完成渲染、字体、示例和场景的设置。本页解释每个步骤、它做的每项检查、它对你项目的改动，以及还有遗留问题时该怎么办。

#在哪里

  • 导入 KitARPG 后编辑器第一次加载时，它会自动打开。
  • KitARPG > Setup Wizard 可以随时打开它。
  • KitARPG 窗口侧边栏底部的 Setup wizard 按钮，以及 Overview 中的 Setup wizard > Open 工具，也能打开它。

窗口标题是 KitARPG Setup。顶部的条显示两个步骤 Your game 和 Get ready，当前步骤高亮显示，已完成的步骤带有勾号。

#何时自动打开

向导在每个项目中自动打开一次。你完成或关闭它时，它会写入文件 UserSettings/KitARPG/setup-done，只要该文件存在就不会再自动打开。

以下情况它永远不会自动打开：

  • 在批处理模式下（命令行构建和测试）；
  • 在 Play with two players 打开的第二个编辑器中；
  • 编辑器正在进入 Play 模式时。

想让它再次自动打开，删除 UserSettings/KitARPG/setup-done。无论该文件是否存在，都可以从菜单打开它。

#第 1 步：Your game

标题是 Welcome to KitARPG。下方的 How does your game run? 显示两张大卡片：

卡片 含义
Single player 游戏自己托管自己的世界，并保存在玩家的电脑上。无需运行服务器
MMO 玩家登录到你的服务器：Login、Central 以及每张地图一个服务器

点击卡片来选择。卡片下方的文字会解释这个选择：

  • 选择 Single player 时："Nothing else to install. You can turn it into an MMO later; the maps and their code stay the same."（无需安装其他东西。以后可以变成 MMO；地图及其代码保持不变。）
  • 选择 MMO 时：制作游戏期间服务器在你的电脑上运行，使用本地数据库。你从 KitARPG 窗口启动它们，上线时在那里选择 PostgreSQL。

你的选择会立即保存到 Assets/Settings/Resources/KitARPGSettings.asset（字段 mode）。如果该资源不存在会被创建。新的设置资源默认是 MMO（Online）。

提示

拿不准？选 Single player。它不需要 Unity 以外的任何东西，以后你可以在 Play & Servers 中切换到 MMO，而无需修改任何内容。

底部的按钮：

按钮 作用
Not now 关闭向导。仍算作已完成，并打开 KitARPG 窗口
Next 进入第 2 步

#第 2 步：Get ready

标题是 Get the project ready，附有 "One click sets up everything below. Nothing in your own assets is touched."（一键设置下面所有内容。不会改动你自己的任何资源。）一张卡片列出五项检查。每一行有一个指示灯：已完成、待处理，或向导工作时的忙碌状态。

行 检查什么 Set everything up 做什么
Graphics 默认渲染管线是 URP 资源，每个质量等级都使用 URP（或不设置），并且颜色空间是 Linear 如果项目在 Assets 中有 URP 资源就使用它。否则创建 Assets/Settings/KitARPG_URP.asset 及其渲染器 Assets/Settings/KitARPG_URP_Renderer.asset。把它设为默认管线，并设到每个使用其他管线的质量等级上，再把颜色空间设为 Linear
Fonts 项目中有 TextMesh Pro 的基本资源 导入 TMP Essential Resources
Sample Assets/Blunnyn/KitARPG/Samples/Starter/Scenes/Title.unity 存在 构建入门示例（KitARPG > Starter > Build Scenes and Prefabs）
Scenes in the build Build Settings 中第一个启用的场景是 Title 用存在的入门场景替换 Build Settings 列表，顺序为：Title、Server、Town、Forest、Crypt
Scenes up to date 每个场景的 EventSystem 使用项目所开启输入方式的 UI 模块，并且没有场景在其 Game Instance 上覆盖 Game Settings 根据需要把每个 EventSystem 切换为 InputSystemUIInputModule 或 StandaloneInputModule，并还原每个场景中 Game Instance 的覆盖，使其从预制体获取设置
注意

向导只在 Assets 内查找 URP 资源。URP 包自带一个无法编辑的只读资源，所以向导永远不会使用它。

#运行 Set everything up

  1. 按下 Set everything up。按钮变为 Setting up...，各行变为忙碌状态。一条消息显示 "Setting up... Unity may import and compile for a moment."（正在设置……Unity 可能会导入和编译一会儿。）
  2. Unity 导入并编译。向导在重新编译期间保持进度。
  3. 片刻后 TextMesh Pro 的导入会自行完成。向导最多等待 30 秒。
  4. 向导运行 Project Check 并统计错误数。
  5. 向导关闭。如果示例存在，它会请你保存所有已修改的场景，然后打开 Title 场景。
  6. KitARPG 窗口打开：
    • Project Check 没有发现错误时，打开 Overview；
    • 还有遗留错误时，打开 Project Check，以便你修复。

如果一切就绪后再次打开向导，标题会显示 "Everything is in place."，按钮变为 Open the sample，它会打开 Title 和 KitARPG 窗口。

#有遗留错误时

如果 Project Check 发现错误，卡片会显示一行 Project check 及错误数（"N problem(s) left, most with a fix button."，即还剩 N 个问题，大多数都有修复按钮），以及一个 See them 按钮。大多数问题在 Project Check 中都有修复按钮。修复后回来再按一次按钮，或在 KitARPG 窗口中继续。

#向导改动了什么

改动 位置
游戏模式 Assets/Settings/Resources/KitARPGSettings.asset
渲染管线 Graphics 设置和每个质量等级；可能在 Assets/Settings/ 中新建资源
颜色空间 Player Settings > Other Settings > Color Space
TMP Essentials Assets/TextMesh Pro/
入门示例 Assets/Blunnyn/KitARPG/Samples/Starter/（仅在缺失时）
Build Settings 场景列表 替换为入门场景
入门场景 EventSystem 输入模块和 Game Instance 覆盖
完成标记 UserSettings/KitARPG/setup-done

它永远不会改动你自己的资源，永远不会重建已存在的示例，也不会碰数据库或服务器。MMO 服务器和数据库稍后在 Play & Servers 中设置。

#完成向导之后

你选择了 下一步
Single player 快速入门：单人模式
MMO 快速入门：MMO

向导设置的所有内容以后都可以更改：模式在 Play & Servers 中，场景在 Build Settings 中，渲染设置在 Project Settings 中。

#常见问题

问题 解决办法
Fonts 一直是待处理 TMP 导入没有在 30 秒内完成。再按一次 Set everything up，或使用 Window > TextMeshPro > Import TMP Essential Resources
Graphics 一直是待处理 某个质量等级仍指向一个你无法更改的非 URP 管线，或者颜色空间无法设置。检查 Project Settings > Quality 和 Player > Color Space
向导要求保存场景 它即将打开 Title。保存或放弃你的修改；取消则保留当前场景打开
完成向导后材质仍然是粉色 参见故障排除
你误关了向导 打开 KitARPG > Setup Wizard
