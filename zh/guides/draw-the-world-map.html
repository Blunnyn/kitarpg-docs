分步指南

绘制世界地图

地图窗口（M）可以显示整个世界的图片，每张地图对应一个区域。玩家可以看到自己所在的位置、每个区域的名称和等级，并点击区域来列出其中的怪物及其掉落。本指南为示例的岛屿添加一个区域。

#1. 打开编辑器

打开 KitARPG > World Map Editor。它会打开数据库的世界地图；示例的世界地图是 Samples/Starter/Data 中的 WorldMap。对于你自己的游戏，按 New world map 并设置其 Picture：任意一张描绘你的世界的 sprite，绘制或手画均可。示例的岛屿由 Art/Tools/make_world_map.py 绘制。

#2. 绘制区域

  1. 在图片的空白处拖动。会出现一个矩形区域并被选中。
  2. 根据需要多次按右侧的 Add corner。每次都会拆分最长的一条边。
  3. 把各个角拖到区域周围。这里它们环绕着群山。

滚动来缩放，用中键（或按住 Alt）拖动来移动视图。

#3. 设置区域

选中区域后，在右侧：

字段 作用
Name 显示在区域上。留空则使用其地图的名称。
Map 它所代表的地图。在该地图上的玩家会看到自己位于此区域，并列出该地图的怪物。
Color 区域的填充色。
Min Level、Max Level 名称下方显示的等级。为 0 时取自地图中的怪物。
World Area 地图场景覆盖的地面范围，使玩家显示在区域中的正确位置。按 World area from the scene 读取。

#4. 试一试

按 Play，进入游戏后按 M。拖动来移动，滚动来缩放，点击区域查看其怪物，点击怪物查看其掉落。顶部的搜索可按名称查找区域和怪物。

地图的怪物来自其刷怪点：添加刷怪点后，在 Game Database（World > Maps）中该地图上按 Read from scene。
