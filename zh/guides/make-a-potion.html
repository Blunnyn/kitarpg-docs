分步指南

制作药水

本指南制作一瓶 Greater Health Potion：它立即治疗 150，然后在 20 秒内持续治疗，并由炼金术士 Mira 在城镇中出售。

#1. 打开消耗品

  1. 用 KitARPG > Open KitARPG（Ctrl/Cmd+Shift+K）打开 KitARPG 窗口，进入 Game Database。
  2. 在 Items 下点击 Items，然后点击 Consumables。列表显示游戏中的每种药水、卷轴和书。

#2. 创建物品

按列表底部的 + New consumable。套件会在其他资源旁边创建该资源，把它加入数据库并打开它。

页面以 In game 开头：即玩家将看到的提示框。它会随你的输入实时更新。

#3. 填写内容

在 General 中：

字段 值 原因
Id greater_health_potion 与玩家拥有的每个副本一起保存。现在就设好，之后不要再改。
Display Name Greater Health Potion
Description Restores a lot of health, then keeps healing for a while. 提示框的最后一行。
Icon 任意 sprite 示例的药水图标位于 Art/Sprites/Icons。
Rarity Magic 名称显示为蓝色。
Max Stack 20 一个背包格可放 20 个。
Sell Price 15 除非你设置 Buy Price，商店会按此价格的四倍出售。
Restore Health 150 立即治疗的量。

如果也要重命名文件，使用 Show file 并在 Project 窗口中重命名。id 保持不变。

#4. 添加效果

Effects 可以添加治疗之外的任何东西：经验、等级、技能、状态、回城。

  1. 打开 Effects 并按 +。
  2. 在新的一行上按 Pick a type，选择 Status。
  3. 将 Status 设为 Regeneration，Duration 设为 20，Level 设为 1。

提示框现在会加上 "Regeneration for 20s" 及其作用。所有效果类型见物品。

#5. 在商店出售

  1. 在 Game Database 中打开 Items > Shops，选择 Alchemist。
  2. 打开 Items，按底部的 +，选择 Greater Health Potion。
  3. 将 Price 设为 60。Stock 保持为 0 表示无限供应。

Mira 使用的就是这个商店，因此无需其他操作。要从新的 NPC 出售，参见 NPC 商店。

#6. 试一试

  1. 打开 Title 场景并按 Play。以单人模式进入游戏。
  2. 走到城镇中央的炼金术士 Mira 那里并点击她。药水在她列表的最后。
  1. 买一瓶，或在聊天框中输入 /item greater_health_potion 5。
  2. 在背包中使用它（双击），或把它拖到快捷栏并按对应的键。

只能治疗的药水在满血时无法使用。这瓶还带有 Regeneration，所以可以使用。
