分步指南

制作怪物

本指南用一个 3D 模型制作一只 Moss Golem，为它设置掉落，并在森林中放置三只。

#1. 启动向导

  1. 在 Game Database 中打开 World > Monsters。
  2. 按 + New monster。向导在右侧打开，共四步：Model、Combat、Animations 和 Create。

#2. 模型

  1. 把模型拖到字段中：FBX 或 prefab。本指南使用 Art/3D/VoxelHero/Monsters/Golem。
  2. 下方一行在模型带有 Animator 时显示 Animated，否则显示 No Animator。没有 Animator 时，怪物仍会移动、跳动、按时攻击并在受击时闪烁（由 MonsterBody 组件完成），就像示例中的史莱姆。
  3. 输入 Display name：Moss Golem。下方的 id moss_golem 由它生成。

按 Next。

#3. 战斗

Start from a monster 会复制另一只怪物的所有设置。保持为 Nothing 并设置：

字段 值
Level 6
Health 260
Damage 8 到 14
Move speed 2.4
Experience 60
Loot table GolemLoot
Respawn seconds 45

其余保持默认值：近战距离 1.4，每秒 0.8 次攻击，Aggressive。

按 Next。Animations 这一步只在动画模型上有可选内容：待机、行走、受击、死亡和攻击的片段，以及攻击命中的时刻。再按一次 Next。

#4. 创建

最后一步显示 prefab 的存放位置，并列出将要创建的内容。保持 Render its bestiary icon 开启，然后按 Create monster。

套件会创建怪物数据、一个包含怪物所需一切（网络、移动、点击区域、血条）的 prefab 以及它的图标，将其加入数据库并打开。技能、阶段、抗性等其余内容都在这里编辑。

#5. 放入世界

怪物存在于 Monster Spawner 维持它们的地方。

  1. 打开 Forest 场景（Samples/Starter/Scenes）。
  2. GameObject > Create Empty，命名为 Moss Golem Spawner，并把它移到 NavMesh 上的空旷地面（开启 AI Navigation 叠加层时的蓝色区域），远离 SpawnPoint。
  3. Add Component > Monster Spawner。将 Monster 设为 Moss Golem，Count 设为 3，Radius 设为 6。
  4. 保存场景。
森林中的刷怪点 它的 inspector
  1. 在 Game Database 中打开 World > Maps > Forest 并按 Read from scene。从此怪物图鉴和世界地图都会在森林中列出 Moss Golem。

#6. 试一试

  1. 按 Play 进入游戏。
  2. 走到森林，或输入 /map forest。
  3. 输入 /god 以便观看战斗而不会死亡，然后找到这些魔像。

/spawn moss_golem 3 会在任意位置把三只带到你面前（它们不会重生），/killall 20 会清除它们。

#下一步

  • 行为、等阶、技能和所有字段：怪物。
  • 它掉落什么：掉落。
  • 带阶段的首领：首领。
  • 猎杀它的任务：制作任务。
