分步指南

制作技能

本指南制作 Frost Wave：施法者前方的一道冰锥，造成水属性伤害，使每个被击中的敌人减速，并在地面停留两秒。然后把它交给战士。

#1. 创建技能

  1. 在 Game Database 中打开 Combat > Skills，按 + New skill。
  2. 在 General 中设置 Id frost_wave、Display Name Frost Wave、一段 Description 和一个 Icon。
  3. 设置基础项：
字段 值 作用
Max Level 5 玩家可以学习的等级数。
Target Enemy 对敌人施放。
Mana Cost 20，每级 3 每个数值都有一个基础值和每级的变化。
Cooldown 8，每级 -0.5 每升一级都更快。
Cast Time 0.4 生效前的秒数。
Range 8 到目标的米数。

#2. 范围

在 Area 中，将 Shape 设为 Cone，Size 设为 5（每级 0.5），Width 设为 70 度。范围内的每个敌人都会被击中。其他形状有 Circle、Line 和 Single。

在 Zone 中，将 Zone Time 设为 2，Zone Tick 设为 1：冰锥会停留在施放的位置，每秒再次命中。

#3. 它的作用

Effects 卡片列出对每个目标发生的事情。

  1. 按 +，然后 Pick a type > Damage。将 Element 设为 Water，Min 设为 10（每级 4），Max 设为 15（每级 5）。
  2. 再按一次 + 并选择 Apply Status。将 Status 设为 Slowed，Duration 设为 3（每级 0.5）。

Look 卡片设置粒子：Cast Effect 在施法者身上，Area Effect 在地面上，Hit Effect 在每个目标身上。没有 Area Effect 时，范围会以元素颜色的平面轮廓绘制。本指南使用示例中的 Frost Nova 效果。

#4. 交给职业

  1. 打开 Characters > Classes > Warrior。
  2. 打开 Skills，按 + 并选择 Frost Wave。将 Level 设为 8：战士从 8 级起可以学习它。

如果想让其他职业通过训练师或书来学习它，参见在职业之外学习技能。

#5. 试一试

  1. 按 Play，用战士进入游戏。如果等级不到 8，输入 /level 8。
  2. 打开 Skills 窗口（K），学习 Frost Wave 并把它拖到快捷栏。作为 GM，/skill frost_wave 1 会立即教会它。
  3. 找一群史莱姆（/spawn slime 4）并按它的键。当 Settings > Controls 中的 Cast at once 关闭时，会先显示冰锥，点击后施放。

#下一步

  • 所有形状、效果和字段：技能。
  • 增益和减益：状态与增益。
  • 技能的动画：玩家模型上的 Character Animations > Skills。参见玩家模型。
