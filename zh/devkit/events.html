开发套件

事件

套件触发的、你的代码可以监听的每个事件：它在哪里运行，它交给你什么，如何订阅才能在不重新加载域的 Play 中保持有效，以及示例。

#静态事件

套件的大多数事件都是 static：你从自己的一个静态类中订阅一次，就能覆盖每个玩家或怪物。它们分为三类：

  • 服务器事件以 Server 开头，在地图服务器（以及单人模式的主机）上运行。用它们实现规则：奖励、进度、日志。
  • 所有者客户端事件在相关玩家的客户端上运行。用它们驱动界面。
  • 客户端事件在每个能看到该对象的客户端上运行，例如战斗效果。

#正确订阅

套件的项目在不重新加载域的情况下 Play，所以每个类都会在每次 Play 开始时，于一个 SubsystemRegistration 方法中清空自己的静态事件。Unity 没有规定各个 SubsystemRegistration 方法之间的顺序，所以要更晚订阅，在 AfterAssembliesLoaded 中：

public static class LevelRewards
{
    [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterAssembliesLoaded)]
    static void Hook()
    {
        PlayerCharacter.ServerLeveledUp -= OnLevel;
        PlayerCharacter.ServerLeveledUp += OnLevel;
    }

    static void OnLevel(PlayerCharacter player) { /* ... */ }
}

+= 之前的 -= 可以防止方法再次运行时重复订阅。用具名方法订阅，不要用 lambda，这样 -= 才有效。AfterSceneLoad 也可以；它运行得更晚。

完整规则参见不重新加载域的 Play。

#服务器事件

事件 参数 触发时机
PlayerCharacter.ServerSpawned PlayerCharacter 玩家在此地图上生成，在其保存的状态加载之后。
PlayerCharacter.ServerLeveledUp PlayerCharacter 升了一级或多级之后。
PlayerCharacter.ServerExperienceGained PlayerCharacter, long amount 获得了经验，在升级之前。
Monster.ServerKilled Monster, PlayerCharacter killer 一个怪物死亡。killer 是获得这次击杀的玩家，或为 null。
Monster.ServerPhaseStarted Monster, int phase 首领开始了一个阶段；索引对应其数据中的 phases。
PlayerQuests.ServerCompleted PlayerCharacter, QuestData 交付了一个任务。
PlayerTrade.ServerTraded PlayerCharacter a, PlayerCharacter b 一次交易完成。
PlayerForge.ServerUpgraded PlayerCharacter, string itemId, bool success, int level 强化成功（true）或失败（false）；level 是最终等级，装备损坏时为 -1。
PlayerProgress.ServerFlagChanged PlayerCharacter, string key, int value 一个角色标记发生变化。
PlayerProgress.ServerDiscovered PlayerCharacter, string placeId 发现了一张地图或一个区域。
PlayerPvp.ServerDefeated PlayerCharacter killer, PlayerCharacter victim, bool duel 一名玩家在 PvP 或决斗中击败了另一名玩家。
WorldTrigger.ServerFired WorldTrigger, PlayerCharacter 一个世界触发器被触发（对于"所有人"触发器，是触发它的那名玩家）。
GmCommands.ServerUsed PlayerCharacter, string line 一条斜杠命令即将运行。仅服务器程序集。
GmAudit.Recorded GmAuditEntry 记录了一条 GM 审计。仅服务器程序集。
MapInstances.ServerChanged string key, bool made 一个副本地图的副本被创建（true）或被释放。仅服务器程序集。
GameLog.Written GameLogEntry 任何一条游戏日志，在写入时。

#单个对象上的服务器事件

事件 所在对象 触发时机
ServerStatsChanged 一个 PlayerCharacter 属性或状态发生变化：速度、眩晕和定身可能不同了。
ServerChanged 一个 PlayerInventory 背包或装备被发布给所有者。

#所有者客户端事件

事件 参数 触发时机
PlayerCharacter.LocalSpawned PlayerCharacter 本地玩家出现。这是向服务器询问你的功能状态的时机。
PlayerInventory.LocalSpawned PlayerInventory 本地玩家的背包出现。
PlayerInventory.LootDropped、LootRemoved、LootOpened LootDrop、int、int 个人掉落出现、消失，或打开了一个掉落。
PlayerChat.Received ChatView 收到一行聊天。
PlayerMail.Arrived string from, string subject 收到一封信（立即领取的商店信件不算）。
PlayerMail.Opened 无 NPC 打开了邮箱。
PlayerTrade.Asked、Opened、Changed、Closed 名字；名字；双方报价；原因 交易请求和交易窗口更新。
PlayerParty.Invited string name 一个队伍邀请。
PlayerGuild.Invited string from, string guild 一个公会邀请。
PlayerGuild.AllianceInvited string alliance, string guild 一个联盟邀请。
PlayerGuild.BankOpened、PlayerBank.Opened、PlayerMarket.Opened、PlayerForge.Opened bool open NPC 打开（true）或关闭（false）了该窗口。
PlayerGuild.FoundingOpened 无 NPC 打开了公会创建。
PlayerForge.Result string text, bool good 上一次锻造请求的结果。
PlayerPvp.Challenged string name 一个决斗挑战。
PlayerQuests.Shown Npc, QuestData NPC 展示了一个任务。
PlayerInteraction.Talked Npc, string text, int[] options, string[] labels, bool[] open NPC 作出回答：它的文本和屏幕上的选项行。
PlayerInteraction.ShopOpened Npc, ShopOption, int[] stock 打开了一个商店。
PlayerInteraction.StockChanged、BuybackChanged 库存；回购栏位和价格 商店更新。
PlayerInteraction.ErrorReceived string code NPC 请求被拒绝，或某个 NPC 选项返回了文本。

单个对象上的所有者事件：PlayerQuests、PlayerProgress、PlayerInventory、PlayerMail、PlayerParty、PlayerGuild、PlayerBank 及其他系统上的 Changed（它们的同步状态发生变化）；PlayerInventory 上的 ErrorReceived（一个背包请求被拒绝）。

#用于效果的客户端事件

CombatEvents（命名空间 Blunnyn.KitARPG.Net）告诉每个客户端附近的战斗中发生了什么，用于动画、特效、伤害数字和音效：

事件 参数
CombatEvents.Damaged Transform who, int amount, bool critical, DamageElement element, GameData source
CombatEvents.Healed Transform who, int amount, GameData cause
CombatEvents.Announced Transform who, string text, Color color（显示在某人头上的短文本，例如 "+12 XP"）
CombatEvents.Shouted Transform boss, string text（首领阶段台词）
CombatEvents.SkillLanded Transform caster, SkillData skill, Vector3 point
CombatEvents.ActionStarted ActionEvent
CombatEvents.CastStarted、CastStopped Transform, SkillData, float seconds；Transform
CombatEvents.Bounced SkillData, Transform from, Transform to
CombatEvents.ZoneStarted SkillData, Vector3 where, float seconds
FighterStatus.AnyChanged FighterStatus（任何战斗者的状态发生变化）

其他全客户端事件：GameRates.Changed（RatesState，经验或掉落活动开始或结束），ClientOptions.Changed（某个设置发生变化）。

单个对象上的客户端事件：怪物上的 Monster.Acted（CombatAction）和 DeadChanged（bool），玩家上的 DeadChanged。

#网络管理器事件

KitNetworkManager.Instance 触发 ServerStarted、ServerStopping、ServerDisconnecting（NetworkConnectionToClient）、ClientConnected 和 ClientDisconnected。这些是实例事件，所在对象每次 Play 都会重新创建，旧对象会连同订阅者一起消失，所以在 AfterSceneLoad 中订阅，不需要 -=。静态事件仍然先 -=：在检查 Instance 是否为 null 之前订阅它们，这样即使场景中没有网络管理器也会订阅。参见网络消息。

#示例

#每五级给一次奖励

服务器，在 Game 程序集中：

using Blunnyn.KitARPG.Data;
using Blunnyn.KitARPG.Net;
using UnityEngine;

namespace Game
{
    public static class MilestoneRewards
    {
        [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterAssembliesLoaded)]
        static void Hook()
        {
            PlayerCharacter.ServerLeveledUp -= OnLevel;
            PlayerCharacter.ServerLeveledUp += OnLevel;
        }

        static void OnLevel(PlayerCharacter player)
        {
            if (player.level % 5 != 0) return;
            // A flag per milestone, so leveling down and up again (death penalties) pays once.
            string key = $"mygame.milestone_{player.level}";
            IPlayerActor actor = player.Facts;
            if (actor.Flag(key) != 0) return;
            actor.SetFlag(key, 1);
            actor.AddCurrency(null, player.level * 100);
            player.ServerAnnounce($"Level {player.level} milestone!", new Color(1f, 0.85f, 0.3f));
        }
    }
}

#欢迎回来消息

[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterAssembliesLoaded)]
static void Hook()
{
    PlayerCharacter.ServerSpawned -= OnSpawned;
    PlayerCharacter.ServerSpawned += OnSpawned;
}

static void OnSpawned(PlayerCharacter player)
{
    if (player.TryGetComponent(out PlayerChat chat)) chat.Tell($"Welcome back, {player.characterName}.");
}

ServerSpawned 在角色进入的每张地图上都会触发，不仅仅是在登录时。

#连杀，保存在内存中

static readonly Dictionary<PlayerCharacter, int> streaks = new Dictionary<PlayerCharacter, int>();

[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.SubsystemRegistration)]
static void ResetStatics() => streaks.Clear();

[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterAssembliesLoaded)]
static void Hook()
{
    Monster.ServerKilled -= OnKilled;
    Monster.ServerKilled += OnKilled;
    PlayerPvp.ServerDefeated -= OnDefeated;
    PlayerPvp.ServerDefeated += OnDefeated;
}

static void OnKilled(Monster monster, PlayerCharacter killer)
{
    if (killer == null) return;
    streaks.TryGetValue(killer, out int n);
    streaks[killer] = ++n;
    if (n % 10 == 0) killer.ServerAnnounce($"{n} kills!", Color.yellow);
}

static void OnDefeated(PlayerCharacter killer, PlayerCharacter victim, bool duel) => streaks.Remove(victim);

以玩家为键的字典会随着玩家来来去去而增长。在玩家离开时移除条目（KitNetworkManager.ServerDisconnecting），或跳过已销毁的条目（player == null）。

#暴击时播放音效

客户端，在 Game 程序集中。音频片段从你自己的 Resources 文件夹加载：

static AudioClip clip;

[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterAssembliesLoaded)]
static void Hook()
{
    clip = Resources.Load<AudioClip>("MyGame/CriticalHit");
    CombatEvents.Damaged -= OnDamaged;
    CombatEvents.Damaged += OnDamaged;
}

static void OnDamaged(Transform who, int amount, bool critical, DamageElement element, GameData source)
{
    if (critical && clip != null) GameAudio.PlayAt(clip, who.position, SoundChannel.Effects);
}

GameAudio.PlayAt 遵循玩家的音量滑块。

#把稀有掉落发送到 webhook

GameLog.Written 能看到每一行日志，包括值得注意的掉落 item.loot。参见模板中的 Game Log Listener 模板。

#你自己的事件

用同样的方式触发你自己的静态事件，并在 SubsystemRegistration 中清空它们：

public static event Action<PlayerCharacter, MonsterData> ServerTurnedIn;

[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.SubsystemRegistration)]
static void ResetStatics() => ServerTurnedIn = null;

然后 Game.Server 中的代码订阅在 Game 中触发的事件（参见程序集）。

#常见错误

  • **在 SubsystemRegistration 中订阅。**套件可能会在你订阅之后清空该事件。
  • **用无法移除的 lambda 订阅，**而且所在方法可能运行两次。
  • **在客户端代码中使用服务器事件。**它们在在线客户端上永远不会触发。
  • **在 CombatEvents 或 GameLog.Written 中做繁重的工作。**它们触发得很频繁；处理函数要保持简短。
  • **在处理函数中抛出异常。**排在你之后的其他订阅者可能不会运行。GameLog.Written 会捕获异常；大多数其他事件不会。
