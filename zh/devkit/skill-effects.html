技能效果

如何编写你自己的技能效果：SkillEffect 基类、一次施放交给你什么、如何选择目标，以及遵循游戏伤害规则的完整示例。

#技能效果是什么

技能由一个目标、一个范围和一组效果（SkillData.effects）组成。技能命中时，服务器算出它到达了谁，然后对每个目标调用每个效果一次。套件自带的效果有伤害、治疗、属性增益、状态、净化和驱散、击退、复活和召唤。技能还要做的其他任何事情，都是一个新的效果类。

效果是按引用保存的 [Serializable] 类（[SerializeReference, PickType]）。你的类编译后，它会出现在 KitARPG > Game Database > Skills 中每个技能的 Effects 列表的 + 类型菜单里。不需要注册任何东西。

文件放在哪里： Game 程序集。效果是两种构建都会加载的数据（客户端在提示框中显示它们），尽管只有服务器会应用它们。

#基类

SkillEffect 位于 Blunnyn.KitARPG.Data。

成员 作用 默认值
string Summary 显示在技能编辑器效果列表中的短文本，也用作默认的提示行。 类名
bool Harmful true：效果作用于技能到达的敌人。false：作用于施法者和技能到达的盟友。 false
bool OnCaster true：无论技能还到达了谁，效果每次施放只以施法者为目标运行一次。召唤使用这种方式。 false
void Apply(SkillCast cast, IFighter target) 仅限服务器。 每个目标调用一次。必须实现。
void Describe(ItemDescription description, int level, DamageElement fallback) 某个等级下技能卡片上的文字行。在客户端运行。当你的元素为空时，fallback 是要显示的元素。 添加 Summary
void Visit(Action<GameData> visit) 把效果引用的每个资源交给游戏数据库，使它们得到注册。 什么都不做

#如何选择目标

服务器的 SkillRunner 收集技能范围内的敌人和盟友，然后按顺序对每个效果：

  • OnCaster 效果运行一次，target 设为施法者。
  • Harmful 效果在每个到达的敌人身上运行；其他效果在每个到达的盟友身上运行（范围包含施法者时，施法者也算盟友）。
  • 在设置了 Targets Dead 的技能上，只会到达死亡的战斗者；否则只到达活着的。

一个技能在一次施放中可以命中多次：

  • 多段命中动画把一次施放分到多个命中时刻。每次命中在 cast.scale 中带着一部分伤害，只有第一次的 cast.firstHit 为 true。
  • 留在地面上的区域每个 tick 再次命中，每个 tick 都是一次新的施放，firstHit 为 true。
  • 穿透直线在投射物经过时命中每个目标。
  • 弹射跳到下一个目标，cast.scale 按技能的 Bounce Keep 减少。

由此得出两条规则。用 cast.scale 缩放伤害和治疗。把增益、状态和其他一次性效果放在 if (!cast.firstHit) return; 之后，让它们每次施放只生效一次。

#一次施放交给你什么

SkillCast：

字段 是什么
IFighter caster 谁施放的：玩家或怪物。
SkillData skill 该技能。
int level 施放时的等级，包含装备加成。与 LevelValue.At(level) 一起使用。
IReadOnlyList<ElementDamage> weapon 施法者武器的伤害取值，供随武器缩放的效果使用。可能为空或 null。
IFighter target 瞄准的目标，如果技能有目标的话。
Vector3 point 瞄准的位置：目标的位置或地面上的一个点。
float scale 这次命中所带的伤害和治疗比例。只命中一次时为 1。
bool firstHit 在一次施放的后续命中中为 false。
float projectileSpeed 技能投射物的速度（米/秒），没有投射物时为 0。
SkillCast Copy() 一份副本，供稍后才命中的效果使用。

IFighter 是服务器上技能能触及的任何东西：

成员 作用
Transform transform、bool IsDead、int Level 位置、状态、等级。
int Team 玩家为 0，怪物为 1。不同队伍互为敌人。
StatSheet CombatStats 用于攻击和防御的属性和元素。仅限服务器。
void ServerDamage(Hit hit, IFighter source) 造成一次命中。护盾、免疫和死亡都在内部处理。
void ServerHeal(int amount, IFighter source, GameData cause = null) 治疗。数量是最终值：不会再次加上治疗者的属性。cause 决定客户端显示的特效。
bool ServerAddBuff(Buff buff) 添加增益或状态。没有生效时（免疫、已死亡）返回 false。
int ServerRemoveBuffs(Predicate<Buff> match, int max = 0) 移除匹配的增益，从最新的开始；0 表示全部移除。返回移除的数量。
StatusFlags Status 它的状态当前阻止它做什么（眩晕、定身、隐身）。
bool ServerKnock(Vector3 to, float seconds) 推开或拉近它。无法移动时返回 false。
bool ServerRevive(float health, float mana, IFighter by) 以一定比例的生命和法力让它复活。

在服务器上，玩家是 PlayerCharacter，怪物是 Monster（都在 Blunnyn.KitARPG.Net 中）。需要 IFighter 没有的东西（例如生命值）时，转换成它们。

#随等级增长的数值

LevelValue 是 1 级时的数值，加上之后每级增加的量：

public LevelValue amount = new LevelValue(10, 2);   // 10 at rank 1, 12 at rank 2, 14 at rank 3
float value = amount.At(cast.level);
int whole = amount.AtInt(cast.level);               // rounded

检视面板把它显示为 Base Value 和 Per Level。

#命中和伤害公式

Hit 包含 amount、critical、element（造成大部分伤害的元素，决定它的颜色）和 source（技能、武器类型或怪物，决定命中特效）。

要遵循游戏的伤害规则（元素伤害、强度、固定和百分比抗性、暴击），让战斗公式来生成命中：

var rolls = new List<ElementDamage> { new ElementDamage(element, min.At(cast.level), max.At(cast.level)) };
Hit hit = GameInstance.Combat.Attack(cast.caster.CombatStats, rolls, target.CombatStats, cast.scale);
hit.source = cast.skill;
target.ServerDamage(hit, cast.caster);

对于治疗，GameInstance.Combat.Heal(cast.caster.CombatStats, amount) 会加上施法者的治疗属性和治疗加成。如果游戏替换了公式（见公式），你的效果也会随之改变。

#示例：模板

Create > KitARPG > Scripts > Skill Effect 会生成一个固定伤害的效果。它为了保持简短，有意跳过了公式。模板页面展示了它。

#示例：生命偷取

造成伤害，并按造成伤害的一定比例治疗施法者。

using System;
using System.Collections.Generic;
using Blunnyn.KitARPG.Data;
using UnityEngine;

namespace Game
{
    /// <summary>Hits each enemy and heals the caster for a share of the damage.</summary>
    [Serializable]
    public class LifeStealEffect : SkillEffect
    {
        [Tooltip("Empty uses the database's default element.")]
        public DamageElement element;
        public LevelValue min = new LevelValue(8, 3);
        public LevelValue max = new LevelValue(12, 4);
        [Tooltip("Share of the damage dealt that heals the caster, from 0 to 1.")]
        public LevelValue steal = new LevelValue(0.2f, 0.02f);

        public override string Summary => $"Life steal {min.baseValue:0}-{max.baseValue:0}";

        public override bool Harmful => true;

        public override void Apply(SkillCast cast, IFighter target)
        {
            var rolls = new List<ElementDamage> { new ElementDamage(element, min.At(cast.level), max.At(cast.level)) };
            Hit hit = GameInstance.Combat.Attack(cast.caster.CombatStats, rolls, target.CombatStats, cast.scale);
            hit.source = cast.skill;
            target.ServerDamage(hit, cast.caster);

            int healed = Mathf.RoundToInt(hit.amount * Mathf.Clamp01(steal.At(cast.level)));
            if (healed > 0 && !cast.caster.IsDead) cast.caster.ServerHeal(healed, cast.caster, cast.skill);
        }

        public override void Describe(ItemDescription description, int level, DamageElement fallback)
        {
            DamageElement shown = element != null ? element : fallback;
            description.Add($"{min.At(level):0} to {max.At(level):0} {(shown != null ? shown.DisplayName : "Neutral")} damage",
                ItemDescription.Kind.Effect, shown != null ? shown.Icon : null);
            description.Add($"Heals you for {steal.At(level) * 100:0}% of the damage", ItemDescription.Kind.Effect);
        }

        // The element is an asset: hand it over so the database registers it.
        public override void Visit(Action<GameData> visit) => visit(element);
    }
}

治疗使用的是护盾吸收之前的命中数量。如果这在你的游戏中很重要，比较目标受击前后的生命值（读取生命值的方法见下一个示例）。

#示例：斩杀

对生命低于一定比例的目标造成额外伤害。

using System;
using System.Collections.Generic;
using Blunnyn.KitARPG.Data;
using Blunnyn.KitARPG.Net;
using UnityEngine;

namespace Game
{
    /// <summary>Hits harder when the target is low on health.</summary>
    [Serializable]
    public class ExecuteEffect : SkillEffect
    {
        public DamageElement element;
        public LevelValue min = new LevelValue(10, 3);
        public LevelValue max = new LevelValue(14, 4);
        [Tooltip("Below this share of health, from 0 to 1, the bonus applies.")]
        [Range(0, 1)] public float below = 0.3f;
        [Tooltip("Extra damage below the threshold: 1 doubles it.")]
        public LevelValue bonus = new LevelValue(1f, 0.25f);

        public override string Summary => $"Execute below {below * 100:0}%";

        public override bool Harmful => true;

        public override void Apply(SkillCast cast, IFighter target)
        {
            float scale = cast.scale;
            if (HealthShare(target) < below) scale *= 1 + bonus.At(cast.level);
            var rolls = new List<ElementDamage> { new ElementDamage(element, min.At(cast.level), max.At(cast.level)) };
            Hit hit = GameInstance.Combat.Attack(cast.caster.CombatStats, rolls, target.CombatStats, scale);
            hit.source = cast.skill;
            target.ServerDamage(hit, cast.caster);
        }

        static float HealthShare(IFighter fighter)
        {
            if (fighter is PlayerCharacter player) return player.maxHealth > 0 ? (float)player.health / player.maxHealth : 1f;
            if (fighter is Monster monster) return monster.maxHealth > 0 ? (float)monster.health / monster.maxHealth : 1f;
            return 1f;
        }

        public override void Describe(ItemDescription description, int level, DamageElement fallback)
        {
            description.Add($"{min.At(level):0} to {max.At(level):0} damage", ItemDescription.Kind.Effect);
            description.Add($"+{bonus.At(level) * 100:0}% against targets below {below * 100:0}% health", ItemDescription.Kind.Effect);
        }

        public override void Visit(Action<GameData> visit) => visit(element);
    }
}

#示例：返还施法者法力

OnCaster 效果每次施放运行一次，target 为施法者。这个效果每次施放都会返还法力，无论技能是否到达任何人。firstHit 检查让它在多段命中动画中只生效一次；区域每跳都会再返还一次，因为每跳都是一次新的施放。

using System;
using Blunnyn.KitARPG.Data;
using UnityEngine;

namespace Game
{
    [Serializable]
    public class ManaRefundEffect : SkillEffect
    {
        public LevelValue mana = new LevelValue(5, 1);

        public override string Summary => $"Refund {mana.baseValue:0} mana";

        public override bool OnCaster => true;

        public override void Apply(SkillCast cast, IFighter target)
        {
            if (!cast.firstHit) return;
            // Players are item users too, which is how mana is restored from data code.
            if (target is IItemUser user) user.RestoreMana(mana.AtInt(cast.level));
        }

        public override void Describe(ItemDescription description, int level, DamageElement fallback) =>
            description.Add($"Restores {mana.At(level):0} mana when cast", ItemDescription.Kind.Effect);
    }
}

#示例：来自字段的状态

引用资源（状态、怪物、物品）的效果必须把它们交给 Visit。否则，只被你的效果引用的资源可能会被排除在游戏数据库之外，服务器就无法通过 id 找到它。

[Serializable]
public class MarkForDeathEffect : SkillEffect
{
    public StatusData status;
    public LevelValue seconds = new LevelValue(6, 0.5f);

    public override string Summary => status != null ? $"Mark: {status.DisplayName}" : "Mark (none)";

    public override bool Harmful => true;

    public override void Apply(SkillCast cast, IFighter target)
    {
        if (status == null || !cast.firstHit) return;
        target.ServerAddBuff(Buff.Of(status, cast.level, seconds.At(cast.level), cast.caster));
    }

    public override void Visit(Action<GameData> visit) => visit(status);
}

对于大多数状态，套件的 ApplyStatusEffect 已经做到了这一点，并且带有几率和叠加层数。只有规则不同时才自己编写。

#服务器和客户端

运行于
Apply 仅限服务器：在线时为地图服务器，单人模式中为主机。
Describe、Summary 任何显示技能卡片的地方：客户端和编辑器。
字段值 两者：资源在两种构建中是相同的。

客户端通过套件自己的同步看到结果：生命条、伤害数字（CombatEvents.Damaged）、增益图标和技能的特效。你的效果不需要发送任何东西。

#单人模式和 MMO

没有任何变化。在单人模式中，主机运行同样的 Apply。玩家之间的伤害只会在 PvP 或决斗允许的地方生效；这项检查在收集目标时、在你的效果被调用之前进行。

#常见错误

  • 每次命中都施加增益。 多段命中动画和区域会多次调用 Apply。用 cast.firstHit 保护一次性效果。
  • 忽略 cast.scale。 这样三段命中的动画就会造成三次完整伤害。
  • 在 Describe 中使用 UnityEngine.Random。 提示框必须稳定；只在 Apply 中掷随机数。
  • 在字段中保存每次施放的状态。 一个效果实例被该技能的每次施放、每个玩家共享。运行时不要在字段中保存任何东西；使用局部变量，或者在服务器端系统中使用以战斗者为键的字典。
  • 忘记 Visit。 只被你的效果引用的资源可能会从数据库中缺失。
  • 重命名类。 技能按类型名保存你的效果。重命名会留下 "missing type" 条目，由验证器列出。保留原名，或者添加带旧名称的 [UnityEngine.Scripting.APIUpdating.MovedFrom(...)]。
  • 用原始数字调用 ServerHeal 之后又套用一次公式。 ServerHeal 接受的是最终数值。
