开发套件

菜单和设置选项

如何从你自己的代码中，向物品菜单和玩家菜单添加选项行，以及向 Settings 窗口添加选项。

这三者都是客户端的列表，套件在每次 Play 开始时用自己的条目填充它们。你在那之后，从 Game 程序集中的一个静态方法添加你的条目。

#物品菜单

右键点击背包或装备中的物品会打开物品菜单（ItemMenu）。它的选项行来自 ItemMenu.Entries，按顺序排列，开头是套件自己的：背包旁打开的窗口对应的操作（出售、存放、报价）、Equip、Take off、Use、Split、Salvage all、Possible values、View set 和 Destroy。

#ItemMenuEntry

字段 是什么
string label 该行的文本。
Func<ItemMenuTarget, string> labelFor 针对这个物品的文本，当文本会变化时使用。为 null 时使用 label。
Func<ItemMenuTarget, bool> shows 该行是否对这个物品显示。为 null 时总是显示。
Action<ItemMenuTarget> run 选择该行时执行什么。

#ItemMenuTarget

成员 是什么
UIItem view 屏幕上该物品的栏位。
InventoryWindow window 打开菜单的背包窗口。
ItemContainer Container Bag、Equipment 或 Bank。
int Slot 在该容器中的栏位索引。
ItemSlotState State 栏位中的内容：物品 id、数量、强化等级、随机加成。
IItem Item 物品的数据（ItemData 及其子类实现了它）。
bool InBag Container == ItemContainer.Bag。

#示例：与身上穿戴的装备比较

using Blunnyn.KitARPG.Client;
using Blunnyn.KitARPG.Data;
using UnityEngine;

namespace Game
{
    public static class CompareLine
    {
        [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterAssembliesLoaded)]
        static void Register()
        {
            ItemMenu.Entries.Add(new ItemMenuEntry
            {
                label = "Compare",
                shows = t => t.InBag && t.Item is IEquippable,
                run = t => CompareWindow.Instance?.Show((IEquippable)t.Item),
            });
        }
    }
}

（CompareWindow 代表你自己的一个窗口。）

#示例：在指定位置插入一行

Entries 是一个普通的 List<ItemMenuEntry>。用插入的方式把一行放在套件的 Destroy 之前：

int destroy = ItemMenu.Entries.FindIndex(e => e.label == "Destroy");
ItemMenu.Entries.Insert(destroy >= 0 ? destroy : ItemMenu.Entries.Count, myEntry);

#改变游戏的选项行

菜单在客户端上运行。对游戏产生影响的选项行要通过玩家系统命令或网络消息向服务器请求，服务器会再次检查一切：该栏位确实装着那个物品，该玩家确实可以这样做。套件自己的选项行调用 PlayerInventory.Local.Equip(slot)、Use(slot) 等，这些都是请求。参见玩家系统和网络消息。

#玩家菜单

在俯视角模式中右键点击另一名玩家，或右键点击聊天中的名字，会打开玩家菜单（PlayerMenu）。它的选项行来自 PlayerMenu.Entries：Whisper、Trade、Invite to party、Make leader、Remove from party、Add friend、Invite to guild、Duel、Report 和 Give up the duel。套件的每一行在其模块关闭时都会隐藏自己。

#PlayerMenuEntry

字段 是什么
string label 该行的文本。
Func<PlayerMenuTarget, bool> shows 该行是否对这名玩家显示。为 null 时总是显示。
Action<PlayerMenuTarget> run 选择该行时执行什么。

#PlayerMenuTarget

字段 是什么
string name 角色的名字。
PlayerCharacter character 屏幕上的玩家；如果只是在聊天中提到了名字，则为 null。

#示例：查看玩家的装备

[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterAssembliesLoaded)]
static void Register()
{
    PlayerMenu.Entries.Add(new PlayerMenuEntry
    {
        label = "Inspect",
        shows = t => t.character != null,
        run = t => InspectWindow.Instance?.Show(t.character),
    });
}

穿戴的装备会同步给每个能看到该玩家的人（PlayerCharacter.gear，按装备位置排列的物品 id），所以查看窗口可以在客户端上读取它。背包是所有者私有的。

#示例：为你的某个模块添加一行

PlayerMenu.Entries.Add(new PlayerMenuEntry
{
    label = "Challenge to a race",
    shows = t => t.character != null && RaceRules.Enabled,
    run = t => Races.Ask(t.name),
});

Races.Ask 按名字发送请求；服务器在自己的地图上按名字查找该玩家（PlayerCharacter.ServerFind(name)），并检查距离和规则。

#Settings 窗口

Settings 窗口（按 Esc 或点击齿轮，然后选 Settings，标题画面上也有）有这些标签页：Graphics、Audio、Interface，加上来自俯视角模式的 Controls，以及你添加的任何页面。每一行都是 ClientOptions.All 中的一个 GameOption。值保存在玩家的电脑上，永远不会到达服务器。

#选项的种类

所有选项都有这些字段：

字段 是什么
string page 标签页：ClientOptions.Graphics、ClientOptions.Audio、ClientOptions.Interface，或一个新名字，它会成为末尾的一个新标签页。
string label 该行的文本。
string hint 简短的说明。
Func<bool> available 返回否时隐藏该行，用于某个平台不具备的选项。
Action reset 把值恢复原状，供标签页的 Reset 按钮使用。
种类 额外字段
ToggleOption Func<bool> get、Action<bool> set
SliderOption int min（0）、int max（100）、int step（5）、Func<int> get、Action<int> set、Func<int, string> format（默认显示 "50%"）
ChoiceOption Func<string[]> choices、Func<int> get、Action<int> set（索引）

ClientOptions.Add(option) 添加一个选项。改动在玩家操作时立即生效；套件在窗口关闭时保存自己的值，你的 set 负责保存你的值。

#示例：模板

using Blunnyn.KitARPG.Client;
using UnityEngine;

namespace Game
{
    /// <summary>
    /// An option of your own in the Settings window. Kept on the player's computer and never sent
    /// anywhere, so use it for how the game looks and sounds, not for anything the server decides.
    /// </summary>
    public static class MySettings
    {
        const string Key = "MyGame.ShowHints";

        public static bool ShowHints
        {
            get => PlayerPrefs.GetInt(Key, 1) == 1;
            set => PlayerPrefs.SetInt(Key, value ? 1 : 0);
        }

        [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterAssembliesLoaded)]
        static void Register()
        {
            ClientOptions.Add(new ToggleOption
            {
                // A page name the kit doesn't have becomes a new tab.
                page = ClientOptions.Interface,
                label = "Show hints",
                hint = "Short tips the first time something new shows up.",
                get = () => ShowHints,
                set = v => ShowHints = v,
                reset = () => ShowHints = true,
            });
        }
    }
}

#示例：在你自己的页面上添加滑块和选择项

[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterAssembliesLoaded)]
static void Register()
{
    ClientOptions.Add(new SliderOption
    {
        page = "Gameplay",
        label = "Screen shake",
        min = 0, max = 100, step = 10,
        get = () => PlayerPrefs.GetInt("MyGame.Shake", 50),
        set = v => PlayerPrefs.SetInt("MyGame.Shake", v),
        reset = () => PlayerPrefs.DeleteKey("MyGame.Shake"),
    });

    ClientOptions.Add(new ChoiceOption
    {
        page = "Gameplay",
        label = "Damage numbers",
        choices = () => new[] { "All", "Mine only", "None" },
        get = () => PlayerPrefs.GetInt("MyGame.Numbers", 0),
        set = i => PlayerPrefs.SetInt("MyGame.Numbers", i),
        reset = () => PlayerPrefs.DeleteKey("MyGame.Numbers"),
    });
}

滑块按整步移动。给每个选项一个 reset，这样标签页的 Reset 按钮也能覆盖它。

#设置的用途

设置用于游戏在那台电脑上的画面、声音和操作手感。任何影响其他玩家或规则的东西（PvP 开关、掉落分享）都属于服务器，应放在带命令的玩家系统中，而不是 PlayerPrefs。对于你自己的按键，读取前先检查 GameInstance.KeysOn：在 Touch 输入布局下，游戏的按键是关闭的。

#何时注册

套件在每次 Play 开始时，于 SubsystemRegistration 中用自己的选项行重建 ItemMenu.Entries 和 PlayerMenu.Entries，并清空 ClientOptions.All。在 AfterAssembliesLoaded 或更晚的时机注册你的条目。Settings 窗口在打开时读取列表，所以在那之前任何时候添加的选项都会显示出来。

地图服务器以批处理模式运行，从不打开这些菜单；在那里注册不会有害处。

#常见错误

  • **在 SubsystemRegistration 中注册。**套件可能在你之后重置列表。
  • **在 run 中直接做改动。**菜单是客户端代码；要向服务器请求。
  • **没有 reset。**标签页的 Reset 按钮会让你的选项保持原样。
  • **把游戏规则放在 PlayerPrefs 中。**玩家可以修改它们。
